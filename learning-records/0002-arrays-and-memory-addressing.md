# Arrays, Contiguous Memory, and Address Calculations

Comprehensive coverage of arrays established across physical silicon layout and algorithmic design. Key insights include:

- Address calculation derivations for 1D, 2D Row-Major Order (RMO), and 2D Column-Major Order (CMO).
- Structural variants: Static, Dynamic, Multidimensional, Jagged/Ragged, Circular (modulo arithmetic), Sparse (Coordinate Triplet representation), and Parallel arrays.
- Hardware cache locality (64-byte streaming) and geometric expansion trade-offs ($1.5\times$ vs $2.0\times$ for memory recycling).
