# Learning Roadmap — Table of Contents

A structured journey from foundational computer science and systems engineering to scalable distributed architectures and production AI agents.

## Modules

### Computer Basics
Foundational mindset, computer science fundamentals from bits to networks, and a gentle intro to programming.

### Developer Tools
Daily local workflow: terminal and shells (Linux Bash, PowerShell), JS package managers (npm, pnpm, bun), Python tooling (pip, uv), and version control with Git.

### Learn Python
Python-first programming: syntax, control flow, functions, data structures (arrays, linked lists, trees, graphs), algorithms (sorting, search, Big-O), and programming paradigms.

### Operating Systems
How operating systems work: kernels, processes and threads, virtual memory, file systems, and system calls.

### Computer Networking
The OSI 7-layer and TCP/IP models, routing, switching, subnetting, DNS resolution, HTTP/HTTPS, WebSockets, TLS/SSL, and network security.

### Databases, SQL & Data-Intensive Systems
Relational data modeling, SQL optimization, B-Tree and LSM indexing, ACID transactions, isolation levels, NoSQL datastores, replication, and caching.

### System Design & Backend Architecture
Scalable distributed systems, microservices vs modular monoliths, load balancing, message queues (Kafka, RabbitMQ), caching strategies, rate limiting, and CAP theorem.

### DevOps, CI/CD & Performance
Containerization with Docker, container orchestration via Kubernetes, automated CI/CD pipelines, observability (metrics, logs, traces), and profiling.

### AI / ML Foundations
Math for machine learning (linear algebra, multivariate calculus, probability & statistics), classical ML algorithms, loss functions, backpropagation, and neural networks.

### AI Agents (Loops, Graphs, Swarms)
Autonomous agent loops (ReAct), function and tool calling, memory management, stateful graph workflows (LangGraph), and multi-agent coordination.

### Projects
Guided, hands-on builds that combine modules into real systems you can ship and show.

### Cheatsheets
Condensed one-page references that compress a whole track into tables and memory anchors you can revise at a glance. Browse [all cheat sheets](/docs/cheatsheets).

### Books Library
A curated collection of seminal engineering books, influential papers, and must-read references for deep software and AI mastery. See [the full shelf](/docs/books).
