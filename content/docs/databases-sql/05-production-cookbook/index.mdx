Welcome to **Stage 5: Production Cookbook** — where theory becomes uptime.

Stages 1–4 gave you the model, the machinery, the correctness guarantees, and the distribution tools. This final stage is the field guide: how to design schemas you can live with, migrate them without downtime, make queries fast with caches and pools, and diagnose the 3 a.m. incident when the database is on fire.

---

## Pedagogical Philosophy

<Callout type="info" title="Most Outages Are Boring and Predictable">
The database incidents that take down production are rarely exotic. They are a missing index, an unbounded query, a connection pool one size too small, a migration that took an `ACCESS EXCLUSIVE` lock, or autovacuum that fell too far behind. This stage is a **checklist culture**: the disciplines that prevent the boring failures and the runbooks that resolve them fast.
</Callout>

By the end of this stage you will be able to:

- Normalize to 3NF/BCNF, then **denormalize deliberately** where reads demand it.
- Design zero-downtime migrations (expand → migrate → contract).
- Eliminate the N+1 query and paginate without `OFFSET` performance cliffs.
- Apply the right caching pattern and defend against cache stampedes.
- Size and configure a connection pool correctly.
- Run the diagnostic queries that find slow queries, locks, bloat, and replication lag.
