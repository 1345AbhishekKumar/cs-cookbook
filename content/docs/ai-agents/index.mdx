## Sub-modules

- **[Agentic AI (Stanford CME295)](/docs/ai-agents/agentic-ai)** — the complete Stanford course on Transformers & Large Language Models: Scaled Dot-Product Attention, RoPE, Sparse MoE, petabyte pre-training & FlashAttention, RLHF & DPO alignment, test-time reasoning (GRPO & DeepSeek-R1), Model Context Protocol (MCP), ReAct agent loops, and evaluation benchmarks.
- **[Self-Improving AI Agents (Stanford CS329A)](/docs/ai-agents/self-improving-ai-agents)** — the complete Stanford course on test-time compute scaling, robust verification (ORMs/PRMs), environment grounding (ReAct/RLEF/Reflexion), planning (LATS/MCTS), train-time RL scaling (STaR/GRPO/DAPO), deep research, and long-horizon evaluations.
- **[Agent Engineer](/docs/ai-agents/agent-engineer)** — the full lesson track: tool calling, memory, planning, multi-agent systems, MCP and A2A, harnesses, loops, and governed state graphs.
- **[Self-Evolving Agents](/docs/ai-agents/self-evolving-agents)** — agents that improve themselves: reflection loops, memory and skill accumulation, eval-driven hill-climbing, and safe oversight.
- **[LangChain](/docs/ai-agents/langchain)** — the integration library: prompts, models, output parsers, LCEL chains, tools, and RAG.
- **[LangGraph](/docs/ai-agents/langgraph)** — stateful graph orchestration: typed state, nodes, conditional edges, checkpointers, human-in-the-loop, and multi-agent graphs.
- **[Model Context Protocol (MCP)](/docs/ai-agents/mcp)** — the hands-on protocol track: build FastMCP servers, connect Python clients over stdio/SSE/Streamable HTTP, integrate OpenAI, containerize, manage lifecycle, and ship a real transcript server.
- **[Books Info](/docs/ai-agents/books-info)** — fourteen engineering classics turned into operational rule sets your agent can load, in three depths each.

## Lessons

This module is organized into specialized curriculum sub-modules above. Start with **[Agentic AI (Stanford CME295)](/docs/ai-agents/agentic-ai)** for core architectural and agent foundations, or dive into **[Self-Improving AI Agents](/docs/ai-agents/self-improving-ai-agents)** and **[Agent Engineer](/docs/ai-agents/agent-engineer)** for autonomous workflows.
