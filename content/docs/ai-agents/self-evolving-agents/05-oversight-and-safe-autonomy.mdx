> **Learning goals:** Name the minimum oversight controls; track comprehension, intent, and unverified-code debt; define a kill switch.
> **Prerequisites:** [Eval-driven hill-climbing](/docs/ai-agents/self-evolving-agents/04-eval-driven-hill-climbing).

## Minimum viable oversight

| Control | Implementation | Answers |
|---|---|---|
| Approval gates | Human confirms destructive / irreversible actions | "Who said yes?" |
| Audit trail | Append-only event log per run | "What did it do, when?" |
| Transparency | Citations, diffs, confidence flags | "Why does it believe that?" |
| Accountability | Named human owner per worker | "Who is responsible?" |
| Kill switch | One command stops all workers | "How do we stop it now?" |

Oversight is what makes autonomy **deployable**. See [Guardrails](/docs/ai-agents/agent-engineer/10-guardrails-and-safety) for mechanics.

## The three debts

| Debt | Symptom | Payment |
|---|---|---|
| Comprehension | "It works, do not touch it" | Document critical paths weekly |
| Intent | "Why is it like this?" | Decision records with every harness edit |
| Unverified code | Silent regressions | Evals + reviews + pre-code contracts |

**Cognitive surrender** — accepting fluent output because it sounds right — is paid with verification artifacts (tests, sources, diffs), not vigilance.

## Kill-switch checklist

- Single command halts schedulers, workers, and hill-climbing proposals.
- State checkpoints survive the halt so work resumes cleanly.
- Last shipped harness version is one revert away.

## Key takeaways

1. Gates + audit + owner + kill switch before autonomy scales.
2. Pay the three debts on a schedule or they compound silently.
3. Humans own the merge button until the loop has a long green record.
