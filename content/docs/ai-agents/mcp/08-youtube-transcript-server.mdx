> **Learning goals:** Package a server so `uv run` resolves everything; wrap a service in a tool; connect the server to Claude Desktop and Claude Code.
> **Prerequisites:** [Lifecycle management](/docs/ai-agents/mcp/07-lifecycle-management), Python 3.12+, and [`uv`](https://docs.astral.sh/uv/).

## Why this example

Not every MCP server is enterprise infrastructure. A **small dev automation** — fetch a YouTube transcript so you can summarise it without opening a browser tab — is a perfect fit for a local stdio server. It needs no deployment and no UI; the assistant in your IDE or desktop calls it directly.

```mermaid
flowchart LR
  U["You ask Claude"] --> T["get_transcript tool"]
  T --> S["YouTubeTranscriptService"]
  S --> Y["youtube-transcript-api"]
  Y --> R["Plain-text transcript"]
```

## Step 1 — a uv script header

Putting the dependencies at the top of `server.py` lets `uv run server.py` create an isolated environment automatically:

```python
# /// script
# requires-python = ">=3.12"
# dependencies = [
#     "mcp[cli]>=1.12.3",
#     "pydantic>=2.11.7",
#     "python-dotenv>=1.1.1",
#     "requests>=2.32.4",
#     "youtube-transcript-api>=1.2.2",
# ]
# ///
```

## Step 2 — the server and its tool

Keep tool functions thin: validate nothing by hand, delegate to a service, and return errors as text so the model can recover.

```python
from mcp.server.fastmcp import FastMCP
from src.service import YouTubeTranscriptService

mcp = FastMCP(name="YouTube", stateless_http=True)

_service = YouTubeTranscriptService(use_proxy=True)


@mcp.tool()
def get_transcript(video_url_or_id: str) -> str:
    """Get transcript as plain text."""
    try:
        return _service.get_transcript_text(video_url_or_id)
    except Exception as e:
        return f"Error: {str(e)}"


if __name__ == "__main__":
    mcp.run(transport="stdio")
```

The service layer accepts a URL or a bare ID and normalises it:

```python
import re


def extract_video_id(url_or_id: str) -> str:
    """Extract video ID from URL or return as-is if already an ID."""
    patterns = [
        r"(?:v=|\/)([0-9A-Za-z_-]{11}).*",
        r"(?:embed\/)([0-9A-Za-z_-]{11})",
        r"([0-9A-Za-z_-]{11})$",
    ]
    for pattern in patterns:
        match = re.search(pattern, url_or_id)
        if match:
            return match.group(1)
    return url_or_id
```

## Step 3 — run the dev server

```bash
mcp dev server.py
```

Open the MCP Inspector: **Connect → Tools → List Tools → get_transcript → insert a URL → Run Tool**.

## Step 4 — optional proxy support

The transcript service can route through a proxy if you set these environment variables (otherwise it connects directly):

```bash
WEBSHARE_USERNAME=<your_username>
WEBSHARE_PASSWORD=<your_password>
```

## Step 5 — connect from Claude Desktop

Edit `claude_desktop_config.json` (Settings → Developer → Edit Config) and add an entry pointing at this folder:

```json
{
  "mcpServers": {
    "YouTube": {
      "command": "uv",
      "args": [
        "--directory",
        "<ABSOLUTE_PATH_TO_THIS_DIR>",
        "run",
        "server.py"
      ]
    }
  }
}
```

Restart Claude Desktop and `get_transcript` appears in the tools list.

## Step 6 — connect from Claude Code

```bash
claude mcp add --transport stdio YouTube -- \
  uv --directory "<ABSOLUTE_PATH_TO_THIS_DIR>" run server.py

claude mcp tools YouTube
```

## The workflow this enables

1. A new video drops and you have no time to watch it.
2. In Claude, call `get_transcript` with the URL.
3. Paste the transcript to your model for a quick summary.
4. Decide whether it is worth a full watch — without opening a browser tab.

The pattern generalises to countless "small but effective" developer automations.

## Key takeaways

1. A uv script header makes a single-file server portable.
2. Keep tools thin and services testable.
3. stdio is ideal for personal, local automations — no deployment required.
4. The same server connects to Claude Desktop and Claude Code unchanged.
