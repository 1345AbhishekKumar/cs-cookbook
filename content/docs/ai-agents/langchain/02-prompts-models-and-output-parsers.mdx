> **Learning goals:** Build chat prompt templates; pick a model tier; parse outputs into JSON / pydantic reliably.
> **Prerequisites:** [What is LangChain?](/docs/ai-agents/langchain/01-what-is-langchain).

## Prompt templates

```python
from langchain_core.prompts import ChatPromptTemplate

prompt = ChatPromptTemplate.from_messages([
  ("system", "You are a release-notes writer. Cite sources. Say UNKNOWN when unsure."),
  ("human", "Summarise these commits for {audience}:\n{commits}"),
])
```

One template per file, versioned. Never inline long prompts in code.

## Models: two tiers is enough

| Tier | Use for | Example |
|---|---|---|
| Frontier (Pro / Opus-class) | Planning, hard reasoning, final answers | Draft + judge |
| Flash / mini | Extraction, classification, reformat | Parse, label, route |

Route by difficulty, not by habit. Most token spend should be cheap-tier.

## Output parsers

```python
from langchain_core.output_parsers import JsonOutputParser
from pydantic import BaseModel

class Brief(BaseModel):
  title: str
  risks: list[str]
  confidence: float

parser = JsonOutputParser(pydantic_object=Brief)
# prompt must include: parser.get_format_instructions()
```

Parsers fail when the prompt never shows the schema. Always inject format instructions and retry once with the validation error attached.

## Key takeaways

1. Templates + model + parser = one typed unit you can test.
2. Two model tiers control cost without hurting quality.
3. Schema-first prompts make structured output reliable.
