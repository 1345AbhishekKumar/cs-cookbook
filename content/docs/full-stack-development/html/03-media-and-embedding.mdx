Modern web applications are rich with multimedia. Understanding how to embed and optimize images, audio, video, and third-party content is crucial for performance, responsiveness, and accessibility.

---

## 1. Images (`<img>`) & Performance Optimization

The `<img>` tag embeds bitmap or vector graphics into an HTML document:

```html
<img
  src="/images/hero-banner.webp"
  alt="Illustration of a cloud infrastructure dashboard with real-time metrics"
  width="1200"
  height="630"
  loading="lazy"
  decoding="async"
/>
```

### Essential Image Attributes:
- **`alt` (Mandatory)**: Describes the image content for screen reader users and displays when the image fails to load.
- **`width` & `height`**: Defining aspect ratios in HTML allows the browser to reserve layout space *before* the image downloads, eliminating **Cumulative Layout Shift (CLS)**.
- **`loading="lazy"`**: Native browser lazy loading. Defers downloading offscreen images until the user scrolls near them.
- **`decoding="async"`**: Allows the browser to decode image bytes off the main thread, keeping the UI responsive.

<Callout type="warn" title="Decorative Images">
If an image is purely decorative (like a background pattern or decorative divider), provide an empty alt attribute (`alt=""`). This informs screen readers to skip the element entirely rather than reciting raw image filenames.
</Callout>

## 2. Responsive Images: `<picture>` & `srcset`

Modern responsive designs must serve different image resolutions to mobile devices vs high-DPI desktop displays to conserve bandwidth.

### Approach A: `srcset` and `sizes` (Resolution Switching)
When you have the *same image* in multiple resolutions:

```html
<img
  src="/images/profile-400.jpg"
  srcset="
    /images/profile-400.jpg 400w,
    /images/profile-800.jpg 800w,
    /images/profile-1200.jpg 1200w
  "
  sizes="(max-width: 600px) 100vw, 50vw"
  alt="Software engineer working at a desk"
  loading="lazy"
/>
```

### Approach B: `<picture>` Element (Art Direction & Next-Gen Formats)
Use `<picture>` when you want to serve **AVIF/WebP** with fallback to PNG/JPEG, or change the image crop on smaller screens:

```html
<picture>
  <!-- Next-Gen AVIF format for supporting browsers -->
  <source type="image/avif" srcset="/images/banner.avif" />
  
  <!-- Next-Gen WebP format -->
  <source type="image/webp" srcset="/images/banner.webp" />

  <!-- Mobile screen crop (Art Direction) -->
  <source media="(max-width: 768px)" srcset="/images/banner-mobile.jpg" />

  <!-- Default Fallback Image -->
  <img 
    src="/images/banner-default.jpg" 
    alt="Developers collaborating in a conference room" 
    width="1200" 
    height="600" 
    loading="lazy" 
  />
</picture>
```

## 3. Video (`<video>`)

HTML5 provides native video playback without Flash or third-party plugins:

```html
<video 
  controls 
  width="800" 
  height="450" 
  poster="/images/video-thumbnail.jpg" 
  preload="metadata"
>
  <!-- Modern VP9/AV1 WebM format -->
  <source src="/media/tutorial.webm" type="video/webm" />
  
  <!-- Widely compatible H.264 MP4 format -->
  <source src="/media/tutorial.mp4" type="video/mp4" />

  <!-- Captions and Subtitles for Accessibility -->
  <track 
    src="/media/subtitles-en.vtt" 
    kind="subtitles" 
    srclang="en" 
    label="English" 
    default 
  />

  <p>Your browser does not support HTML5 video. <a href="/media/tutorial.mp4">Download the video here</a>.</p>
</video>
```

### Key Attributes:
- **`controls`**: Displays native playback controls (play/pause, volume, seek bar, fullscreen).
- **`poster`**: Image displayed while the video is downloading or until the user hits play.
- **`preload="metadata"`**: Loads only duration and dimensions initially, saving user bandwidth.
- **`autoplay muted loop playsinline`**: Standard combination required for background video loops (modern browsers block autoplay with sound).

## 4. Audio (`<audio>`)

Embed podcasts, voice memos, or sound effects:

```html
<audio controls preload="none">
  <source src="/audio/podcast-episode-1.mp3" type="audio/mpeg" />
  <source src="/audio/podcast-episode-1.ogg" type="audio/ogg" />
  <p>Your browser does not support the audio element.</p>
</audio>
```

## 5. Embedding External Content (`<iframe>`)

The `<iframe>` (Inline Frame) element embeds another HTML document inside the current page (e.g. YouTube video embeds, Google Maps, code sandboxes).

```html
<iframe
  src="https://www.youtube-nocookie.com/embed/dQw4w9WgXcQ"
  title="Introduction to Full-Stack Web Development"
  width="560"
  height="315"
  allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture"
  allowfullscreen
  loading="lazy"
  sandbox="allow-scripts allow-same-origin allow-presentation"
></iframe>
```

### Security & Accessibility Rules for Iframes:
1. **Always include a descriptive `title` attribute**: Screen readers announce the `title` so visually impaired users know what content is framed.
2. **Use `sandbox`**: Restricts scripts, popups, and form submissions from untrusted third-party framed origins.
3. **Use `loading="lazy"`**: Prevents heavy iframes from blocking the initial page load.
