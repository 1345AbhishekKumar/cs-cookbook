## 1. Categorized Element Reference

    | `<em>` | Stress emphasis altering spoken inflection (italic). |

    | `<code>` | Inline computer code fragment. |
    | `<pre>` | Pre-formatted text preserving spaces and line breaks. |
    | `<blockquote>` | Quoted block from external source. |

    | `<time>` | Machine-readable date/time representation (`datetime="YYYY-MM-DD"`). |

## 2. Global Attributes Reference

Global attributes are valid on **all** HTML elements:

| Attribute | Purpose | Example |
| :--- | :--- | :--- |
| `id` | Unique document-wide identifier for styling, fragment links, and JS targeting. | `id="user-profile"` |
| `class` | Space-separated list of CSS styling and JS query classes. | `class="card card-active"` |
| `style` | Inline CSS declarations (avoid in production; prefer external styles). | `style="display: none;"` |
| `title` | Informational tooltip displayed on mouse hover. | `title="Click to expand"` |
| `data-*` | Custom data attributes accessible via DOM dataset (`el.dataset.userID`). | `data-user-id="9823"` |
| `hidden` | Boolean indicating the element is not currently relevant (browser applies `display: none`). | `<div hidden>` |
| `tabindex` | Controls focusability (`0` = sequential, `-1` = programmatic only). | `tabindex="0"` |
| `lang` | Language tag for the element's content. | `lang="es"` |
| `dir` | Text directionality (`ltr` = left-to-right, `rtl` = right-to-left). | `dir="rtl"` |
| `contenteditable` | Boolean allowing user to edit inner text content directly in browser. | `contenteditable="true"` |
| `draggable` | Defines whether element can be dragged with native Drag and Drop API. | `draggable="true"` |

## 3. Deprecated & Obsolete Tags (Never Use in Modern Code)

Modern web development strictly separates content semantics (HTML) from visual presentation (CSS). The following tags are obsolete and must **never** be used:

| Obsolete Tag | Why It Was Deprecated | Modern Replacement |
| :--- | :--- | :--- |
| `<center>` | Pure presentation styling | Use CSS `text-align: center` or Flexbox/Grid `justify-center` |
| `<font>` | Hardcoded typeface and color | Use CSS `font-family`, `font-size`, `color` |
| `<marquee>` | Distracting auto-scrolling text; terrible accessibility | Use CSS animations or transitions |
| `<blink>` | Flashing text; triggers seizures and fails WCAG compliance | Avoid entirely |
| `<frameset>` / `<frame>` | Fragile multi-window framing | Use standard layout CSS or targeted `<iframe>` |
| `<big>` | Visual sizing tag | Use CSS `font-size: 1.25rem` |
| `<s>` / `<strike>` | Legacy strikethrough | Use `<del>` (deleted text) or `<s aria-hidden="true">` with CSS |
| `<b>` vs `<strong>` | `<b>` is purely visual bold; `<strong>` carries semantic importance | Prefer `<strong>` for semantic meaning; use CSS for stylistic weight |
| `<i>` vs `<em>` | `<i>` is purely visual italic; `<em>` alters spoken stress emphasis | Prefer `<em>` for emphasized speech |
