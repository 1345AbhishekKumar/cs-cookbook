HTML tables are specifically designed to represent **tabular data** — information organized into rows and columns with two-dimensional relationships (e.g. financial ledgers, product comparisons, system metrics, schedules).

<Callout type="error" title="Never Use Tables for Layout">
In the 1990s, developers used tables to lay out entire web pages. Today, using tables for layout destroys accessibility, violates semantic standards, and causes responsive rendering bugs. Always use modern CSS (Flexbox and Grid) for page layouts.
</Callout>

---

## 1. Anatomy of a Semantic Table

A robust, accessible table consists of a clear hierarchy:

```
┌────────────────────────────────────────────────────────┐
│                        <table>                         │
│  <caption> Table Title & Description </caption>        │
│  <thead>                                               │
│    <tr> <th scope="col">...</th> </tr>                 │
│  </thead>                                              │
│  <tbody>                                               │
│    <tr> <th scope="row">...</th> <td>...</td> </tr>   │
│  </tbody>                                              │
│  <tfoot>                                               │
│    <tr> <td>Totals or summaries</td> </tr>             │
│  </tfoot>                                              │
└────────────────────────────────────────────────────────┘
```

### Core Table Elements:

| Tag | Purpose |
| :--- | :--- |
| `<table>` | The root container for all tabular content. |
| `<caption>` | A descriptive title placed immediately after `<table>`. Read first by screen readers. |
| `<thead>` | Groups the column header rows. |
| `<tbody>` | Groups the primary data rows. |
| `<tfoot>` | Groups footer summary or aggregate calculation rows. |
| `<tr>` | Table Row containing header cells (`<th>`) or data cells (`<td>`). |
| `<th>` | Table Header cell (bold and centered by default, announces as header in assistive tech). |
| `<td>` | Table Data cell containing values. |

## 2. Table Accessibility & The `scope` Attribute

Screen readers do not see tables as visual grids. They announce cells as: *"Column: Plan, Row: Enterprise, Value: $99/mo"*.

To allow assistive tech to connect data cells with the correct headers, declare the `scope` attribute on every `<th>`:

- `scope="col"`: The header applies to all cells in that vertical column.
- `scope="row"`: The header applies to all cells in that horizontal row.
- `scope="colgroup"` / `scope="rowgroup"`: Used for complex multi-level nested headers.

```html
<table>
  <caption>Cloud Database Pricing Comparison</caption>
  <thead>
    <tr>
      <th scope="col">Tier</th>
      <th scope="col">RAM</th>
      <th scope="col">Storage</th>
      <th scope="col">Monthly Cost</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">Developer</th>
      <td>2 GB</td>
      <td>20 GB SSD</td>
      <td>$15</td>
    </tr>
    <tr>
      <th scope="row">Production</th>
      <td>16 GB</td>
      <td>250 GB NVMe</td>
      <td>$120</td>
    </tr>
    <tr>
      <th scope="row">Enterprise</th>
      <td>64 GB</td>
      <td>1 TB NVMe</td>
      <td>$450</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <td colspan="4">* Custom enterprise SLAs available upon request.</td>
    </tr>
  </tfoot>
</table>
```

## 3. Spanning Rows & Columns (`colspan` & `rowspan`)

When a cell needs to stretch across multiple columns or rows, use `colspan` and `rowspan`:

### Example: Multi-Column and Multi-Row Schedule

```html
<table>
  <caption>Engineering Team On-Call Rotation</caption>
  <thead>
    <tr>
      <th scope="col">Shift</th>
      <th scope="col">Primary Responder</th>
      <th scope="col">Secondary Escalation</th>
      <th scope="col">Status</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">Morning (08:00 - 16:00)</th>
      <td>Sarah Connor</td>
      <td>John Doe</td>
      <!-- Rowspan: Stretches 2 rows down -->
      <td rowspan="2">Active</td>
    </tr>
    <tr>
      <th scope="row">Evening (16:00 - 00:00)</th>
      <td>Marcus Wright</td>
      <td>Kyle Reese</td>
    </tr>
    <tr>
      <th scope="row">Night (00:00 - 08:00)</th>
      <!-- Colspan: Stretches across 2 columns -->
      <td colspan="2">Automated Incident Alert Bot (Paging Duty)</td>
      <td>Standby</td>
    </tr>
  </tbody>
</table>
```

## 4. Making Tables Responsively Accessible

On mobile viewports, wide tables can break page layouts. The standard full-stack solution is to wrap the table in a container with horizontal overflow scrolling and keyboard focusability:

```html
<!-- Accessible scrollable wrapper -->
<div 
  class="table-responsive" 
  tabindex="0" 
  role="region" 
  aria-label="Cloud Database Pricing Comparison"
>
  <table>
    <!-- Table content -->
  </table>
</div>
```

```css
/* Accompanying CSS */
.table-responsive {
  overflow-x: auto;
  max-width: 100%;
}
```

<Callout type="tip" title="Why tabindex='0' on Table Wrappers?">
Adding `tabindex="0"` allows keyboard-only users to navigate into the scrollable container and scroll horizontally with the arrow keys. The `role="region"` and `aria-label` announce the purpose of the scrollable region to screen readers.
</Callout>
