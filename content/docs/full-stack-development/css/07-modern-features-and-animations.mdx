Modern CSS includes powerful features previously only possible with JavaScript or preprocessors like Sass. Today, browsers natively support relational parent selection, nested stylesheets, and hardware-accelerated animations.

---

## 1. The `:has()` Relational Selector

Known historically as the "parent selector", `:has()` lets an element style itself or siblings based on what descendants it contains or their dynamic states:

```css
/* 1. Style a card if it contains a featured badge */
.card:has(.badge-featured) {
  border: 2px solid oklch(0.65 0.24 260);
  background: oklch(0.98 0.02 260);
}

/* 2. Style a form group when its internal input is invalid */
.field-group:has(input:invalid:focus) {
  border-left: 4px solid red;
}

/* 3. Darken the body background when an interactive modal is open */
body:has(dialog[open]) {
  overflow: hidden; /* Prevents background scrolling */
}

/* 4. Previous sibling selector: Style a link when the NEXT link is hovered */
li:has(+ li:hover) {
  opacity: 0.7;
}
```

## 2. Native CSS Nesting

CSS now natively supports selector nesting without needing Sass, SCSS, or pre-compilers:

```css
.card {
  background-color: white;
  border-radius: 0.5rem;
  padding: 1.5rem;

  /* Direct child selector */
  & > .card-title {
    font-size: 1.25rem;
    font-weight: 700;
  }

  /* Pseudo-classes and state */
  &:hover {
    box-shadow: 0 10px 15px -3px rgba(0, 0, 0, 0.1);
  }

  /* Modifiers */
  &.is-selected {
    outline: 2px solid #3b82f6;
  }

  /* Nested Media Queries */
  @media (min-width: 768px) {
    padding: 2.5rem;
  }
}
```

## 3. High-Performance Hardware-Accelerated Transitions

To achieve buttery 60 FPS transitions without stutter or layout jank, **only animate composite-only properties**:
- **GPU accelerated (Smooth)**: `transform` (`translate`, `scale`, `rotate`) and `opacity`.
- **CPU bound (Causes layout thrashing)**: `width`, `height`, `top`, `left`, `margin`, `padding`.

```css
/* BAD: Forces browser reflow on every animation frame */
.box-laggy {
  transition: width 0.3s ease, top 0.3s ease;
}
.box-laggy:hover {
  width: 320px;
  top: -10px;
}

/* GOOD: Hardware-accelerated GPU composite (60+ FPS) */
.box-performant {
  transition: transform 0.25s cubic-bezier(0.16, 1, 0.3, 1), opacity 0.25s ease;
  will-change: transform; /* Signals GPU layer allocation */
}
.box-performant:hover {
  transform: translateY(-8px) scale(1.02);
}
```

## 4. Keyframe Animations (`@keyframes`)

Keyframe animations define state milestones along an animated timeline:

```css
/* Spinner Loader Animation */
@keyframes spin {
  from {
    transform: rotate(0deg);
  }
  to {
    transform: rotate(360deg);
  }
}

.loading-spinner {
  width: 24px;
  height: 24px;
  border: 3px solid rgba(0, 0, 0, 0.1);
  border-top-color: #3b82f6;
  border-radius: 50%;
  animation: spin 0.8s linear infinite;
}

/* Subtle Pulsing Beacon */
@keyframes pulse {
  0%, 100% {
    opacity: 1;
    transform: scale(1);
  }
  50% {
    opacity: 0.5;
    transform: scale(0.95);
  }
}

.status-beacon {
  animation: pulse 2s ease-in-out infinite;
}
```

## 5. Motion Accessibility: `prefers-reduced-motion`

Many users experience vestibular motion sickness, dizziness, or seizures from rapid web animations. Web accessibility guidelines (WCAG 2.2) mandate respecting system reduced-motion settings:

```css
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```

/* Glassmorphism with Backdrop Blur */
.glass-panel {
  background: oklch(1 0 0 / 0.7); /* Translucent white */

  border: 1px solid oklch(1 0 0 / 0.3);
  box-shadow: 0 8px 32px 0 oklch(0 0 0 / 0.1);

/* Modern OKLCH Gradient Interpolation (Vibrant, no muddy gray midpoints) */
.vibrant-gradient {
  background: linear-gradient(
    in oklch 90deg,
    oklch(0.65 0.24 260),
    oklch(0.75 0.18 150)
  );
}
