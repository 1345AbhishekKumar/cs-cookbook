While Flexbox is designed for 1-dimensional item alignment, **CSS Grid** is the browser's native **2-dimensional** layout engine. It allows you to align content across rows and columns simultaneously.

---

## 1. Grid Fundamentals & The `fr` Unit

Activating `display: grid` enables a coordinate track system:

```css
.grid-container {
  display: grid;
  /* 3 columns: Left fixed 200px, Middle takes remaining space, Right takes 25% */
  grid-template-columns: 200px 1fr 25%;
  grid-template-rows: auto 1fr;
  gap: 1.5rem; /* Row and column gutters */
}
```

### The `fr` (Fractional) Unit
The `fr` unit represents a fraction of the leftover free space inside the grid container:

```css
/* 3 equal-width columns that dynamically expand and contract */
.three-cols {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  /* Equivalent shorthand using repeat(): */
  grid-template-columns: repeat(3, 1fr);
  gap: 1rem;
}
```

---

## 2. The Responsive Holy Grail: Auto-Fit + MinMax

You do **not** need media queries to build responsive card grids. Combine `repeat()`, `auto-fit`, and `minmax()`:

```css
.card-grid {
  display: grid;
  /* Fits as many columns as possible, each at least 280px wide up to 1fr */
  grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
  gap: 1.5rem;
}
```

```
Desktop Screen (>900px):   [ Card 1 ] [ Card 2 ] [ Card 3 ]
Tablet Screen (600-900px):  [ Card 1 ] [ Card 2 ]
Mobile Screen (<600px):    [ Card 1 ]
                           [ Card 2 ]
                           [ Card 3 ]
```

### `auto-fit` vs `auto-fill`
- **`auto-fit` (Recommended for cards)**: Drops empty tracks and expands existing cards to fill the remaining width.
- **`auto-fill`**: Preserves empty invisible column slots even if there aren't enough items to fill them.

## 3. Page Layout with `grid-template-areas`

Named grid areas provide an intuitive, ASCII-art style syntax for page scaffolds:

```css
.dashboard-layout {
  display: grid;
  grid-template-columns: 260px 1fr;
  grid-template-rows: 64px 1fr 50px;
  grid-template-areas:
    "sidebar header"
    "sidebar main"
    "sidebar footer";
  min-height: 100dvh;
}

/* Assign elements to their named areas */
.site-sidebar { grid-area: sidebar; }
.site-header  { grid-area: header; }
.main-content { grid-area: main; }
.site-footer  { grid-area: footer; }
```

## 4. Spanning Columns & Rows (Bento Grids)

In modern UI design (popularized by Apple and GitHub dashboards), "Bento Grids" showcase cards with varying sizes:

```css
.bento-grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-auto-rows: 200px;
  gap: 1rem;
}

/* Hero card spans 2 columns and 2 rows */
.bento-featured {
  grid-column: span 2;
  grid-row: span 2;
}

/* Full-width callout bar */
.bento-banner {
  grid-column: 1 / -1; /* Starts at line 1, stretches to final line */
}
```

## 5. Modern Subgrid (`grid-template-rows: subgrid`)

A classic CSS challenge occurs when cards in a grid have varying amounts of text, causing action buttons at the bottom to misalign:

```
Without Subgrid:          With Subgrid:
┌──────────────┐          ┌──────────────┐
│ Title        │          │ Title        │
│ Short text   │          │ Short text   │
│ [Button]     │          │              │
├──────────────┤          ├──────────────┤
│ Title        │          │ Title        │
│ Very long    │          │ Very long    │
│ multi-line   │          │ multi-line   │
│ paragraph... │          │ paragraph... │
│ [Button]     │          │ [Button]     │
└──────────────┘          └──────────────┘
(Buttons at different heights) (Buttons perfectly aligned!)
```

```css
.card-grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-auto-rows: auto;
  gap: 1.5rem;
}

.card {
  display: grid;
  /* Card inherits its 3 internal rows (Header, Body, Button) from the parent grid */
  grid-row: span 3;
  grid-template-rows: subgrid;
}
```

<Callout type="tip" title="Subgrid Browser Support">
Subgrid is universally supported in all modern browser engines (Chrome, Firefox, Safari, Edge). It eliminates the need for JavaScript card-height balancing scripts.
</Callout>
