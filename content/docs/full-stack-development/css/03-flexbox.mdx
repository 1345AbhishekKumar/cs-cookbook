**Flexbox (Flexible Box Layout)** is designed for **one-dimensional** layouts — distributing space and aligning items along a single axis (either as a row OR as a column).

---

## 1. The Flexbox Mental Model: Main vs Cross Axis

When an element is set to `display: flex`, it establishes two perpendicular axes:

```
flex-direction: row (Default)
══════════════════════════════════════════════════════════> Main Axis (justify-content)
║  ┌───────────┐   ┌───────────┐   ┌───────────┐
║  │  Item 1   │   │  Item 2   │   │  Item 3   │
║  └───────────┘   └───────────┘   └───────────┘
▼
Cross Axis (align-items)
```

- **Main Axis**: Controlled by `flex-direction` (`row` or `column`). Aligned using `justify-content`.
- **Cross Axis**: Runs perpendicular to the Main Axis. Aligned using `align-items`.

---

## 2. Flex Container Properties

Apply these properties to the parent element wrapping the items:

| Property | Values | Description |
| :--- | :--- | :--- |
| `display` | `flex`, `inline-flex` | Activates flexbox formatting context. |
| `flex-direction` | `row`, `row-reverse`, `column`, `column-reverse` | Sets the orientation of the main axis. |
| `flex-wrap` | `nowrap` (default), `wrap`, `wrap-reverse` | Dictates if children break onto new lines. |
| `justify-content`| `flex-start`, `center`, `flex-end`, `space-between`, `space-around`, `space-evenly` | Distributes leftover space along the **main axis**. |
| `align-items` | `stretch` (default), `center`, `flex-start`, `flex-end`, `baseline` | Aligns items along the **cross axis**. |
| `gap` | `<length>` (e.g. `1rem`, `16px 24px`) | Sets uniform gutters between items without margins. |

### Visualizing `justify-content`:

```
space-between:  [Item 1] ─────────── [Item 2] ─────────── [Item 3]
space-around:   ── [Item 1] ─────── [Item 2] ─────── [Item 3] ──
space-evenly:   ──── [Item 1] ──── [Item 2] ──── [Item 3] ────
center:         ─────────── [Item 1][Item 2][Item 3] ───────────
```

## 3. Flex Item Properties

Apply these properties directly to children inside the flex container:

### `flex-grow`, `flex-shrink`, and `flex-basis`

- **`flex-grow` (Factor)**: How much of the remaining empty space this item absorbs relative to siblings. (`0` = don't grow).
- **`flex-shrink` (Factor)**: How much this item shrinks when space is insufficient. (`1` = shrink normally, `0` = never shrink).
- **`flex-basis` (Length)**: The default initial size of the item before remaining space is distributed.

```css
/* Shorthand: flex: <grow> <shrink> <basis> */

/* Grow to fill all available space equally */
.fill-remaining {
  flex: 1 1 0; /* Or simply: flex: 1; */
}

/* Fixed sidebar that never grows or shrinks */
.fixed-sidebar {
  flex: 0 0 260px;
}

/* Auto-size based on content, but can shrink if needed */
.content-auto {
  flex: 0 1 auto;
}
```

### Overriding Alignment: `align-self`
Allows an individual child to break away from the container's `align-items` rule:

```css
.container {
  display: flex;
  align-items: center; /* All items centered vertically */
}

.special-badge {
  align-self: flex-start; /* This specific item stays at the top */
}
```

## 4. Battle-Tested Flexbox Patterns

  <Tab value="Centering a Div">
    The classic problem solved in two lines of code:

    ```css
    .center-box {
      display: flex;
      justify-content: center; /* Horizontal center */
      align-items: center;     /* Vertical center */
      min-height: 100dvh;
    }
    ```
  </Tab>
  <Tab value="Responsive Navbar">
    Logo on the far left, navigation links grouped on the far right:

    ```css
    .navbar {
      display: flex;
      justify-content: space-between;
      align-items: center;
      padding: 1rem 2rem;
      gap: 1rem;
    }

    .nav-links {
      display: flex;
      align-items: center;
      gap: 1.5rem;
      list-style: none;
    }
    ```
  </Tab>
  <Tab value="Sticky App Shell Footer">
    Keeps the footer pinned to the bottom of the viewport even on pages with minimal content:

    ```css
    body {
      display: flex;
      flex-direction: column;
      min-height: 100dvh;
      margin: 0;
    }

    main {
      flex: 1 0 auto; /* Expands to push footer down */
    }

    footer {
      flex-shrink: 0; /* Never collapses */
    }
    ```
  </Tab>
