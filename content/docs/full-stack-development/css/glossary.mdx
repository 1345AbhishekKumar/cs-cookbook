## 1. Categorized Property Reference

<Tabs items={['Layout & Flex/Grid', 'Box Model & Sizing', 'Typography & Text', 'Positioning & Stacking', 'Transforms & Motion', 'Visual Effects']}>
  <Tab value="Layout & Flex/Grid">
    | Property | Common Values | Description |
    | :--- | :--- | :--- |
    | `display` | `block`, `inline`, `inline-block`, `flex`, `grid`, `none`, `contents` | Defines element formatting context. |
    | `flex-direction` | `row`, `row-reverse`, `column`, `column-reverse` | Orientation of main axis in flexbox. |
    | `justify-content` | `flex-start`, `center`, `flex-end`, `space-between`, `space-evenly` | Alignment along main axis. |
    | `align-items` | `stretch`, `center`, `flex-start`, `flex-end`, `baseline` | Alignment along cross axis. |
    | `gap` | `<length>` (e.g. `1rem`, `16px 24px`) | Gutter distance between grid/flex items. |
    | `grid-template-columns` | `repeat(auto-fit, minmax(280px, 1fr))`, `1fr 2fr` | Track definitions for grid columns. |
    | `grid-template-areas` | `"header header" "sidebar main"` | Named layout area map. |
    | `grid-column` / `grid-row` | `span 2`, `1 / -1` | Track spanning instructions. |
  </Tab>

  <Tab value="Box Model & Sizing">
    | Property | Common Values | Description |
    | :--- | :--- | :--- |
    | `box-sizing` | `border-box`, `content-box` | Calculation model for width/height. Always default to `border-box`. |
    | `width` / `height` | `<length>`, `%`, `auto`, `fit-content`, `max-content` | Element dimensions. |
    | `min-width` / `max-width` | `<length>`, `none` | Lower and upper dimensional constraints. |
    | `padding` | `1rem`, `8px 16px` | Inner buffer between border and content. |
    | `margin` | `1rem`, `0 auto` | Outer buffer around element. |
    | `border` | `1px solid var(--border-color)` | Perimeter border stroke. |
    | `border-radius` | `0.5rem`, `9999px` (pill) | Corner rounding curvature. |
    | `aspect-ratio` | `16 / 9`, `1 / 1` | Locks proportional width-to-height ratio. |
  </Tab>

  <Tab value="Typography & Text">
    | Property | Common Values | Description |
    | :--- | :--- | :--- |
    | `font-family` | `system-ui`, `sans-serif`, `monospace` | Font priority stack. |
    | `font-size` | `1rem`, `clamp(1rem, 2vw, 2.5rem)` | Size of rendered text. |
    | `font-weight` | `400` (normal), `600` (semibold), `700` (bold) | Stroke thickness of typeface. |
    | `line-height` | `1.5`, `1.2` (unitless multiplier preferred) | Vertical spacing of text lines. |
    | `letter-spacing` | `-0.02em`, `0.05em` | Tracking space between characters. |
    | `text-align` | `left`, `center`, `right`, `justify` | Horizontal text alignment. |
    | `text-decoration` | `none`, `underline`, `line-through` | Decorative text embellishments. |
    | `text-overflow` | `ellipsis`, `clip` | Truncation behavior for overflowing text. |
  </Tab>

  <Tab value="Positioning & Stacking">
    | Property | Common Values | Description |
    | :--- | :--- | :--- |
    | `position` | `static`, `relative`, `absolute`, `fixed`, `sticky` | Document flow positioning scheme. |
    | `inset` | `0`, `1rem` | Shorthand for `top`, `right`, `bottom`, `left`. |
    | `top` / `bottom` / `left` / `right` | `<length>`, `auto` | Coordinate offset values. |
    | `z-index` | `auto`, `<integer>` | Stacking order within active stacking context. |
    | `isolation` | `isolate`, `auto` | Generates a new, isolated stacking context. |
  </Tab>

  <Tab value="Transforms & Motion">
    | Property | Common Values | Description |
    | :--- | :--- | :--- |
    | `transform` | `translate(X, Y)`, `scale(N)`, `rotate(deg)` | GPU-accelerated coordinate transformations. |
    | `transition` | `transform 0.2s ease, opacity 0.2s` | Smooth state change interpolation. |
    | `animation` | `spin 1s linear infinite` | Executes `@keyframes` rule sequence. |
    | `will-change` | `transform`, `opacity` | Performance hint allocating GPU hardware layer. |
  </Tab>

  <Tab value="Visual Effects">
    | Property | Common Values | Description |
    | :--- | :--- | :--- |
    | `opacity` | `0` (invisible) to `1` (opaque) | Transparency level of element and descendants. |
    | `box-shadow` | `0 4px 6px -1px rgba(0,0,0,0.1)` | Outer or inset (`inset`) elevation shadows. |
    | `backdrop-filter` | `blur(12px) saturate(180%)` | Applies blur or filters to pixels *behind* the element. |
    | `clip-path` | `circle(50%)`, `polygon(...)` | Masks visible boundaries into geometric shapes. |
    | `overflow` | `visible`, `hidden`, `scroll`, `auto` | Clipping behavior for overflowing content. |
  </Tab>
</Tabs>

## 2. Selectors Cheatsheet

| Pattern | Type | Example | Matches |
| :--- | :--- | :--- | :--- |
| `*` | Universal | `*` | All elements |
| `tag` | Type | `p` | All `<p>` elements |
| `.class` | Class | `.btn` | Elements with `class="btn"` |
| `#id` | ID | `#hero` | Element with `id="hero"` |
| `A > B` | Child | `ul > li` | Direct children only |
| `A B` | Descendant | `article p` | Any `p` nested inside `article` |
| `A + B` | Adjacent Sibling | `h2 + p` | Immediate next sibling |
| `A ~ B` | General Sibling | `h2 ~ p` | Any subsequent sibling |
| `:hover` | State | `button:hover` | Pointer hovering over element |
| `:focus-visible` | Keyboard Focus | `a:focus-visible` | Focused specifically via keyboard |
| `:nth-child(n)` | Structural | `li:nth-child(2)` | Second child of parent |
| `:is(...)` | Grouping | `:is(h1, h2, h3)` | Matches any selector in list |
| `:where(...)` | Zero Specificity | `:where(h1, h2)` | Same as `:is()`, but adds **0** specificity |
| `:has(...)` | Relational | `card:has(img)` | Parent that contains specified descendant |
| `::before` / `::after` | Pseudo-element | `h2::after` | Virtual inline node rendered before/after |

## 3. Core Sizing Units Reference

| Unit | Measurement Reference | Ideal Application |
| :--- | :--- | :--- |
| `rem` | Root `<html>` font size (default `16px`) | Typography, paddings, margins, components |
| `em` | Current or parent font size | Proportionally scaling icons/badges |
| `%` | Parent container's corresponding dimension | Flexible widths |
| `dvh` | Dynamic Viewport Height (mobile address-bar aware) | Fullscreen hero layouts on smartphones |
| `cqw` / `cqh` | 1% of Container Query parent width / height | Adaptive modular component sizing |
| `fr` | Fraction of remaining free grid space | CSS Grid column tracks |
