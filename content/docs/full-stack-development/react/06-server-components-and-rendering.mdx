In modern full-stack web applications, React divides components into two distinct execution environments: **Server Components (RSC)** and **Client Components**.

---

## 1. Server Components vs Client Components

| Feature | Server Components (Default) | Client Components (`'use client'`) |
| :--- | :--- | :--- |
| **Execution Environment** | Runs **only** on the server | Runs on server (pre-render) and browser |
| **Client Bundle Size** | **Zero bytes** of JavaScript sent to browser | Included in the downloaded JS bundle |
| **Async Data Fetching** | Direct `async/await` with databases/APIs | Hooks like `useEffect` or TanStack Query |
| **State & Interactivity** | No (`useState`, `useReducer` unavailable) | Yes (`useState`, `onClick`, `onChange`) |
| **Browser APIs** | No (`window`, `localStorage` unavailable) | Yes (full DOM and browser API access) |

---

## 2. Server Components: Direct Database & Microservice Access

Because Server Components execute exclusively on the server, they can directly query databases without creating intermediate API endpoints or leaking secret keys:

```tsx
// Server Component (Default in Next.js App Router)
import { db } from "@/lib/database";

export default async function ProductCatalog({ category }: { category: string }) {
  // Direct, secure database query inside the component!
  const products = await db.query(
    "SELECT id, name, price FROM products WHERE category = $1", 
    [category]
  );

  return (
    <div className="product-grid">
      {products.map((p) => (
        <div key={p.id} className="product-card">
          <h4>{p.name}</h4>
          <p>${p.price}</p>
        </div>
      ))}
    </div>
  );
}
```

## 3. Client Components & The `'use client'` Directive

When you need browser interactivity (click events, state, forms, browser storage), declare `'use client'` at the very top of the file:

```tsx
"use client"; // Marks this module and its imports as client components

import { useState } from "react";

export function CounterButton() {
  const [count, setCount] = useState(0);

  return (
    <button onClick={() => setCount(count + 1)} className="btn">
      Clicked {count} times
    </button>
  );
}
```

<Callout type="tip" title="Rule of Thumb: Push Client Boundaries Down">
Keep your client components as small leaf nodes at the edge of your component tree. Do not mark an entire page as `'use client'`; keep the page as a Server Component and import small, interactive client buttons.
</Callout>

## 4. The Composition Pattern (Passing Server Components as Children)

A Client Component cannot import a Server Component directly. However, it can accept a Server Component passed as the **`children`** prop:

```tsx
// Client Component: Modal dialog with open/close state
"use client";
import { useState } from "react";

export function InteractiveModal({ children }: { children: React.ReactNode }) {
  const [isOpen, setIsOpen] = useState(false);

  return (
    <div>
      <button onClick={() => setIsOpen(true)}>Open Modal</button>
      {isOpen && (
        <div className="dialog">
          {/* 'children' is rendered by the server with 0 client JS! */}
          {children}
        </div>
      )}
    </div>
  );
}
```

```tsx
// Server Component: Assembles them cleanly
import { InteractiveModal } from "./InteractiveModal";
import { HeavyDatabaseReport } from "./HeavyDatabaseReport";

export default function Page() {
  return (
    <InteractiveModal>
      {/* HeavyDatabaseReport executes on the server and streams pure HTML! */}
      <HeavyDatabaseReport />
    </InteractiveModal>
  );
}
```

## 5. `<Suspense>` & Progressive HTML Streaming

Wrap asynchronous Server Components in `<Suspense>` to stream fast shell content immediately while heavy database queries resolve:

```tsx
import { Suspense } from "react";
import { SlowAnalyticsDashboard } from "./Analytics";
import { DashboardSkeleton } from "./Skeletons";

export default function DashboardPage() {
  return (
    <main>
      <h1>Real-Time Analytics</h1>

      {/* Renders DashboardSkeleton instantly, streams live content when ready */}
      <Suspense fallback={<DashboardSkeleton />}>
        <SlowAnalyticsDashboard />
      </Suspense>
    </main>
  );
}
```
