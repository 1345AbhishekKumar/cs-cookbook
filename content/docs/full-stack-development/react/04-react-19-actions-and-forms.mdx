React 19 fundamentally modernizes form handling and data mutations by replacing manual `onSubmit` event handlers, `isSubmitting` flags, and error states with native **Actions**.

---

## 1. Native Form Actions

In React 19, the HTML `<form action>` attribute accepts an asynchronous function (an Action). React automatically manages the lifecycle, pending state, and resets:

```tsx
async function updateUsername(formData: FormData) {
  const newName = formData.get("username") as string;
  await api.saveUsername(newName);
}

export function UsernameForm() {
  return (
    <form action={updateUsername}>
      <input name="username" defaultValue="Alex" />
      <button type="submit">Save</button>
    </form>
  );
}
```

## 2. Managing Form State: `useActionState`

`useActionState` manages the result, error state, and pending flag of an async action:

```tsx
import { useActionState } from "react";

// Action function receives previous state and submitted FormData
async function registerUser(previousState: any, formData: FormData) {
  const email = formData.get("email") as string;

  try {
    const user = await api.register({ email });
    return { success: true, message: `Account created for ${user.email}` };
  } catch (err: any) {
    return { success: false, error: err.message };
  }
}

export function RegistrationForm() {
  const [state, formAction, isPending] = useActionState(registerUser, { success: false });

  return (
    <form action={formAction}>
      <input name="email" type="email" required placeholder="user@domain.com" />
      
      <button type="submit" disabled={isPending}>
        {isPending ? "Creating Account..." : "Sign Up"}
      </button>

      {state.error && <p className="error">{state.error}</p>}
      {state.success && <p className="success">{state.message}</p>}
    </form>
  );
}
```

## 3. Reading Parent Status: `useFormStatus`

`useFormStatus` allows child components to read whether the enclosing `<form>` is currently submitting, without needing to pass down `isPending` via props:

```tsx
import { useFormStatus } from "react-dom";

// Reusable submit button that automatically detects parent form state
export function SubmitButton({ children }: { children: React.ReactNode }) {
  const { pending } = useFormStatus();

  return (
    <button type="submit" disabled={pending} className="btn-primary">
      {pending ? "Processing..." : children}
    </button>
  );
}
```

## 4. Instant UI Feedback: `useOptimistic`

When a user likes a post or sends a message, waiting 500ms for a server response makes the app feel sluggish. `useOptimistic` immediately displays the anticipated UI change while the request is in flight, and automatically reverts if the server rejects it:

```tsx
import { useOptimistic, useActionState } from "react";

export function PostLikes({ post }: { post: { id: string; likes: number } }) {
  // Optimistic state: immediately reflects increment
  const [optimisticLikes, setOptimisticLikes] = useOptimistic(
    post.likes,
    (currentLikes, update: number) => currentLikes + update
  );

  async function handleLike() {
    setOptimisticLikes(1); // 1. Immediate instant UI update
    await api.likePost(post.id); // 2. Async server mutation in background
  }

  return (
    <form action={handleLike}>
      <button type="submit">❤️ {optimisticLikes} Likes</button>
    </form>
  );
}
```

## 5. The `use()` API (Reading Promises & Context)

In React 19, the new `use()` function can read resources (Promises or Context) directly during render, and can even be called **inside conditional branches or loops**:

<Tabs items={['Reading Promises with Suspense', 'Reading Context Conditionally']}>
  <Tab value="Reading Promises with Suspense">
    ```tsx
    import { use, Suspense } from "react";

    function UserDetails({ userPromise }: { userPromise: Promise<{ name: string }> }) {
      // Unwraps the promise value directly!
      const user = use(userPromise);
      return <h2>User: {user.name}</h2>;
    }

    export function ProfilePage() {
      const userPromise = fetchUser(); // Initiates fetch
      return (
        <Suspense fallback={<p>Loading user details...</p>}>
          <UserDetails userPromise={userPromise} />
        </Suspense>
      );
    }
    ```
  </Tab>
  <Tab value="Reading Context Conditionally">
    ```tsx
    import { use } from "react";
    import { ThemeContext } from "./theme";

    export function Header({ showCustomTheme }: { showCustomTheme: boolean }) {
      if (showCustomTheme) {
        // Valid in React 19! Traditional useContext cannot be called inside 'if'
        const theme = use(ThemeContext);
        return <header style={{ background: theme.color }}>Header</header>;
      }
      return <header>Default Header</header>;
    }
    ```
