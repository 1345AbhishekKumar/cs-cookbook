## 1. Built-in Hooks Reference

  <Tab value="State & Lifecycle">
    | Hook | Primary Purpose | Example Syntax |
    | :--- | :--- | :--- |
    | `useState` | Declares local reactive state snapshot. | `const [state, setState] = useState(initial)` |
    | `useReducer` | Manages complex state transitions with a reducer function. | `const [state, dispatch] = useReducer(reducer, init)` |
    | `useEffect` | Synchronizes component with external systems (timers, APIs). | `useEffect(() => { ... return cleanup; }, [deps])` |
    | `useLayoutEffect` | Fires synchronously after DOM mutations before browser paint. | `useLayoutEffect(() => { measureDOM(); }, [])` |
  </Tab>

  <Tab value="React 19 Actions">
    | Hook / API | Primary Purpose | Example Syntax |
    | :--- | :--- | :--- |
    | `useActionState` | Manages pending status, return values, and form action errors. | `const [state, formAction, isPending] = useActionState(fn, init)` |
    | `useFormStatus` | Reads parent `<form>` pending submission status in child components. | `const { pending, data, method } = useFormStatus()` |
    | `useOptimistic` | Optimistically displays anticipated updates before server settles. | `const [optVal, setOpt] = useOptimistic(val, updateFn)` |
    | `use()` | Reads a Promise or Context conditionally directly during render. | `const data = use(fetchPromise)` |
  </Tab>

  <Tab value="Context & Refs">
    | Hook / API | Primary Purpose | Example Syntax |
    | :--- | :--- | :--- |
    | `useContext` | Reads context value from nearest matching context ancestor. | `const theme = useContext(ThemeContext)` |
    | `useRef` | Stores mutable values or DOM node references without re-renders. | `const inputRef = useRef<HTMLInputElement>(null)` |
    | `useImperativeHandle` | Customizes instance ref exposed to parent component. | `useImperativeHandle(ref, () => ({ focus: ... }))` |
  </Tab>

  <Tab value="Performance & Concurrency">
    | Hook / API | Primary Purpose | Example Syntax |
    | :--- | :--- | :--- |
    | `useMemo` | Caches calculation results across renders (largely automated by React Compiler). | `const val = useMemo(() => calc(a), [a])` |
    | `useCallback` | Caches function definitions across renders (automated by React Compiler). | `const fn = useCallback(() => act(b), [b])` |
    | `useTransition` | Marks state updates as non-blocking low-priority transitions. | `const [isPending, startTransition] = useTransition()` |
    | `useDeferredValue` | Defers updating a non-urgent part of the UI while user types. | `const deferredQuery = useDeferredValue(query)` |
  </Tab>

  <Tab value="Forms & Validation (RHF)">
    | Hook / API | Primary Purpose | Example Syntax |
    | :--- | :--- | :--- |
    | **`useForm`** | Root hook managing uncontrolled inputs, validation, and form state. | `const { register, handleSubmit } = useForm({ resolver })` |
    | **`register`** | Connects native HTML input to RHF via ref and event subscriptions. | `<input {...register("email", { required: true })} />` |
    | **`<Controller />`** | Bridges controlled UI components (shadcn/ui, Radix) into RHF. | `<Controller name="role" control={control} render={...} />` |
    | **`useFieldArray`** | Manages dynamic array rows (append, prepend, remove, swap). | `const { fields, append, remove } = useFieldArray({ control, name })` |
    | **`useWatch`** | Subscribes to input updates in an isolated component without re-rendering form. | `const val = useWatch({ control, name: "plan" })` |
    | **`<FormProvider />`** | Context provider broadcasting form methods to deep child trees. | `<FormProvider {...methods}><ChildInputs /></FormProvider>` |
    | **`useFormContext`** | Consumes methods from `<FormProvider />` in deep child components. | `const { register } = useFormContext()` |
    | **`formState`** | Reactive metadata: `errors`, `isSubmitting`, `isDirty`, `isValid`. | `const { errors, isSubmitting } = formState` |
  </Tab>

  <Tab value="State Management (Ecosystem)">

    | :--- | :--- | :--- |

    | **Zustand (`useShallow`)** | Prevents selector re-render loops on multi-field objects. | `const { a, b } = useStore(useShallow(s => ({ a: s.a, b: s.b })))` |
    | **TanStack Query (`useQuery`)** | Asynchronous server-state caching and deduplication. | `const { data, isPending } = useQuery({ queryKey, queryFn })` |
    | **TanStack Query (`useMutation`)** | Modifies remote data and triggers cache invalidation. | `const mut = useMutation({ mutationFn, onSuccess })` |
    | **TanStack Query (`useSuspenseQuery`)** | Declarative Suspense-integrated data fetching. | `const { data } = useSuspenseQuery({ queryKey, queryFn })` |

## 2. React 19 Key Additions Summary

1. **Native Form Actions**: Pass async functions directly to `<form action={asyncFn}>` and `<button formAction={asyncFn}>`.
2. **Simplified Context**: Render `<ThemeContext value={...}>` directly without appending `.Provider`.
3. **Document Metadata**: Native `<title>`, `<meta>`, and `<link>` tags can now be rendered anywhere in your component tree and are automatically hoisted to `<head>`.
4. **Direct Ref Props**: Function components can receive `ref` as a normal prop without wrapping in `forwardRef()`.
5. **Preloading Resources**: New APIs like `preload`, `preinit`, and `prefetchDNS` to optimize asset downloads.

## 3. Common React Anti-Patterns & Bugs

### 1. The Stale Closure Bug
- **Cause**: An asynchronous callback or `useEffect` captures an outdated state variable from an earlier render snapshot.
- **Fix**: Use functional state updates (`setCount(prev => prev + 1)`) or include the state in the hook's dependency array.

### 2. Infinite Re-Render Loop
- **Cause**: Calling a state updater directly in the render body or inside `useEffect` without an appropriate dependency array.
- **Fix**: Move state updaters into event handlers or provide explicit dependencies.

### 3. Mutating State Directly
- **Cause**: Doing `state.items.push(newItem)` or `state.user.name = "Alex"`.
- **Fix**: React relies on shallow reference equality (`prev !== next`) to trigger re-renders. Always create a new object or array copy via spread (`[...prev, newItem]`).

### 4. Zustand 5 Object Selector Loop
- **Cause**: Returning an object literal `(state) => ({ a: state.a, b: state.b })` in Zustand 5. Because Zustand 5 defaults to `Object.is`, a new object reference triggers continuous re-renders.
- **Fix**: Wrap multi-property selectors in `useShallow()` from `zustand/react/shallow` or use atomic individual selectors.

### 5. Storing Server State in Global Client Stores
- **Cause**: Copying API fetch responses into Zustand or Redux stores and managing loading/error flags manually.
- **Fix**: Use TanStack Query for all remote asynchronous state to gain automatic caching, deduplication, retry, and garbage collection.
