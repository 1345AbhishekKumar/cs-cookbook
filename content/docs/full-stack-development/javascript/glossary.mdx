## 2. Common Quirks & Interview Traps

### 1. `typeof null === "object"`
This is a legacy bug from the very first version of JavaScript (1995) where values were tagged with a 3-bit type identifier. The null pointer tag was `000`, which matched the object tag. It can never be fixed without breaking the entire web.

### 2. Floating Point Precision (`0.1 + 0.2 !== 0.3`)
JavaScript numbers are standard IEEE 754 64-bit binary floating points. Binary cannot precisely represent fractions like `1/10`.
```javascript
console.log(0.1 + 0.2); // 0.30000000000000004
// Accurate comparison check:
console.log(Math.abs((0.1 + 0.2) - 0.3) < Number.EPSILON); // true
```

### 3. The `==` Truthiness Matrix
```javascript
[] == ![]          // true (empty array coerces to 0, ![] coerces to false -> 0)
NaN === NaN        // false (NaN is the only value not equal to itself!)
```

### 4. Arrow Functions Have No `arguments` and No `this`
Arrow functions do not bind their own `this`, `arguments`, `super`, or `new.target`. Attempting to use `new ArrowFunc()` throws a `TypeError`.
