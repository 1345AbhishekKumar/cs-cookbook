## 1. Declarative Array Transformations

Avoid imperative `for` loops in full-stack code. Use immutable functional methods:

```javascript
const transactions = [
  { id: "tx_1", amount: 150, category: "cloud" },
  { id: "tx_2", amount: 80,  category: "saas" },
  { id: "tx_3", amount: 220, category: "cloud" },
];

// 1. Filter: Extract subset matching predicate
const cloudBills = transactions.filter(t => t.category === "cloud");

// 2. Map: Project array elements into a new shape
const ids = transactions.map(t => t.id);

// 3. Reduce: Aggregate array into a single accumulated value
const totalSpend = transactions.reduce((acc, t) => acc + t.amount, 0);

// 4. Find & Some
const hasLargeBill = transactions.some(t => t.amount > 200); // true
const firstMatch = transactions.find(t => t.category === "saas");
```

### Modern Non-Mutating Array Methods
Traditional array methods like `.sort()` and `.reverse()` mutate the original array in place, causing bugs in React state. Modern JavaScript provides pure, non-mutating alternatives:

```javascript
const numbers = [3, 1, 4, 1, 5];

// Does NOT mutate 'numbers'; returns a new sorted copy
const sorted = numbers.toSorted((a, b) => a - b);

// Does NOT mutate 'numbers'; returns a reversed copy
const reversed = numbers.toReversed();

// Replaces an item at an index immutably
const replaced = numbers.with(2, 99); // [3, 1, 99, 1, 5]
```

### Classic Array Operations: Mutating vs Non-Mutating

Understanding which methods mutate an array in place vs return a new array is essential for avoiding state bugs:

| Operation | Mutating Method (In-Place) | Non-Mutating Alternative |
| :--- | :--- | :--- |
| **Add to End** | `arr.push(item)` (returns new length) | `[...arr, item]` or `arr.concat(item)` |
| **Remove from End** | `arr.pop()` (returns removed item) | `arr.slice(0, -1)` |
| **Remove from Front** | `arr.shift()` (returns removed item) | `arr.slice(1)` |
| **Add to Front** | `arr.unshift(item)` (returns new length) | `[item, ...arr]` |
| **Delete / Insert at Index** | `arr.splice(start, count, ...items)` | `arr.toSpliced(start, count, ...items)` |
| **Extract Range** | *None* | `arr.slice(start, end)` (copies slice) |
| **Check Inclusion** | *None* | `arr.includes(value)` (returns boolean) |
| **Join to String** | *None* | `arr.join(", ")` (returns joined string) |

```javascript
const fruits = ["apple", "banana", "orange"];

// Mutating queue-style operations:
fruits.push("mango");     // ['apple', 'banana', 'orange', 'mango']
const removed = fruits.shift(); // 'apple', fruits is now ['banana', 'orange', 'mango']

// Non-mutating slice and join:
const citrus = fruits.slice(0, 2); // ['banana', 'orange']
console.log(fruits.includes("orange")); // true
console.log(fruits.join(" - "));       // "banana - orange - mango"
```

## 2. Objects, Destructuring & Prototypes

```javascript
const apiResponse = {
  status: 200,
  data: {
    user: { id: "u_42", email: "alex@example.com" }
  },
  timestamp: Date.now()
};

// Nested destructuring with aliases and defaults
const {
  data: { user: { email: userEmail } },
  status = 500
} = apiResponse;
```

### The Prototype Chain
Every JavaScript object has an internal link to another object called its **prototype**. When attempting to access a property that does not exist on the object, the engine searches up the chain until it finds it or reaches `null`.

```javascript
const animal = {
  isAlive: true,
  breathe() {
    return "inhale / exhale";
  }
};

// Create a dog object inheriting directly from animal
const dog = Object.create(animal);
dog.bark = () => "woof!";

console.log(dog.bark());    // "woof!" (Own property)
console.log(dog.breathe()); // "inhale / exhale" (Delegated to animal prototype!)
console.log(dog.isAlive);   // true (Delegated to animal prototype!)
```

### Static Object Utilities & Property Iteration

JavaScript provides standard static methods for inspecting, merging, and iterating over object keys and values:

```javascript
const userProfile = { id: 101, username: "alex", role: "admin" };

// 1. Object.keys: Array of enumerable property names
console.log(Object.keys(userProfile)); // ['id', 'username', 'role']

// 2. Object.values: Array of enumerable property values
console.log(Object.values(userProfile)); // [101, 'alex', 'admin']

// 3. Object.entries: Array of [key, value] pairs (great for Map conversion or loops)
for (const [key, val] of Object.entries(userProfile)) {
  console.log(`${key}: ${val}`);
}

// 4. Object.assign: Shallow merge source objects into target
const preferences = { theme: "dark", notifications: true };
const merged = Object.assign({}, userProfile, preferences);

// 5. Property Value Shorthand
const title = "Developer";
const salary = 120000;
const job = { title, salary }; // Equivalent to { title: title, salary: salary }
```

## 3. ES6 Classes & Private Fields

Classes in JavaScript are syntactic sugar over prototypal inheritance, offering a clean, standard syntax:

```javascript
class DatabasePool {
  // Private field: Inaccessible outside this class definition
  #connections = 0;
  #maxConnections;

  constructor(maxConnections = 10) {
    this.#maxConnections = maxConnections;
  }

  // Getter
  get activeCount() {
    return this.#connections;
  }

  acquire() {
    if (this.#connections >= this.#maxConnections) {
      throw new Error("Connection pool exhausted.");
    }
    this.#connections += 1;
    return { connectionId: `conn_${this.#connections}` };
  }

  release() {
    if (this.#connections > 0) this.#connections -= 1;
  }
}

const pool = new DatabasePool(5);
const conn = pool.acquire();
// pool.#connections; // SyntaxError: Private field '#connections' must be declared in an enclosing class
```

## 4. Modern Collections: `Map`, `Set` & `WeakMap`

### `Map` vs Regular Object
- An `Object` only allows strings and symbols as keys.
- A `Map` allows **any value** (objects, functions, primitives) as keys, preserves insertion order, and provides a `.size` property.

```javascript
const userCache = new Map();
const userObj = { id: 101 };

userCache.set(userObj, { lastAccessed: Date.now() });
console.log(userCache.get(userObj)); // Fast O(1) lookup
```

### `Set` & Modern Set Operations
A `Set` is an ordered collection of unique values:

```javascript
const setA = new Set([1, 2, 3]);
const setB = new Set([3, 4, 5]);

// Modern Set Methods (ES2025+)
const union = setA.union(setB);             // Set { 1, 2, 3, 4, 5 }
const common = setA.intersection(setB);      // Set { 3 }
const diff = setA.difference(setB);          // Set { 1, 2 }
```

### `WeakMap` and Memory Management
In a standard `Map`, storing an object as a key prevents garbage collection even if all other references to that object are deleted. A **`WeakMap`** holds "weak" references to its keys, allowing the garbage collector to free the memory automatically when the object is no longer referenced elsewhere.
