**JSON** (**JavaScript Object Notation**) is a lightweight, language-independent, text-based data format used universally for transmitting structured data across networks between web clients, servers, and storage databases.

---

## 1. JSON vs JavaScript Objects

While JSON syntax is derived from JavaScript object literal notation, they have strict differences:

| Feature | JSON | JavaScript Object Literal |
| :--- | :--- | :--- |
| **Key Formatting** | **Must** be enclosed in double quotes (`"key"`) | Quotes optional unless containing special characters |
| **String Delimiters** | Double quotes **only** (`"value"`) | Single quotes (`'`), double quotes (`"`), or backticks (``` ` ```) |
| **Trailing Commas** | Strictly forbidden (`SyntaxError`) | Allowed and standard in modern code |
| **Supported Data Types** | `string`, `number`, `boolean`, `null`, `object`, `array` | All primitive types plus `function`, `symbol`, `BigInt`, `undefined` |
| **Functions & Methods** | **Not supported** | Supported |
| **Portability** | Language-agnostic (parsed in Python, Go, C#, Rust, etc.) | JavaScript runtime-specific |

```json
// Valid JSON syntax
{
  "name": "Sarah Connor",
  "age": 28,
  "roles": ["developer", "admin"],
  "verified": true,
  "metadata": null
}
```

## 2. Converting Objects to JSON: `JSON.stringify()`

The `JSON.stringify(value, replacer, space)` method converts a JavaScript value into a JSON string:

```javascript
const user = {
  id: 101,
  username: "alice",
  active: true,
  lastLogin: new Date(),
  calculateScore: () => 100, // Skipped during serialization
  token: undefined           // Skipped during serialization
};

const jsonString = JSON.stringify(user, null, 2);
console.log(jsonString);
```

### The `replacer` Parameter (Filtering & Transformation)
You can selectively filter properties by passing an array of allowed keys or a replacer function:

<Tabs items={['Array Whitelist', 'Replacer Function']}>
  <Tab value="Array Whitelist">
    ```javascript
    const payload = { id: 1, secretKey: "x9!z", email: "user@example.com" };
    // Only serialize 'id' and 'email'
    const cleanJSON = JSON.stringify(payload, ["id", "email"]);
    console.log(cleanJSON); // '{"id":1,"email":"user@example.com"}'
    ```
  </Tab>
  <Tab value="Replacer Function">
    ```javascript
    const serialized = JSON.stringify(user, (key, value) => {
      // Mask password fields
      if (key === "password") return undefined; // Removes key
      // Convert BigInt to string to prevent TypeError
      if (typeof value === "bigint") return value.toString();
      return value;
    });
    ```
  </Tab>
</Tabs>

### Custom Serialization: The `.toJSON()` Method
If an object defines a `toJSON()` method, `JSON.stringify()` automatically calls it and serializes the returned value:

```javascript
class Session {
  constructor(userId, secretToken) {
    this.userId = userId;
    this.secretToken = secretToken;
  }

  toJSON() {
    return {
      userId: this.userId,
      exportedAt: Date.now()
    };
  }
}

const session = new Session(42, "sensitive_token");
console.log(JSON.stringify(session));
// '{"userId":42,"exportedAt":1772718000000}'
```

## 3. Parsing JSON: `JSON.parse()`

`JSON.parse(text, reviver)` transforms a JSON string back into a JavaScript object:

```javascript
const raw = '{"name":"John","joined":"2026-03-01T10:00:00.000Z"}';

try {
  const parsed = JSON.parse(raw);
  console.log(parsed.name); // "John"
} catch (error) {
  console.error("Malformed JSON received:", error.message);
}
```

<Callout type="warn" title="Always Wrap JSON.parse in try...catch">
Unsanitized network responses or corrupt storage strings that contain syntax errors will throw an uncaught `SyntaxError` and crash execution unless handled.
</Callout>

### The `reviver` Parameter (Rehydrating Complex Data)
JSON does not have a native `Date` type. When serialized, dates become ISO 8601 strings. You can automatically rehydrate them into true `Date` instances using the reviver callback:

```javascript
const rawJSON = '{"orderId":901,"createdAt":"2026-10-04T12:00:00.000Z"}';

const order = JSON.parse(rawJSON, (key, value) => {
  if (key === "createdAt") {
    return new Date(value); // Rehydrate back to Date object
  }
  return value;
});

console.log(order.createdAt instanceof Date); // true
console.log(order.createdAt.getFullYear());     // 2026
```

## 4. Circular References & Edge Cases

If an object references itself, `JSON.stringify()` throws a `TypeError`:

```javascript
const nodeA = { name: "Node A" };
const nodeB = { name: "Node B" };
nodeA.sibling = nodeB;
nodeB.sibling = nodeA;

// TypeError: Converting circular structure to JSON
JSON.stringify(nodeA); 
```

To deep-clone circular structures without JSON errors, use the native browser and Node.js API:
```javascript
const cloned = structuredClone(nodeA); // Native deep clone with circular support
```
