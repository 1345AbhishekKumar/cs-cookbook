<ModuleOverview slug="full-stack-development" />

Full stack development bridges user interfaces, server runtimes, data persistence layers, and native operating systems into cohesive, production-ready applications.

This curriculum provides a complete, progressive path across **Web Foundations**, **Frontend Systems**, **Backend Engineering**, and **Integrated Production Stacks**.

<Callout type="info" title="Networking & Database Prerequisites">
Before designing high-scale networked applications:
- For underlying network protocols (TCP sockets, UDP, TLS 1.3, and HTTP framing), explore **[Computer Networking](/docs/computer-networking)**.
- For relational schemas, indexing, and ACID transaction isolation, explore **[Databases, SQL & Data-Intensive Systems](/docs/databases-sql)**.
</Callout>
