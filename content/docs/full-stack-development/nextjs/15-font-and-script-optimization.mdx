Typography and third-party scripts are primary culprits behind poor First Contentful Paint (FCP) and Cumulative Layout Shift (CLS). Next.js provides built-in loaders to guarantee optimal loading performance.

---

## 1. Font Optimization (`next/font`)

`next/font` automatically optimizes custom and Google fonts at build time:
- **Zero Privacy Leaking**: Font files are downloaded at build time and self-hosted with your static assets. No external requests are made to Google servers from client browsers.
- **Zero Layout Shift**: Automatically calculates CSS `size-adjust` fallback metrics so the fallback system font occupies the exact same dimensions as the custom font before it loads.

### 1. Google Fonts (`next/font/google`)

```tsx
// app/layout.tsx
import { Inter, Roboto_Mono } from 'next/font/google';

const inter = Inter({
  subsets: ['latin'],
  display: 'swap',
  variable: '--font-inter',
});

const robotoMono = Roboto_Mono({
  subsets: ['latin'],
  display: 'swap',
  variable: '--font-mono',
});

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en" className={`${inter.variable} ${robotoMono.variable}`}>
      <body className="font-sans antialiased">{children}</body>
    </html>
  );
}
```

### 2. Custom Local Fonts (`next/font/local`)

```tsx
// app/fonts.ts
import localFont from 'next/font/local';

export const customSans = localFont({
  src: [
    {
      path: '../public/fonts/Custom-Regular.woff2',
      weight: '400',
      style: 'normal',
    },
    {
      path: '../public/fonts/Custom-Bold.woff2',
      weight: '700',
      style: 'normal',
    },
  ],
  variable: '--font-custom-sans',
});
```

## 2. Script Optimization (`next/script`)

Third-party analytics and tracking scripts (Google Tag Manager, Meta Pixel, Intercom) often block the main JavaScript thread. Use `<Script>` to control execution timing:

```tsx
import Script from 'next/script';

export function AnalyticsScripts() {
  return (
    <>
      {/* 1. Critical security or bot-protection script */}
      <Script
        src="https://challenges.cloudflare.com/turnstile/v0/api.js"
        strategy="beforeInteractive"
      />

      {/* 2. Standard analytics (Loads immediately after hydration) */}
      <Script
        src="https://www.googletagmanager.com/gtag/js?id=G-XYZ"
        strategy="afterInteractive"
      />

      {/* 3. Non-critical support chat widget (Loads during browser idle time) */}
      <Script
        src="https://widget.intercom.io/widget/xyz"
        strategy="lazyOnload"
        onLoad={() => console.log('Support chat widget initialized')}
      />
    </>
  );
}
```

### Script Strategies Overview

| Strategy | When It Runs | Best For |
| :--- | :--- | :--- |
| `beforeInteractive` | Injected into `<head>` before page hydration | Polyfills, security tokens, consent managers |
| `afterInteractive` (Default) | Injected immediately after page hydration | Google Tag Manager, analytics, A/B testing |
| `lazyOnload` | Injected during browser idle periods | Support chat widgets, social share buttons |
| `worker` (experimental) | Offloaded to Web Worker via Partytown | Heavy analytics tracking scripts |
