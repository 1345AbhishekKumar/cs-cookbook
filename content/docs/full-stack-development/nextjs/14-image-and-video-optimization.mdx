Unoptimized visual media accounts for over 70% of typical web page payload. Next.js includes native media tooling to ensure zero Cumulative Layout Shift (CLS) and minimal bandwidth consumption.

---

## 1. The `next/image` Component

The Next.js `Image` component extends standard HTML `<img>` elements with automated performance optimizations:

- **Next-Gen Formats**: Converts source images into modern formats (**AVIF** and **WebP**) based on client browser support.
- **Zero CLS**: Reserves exact bounding layout space before images finish downloading.
- **Native Lazy Loading**: Defers fetching until elements enter the viewport.
- **Dynamic Resizing**: Serves device-tailored image widths via responsive `srcset` generation.

## 2. Image Implementation Patterns

### 1. Static Local Images

When importing images from the local repository, Next.js calculates intrinsic dimensions automatically:

```tsx
import Image from 'next/image';
import heroBanner from '@/public/banner.jpg';

export function Hero() {
  return (
    <Image
      src={heroBanner}
      alt="Platform overview banner"
      placeholder="blur" // Smooth blur-up transition
      priority // Preloads above-the-fold content immediately
    />
  );
}
```

### 2. Remote CDN Images

For dynamic images from external APIs or storage buckets, supply explicit `width` and `height`:

```tsx
import Image from 'next/image';

export function ProductThumbnail({ url }: { url: string }) {
  return (
    <Image
      src={url}
      alt="Product thumbnail"
      width={400}
      height={300}
    />
  );
}
```

### 3. Responsive Images with `fill`

When image dimensions depend on responsive CSS containers:

```tsx
import Image from 'next/image';

export function ResponsiveCard({ imageUrl }: { imageUrl: string }) {
  return (
    <div className="relative w-full h-64 overflow-hidden rounded-lg">
      <Image
        src={imageUrl}
        alt="Card image"
        fill
        sizes="(max-width: 768px) 100vw, (max-width: 1200px) 50vw, 33vw"
        className="object-cover"
      />
    </div>
  );
}
```

## 3. Whitelisting Remote Domains in `next.config.ts`

Protect your application against malicious external image URLs by defining strict domain matchers:

```typescript
// next.config.ts
import type { NextConfig } from 'next';

const nextConfig: NextConfig = {
  images: {
    remotePatterns: [
      {
        protocol: 'https',
        hostname: 'images.unsplash.com',
        pathname: '/**',
      },
      {
        protocol: 'https',
        hostname: 's3.amazonaws.com',
        pathname: '/my-bucket/**',
      },
    ],
  },
};

export default nextConfig;
```

## 4. Video Embedding Strategies

### 1. Self-Hosted HTML5 Video with Caption Tracks

```tsx
export function VideoPlayer() {
  return (
    <video width="640" height="360" controls preload="metadata">
      <source src="/videos/overview.mp4" type="video/mp4" />
      <track
        src="/captions/en.vtt"
        kind="subtitles"
        srcLang="en"
        label="English"
      />
      Your browser does not support HTML5 video tags.
    </video>
  );
}
```

### 2. External Video Streaming with Server Components & Suspense

```tsx
// app/components/YouTubePlayer.tsx
import { Suspense } from 'react';

export function YouTubePlayer({ videoId }: { videoId: string }) {
  return (
    <Suspense fallback={<div className="h-64 bg-gray-200 animate-pulse rounded" />}>
      <iframe
        src={`https://www.youtube.com/embed/${videoId}`}
        className="w-full aspect-video rounded-lg"
        allowFullScreen
      />
    </Suspense>
  );
}
```
