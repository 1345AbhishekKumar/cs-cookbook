If you prefer to configure your application manually or integrate Next.js into an existing repository, follow this step-by-step setup guide.

---

## 1. Install Dependencies

Install the core Next.js runtime alongside React and React DOM:

```bash
npm install next@latest react@latest react-dom@latest
```

---

## 2. Update `package.json`

Open `package.json` and configure scripts for local development, production builds, and code linting:

```json
{
  "scripts": {
    "dev": "next dev",
    "build": "next build",
    "start": "next start",
    "lint": "next lint"
  }
}
```

- `dev`: Starts the Next.js development server with hot-module replacement on `http://localhost:3000`.
- `build`: Compiles and optimizes your application for production deployment.
- `start`: Starts the Next.js production server (requires running `next build` first).
- `lint`: Runs Next.js's built-in ESLint checks.

---

## 3. Creating Directories & File Structure

### App Directory (Recommended: App Router)

Create an `app` directory in the root of your project and add `layout.tsx` and `page.tsx`:

#### `app/layout.tsx`
Defines the required root layout HTML shell that wraps every page:

```tsx
export default function RootLayout({
  children,
}: {
  children: React.ReactNode;
}) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  );
}
```

#### `app/page.tsx`
Defines the UI rendered at the root URL (`/`):

```tsx
export default function Page() {
  return <h1>Hello, Next.js!</h1>;
}
```

---

### Pages Directory (Optional: Pages Router Legacy)

If your project utilizes the Pages Router rather than the App Router:

1. Create a `pages` directory.
2. Add `pages/index.tsx`:

```tsx
export default function Page() {
  return <h1>Hello, Next.js!</h1>;
}
```

3. Add `pages/_app.tsx` to define a global layout and persist state across page transitions:

```tsx
import type { AppProps } from 'next/app';

export default function App({ Component, pageProps }: AppProps) {
  return <Component {...pageProps} />;
}
```

4. Add `pages/_document.tsx` to customize the initial server-rendered HTML document structure:

```tsx
import { Html, Head, Main, NextScript } from 'next/document';

export default function Document() {
  return (
    <Html>
      <Head />
      <body>
        <Main />
        <NextScript />
      </body>
    </Html>
  );
}
```

---

### Public Folder (Optional)

Create a `public` directory in the project root to serve uncompiled static assets such as images, icons, robots.txt, and fonts:

```plaintext
my-project/
├── app/
│   ├── layout.tsx
│   └── page.tsx
├── public/
│   ├── logo.svg
│   └── favicon.ico
└── package.json
```

Files inside `public` can be referenced directly from code starting from the base URL (e.g., `/logo.svg`).

---

## 4. Run the Development Server

Start the local server:

```bash
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) in your browser. Edit `app/page.tsx` and save to see instant live updates in the browser thanks to Fast Refresh.
