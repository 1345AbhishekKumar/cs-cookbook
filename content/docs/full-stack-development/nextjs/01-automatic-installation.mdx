The recommended and fastest way to start a new Next.js application is using `create-next-app`, which automatically configures project tooling, dependencies, and recommended directory structure.

---

## 1. System Requirements

Before initializing a Next.js project, ensure your environment meets the minimum version constraints:

- **Node.js**: `18.17` or later.
- **Operating Systems**: macOS, Windows (including WSL), and Linux.

---

## 2. Using `create-next-app`

Run `create-next-app` with your package manager in your terminal:

```bash
npx create-next-app@latest
```

### Interactive Prompts

On execution, the CLI will guide you through project configuration:

```plaintext
What is your project named? my-app
Would you like to use TypeScript? No / Yes
Would you like to use ESLint? No / Yes
Would you like to use Tailwind CSS? No / Yes
Would you like your code inside a `src/` directory? No / Yes
Would you like to use App Router? (recommended) No / Yes
Would you like to use Turbopack for `next dev`? No / Yes
Would you like to customize the import alias (`@/*` by default)? No / Yes
```

This command provisions all required dependencies, sets up package scripts, and configures build toolchains out of the box.

---

## 3. Key Defaults & Good to Know

<Callout type="info" title="Included Out of the Box">
- **Tooling Defaults**: Next.js automatically sets up TypeScript, ESLint, formatters, Prettier, and Tailwind CSS configurations by default.
- **Source Directory (`src/`)**: You can opt to use an `src` directory to cleanly separate your application routing code (`src/app`) from configuration files (`next.config.js`, `tsconfig.json`, `package.json`) located at the root of the project.
</Callout>
