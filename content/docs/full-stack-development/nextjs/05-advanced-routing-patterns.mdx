Advanced routing conventions in Next.js enable complex UI patterns—such as split-view dashboards, contextual modals with shareable URLs, and conditional tab flows—without external state management libraries.

## 1. Parallel Routes (`@slot`)

Parallel Routes allow you to simultaneously render multiple independent pages within the same parent layout. Each parallel route is defined as a **slot** using the `@folder` naming convention.

```plaintext
app/
├── layout.tsx                 # Parent Layout receiving slots as props
├── page.tsx                   # Main route content (implicit @children)
├── @analytics/
│   ├── page.tsx               # Content for analytics slot
│   └── loading.tsx            # Isolated loading skeleton
└── @team/
    ├── page.tsx               # Content for team slot
    └── error.tsx              # Isolated error boundary
```

### Layout Slot Injection

Slots are passed directly as props to the layout component:

```tsx
// app/layout.tsx
export default function DashboardLayout({
  children,
  analytics,
  team,
}: {
  children: React.ReactNode;
  analytics: React.ReactNode;
  team: React.ReactNode;
}) {
  return (
    <div className="dashboard-grid">
      <main className="main-feed">{children}</main>
      <aside className="analytics-panel">{analytics}</aside>
      <aside className="team-panel">{team}</aside>
    </div>
  );
}
```

### The `default.tsx` Requirement

<Callout type="warning" title="Always Provide default.tsx">
During client-side (soft) navigation, Next.js maintains the active state of unchanged slots. However, on a hard browser refresh or direct URL navigation, Next.js cannot determine the state of unmatched slots. You **must** provide a `default.tsx` in every slot folder to render fallback UI or `null`, preventing 404 errors.
</Callout>

```tsx
// app/@team/default.tsx
export default function DefaultTeamSlot() {
  return null; // Or a fallback placeholder
}
```

## 2. Intercepting Routes (`(.)`, `(..)`, `(...)`)

Intercepting routes allow you to load and display a route from another part of your application within the current layout context (e.g. displaying an image modal without leaving the feed).

### Matching Conventions
- **`(.)`**: Intercepts segments on the **same level**.
- **`(..)`**: Intercepts segments **one level above**.
- **`(..)(..)`**: Intercepts segments **two levels above**.
- **`(...)`**: Intercepts segments starting from the **root `app` directory**.

---

## 3. The Complete Modal Pattern: Photo Gallery

Combining Parallel Routes and Intercepting Routes creates a shareable modal:
1. Clicking an image inside the feed opens the photo inside an overlay modal, changing the URL to `/photos/123`.
2. Refreshing the page or copying the link directly loads the standalone `/photos/123` full-page view.

### Directory Structure

```plaintext
app/
├── layout.tsx
├── page.tsx                         # Gallery Feed
├── @modal/
│   ├── default.tsx                  # Returns null
│   └── (.)photos/[id]/
│       └── page.tsx                 # Modal overlay component
└── photos/[id]/
    └── page.tsx                     # Standalone full page
```

### 1. Root Layout

```tsx
// app/layout.tsx
export default function RootLayout({
  children,
  modal,
}: {
  children: React.ReactNode;
  modal: React.ReactNode;
}) {
  return (
    <html lang="en">
      <body>
        {children}
        {modal}
      </body>
    </html>
  );
}
```

### 2. Slot Fallback

```tsx
// app/@modal/default.tsx
export default function DefaultModal() {
  return null;
}
```

### 3. Intercepted Modal (`app/@modal/(.)photos/[id]/page.tsx`)

```tsx
'use client';

import { useRouter } from 'next/navigation';

export default function PhotoModal({ params }: { params: { id: string } }) {
  const router = useRouter();

  return (
    <div className="modal-backdrop" onClick={() => router.back()}>
      <div className="modal-card" onClick={(e) => e.stopPropagation()}>
        <h2>Photo Modal #{params.id}</h2>
        <button onClick={() => router.back()}>Close</button>
      </div>
    </div>
  );
}
```

<Callout type="tip" title="Modal Dismissal Rule">
Always dismiss intercepted modals using `router.back()`. Calling `router.push('/')` creates redundant browser history entries and can prevent clean unmounting.
</Callout>
