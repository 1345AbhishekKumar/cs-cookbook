## The 6 Architecture Pillars

### 1. Foundations & Routing
Covers the core routing conventions of full-stack applications:
- Standard file-system routing (`layout`, `template`, `page`, `loading`, `error`, `not-found`).
- Advanced patterns: Parallel Routes (`@slot`), Intercepting Routes (`(.)`, `(..)`), and modal architectures.

### 2. Rendering & Component Directives
Explores the hybrid execution boundary between client and server:
- React Server Components (RSC) by default with zero client JavaScript bundle impact.
- The Directive System: `'use client'` (hydration boundary) vs `'use server'` (RPC action endpoint) vs `'use cache'` (cache boundary).
- Progressive Streaming with `<Suspense>` and Partial Prerendering (PPR) blending static shells with dynamic holes.

### 3. Data Fetching & Caching
Explains server-first data access and performance optimizations:
- Direct database querying in Server Components without REST API boilerplate.
- Next.js 15+ Async Request APIs (`await cookies()`, `await headers()`, `await params`).
- The 4 Caching Layers (Request Memoization, Data Cache, Full Route Cache, Router Cache) and Next.js 16's Cache Components (`cacheLife`, `cacheTag`, `updateTag`).
- Custom HTTP Route Handlers (`app/api/**/route.ts`) for webhooks and public REST endpoints.

### 4. Mutations & Forms
Transforms form handling into progressive enhancement:
- Server Actions for zero-API server mutations.
- React 19 Action Hooks: `useActionState` (form errors and state), `useFormStatus` (nested button loading spinners), and `useOptimistic` (zero-latency instant UI updates).

### 5. Media, Assets & Styling
Guarantees optimal Core Web Vitals and zero Cumulative Layout Shift (CLS):
- `next/image` with automated AVIF/WebP conversion, responsive sizing, and remote pattern whitelisting.
- `next/font` with zero-CLS font self-hosting for Google and local typography.
- `<Script>` loading strategies (`beforeInteractive`, `afterInteractive`, `lazyOnload`).
- Tailwind CSS v4 CSS-first design tokens and scoped CSS Modules.

### 6. Security, Production & Operations
Production-grade deployment and enterprise security:
- The Metadata API, dynamic OpenGraph social share cards with `ImageResponse`, and automated `sitemap.ts` / `robots.ts`.
- Edge Middleware (`proxy.ts`) for authentication redirects and URL rewrites.
- Zero-Trust Security with the Data Access Layer (DAL) pattern, `server-only` package, and React Taint APIs.
- Automated testing with Vitest and Playwright, Docker multi-stage containerization (`output: 'standalone'`), and static site exports (`output: 'export'`).
