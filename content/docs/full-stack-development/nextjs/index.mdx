## Next.js

Next.js is an open-source development framework built on top of Node.js, enabling React-based web application functionalities such as server-side rendering and generating static websites. It is optimal for building static sites, SEO-friendly pages, or backend services for mobile applications.

The framework offers multiple key features such as:

- **Pre-rendering**: Next.js generates your pages ahead of time, so the browser can download the static HTML and render it on the client-side.
- **Automatic code splitting**: Next.js splits your code into various bundles, which are loaded as needed, rather than all at once. This leads to faster page load times.
- **Hot Code Reloading**: This allows developers to save time and work more efficiently by automatically refreshing the page whenever a file is saved.
- **Built-in CSS support**: Next.js offers compatibility with styled-jsx, and any CSS-in-JS library, like styled-components or emotion.
- **Server-side rendering**: It serves each page on-demand, as a server response, improving performance and making the application SEO-friendly.
- **API routes**: Next.js supports creation of API endpoints, which can be used to build a backend application with CRUD operations.
- **TypeScript support**: Next.js provides automatic TypeScript configuration and compilation.

In summary, Next.js is a comprehensive solution for React development, offering a seamless developer experience.

---

### Modern Next.js (15 & 16) Architecture

Modern Next.js unifies full-stack React development around **Turbopack**, **React 19**, and **Server-First Web Architecture**:

- **React Server Components (RSC)**: Code runs on the server by default, eliminating unnecessary client JavaScript.
- **Strict Boundary Directives**: Explicit contracts between server and client execution (`'use client'`, `'use server'`, `'use cache'`).
- **Server Actions & React 19 Hooks**: Type-safe mutations directly from forms without writing boilerplate REST endpoints.
- **Turbopack Engine**: High-speed incremental bundler powering both development and production builds.
- **Predictable Caching & PPR**: Component-level caching (`'use cache'`) and Partial Prerendering (PPR) blending static shells with streaming dynamic holes.
