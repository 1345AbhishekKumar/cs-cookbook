Modern web applications categorize state into two distinct domains:
1. **Client State**: Transient, synchronous UI state owned locally by the browser (modals, user preferences, active form wizards).
2. **Server State**: Remote, asynchronous, cacheable data owned by an external database that can drift out of date (user profiles, product lists, notifications).

Managing these two concerns with dedicated tools eliminates boilerplate and synchronization bugs.
