## 1. Type-Level Operators

| Operator | Syntax | Description | Example |
| :--- | :--- | :--- | :--- |
| `keyof` | `keyof T` | Produces a union of all string/numeric keys of `T`. | `keyof { id: 1, name: "" } -> "id" \| "name"` |
| `typeof` | `typeof value` | Captures the static type of a JavaScript runtime value. | `const cfg = { a: 1 }; type Cfg = typeof cfg;` |
| Indexed Access | `T[K]` | Looks up the property type for key `K` on type `T`. | `User["email"] -> string` |
| `as` | `expr as Type` | Type Assertion (override compiler's inferred type). | `const el = e.target as HTMLInputElement;` |
| `as const` | `expr as const` | Locks object/array properties into `readonly` literal types. | `const methods = ["GET", "POST"] as const;` |
| `satisfies` | `expr satisfies Type` | Validates value matches contract without widening literal types. | `const c = { a: 1 } satisfies Record<string, number>;` |
| `is` | `arg is Type` | Custom Type Predicate for user-defined type guards. | `function isUser(x: unknown): x is User` |
| `in` | `K in Keys` | Iterates over union keys in mapped types. | `[K in "a" \| "b"]: string` |
| `infer` | `infer R` | Declares a type variable to be deduced inside conditional types. | `T extends (...args: any[]) => infer R ? R : never` |

## 2. Standard Built-in Utility Types

| Utility Type | Input Type | Output |
| :--- | :--- | :--- |
| `Partial<T>` | Object `T` | Makes all properties optional (`?`). |
| `Required<T>` | Object `T` | Removes optionality from all properties. |
| `Readonly<T>` | Object `T` | Marks all properties as `readonly`. |
| `Record<K, T>` | Keys `K`, Value `T` | Constructs an object type with keys `K` and values `T`. |
| `Pick<T, K>` | Object `T`, Keys `K` | Extracts a subset of properties from `T`. |
| `Omit<T, K>` | Object `T`, Keys `K` | Drops specified properties from `T`. |
| `Exclude<T, U>` | Union `T`, Types `U` | Removes members in `U` from union `T`. |
| `Extract<T, U>` | Union `T`, Types `U` | Retains only members in `U` from union `T`. |
| `NonNullable<T>`| Any type `T` | Strips `null` and `undefined` from `T`. |
| `Parameters<T>` | Function `T` | Tuple of function parameter types. |
| `ReturnType<T>` | Function `T` | The return type of function `T`. |
| `Awaited<T>` | Promise/Type `T` | Recursively unwraps Promise resolution type. |

## 3. Top and Bottom Types Matrix

| Type | Assignable To Everything? | Anything Assignable To It? | Safe to Access Properties? |
| :--- | :--- | :--- | :--- |
| **`any`** | **Yes** | **Yes** | Yes (No compiler checks; dangerous!) |
| **`unknown`** | No (Must narrow first) | **Yes** | No (Forces safe narrowing first) |
| **`never`** | **Yes** (Bottom type) | No (Uninhabited) | N/A (Cannot exist) |
| **`void`** | Only `undefined` | Undefined/Null | No (Represents no return value) |

## 4. Common Compiler Errors & Fixes

### 1. `Object is possibly 'undefined'`
- **Cause**: Accessing an array index or optional property without checking.
- **Fix**: Use optional chaining (`item?.property`) or an explicit `if (item)` guard.

### 2. `Type 'string' is not assignable to type '"admin" | "user"'`
- **Cause**: Passing a widened `string` variable into a strict string literal union.
- **Fix**: Use `as const` on the source object, or declare the variable with the union type.

### 3. `Property 'xyz' does not exist on type 'never'`
- **Cause**: Control flow analysis has eliminated all possibilities, leaving the variable as `never`.
- **Fix**: Re-check your conditional branching to ensure an impossible branch was not created.
