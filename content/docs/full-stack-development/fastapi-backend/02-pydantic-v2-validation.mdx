FastAPI uses **Pydantic V2** (rewritten in Rust) to parse, validate, and serialize JSON payloads.

## 1. Defining Request Bodies with `BaseModel` & `Field`

```python
from pydantic import BaseModel, Field, EmailStr

class CreateProductSchema(BaseModel):
    name: str = Field(min_length=2, max_length=100, description="Product title")
    price: float = Field(gt=0, description="Price must be strictly positive")
    sku: str = Field(pattern=r"^[A-Z]{3}-\d{4}$", description="SKU format: ABC-1234")
    tags: list[str] = Field(default_factory=list)
```

FastAPI automatically parses the JSON request body and validates it against the schema:

```python
from fastapi import FastAPI, status

app = FastAPI()

@app.post("/products", status_code=status.HTTP_201_CREATED)
async def create_product(product: CreateProductSchema):
    # 'product' is a fully typed and validated Pydantic model instance
    print("Saving product:", product.name)
    return {"message": "Product created", "sku": product.sku}
```

## 2. Modern Validation with `@field_validator`

In Pydantic V2, the legacy `@validator` decorator has been replaced with `@field_validator`:

```python
from pydantic import BaseModel, field_validator

class UserRegistration(BaseModel):
    username: str
    password: str

    @field_validator("username")
    @classmethod
    def validate_username_alphanumeric(cls, v: str) -> str:
        if not v.isalnum():
            raise ValueError("Username must contain only letters and numbers")
        return v.lower()
```

## 3. Data Protection with `response_model`

A major security vulnerability in web APIs is accidentally leaking sensitive database fields (such as `hashed_password` or internal flags) to the client.

FastAPI's **`response_model`** guarantees that outgoing data is filtered through an explicit schema before JSON serialization:

```python
from pydantic import BaseModel, EmailStr
from fastapi import FastAPI

app = FastAPI()

# Database Representation (Internal)
class UserInDB(BaseModel):
    id: int
    email: EmailStr
    hashed_password: str
    is_superuser: bool

# Public Representation (Sent to Client)
class UserPublic(BaseModel):
    id: int
    email: EmailStr

@app.get("/users/{user_id}", response_model=UserPublic)
async def get_user(user_id: int):
    user_db = UserInDB(
        id=user_id,
        email="alex@example.com",
        hashed_password="secret_argon2_hash",
        is_superuser=False
    )
    # FastAPI automatically filters out 'hashed_password' and 'is_superuser'!
    return user_db
```

## 4. Exporting Pydantic Models

In Pydantic V2, conversion methods were updated:
- Use `.model_dump()` instead of `.dict()`.
- Use `.model_dump_json()` instead of `.json()`.

```python
product_dict = product.model_dump(exclude_unset=True)
json_string = product.model_dump_json(indent=2)
```
