## 1. Parameter Functions Reference

| Function | Extraction Source | Example Usage |
| :--- | :--- | :--- |
| `Path(...)` | URL path parameter segment | `item_id: Annotated[int, Path(ge=1)]` |
| `Query(...)` | URL query string parameter | `search: Annotated[str, Query(min_length=3)]` |
| `Header(...)` | HTTP request header | `user_agent: Annotated[str, Header()]` |
| `Cookie(...)` | Browser HTTP cookie | `session_id: Annotated[str, Cookie()]` |
| `Body(...)` | JSON request payload body | `payload: Annotated[dict, Body()]` |
| `Form(...)` | Form-encoded body (`application/x-www-form-urlencoded`) | `username: Annotated[str, Form()]` |
| `File(...)` | File upload body (`multipart/form-data`) | `avatar: Annotated[UploadFile, File()]` |
| `Depends(...)` | Injected dependency function | `db: Annotated[Session, Depends(get_db)]` |
| `Security(...)` | Dependency with specific security scopes | `user: Annotated[User, Security(get_user, scopes=["read"])]` |

## 2. Pydantic V2 Field Constraints Reference

| Constraint | Applicable Types | Description |
| :--- | :--- | :--- |
| `gt` / `ge` | Number (int, float) | Greater than / Greater than or equal to. |
| `lt` / `le` | Number (int, float) | Less than / Less than or equal to. |
| `min_length` / `max_length` | String, List, Dict | Length/element boundary limits. |
| `pattern` | String | Regular expression pattern the string must match. |
| `default_factory` | Any | Callable function invoked to generate default value (e.g. `list`, `datetime.now`). |
| `description` | Any | Documentation string emitted to interactive Swagger UI. |

## 3. Common HTTP Status Codes

| Code | Constant | Meaning |
| :--- | :--- | :--- |
| `200` | `status.HTTP_200_OK` | Request succeeded. |
| `201` | `status.HTTP_201_CREATED` | New resource created successfully. |
| `204` | `status.HTTP_204_NO_CONTENT` | Request succeeded with no response body. |
| `400` | `status.HTTP_400_BAD_REQUEST` | Malformed request or client business logic error. |
| `401` | `status.HTTP_401_UNAUTHORIZED` | Missing or invalid authentication token. |
| `403` | `status.HTTP_403_FORBIDDEN` | Authenticated, but lacks required role/permission. |
| `404` | `status.HTTP_404_NOT_FOUND` | Resource does not exist. |
| `422` | `status.HTTP_422_UNPROCESSABLE_ENTITY` | Pydantic validation failed for request payload. |
| `500` | `status.HTTP_500_INTERNAL_SERVER_ERROR` | Unhandled server exception. |

## 4. Top FastAPI Production Gotchas

### 1. Blocking the Async Event Loop
- **The Bug**: Calling blocking synchronous code (`time.sleep()`, synchronous `requests.get()`, or synchronous database drivers) inside an `async def` endpoint.
- **The Consequence**: Freezes the entire Python event loop, blocking all other concurrent users from receiving responses.
- **The Fix**: Use non-blocking async equivalents (`asyncio.sleep()`, `httpx.AsyncClient()`), or define the endpoint as a synchronous `def` function so FastAPI offloads it to a background threadpool.

### 2. Forgetting `expire_on_commit=False` in SQLAlchemy
- **The Bug**: Attempting to read model attributes after calling `await session.commit()`.
- **The Fix**: Always configure `async_sessionmaker(..., expire_on_commit=False)`.
