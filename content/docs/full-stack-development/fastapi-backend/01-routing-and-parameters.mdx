## 1. Minimal Application Setup

```python
from fastapi import FastAPI, status

app = FastAPI(
    title="Cloud Inventory API",
    version="1.0.0",
    docs_url="/docs",      # Interactive Swagger UI
    redoc_url="/redoc"     # Clean ReDoc documentation
)

@app.get("/health", status_code=status.HTTP_200_OK, tags=["System"])
async def health_check():
    return {"status": "healthy", "version": "1.0.0"}
```

Visit `http://localhost:8000/docs` in your browser to inspect and interactively test your live API endpoints.

## 2. Parameter Extraction with `Annotated`

Modern FastAPI code standardizes on Python's `typing.Annotated`. This separates your business type annotations from FastAPI's validation metadata:

```python
from typing import Annotated
from fastapi import FastAPI, Path, Query, status

app = FastAPI()

@app.get("/items/{item_id}", status_code=status.HTTP_200_OK)
async def get_item(
    # Path parameter: Extracted from URL path, must be >= 1
    item_id: Annotated[int, Path(ge=1, description="Unique database ID of the item")],
    
    # Query parameter: Extracted from ?search=... (Optional)
    search: Annotated[str | None, Query(max_length=50, description="Search term filter")] = None,
    
    # Query parameter: Pagination limit with default and bounds
    limit: Annotated[int, Query(ge=1, le=100)] = 20
):
    return {
        "item_id": item_id,
        "search": search,
        "limit": limit
    }
```

### Automatic 422 Validation
If a client sends `GET /items/abc`, FastAPI immediately interrupts execution and returns a structured JSON error:

```json
{
  "detail": [
    {
      "type": "int_parsing",
      "loc": ["path", "item_id"],
      "msg": "Input should be a valid integer, unable to parse string as an integer",
      "input": "abc"
    }
  ]
}
```

## 3. Headers & Cookies

Extract HTTP headers and browser cookies using the same declarative syntax:

```python
from typing import Annotated
from fastapi import Header, Cookie

@app.get("/profile")
async def read_profile(
    user_agent: Annotated[str | None, Header()] = None,
    session_token: Annotated[str | None, Cookie()] = None
):
    return {
        "user_agent": user_agent,
        "session_present": session_token is not None
    }
```

<Callout type="info" title="Automatic Header Underscore Conversion">
FastAPI automatically converts Python snake_case variable names (`user_agent`) to standard HTTP kebab-case headers (`User-Agent`).
</Callout>
