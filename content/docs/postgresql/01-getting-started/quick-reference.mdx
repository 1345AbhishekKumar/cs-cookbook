## Connecting

```bash
psql -h localhost -p 5432 -U myuser -d mydb          # flags
psql "postgresql://myuser:secret@localhost:5432/mydb" # URL
psql -f schema.sql                                    # run a file and exit
```

| Env var | Meaning |
| :--- | :--- |
| `PGHOST` / `PGPORT` | Server host / port |
| `PGUSER` / `PGDATABASE` | Default user / database |
| `PGPASSWORD` | Password (avoid in shared shells) |
| `PGSSLMODE` | `require` for managed/cloud databases |

## `psql` Meta-Commands

| Command | Does |
| :--- | :--- |
| `\l` | List databases |
| `\c dbname` | Connect to a database |
| `\dt` / `\dt *.*` | List tables (current schema / all) |
| `\d table` | Describe a table |
| `\dn` / `\du` / `\df` / `\dv` | Schemas / roles / functions / views |
| `\x` | Toggle expanded output |
| `\timing` | Toggle query timing |
| `\i file.sql` | Run a file |
| `\e` | Edit query in an editor |
| `\h SELECT` | SQL syntax help |
| `\?` | Meta-command help |
| `\q` | Quit |

<Callout type="warn" title="SQL vs. meta-commands">
SQL ends in `;` and goes to the **server**. `\d`-style commands are handled by the **client** and won't work in your app's SQL.
</Callout>

## Type Matrix

| Need | Use | Not |
| :--- | :--- | :--- |
| Whole numbers | `integer`, `bigint` | — |
| Money | `numeric(12,2)` or `bigint` cents | `float` |
| Strings | `text` | `varchar(255)` (no benefit) |
| Instants | `timestamptz` | `timestamp` |
| Date only | `date` | — |
| Durations | `interval` | — |
| Flags | `boolean` | `char(1)` |
| Public ids | `uuid` + `uuidv7()` | random UUIDv4 |
| Internal ids | `bigint GENERATED ALWAYS AS IDENTITY` | `serial` (legacy) |
| Semi-structured | `jsonb` | `json` (unless you need exact text) |
| Tags | `text[]` | comma-separated string |
| Periods | `tstzrange` | two nullable columns |
| Fixed sets | `CHECK (x IN (...))` or lookup table | free `text` |

## Constraint Syntax

```sql
CREATE TABLE t (
    id         uuid        PRIMARY KEY DEFAULT uuidv7(),
    parent_id  bigint      REFERENCES other(id) ON DELETE RESTRICT,
    code       text        NOT NULL UNIQUE,
    kind       text        NOT NULL CHECK (kind IN ('a','b')),
    amount     bigint      NOT NULL CHECK (amount >= 0),
    created_at timestamptz NOT NULL DEFAULT now()
);

CREATE INDEX idx_t_parent ON t (parent_id);   -- index your FKs!
```

| Constraint | Effect |
| :--- | :--- |
| `PRIMARY KEY` | Unique + not null + index |
| `UNIQUE` | No duplicates |
| `NOT NULL` | Value required |
| `CHECK` | Boolean predicate per row |
| `FOREIGN KEY` | Referenced row must exist |
| `ON DELETE CASCADE / SET NULL / RESTRICT` | Referential action |
| `EXCLUDE` | No overlapping pairs (e.g. ranges) |

## Generated Columns & Identity

```sql
id    bigint  GENERATED ALWAYS AS IDENTITY PRIMARY KEY   -- auto number
total numeric GENERATED ALWAYS AS (price * (1 + tax)) STORED
```

| Form | Computed |
| :--- | :--- |
| `GENERATED ... VIRTUAL` (PG18 default) | On read |
| `GENERATED ... STORED` | On write |

## Common `ALTER TABLE` Operations

```sql
ALTER TABLE t ADD COLUMN c integer NOT NULL DEFAULT 0;
ALTER TABLE t RENAME COLUMN a TO b;
ALTER TABLE t ALTER COLUMN c DROP NOT NULL;
ALTER TABLE t ADD CONSTRAINT ck CHECK (c >= 0);
ALTER TABLE t DROP COLUMN c;
```

## First Errors, Explained

| Error | Meaning |
| :--- | :--- |
| `connection refused` | Server not running / wrong host or port |
| `role "x" does not exist` | Wrong username (or role not created) |
| `database "x" does not exist` | Wrong database name |
| `password authentication failed` | Wrong password |
| `permission denied for ...` | Missing `GRANT` |
| `relation "x" does not exist` | Table missing or wrong `search_path` |
| `syntax error at end of input` | Missing `;` |
| `duplicate key value violates unique constraint` | A `UNIQUE`/`PRIMARY KEY` rule worked as intended |
| `must be owner of ...` | You don't own the object you're altering |

```text
\timing on          -- time every query
\x auto            -- vertical output when rows get wide
\set ON_ERROR_STOP on   -- stop a script at the first error
psql -E            -- echo the SQL behind meta-commands (great for learning)
```
