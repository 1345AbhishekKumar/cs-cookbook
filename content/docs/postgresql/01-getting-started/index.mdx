Welcome to **Stage 1: Getting Started** — the zero-to-usable stage.

If you have never touched a database, start here. By the end of this stage you will have a real PostgreSQL server running, you'll be comfortable at the `psql` prompt, and you'll have created a proper schema with the right types and constraints.

---

## Pedagogical Philosophy

<Callout type="info" title="Learn by Running, Not by Reading">
PostgreSQL is a tool. You cannot learn a tool by reading about it. Every lesson here asks you to **run something**: start a server, connect, create a table, insert a row, break a constraint on purpose and read the error. Five minutes of typing beats an hour of reading.
</Callout>

By the end of this stage you will be able to:

- Explain in plain language what a relational database is and why PostgreSQL is a good default choice.
- Install PostgreSQL (Docker, native, or cloud) and connect with `psql`.
- Create databases, users, and schemas, and navigate them confidently.
- Choose the right PostgreSQL data type for real data (including money, time, and UUIDs).
- Define tables with primary keys, foreign keys, checks, and defaults.
