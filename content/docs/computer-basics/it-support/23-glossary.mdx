## A

### Access Control Vestibule (Mantrap)

A physical security entryway featuring two interlocking doors where the second door cannot unlock until the first door closes and authentication is confirmed, preventing tailgating into data centers.

_Module: Security_

### Active Directory Domain Services (AD DS)

Microsoft's centralized directory service providing authentication, group policy, and resource authorization across enterprise networks using Kerberos, LDAP, and DNS.

_Module: Directory Services_

### AGDLP Principle

Microsoft's role-based access control rule: Accounts go into Global Groups, which go into Domain Local Groups, which are granted Permissions on resources.

_Module: Directory Services_

### Abstraction

Hiding a complex system's internal mechanics behind a simpler, intuitive interface so users and technicians can work without knowing every detail. For support, it explains why users only see the symptom while you troubleshoot the layer underneath.

_Module: Foundations_

### Address Bus

A dedicated set of bus lines from the CPU to the Memory Controller Chip that carries the location of requested data in RAM, not the data itself. For support, a faulty address path shows up as addressing errors or blue screens rather than slow storage.

_Module: Hardware_

### Algorithm

A step-by-step set of instructions or rules designed to solve a specific computational or logical problem. For support, recognizing the algorithm behind a process helps you predict its behavior and spot where it breaks.

_Module: Foundations_

### Android

A mobile operating system built on the Linux kernel, widely deployed across smartphones, tablets, and smart devices. For support, expect hardware fragmentation and vendor-specific settings across Android fleets.

_Module: OS_

### Application

A user-space program designed to perform specific tasks for end users, such as word processing, web browsing, or media editing. For support, isolate application faults from OS faults before reinstalling anything.

_Module: OS_

### ASCII

The oldest standard character encoding, using 7 bits to represent 128 characters including English letters, digits 0-9, and punctuation. For support, it explains why legacy files and protocols break on non-English text.

_Module: Foundations_

### ATA / SATA

Advanced Technology Attachment / Serial ATA, the common interface and protocol for connecting internal hard drives and SSDs over thin serial cables. For support, check SATA mode, cables, and port health when a drive is not detected.

_Module: Hardware_

### ATX (Advanced Technology Extended)

The industry-standard full-size desktop motherboard form factor (12 x 9.6 inches) with up to 7 expansion slots. For support, it determines case compatibility, slot count, and replacement board sizing.

_Module: Hardware_

## B

### Blade Server

An ultra-dense server architecture where modular compute boards (blades) slide into a shared chassis that pools power supplies, cooling fans, and network switching.

_Module: Systems Administration_

### Botnet

A network of infected computing devices (zombies) controlled remotely by an adversary (botmaster) through Command and Control (C2) servers to execute DDoS attacks, spam, or credential stuffing.

_Module: Security_

### Backward Compatible

The ability of a newer standard or port, such as USB 3.0 or PCIe Gen 4, to interoperate with older devices. For support, it means you can usually plug in legacy hardware first and rule out compatibility before replacing parts.

_Module: Hardware_

### Binary System (Base-2)

The numerical language of computers, representing all values and instructions with only the digits 0 and 1. For support, it underpins everything from subnet masks to permission bits.

_Module: Foundations_

### BIOS / UEFI

Low-level motherboard firmware that initializes hardware, runs POST diagnostics, and hands control to the OS bootloader. UEFI is the modern 32/64-bit replacement for legacy BIOS, adding a graphical interface, mouse support, Secure Boot, and GPT drive support. For support, this is where you fix boot order, enable virtualization, and resolve no-boot faults.

_Module: Hardware, OS_

### Bit (Binary Digit)

The smallest unit of digital storage, a single binary state of 0 or 1. For support, bits versus bytes confusion is a common cause of misquoted network speeds and storage sizes.

_Module: Foundations_

### BitLocker

Full-volume drive encryption built into Windows Pro and Enterprise that protects data if a machine is stolen or accessed offline. For support, always confirm recovery keys are escrowed before troubleshooting boot or hardware changes.

_Module: OS_

### Block Storage

A storage architecture that splits file data into uniform chunks (blocks) distributed non-contiguously across sectors for faster access and better allocation. For support, it explains why defragmentation and block alignment affect performance.

_Module: OS_

### Boot

The initialization process of starting a computer and loading the OS kernel into memory from an unpowered state. For support, identifying exactly where boot stalls narrows the fault to firmware, bootloader, or OS.

_Module: OS_

### Bootloader

A small program, such as GRUB or Windows Boot Manager, in the drive's boot sector that loads the OS kernel from storage into RAM. For support, a missing or corrupt bootloader is a top cause of "no OS found" errors.

_Module: OS_

### BYOD (Bring Your Own Device)

An organizational policy allowing employees to use personal phones, tablets, and laptops for corporate work under security sandboxes and compliance controls. For support, it means managing enrollment, wiping, and privacy boundaries on hardware you do not own.

_Module: Hardware_

### Byte

A group of 8 bits that can represent 256 unique values (0-255) and hold one ASCII character. For support, bytes are the basis for sizing RAM, storage, and file transfers.

_Module: Foundations_

## C

### Change Advisory Board (CAB)

A cross-functional committee of IT, network, security, and business leads that reviews, schedules, and approves Requests for Change (RFCs) to prevent infrastructure outages.

_Module: Systems Administration_

### CIA Triad

The core information security model balancing Confidentiality (authorized access only), Integrity (data accuracy and non-tampering), and Availability (reliable uptime and access).

_Module: Security_

### CUPS (Common Unix Printing System)

The modular open-source printing system standard across Linux and macOS using IPP (Internet Printing Protocol, port 631) for centralized print job spooling and driver distribution.

_Module: Systems Administration_

### Cache (CPU)

Ultra-fast SRAM integrated into the CPU die that stores frequently accessed instructions and data to avoid slow trips to system RAM, organized in L1, L2, and L3 levels. For support, cache explains why CPUs feel fast on repeated tasks and why cache-clearing rarely fixes real faults.

_Module: Hardware_

### Character Encoding

The standardized dictionary that assigns binary values to letters, numbers, and symbols so humans can read text. For support, encoding mismatches cause garbled characters in files, email, and web pages.

_Module: Foundations_

### Charge Cycle

One full discharge of 100 percent of a rechargeable battery's capacity followed by a full recharge, used as the primary metric of battery degradation and lifespan. For support, cycle count is your first check on swelling or short-runtime batteries.

_Module: Hardware_

### Chipset

The set of integrated circuits on a motherboard, historically Northbridge and Southbridge and now the Platform Controller Hub, that coordinates data flow between CPU, RAM, and peripherals. For support, chipset drivers resolve many mysterious USB, storage, and stability faults.

_Module: Hardware_

### Chrome OS

A lightweight, cloud-centric operating system from Google built on the Linux kernel and centered on the Chrome browser. For support, most Chrome OS faults are identity, network, or policy issues rather than local hardware faults.

_Module: OS_

### Clock Cycle and Clock Speed

A clock cycle is one pulse of work performed by the CPU, and clock speed is the frequency of those cycles per second, measured in gigahertz (GHz). For support, higher clocks mean more heat and power draw, which matters when diagnosing throttling.

_Module: Hardware_

### CMOS RAM and Battery

Low-power volatile memory holding BIOS configuration and the real-time clock, kept energized without wall power by a coin-cell CMOS battery. For support, a dead CMOS battery shows up as reset clocks and lost BIOS settings on every cold boot.

_Module: Hardware_

### Command Line Interface (CLI)

A text-based shell where users type structured commands to run programs, script tasks, and manage system resources. For support, the CLI gives you repeatable diagnostics and fixes that GUIs cannot.

_Module: OS_

### Compiler

Software, first invented by Admiral Grace Hopper, that translates human-readable source code into machine code of zeros and ones. For support, knowing whether code is compiled or interpreted helps you trace build versus runtime errors.

_Module: Foundations_

### Computer

A device that stores and processes data by performing rapid mathematical calculations. For support, this definition keeps the focus on data in, computation, and data out when isolating faults.

_Module: Foundations_

### Computer File

A discrete digital resource on a storage device containing raw data such as documents, images, audio, or executable binaries, managed by the file system. For support, treat every file as data plus metadata when diagnosing access faults.

_Module: OS_

### CPU (Central Processing Unit)

The primary computing engine that executes instructions and performs calculations through its Arithmetic Logic Unit (ALU), Control Unit (CU), and registers. For support, the CPU is rarely the failed part, so verify cooling, power, and RAM before blaming it.

_Module: Hardware_

### CPU Sockets (LGA vs. PGA)

Motherboard connectors for processors: LGA (Land Grid Array) places pins on the socket, while PGA (Pin Grid Array) places pins on the CPU itself. For support, socket type dictates compatible CPUs and how carefully you handle pins during replacement.

_Module: Hardware_

### Cryptography

The discipline of writing and solving secure codes through mathematics to protect messages from third parties. For support, it underpins passwords, certificates, and encryption tools you configure every day.

_Module: Foundations_

## D

### Directory Service

A network database optimized for fast read and search operations that stores users, computers, groups, and security policies hierarchically (e.g., Active Directory, OpenLDAP).

_Module: Directory Services_

### DIT (Directory Information Tree)

The hierarchical inverted-tree structure used by LDAP to organize directory objects from root domain components down to organizational units and leaf objects.

_Module: Directory Services_

### DKIM (DomainKeys Identified Mail)

An email authentication standard that attaches a cryptographic digital signature to outgoing email headers, verified against the sender's public key published in DNS.

_Module: Systems Administration_

### DMARC (Domain-based Message Authentication, Reporting, and Conformance)

An email security protocol linking SPF and DKIM that tells receiving mail gateways whether to accept, quarantine, or reject messages that fail authentication.

_Module: Systems Administration_

### Domain Controller (DC)

A Windows Server running the Active Directory Domain Services role that stores the directory database (`ntds.dit`), authenticates users via Kerberos, and enforces Group Policies.

_Module: Directory Services_

### Data Blocks

Fixed-size storage units, commonly 4 KB clusters, where the file system writes parts of a file to disk. For support, block and cluster size explain slack space and why many small files waste capacity.

_Module: OS_

### DDR SDRAM

Double Data Rate Synchronous DRAM, which transfers data on both the rising and falling edges of the clock to double memory bandwidth, spanning DDR1 through DDR5. For support, generations are not interchangeable, so match the board's DDR version exactly.

_Module: Hardware_

### Decimal Form (Base-10 System)

The standard human counting system based on powers of 10, using the digits 0 through 9. For support, it is the reference point when converting between human numbers and binary or hexadecimal.

_Module: Foundations_

### Digital Divide

The gap in access to modern digital technology and literacy between individuals and communities. For support, it reminds you to design instructions and access paths for users with very different devices and connectivity.

_Module: Foundations_

### DIMM (Dual Inline Memory Module)

The standard physical form factor for desktop RAM sticks, with keyed notches that prevent installing an incompatible DDR generation. For support, check the notch position and board spec before seating RAM.

_Module: Hardware_

### Distributions (Linux Distros)

Complete operating systems built around the Linux kernel plus package managers, utilities, and desktop environments, such as Ubuntu, Debian, and Red Hat. For support, the distro determines package commands and support lifecycle.

_Module: OS_

### DRAM vs. SRAM

DRAM (Dynamic RAM) uses one transistor plus one capacitor per bit and needs constant refresh, serving as system RAM, while SRAM (Static RAM) uses flip-flops, needs no refresh, and serves as CPU cache. For support, this tradeoff explains why cache is fast and tiny while RAM is slower and large.

_Module: Hardware_

## E

### Electrostatic Discharge (ESD)

The sudden flow of static electricity between objects on contact, which can silently damage chips during assembly. For support, always use a grounded wrist strap and mat when handling exposed components.

_Module: Hardware_

### Etcher.io

A popular cross-platform utility for writing OS installation images (.iso) to USB drives to make them bootable from BIOS or UEFI. For support, it is the fastest reliable path to clean bootable media.

_Module: OS_

### External Data Bus (EDB)

The physical set of parallel traces linking CPU, memory, and motherboard components that transports raw binary data in widths from 8 to 64 bits. For support, bus width is one reason identical clock speeds can perform very differently.

_Module: Hardware_

## F

### FSMO Roles (Flexible Single Master Operations)

Five specialized single-master roles in Active Directory (Schema Master, Domain Naming Master, RID Master, PDC Emulator, Infrastructure Master) that prevent replication conflicts.

_Module: Directory Services_

### File Extension

A suffix such as .docx, .jpg, or .exe that identifies file type and tells the OS which default program should open it. For support, hidden or spoofed extensions are a classic malware vector, so show them during triage.

_Module: OS_

### File System

The organizational framework, directory hierarchy, and database that governs how files are named, indexed, stored, and retrieved on storage, such as NTFS, ext4, or APFS. For support, the file system determines permissions, limits, and recovery options.

_Module: OS_

### Finder

The default visual file manager and graphical desktop interface on Apple macOS computers. For support, it is where you verify mounts, permissions, and search-index faults on Macs.

_Module: OS_

### Folders / Directories

Virtual containers the file system uses to organize files hierarchically into folders and subdirectories. For support, path errors and permission inheritance here cause most "file not found" tickets.

_Module: OS_

### Form Factor

The standardized physical size, shape, mounting holes, and layout of motherboards, power supplies, and chassis. For support, matching form factor prevents returns when swapping boards, PSUs, or cases.

_Module: Hardware_

## G

### Group Policy Object (GPO)

A virtual collection of administrative settings, security restrictions, and scripts managed in Active Directory that enforces configuration compliance across domain-joined Windows machines.

_Module: Directory Services_

## H

### Hardware Resource Deficiency

A bottleneck where physical CPU, RAM, or disk I/O is fully exhausted, causing latency and slow response. For support, check Task Manager or Activity Monitor first to identify which resource is saturated.

_Module: OS_

### HDD (Hard Disk Drive)

Non-volatile mechanical storage using spinning magnetic platters and moving actuator arms to read and write persistent data. For support, clicking noises, slow seeks, and SMART warnings mean back up and replace immediately.

_Module: Hardware_

### Heat Sink and Thermal Paste

A finned metal cooler that dissipates CPU heat, paired with thermal paste that fills microscopic air gaps to maximize conduction between CPU and sink. For support, dried paste and loose sinks are prime suspects in thermal throttling and shutdowns.

_Module: Hardware_

### HFS+ / APFS

Apple file systems: HFS+ is the legacy journaling system and APFS is the modern 64-bit encrypted, crash-resistant standard across Apple devices. For support, APFS containers and snapshots change how you resize and recover Mac volumes.

_Module: OS_

### Hostname

A unique human-readable label assigned to a computer to identify it on local networks and internet protocols. For support, consistent hostnames make inventory, remote access, and log searches far easier.

_Module: OS_

## I

### I/O Management

The kernel subsystem that manages communication between the OS and input/output devices through device drivers. For support, faulty or missing drivers here explain undetected peripherals and I/O hangs.

_Module: OS_

### Information Technology (IT)

The use of computers, storage, networking, physical devices, infrastructure, and processes to create, process, store, secure, and exchange electronic data. For support, this scope defines everything you are responsible for keeping running.

_Module: Foundations_

### iOS

Apple's proprietary mobile operating system for iPhone and iPad, emphasizing sandboxed security, touch UX, and power efficiency. For support, expect locked bootloaders and app-sandbox limits when troubleshooting iPhones.

_Module: OS_

### IT/OT Convergence

The integration of data-centric Information Technology systems with machine-monitoring Operational Technology systems across industrial environments. For support, it means IT tickets increasingly involve sensors, PLCs, and uptime-critical plant networks.

_Module: Foundations_

### ITX (Information Technology Extended)

A family of ultra-compact motherboard form factors, including Mini-ITX, Nano-ITX, and Pico-ITX, built for small-form-factor cubes, home theaters, and embedded hardware. For support, expect tight thermals and limited slots in ITX builds.

_Module: Hardware_

## K

### Kernel

The supervisor core of an operating system running in Ring 0 with full hardware control, managing storage, process scheduling, memory, and I/O devices. For support, kernel panics and bug checks point to drivers, RAM, or hardware rather than apps.

_Module: OS_

## L

### LDAP (Lightweight Directory Access Protocol)

The open-standard network protocol (RFC 4511, port 389 / 636 LDAPS) used to query and modify directory services databases arranged in hierarchical Directory Information Trees.

_Module: Directory Services_

### Linux OS

One of the largest open-source operating systems in the world, created by Linus Torvalds, powering cloud infrastructure, servers, and Android. For support, Linux fluency unlocks most server, network, and cloud troubleshooting.

_Module: Foundations_

### Logic Gates

Physical electronic components built from transistors that compute binary outputs from logical input rules. For support, gate logic is the root cause model behind POST codes and hardware self-tests.

_Module: Foundations_

### Logs

Chronological system files recording operational events, software errors, logins, and hardware status. For support, logs are the first evidence source: read them before changing anything.

_Module: OS_

## M

### macOS

Apple's Unix-based desktop operating system preloaded on Mac computers, tightly integrated with Apple hardware. For support, use built-in recovery, Time Machine, and system reports before third-party tools.

_Module: OS_

### Memory Controller Chip (MCC)

The hardware bridge that retrieves requested rows from system RAM based on address-bus queries and places the bytes onto the External Data Bus. For support, memory-controller faults surface as multi-stick RAM errors that survive individual stick swaps.

_Module: Hardware_

### Memory Management

A core kernel function that allocates physical RAM, isolates per-process memory spaces, and manages virtual memory swapping. For support, leaks and pressure here explain slowdowns that reboots only temporarily fix.

_Module: OS_

### Metadata

Structured descriptors giving context about a file, such as creator, timestamps, permissions, size, and extension. For support, metadata reveals ownership, tampering, and permission faults faster than opening the file.

_Module: OS_

### Microsoft Terminal Services Client (MSTSC)

The built-in Windows client used to initiate Remote Desktop Protocol (RDP) connections to remote workstations and servers. For support, mstsc is the quickest built-in path to a remote Windows desktop.

_Module: OS_

### Motherboard

The primary printed circuit board of the computer that holds components and routes all power and data buses. For support, treat it as the interconnect suspect when multiple unrelated subsystems fail together.

_Module: Hardware_

## N

### NFS (Network File System)

A client-server protocol (port 2049) native to Unix and Linux operating systems allowing remote computers to access files over a network as if mounted locally.

_Module: Systems Administration_

### NIST SP 800-88

The United States federal standard for media sanitization, defining Clear (logical overwrite), Purge (degauss / cryptographic erase), and Destroy (physical shredding) levels.

_Module: Systems Administration_

### NTP (Network Time Protocol)

A networking protocol operating over UDP port 123 that synchronizes system clocks across devices to Coordinated Universal Time (UTC), essential for Kerberos and TLS validation.

_Module: Systems Administration_

### Northbridge and Southbridge

The legacy two-chip chipset design where Northbridge handled high-speed RAM and graphics and Southbridge managed slower storage and I/O such as SATA, USB, and audio. For support, recognizing this split helps when reading older board diagrams and manuals.

_Module: Hardware_

### NVMe (Non-Volatile Memory Express)

A modern high-speed storage protocol designed for SSDs that runs over the PCIe bus with ultra-low latency and deep parallel queues. For support, NVMe requires PCIe lanes and correct BIOS settings to reach rated speeds.

_Module: Hardware_

## O

### Organizational Unit (OU)

A subdivision container within an Active Directory domain used to organize user accounts, computers, and groups, and the smallest administrative unit to which Group Policy Objects (GPOs) can be linked.

_Module: Directory Services_

### Open Source

A software model where copyright holders let anyone view, modify, enhance, and distribute the source code for free. For support, open source means community fixes and transparent logs but also self-managed patching.

_Module: Foundations_

### OpenSSH

The premier open-source suite implementing the SSH protocol for encrypted terminal management. For support, it is the standard secure replacement for Telnet-based remote administration.

_Module: OS_

### Operating System (OS)

The system software package that manages hardware, runs application processes, enforces security, and provides user interfaces. For support, every ticket is ultimately about the OS mediating correctly between users, apps, and hardware.

_Module: OS_

### Operational Technology (OT)

Hardware and software systems that monitor and physically control industrial equipment such as SCADA controllers, PLCs, valves, and sensors. For support, OT faults can halt production, so change control is stricter than on office IT.

_Module: Foundations_

### Overclocking

Raising a CPU's clock multiplier, base frequency, or voltage beyond factory specs for higher performance. For support, treat instability, heat, and shortened lifespan as the expected cost and reset to stock clocks when diagnosing crashes.

_Module: Hardware_

## P

### PDC Emulator (Primary Domain Controller Emulator)

The domain-wide FSMO role in Active Directory responsible for network time synchronization (NTP), immediate password change processing, and account lockout evaluation.

_Module: Directory Services_

### PDA (Personal Digital Assistant)

Early portable handheld devices that made calendars, contacts, and email mobile, serving as the direct ancestor of smartphones. For support, PDAs explain legacy sync and mobile-management concepts still used today.

_Module: Foundations_

### PCI Express (PCIe)

The primary high-speed serial expansion bus on modern motherboards for GPUs, NVMe SSDs, and high-speed network cards. For support, check lane width, generation, and seating when expansion cards underperform or vanish.

_Module: Hardware_

### Peripherals and Ports

Ports are the physical connection interfaces on a computer, while peripherals are the external devices connected through them, such as keyboards, mice, monitors, and printers. For support, always isolate port versus device by swapping one side at a time.

_Module: Hardware_

### Platform Controller Hub (PCH)

The modern single-chip architecture that replaced Northbridge and Southbridge after memory controllers moved onto the CPU die. For support, one PCH driver package now covers most onboard I/O faults.

_Module: Hardware_

### Plink (PuTTY Link)

A command-line tool bundled with PuTTY for automating remote SSH sessions from scripts. For support, it lets you script repetitive remote commands instead of opening interactive sessions.

_Module: OS_

### POST (Power-On Self-Test)

The automated diagnostic run by BIOS or UEFI on cold boot to verify CPU, memory, GPU, and controllers before loading the OS. For support, beep codes and POST-card halts pinpoint which subsystem failed first.

_Module: Hardware_

### Power Supply Unit (PSU)

The component that converts high-voltage wall AC into regulated low-voltage DC rails (+12V, +5V, +3.3V) for PC hardware. For support, an undersized or failing PSU mimics RAM, GPU, and drive faults under load.

_Module: Hardware_

### PowerShell

Microsoft's advanced object-oriented command shell and scripting language for task automation and system configuration. For support, it lets you query and fix Windows fleets remotely and repeatably.

_Module: OS_

### Power User

An advanced user or IT specialist who uses shells, scripts, and direct system configuration to maximize productivity. For support, power users need admin boundaries and audit trails, not locked-down defaults.

_Module: OS_

### Process Management

The kernel's capacity to schedule CPU order, assign time slices, allocate resources, and terminate running processes. For support, Task Manager and process monitors reveal runaway processes before you reboot.

_Module: OS_

### Process vs. Program

A program is passive code stored on disk, while a process is an active executing instance loaded into RAM with a PID and CPU time. For support, killing a process never deletes its program, so persistent faults need the underlying program fixed.

_Module: OS_

### Punch Cards

Stiff paper cards with perforated holes once used to control looms and store instructions for early computers. For support, they are a reminder that encoding and input validation problems predate modern computers.

_Module: Foundations_

## Q

### QWERTY Layout

The predominant keyboard layout worldwide, named after the first six keys on the top letter row. For support, layout mismatches explain "wrong character" tickets on international keyboards.

_Module: Foundations_

## R

### Ransomware

Malicious software that encrypts local disks and mapped network shares using strong encryption (AES-256/RSA), holding the decryption key hostage for cryptocurrency payment.

_Module: Security_

### Rootkit

A stealth malware type that subverts the operating system kernel (Ring 0) or UEFI firmware to intercept system APIs, concealing processes, files, and backdoors from antivirus scanners.

_Module: Security_

### RPO (Recovery Point Objective)

The maximum age of files or database records that an organization can afford to permanently lose in a disaster, defining backup frequency.

_Module: Systems Administration_

### RTO (Recovery Time Objective)

The maximum acceptable clock duration within which a business system or service must be fully restored after an outage.

_Module: Systems Administration_

### RAM (Random Access Memory)

Fast volatile system memory the OS uses to hold active application code and working data for high-speed CPU execution. For support, insufficient or faulty RAM causes slowdowns, freezes, and random crashes under load.

_Module: Hardware_

### Registers (CPU)

Microscopic ultra-fast storage cells built into the processor die that hold immediate operands, pointers, and calculation results. For support, register dumps in crash logs show exactly what the CPU was doing when it failed.

_Module: Hardware_

### Reimaging and Disk Image

A disk image is an exact sector-by-sector clone of an OS volume, and reimaging is the automated process of wiping a drive and restoring that pristine image. For support, reimaging is the fastest reliable fix for deeply compromised or misconfigured machines.

_Module: Hardware_

### Remote Desktop Protocol (RDP)

Microsoft's network protocol on port 3389 providing remote graphical desktop access to Windows workstations and servers. For support, verify port, firewall, Network Level Authentication, and licensing when RDP connections fail.

_Module: OS_

### Return Merchandise Authorization (RMA)

A structured warranty process authorizing return of defective hardware to the manufacturer for repair, refund, or replacement. For support, open the RMA with serials, diagnostics, and photos to avoid rejection delays.

_Module: Hardware_

### RGB Color Model

An additive color model combining Red, Green, and Blue light, typically one byte each at values 0-255, to render about 16.7 million screen colors. For support, it explains banding, calibration, and "wrong color" display tickets.

_Module: Foundations_

### ROM (Read-Only Memory)

Non-volatile memory that retains bootstrap instructions without power, spanning PROM, UV-erasable EPROM, and modern Flash EEPROM variants. For support, ROM faults are rare but fatal, since they block firmware initialization.

_Module: Hardware_

## S

### Salting (Cryptographic)

Appending a unique, pseudo-random string to a plain-text password before computing its hash, rendering precomputed rainbow table attacks useless.

_Module: Security_

### SMB (Server Message Block)

A stateful network file-sharing protocol (TCP port 445) native to Microsoft Windows and Samba supporting user-level permissions, encryption, and shared printers.

_Module: Systems Administration_

### SPF (Sender Policy Framework)

A DNS TXT record listing the authorized mail servers and IP addresses permitted to send email on behalf of a specific domain name.

_Module: Systems Administration_

### SYSVOL

A specialized replicated folder share on Active Directory Domain Controllers (`\\domain\SYSVOL`) storing Group Policy Object templates and logon scripts.

_Module: Directory Services_

### Scalability

The ability of a system or network to dynamically increase or decrease capacity and resources as workload demands change. For support, design fixes that scale, such as policies and images, rather than one-off manual tweaks.

_Module: OS_

### Shell

A user-space interpreter such as Bash or PowerShell that translates typed commands into system calls executed by the kernel. For support, shell history and scripts turn one-off fixes into reusable runbooks.

_Module: OS_

### SoC (System on a Chip)

An integrated circuit that bundles CPU, GPU, memory, cellular modem, and I/O into a single compact package for mobile devices. For support, SoC integration means board-level replacement instead of per-part upgrades on phones and tablets.

_Module: Hardware_

### SSD (Solid State Drive)

High-speed non-volatile persistent storage using NAND flash chips with no moving parts for silent, shock-resistant operation. For support, SSDs shift failure diagnosis from mechanics to firmware, wear leveling, and TRIM support.

_Module: Hardware_

### SSH (Secure Shell)

An encrypted cryptographic protocol on port 22 for secure remote command-line administration. For support, SSH with key authentication is the baseline for managing Linux and network devices safely.

_Module: OS_

### Standoffs

Brass or metal mounting spacers screwed into the case beneath the motherboard to prevent metal-on-metal short circuits. For support, a missing or extra standoff is a classic cause of new-build no-boot and intermittent shorts.

_Module: Hardware_

### Swap Space (Pagefile)

Reserved secondary-storage space where virtual memory parks temporarily swapped-out pages when physical RAM fills up. For support, constant heavy swapping means add RAM rather than tuning the pagefile.

_Module: OS_

## T

### Troubleshooting Methodology (6-Stage)

The standardized IT diagnostic lifecycle: (1) Identify problem, (2) Establish theory of probable cause, (3) Test theory, (4) Plan of action & implement, (5) Verify full functionality & prevent, (6) Document findings.

_Module: Helpdesk Operations_

### Taskbar

A persistent desktop GUI element giving quick access to running apps, start menus, notifications, network status, and the clock. For support, its icons and notification area reveal running agents, VPN state, and pending reboots at a glance.

_Module: OS_

### Terminal

A text-based window used to type commands into the shell interpreter. For support, distinguish the terminal app from the shell program when users report "terminal not working."

_Module: OS_

### Time Slice (Quantum)

A microscopic unit of CPU time allocated to a process by the scheduler before context switching to the next process. For support, fair slicing explains why one runaway thread degrades every app instead of just itself.

_Module: OS_

### Transistor

A solid-state semiconductor component that amplifies or switches electrical signals, forming the microscopic foundation of all CPUs and memory chips. For support, every higher-level fault ultimately traces to billions of these switches working or failing together.

_Module: Foundations_

## U

### Ubuntu

A leading Debian-based Linux distribution known for a friendly desktop, cloud-server dominance, and a two-year Long-Term Support (LTS) release cycle. For support, LTS versions are the safe default for stable fleets.

_Module: OS_

### USB-C

A 24-pin reversible connector standard carrying high data bandwidth up to 20/40 Gbps, DisplayPort video, and up to 240W Power Delivery (USB-PD). For support, not all USB-C ports and cables support all three, so check specs before blaming the device.

_Module: Hardware_

### User Space

The unprivileged Ring 3 OS layer where users interact with desktops, browsers, media players, and shells. For support, crashes contained here rarely take down the whole system, unlike kernel faults.

_Module: OS_

### UTF-8

The most prevalent variable-width character encoding today, using 1 to 4 bytes on top of Unicode to cover global languages and emojis. For support, standardize on UTF-8 to eliminate most garbled-text tickets.

_Module: Foundations_

## V

### Vacuum Tube

An early electronic component used to amplify and switch voltages in computers like ENIAC, later replaced by smaller, cooler transistors. For support, it explains why heat, size, and reliability drove every later hardware generation.

_Module: Foundations_

### Virtual Machine (VM)

A complete software emulation of physical hardware that runs multiple isolated guest operating systems concurrently on one host. For support, VMs let you reproduce, snapshot, and roll back faulty states safely.

_Module: OS_

### Virtual Memory

An OS memory technique combining physical RAM with swap or pagefile space so large applications can run without exhausting memory. For support, it prevents crashes under load but heavy paging signals a real RAM shortage.

_Module: Hardware, OS_

### Virtual Private Network (VPN)

An encrypted tunnel connecting a remote client securely to a private corporate LAN across the public internet. For support, verify VPN connection before diagnosing any "cannot reach internal resource" ticket.

_Module: OS_
