You have travelled from IT roles and silicon transistors all the way to operating system kernels, systems administration, Active Directory domain services, and defensive IT security. Here is the entire IT Support Fundamentals curriculum condensed into an essential quick-reference cheat sheet.

## Foundations & Binary Logic

| Concept                   | Architectural Reality                                       | IT Triage Impact                                                                                             |
| :------------------------ | :---------------------------------------------------------- | :----------------------------------------------------------------------------------------------------------- |
| **Bit vs Byte**           | 1 bit = 0 or 1. 1 byte = 8 bits ($2^8 = 256$ states).       | Network bandwidth is quoted in bits (Gbps); storage & RAM in bytes (GB). 1000 Mbps = 125 MB/s transfer rate. |
| **Character Encodings**   | ASCII (7-bit, 128 characters), UTF-8 (1–4 bytes variable).  | Mojibake / garbled text indicates encoding mismatch; standardize databases and filesystems on UTF-8.         |
| **Logic Gates**           | AND, OR, NOT, NAND, NOR, XOR, XNOR.                         | The physical building blocks of silicon ALUs, half-adders, and CPU branch evaluation logic.                  |
| **Hexadecimal (Base-16)** | Digits 0–9, A–F ($10-15$). 1 hex digit = 4 bits (1 nibble). | Used for compact byte representation: MAC addresses, IPv6 segments, memory crash dumps, HTML colors.         |

## Computer Hardware Internals

| Component                 | Architecture & Key Specifications                                        | Primary Symptoms of Failure                                                                        |
| :------------------------ | :----------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------- |
| **CPU (Processor)**       | ALU + CU + Registers + L1/L2/L3 SRAM cache. Clock speed in GHz.          | Thermal throttling, sudden thermal shutdowns, unseated coolers with dried thermal paste.           |
| **RAM (Memory)**          | DDR4/DDR5 SDRAM DIMMs. Volatile, high-speed working memory.              | Blue Screen of Death (BSOD), random application crashes, memory corruptions, POST DRAM error LEDs. |
| **Storage: HDD**          | Magnetic spinning platters (5400/7200 RPM) via SATA (600 MB/s).          | Repetitive clicking noises, failing SMART reallocated sector counts, massive system latency.       |
| **Storage: SSD / NVMe**   | NAND Flash (SLC/MLC/TLC/QLC). NVMe uses PCIe lanes (up to 7,500+ MB/s).  | Sudden read-only lock, missing drive in BIOS, zero audible warning before death.                   |
| **Motherboard & Chipset** | ATX, Micro-ATX, Mini-ITX form factors. PCH manages SATA, USB, audio.     | Intermittent USB drops, dead PCIe slots, swollen capacitors, failed standoffs causing shorts.      |
| **Power Supply (PSU)**    | Converts wall AC to +12V (CPU/GPU), +5V, +3.3V DC rails. Rated in Watts. | Spontaneous reboots under 3D/CPU gaming load, burning smell, tripping breaker, coil whine.         |

## Operating System Subsystems

| Subsystem             | Core Architectural Duty                                                 | Diagnostic Command / Log                                                                                  |
| :-------------------- | :---------------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------- |
| **Kernel (Ring 0)**   | Arbitrates hardware: CPU scheduling, virtual memory, device I/O.        | Windows: `perfmon`, BSOD minidump analysis.<br/>Linux: `dmesg`, `journalctl -k`.                          |
| **Filesystems**       | Manages file naming, cluster allocation, journals, and ACL permissions. | Windows: `chkdsk /f C:`, NTFS permissions dialog.<br/>Linux: `fsck -y /dev/sda1`, `chmod` / `chown`.      |
| **Process Scheduler** | Time-slices CPU execution quanta across threads; tracks PIDs.           | Windows: Task Manager, Resource Monitor, `tasklist`.<br/>Linux: `top`, `htop`, `ps aux`, `kill -9 <PID>`. |
| **Virtual Memory**    | Paginates physical RAM into secondary storage (pagefile / swap).        | High Page Faults/sec indicates memory thrashing; fix by expanding physical RAM.                           |
| **System Event Logs** | Records security audits, system errors, service starts chronologically. | Windows: Event Viewer (`eventvwr.msc`).<br/>Linux: `/var/log/syslog`, `/var/log/auth.log`.                |

## Helpdesk Triage & Troubleshooting Methodology

| Stage / Protocol        | Standard Operational Definition                                                                                                                         | Key Action                                                 |
| :---------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------ | :--------------------------------------------------------- |
| **1. Identify Problem** | Inquire with open-ended questions; review system event logs.                                                                                            | Document symptoms, reproduce failure in isolation.         |
| **2. Establish Theory** | Question the obvious first; consider recent updates and changes.                                                                                        | Work bottom-up from Physical Layer to Application Layer.   |
| **3. Test Theory**      | Isolate one single variable at a time to validate cause.                                                                                                | If theory fails, revert and formulate new hypothesis.      |
| **4. Plan & Implement** | Create step-by-step resolution plan with rollback precautions.                                                                                          | Deploy fix during approved window or escalate to Tier-2/3. |
| **5. Verify & Prevent** | Confirm full functionality with end user; apply safeguards.                                                                                             | Have customer sign off; enforce preventative policies.     |
| **6. Document**         | Record problem, root-cause analysis, and resolution in KB.                                                                                              | Update ticket history; close with customer notes.          |
| **SLA Priorities**      | **P1 (Critical):** `<15m` response (Outage).<br/>**P2 (High):** `<1h` response.<br/>**P3 (Medium):** `<4h` response.<br/>**P4 (Low):** `<24h` response. | Prioritize by organizational impact and business urgency.  |

## Systems Administration & Infrastructure Services

| Service / Tool            | Standard Port / Protocol                                                        | Core Duty & Best Practice Rule                                                                                                                                   |
| :------------------------ | :------------------------------------------------------------------------------ | :--------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **SMB / CIFS**            | TCP Port 445                                                                    | Stateful Windows/Samba file sharing; NTFS ACL permission integration.                                                                                            |
| **NFS**                   | TCP / UDP Port 2049                                                             | High-performance line-rate file shares for Linux/Unix and container volumes.                                                                                     |
| **Print Spooling (CUPS)** | TCP Port 631 (IPP)                                                              | Centralized print driver management and badge-authenticated queue release.                                                                                       |
| **Email Security**        | SPF + DKIM + DMARC                                                              | **SPF:** DNS TXT authorized sender IPs.<br/>**DKIM:** Cryptographic payload signature.<br/>**DMARC:** Enforce reject/quarantine policy on forged sender headers. |
| **Time Sync (NTP)**       | UDP Port 123                                                                    | Synchronizes clocks to UTC. Kerberos breaks if clock drift exceeds **5 minutes**.                                                                                |
| **3-2-1 Backup Rule**     | 3 copies of data, 2 different media formats, 1 copy off-site / immutable cloud. | Protects against ransomware; test restores regularly to meet **RTO** and **RPO** targets.                                                                        |
| **NIST 800-88**           | Clear (overwrite), Purge (degauss/crypto-erase), Destroy (physical shred).      | Standard for certified hardware decommissioning and media sanitization.                                                                                          |

## Directory Services & Active Directory

| Component / Rule        | Syntax / Port                                                         | Architectural Purpose                                                                                             |
| :---------------------- | :-------------------------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------- |
| **LDAP / LDAPS**        | Port 389 / Port 636                                                   | Lightweight Directory Access Protocol for querying hierarchical DIT trees.                                        |
| **Distinguished Name**  | `CN=Alice,OU=Eng,DC=corp,DC=com`                                      | Leaf object (`CN`), Organizational Unit (`OU`), Domain Component (`DC`).                                          |
| **Active Directory DS** | Kerberos Port 88, DNS, LDAP                                           | Centralized identity management across Windows forests, domains, and OUs.                                         |
| **FSMO Roles**          | 2 Forest-Wide + 3 Domain-Wide                                         | **Forest:** Schema Master, Domain Naming Master.<br/>**Domain:** RID Master, PDC Emulator, Infrastructure Master. |
| **The AGDLP Rule**      | **A**ccounts -> **G**lobal -> **D**omain **L**ocal -> **P**ermissions | Microsoft RBAC best practice: never assign NTFS permissions directly to user accounts.                            |
| **GPO Order (LSDOU)**   | Local -> Site -> Domain -> OU                                         | "Last applied wins": OU policies override Domain policies unless marked **Enforced**.                             |
| **GPO Diagnostics**     | `gpupdate /force` / `gpresult /r`                                     | Refreshes and audits active Group Policy Objects from the SYSVOL share.                                           |

## IT Security & Incident Response

| Threat / Control       | Mechanism & Attack Vector                  | Defensive Countermeasure                                                                                                                                                   |
| :--------------------- | :----------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **CIA Triad**          | Confidentiality, Integrity, Availability   | Encryption (AES-256), Hashing (SHA-256), Redundancy/Failover.                                                                                                              |
| **Malware Quarantine** | Active ransomware / trojan infection       | **Step 1:** Disconnect physical RJ-45 cable & kill Wi-Fi immediately.<br/>**Step 2:** Isolate user account in AD.<br/>**Step 3:** Full disk wipe & clean re-image via PXE. |
| **Botnets & C2**       | Compromised zombie endpoints               | Block Command & Control IP/DNS beacons; patch edge IoT vulnerabilities.                                                                                                    |
| **Network Attacks**    | SYN flood, DNS amplification, ARP spoofing | Deploy SYN cookies, upstream DDoS scrubbing, Dynamic ARP Inspection (DAI).                                                                                                 |
| **Password Security**  | Brute force, dictionary, rainbow tables    | Append unique cryptographic **Salts**; slow hashing (**Argon2**, **bcrypt**); lockout rules.                                                                               |
| **MFA Authentication** | Something you know, have, are              | Enforce FIDO2/WebAuthn hardware keys or TOTP apps; avoid vulnerable SMS OTP.                                                                                               |
| **Social Engineering** | Phishing, Spear Phishing, Whaling, Baiting | Security awareness training; verify out-of-band wire transfer requests.                                                                                                    |
| **Physical Security**  | Tailgating, unauthorized room entry        | Access Control Vestibules (Mantraps), badge readers, bollards, clean desk policy.                                                                                          |
