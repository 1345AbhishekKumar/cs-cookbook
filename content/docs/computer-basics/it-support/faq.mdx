### Why does Windows report my 1 TB SSD as only 931 GB? Did the manufacturer cheat me?

No. Storage manufacturers market capacities using standard decimal powers of 10:
$$1 \text{ TB} = 10^{12} = 1,000,000,000,000 \text{ bytes}$$
However, Windows computes capacity using binary powers of 2 (gibibytes, GiB):
$$1 \text{ GiB} = 2^{30} = 1,073,741,824 \text{ bytes}$$
Dividing $1,000,000,000,000$ by $1,073,741,824$ yields **931.32 GiB**. Windows displays the unit label as "GB" while computing in GiB. Every single byte is physically present on your drive.

### Why do computers still beep when they fail to boot? Why not just show an error on the screen?

Because before the Power-On Self-Test (POST) confirms that the CPU, RAM, motherboard bus, and Graphics Card (GPU) are mathematically functional, the computer is physically incapable of rendering pixels to a monitor. A piezoelectric motherboard buzzer (or primitive diagnostic LED) has no software dependencies — it is driven by basic electrical circuits on the motherboard chipset, making it the only reliable output device when the rest of the computer is paralyzed.

### What is the actual difference between closing an app and killing its process in Task Manager?

When you close an application normally (clicking the "X" button), the OS sends a termination message (such as `WM_CLOSE` on Windows or `SIGTERM` on Linux) to the application. The program catches this signal, prompts you to save open files, closes database handles, and cleanly flushes memory buffers to disk. When you "End Task" or force-kill (`kill -9` / `SIGKILL`), the kernel instantly revokes the process's memory space and CPU time slice without notifying the app. Open files may be left corrupted or half-written.

### Why does restarting the computer actually fix so many random problems?

Operating systems and user applications are millions of lines of code that accumulate minute software states: memory leaks that slowly consume RAM, background threads caught in deadlocks, zombie processes holding open file locks, and fragmented virtual memory tables. A complete system restart resets the CPU program counter, empties system RAM completely to an unpowered zero state, unloads all device drivers, and allows the kernel to re-initialize hardware and services from clean storage files.

### Why can't I just use Remote Desktop (RDP) over the internet without a VPN?

RDP operates on TCP port 3389. Automated botnets continuously scan the entire IPv4 address space looking for open port 3389 listeners. If exposed directly to the public web, attackers will launch password-spraying attacks, credential-stuffing dictionaries, and exploit unpatched remote code execution vulnerabilities (such as BlueKeep). A Virtual Private Network (VPN) encapsulates your connection inside strong multi-factor authentication and encryption, ensuring that only trusted enterprise hardware can even see the RDP listening port.

### When should I choose a 64-bit OS over a 32-bit OS?

Always choose 64-bit for modern computing. A 32-bit operating system has an architectural ceiling of $2^{32}$ addressable memory bytes, meaning it can never utilize more than 4 GB of RAM (practically ~3.2 GB after reserving hardware memory-mapped addresses). A 64-bit operating system addresses up to 16 exabytes of RAM, supports modern hardware-enforced security features (like Kernel Patch Protection and Windows 11 VBS), and runs both 32-bit and 64-bit binaries natively.

### Why do Domain logins fail if a laptop's clock is 6 minutes off?

Active Directory uses the **Kerberos** authentication protocol (RFC 4120). Kerberos embeds precise timestamps inside encrypted ticket-granting tickets to defend against **Replay Attacks** (where an attacker snoops on the network, steals an authentication packet, and re-transmits it later to gain unauthorized access). By default, Domain Controllers strictly enforce a maximum clock skew of **5 minutes**. If your laptop clock drifts past this window, the Domain Controller rejects the ticket as a suspected replay attack. Ensure your client synchronizes with the domain's PDC Emulator via NTP.

### Why should a technician immediately unplug the network cable during a malware attack rather than running an antivirus scan?

Modern enterprise malware (particularly automated **Ransomware** and **Worms**) propagates aggressively across local area networks. Once executed on an endpoint, ransomware immediately discovers and encrypts accessible network file shares (via SMB/NFS), enumerates mapped drives, and uses automated lateral movement tools (like EternalBlue or stolen credentials) to infect neighboring servers and domain controllers. Leaving the network cable plugged in while an antivirus scan takes 30 minutes gives the ransomware ample time to cripple the entire company. Unplugging the physical RJ-45 cable and killing Wi-Fi severs the infection in milliseconds.
