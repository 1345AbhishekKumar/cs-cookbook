<LessonIntro>

Every support ticket ends at the same foundational physical and logical layers: the person requesting assistance, the hardware beneath the desk, the operating system mediating between them, the directory service verifying their identity, and the enterprise infrastructure and security policies defending the organization.

This comprehensive track builds that operational foundation from first principles: starting with IT support disciplines and ticketing lifecycles, traveling through computing history and Boolean gate logic, dissecting the physical PC architecture (CPU, RAM, storage, motherboards, power, and peripherals), mastering operating system internals (kernels, filesystems, process scheduling, CLI diagnostics, boot sequences, and remote management), and elevating into enterprise infrastructure (server form factors, systems administration, LDAP, Active Directory Domain Services, Group Policy, and incident response).

</LessonIntro>

## What you'll learn

- **Tier-1 Helpdesk Protocols & Diagnostics:** The 6-step troubleshooting methodology, root-cause isolation, avoiding diagnostic autopilot, ticketing lifecycles (SLA tiers P1–P4), documentation standards, and customer de-escalation.
- **Computing Foundations:** How vacuum tubes evolved into microprocessors, and how binary, hex, ASCII, and logic gates convert electricity into information.
- **Hardware Architecture & Triage:** How to identify, install, test, and troubleshoot CPUs, memory hierarchies (RAM/ROM), storage mediums (HDD, SSD, NVMe), motherboards, BIOS/UEFI firmware, power supplies, and display peripherals.
- **Operating System Subsystems:** How kernels manage hardware abstraction (Ring 0 vs. Ring 3), filesystem allocation and permissions, process scheduling, virtual memory paging, and event logging across Windows, macOS, and Linux.
- **Boot Forensics & System Recovery:** Tracing the 6-step boot sequence from power button to login prompt, diagnosing POST failures, repair via WinRE/live media, and PXE network deployment.
- **Systems Administration & Infrastructure Services:** Server form factors (1U/2U rack, blade, tower), data center environmental controls, asset lifecycle (NIST 800-88 sanitization), formal change management (CAB/RFC), centralized file shares (NFS vs. SMB), print servers (CUPS), email security (SPF, DKIM, DMARC), and disaster recovery (3-2-1 backup rule, RTO/RPO).
- **Directory Services & Identity Management:** Hierarchical LDAP DIT syntax, Active Directory Domain Services (forests, trees, domains, OUs), FSMO single-master roles, AGDLP permission delegation, Group Policy Objects (GPO, LSDOU processing, SYSVOL), and Microsoft Entra ID hybrid synchronization.
- **IT Security Defense & Incident Response:** The CIA Triad, malware taxonomy (viruses, worms, ransomware, rootkits), emergency endpoint quarantine procedures, botnet C2 architecture, network attacks (DoS/DDoS, ARP/DNS spoofing, MitM), password security (salting, slow hashing, FIDO2/TOTP MFA), social engineering psychological vectors, and physical access controls (mantraps, bollards).
