<LessonIntro>

Every support ticket ends at the same three physical and logical layers: the person requesting assistance, the hardware beneath the desk, and the operating system mediating between them. This comprehensive track builds that operational foundation from first principles: starting with IT support disciplines and ticketing lifecycles, traveling through computing history and Boolean gate logic, dissecting the physical PC architecture (CPU, RAM, storage, motherboards, power, and peripherals), and mastering operating system internals (kernels, filesystems, process scheduling, CLI diagnostics, boot sequences, and remote management). Work through this curriculum front to back to diagnose faster, escalate cleaner, and resolve more issues on first contact.

</LessonIntro>

## What you'll learn

- **Tier-1 Helpdesk Protocols:** How IT support roles operate day-to-day, ticketing lifecycles, escalation tiers, and customer communication fundamentals.
- **Computing Foundations:** How vacuum tubes evolved into microprocessors, and how binary, hex, ASCII, and logic gates convert electricity into information.
- **Hardware Architecture & Triage:** How to identify, install, test, and troubleshoot CPUs, memory hierarchies (RAM/ROM), storage mediums (HDD, SSD, NVMe), motherboards, BIOS/UEFI firmware, power supplies, and display peripherals.
- **Operating System Subsystems:** How kernels manage hardware abstraction (Ring 0 vs. Ring 3), filesystem allocation and permissions, process scheduling, virtual memory paging, and event logging across Windows, macOS, and Linux.
- **Boot Forensics & System Recovery:** Tracing the 6-step boot sequence from power button to login prompt, diagnosing POST failures, repair via WinRE/live media, and PXE network deployment.
- **Enterprise Fleet Administration:** Evaluating desktop platforms, mobile sandboxing and MDM policies, Type 1/2 virtualization sandboxing, and secure remote access via RDP, SSH, and VPN tunnels.
