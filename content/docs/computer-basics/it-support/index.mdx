<LessonIntro>

Every support ticket ends at the same three layers: the person asking for help, the hardware under the desk, and the operating system mediating between them. This track builds that foundation in order — starting with what IT support actually does, traveling through computing history and the binary logic underneath, opening up the PC to study CPU, memory, storage, boards, and peripherals, then closing with the operating system: kernels, file systems, processes, shells, boot, and remote access. Work through it front to back and you will triage faster, escalate cleaner, and fix more on first contact.

</LessonIntro>

## What you'll learn

- What IT support roles do day to day and how tickets flow from user to resolution
- How computing evolved from punch cards and vacuum tubes to modern PCs and phones
- How bits, encodings, logic gates, and binary math turn electricity into software
- How to identify, install, and troubleshoot CPUs, RAM, ROM, storage, motherboards, firmware, power, and peripherals
- How operating systems manage files, processes, memory, users, boot, and remote access across Windows, macOS, Linux, and mobile
- Where to look first in logs, shells, and system tools when something breaks
