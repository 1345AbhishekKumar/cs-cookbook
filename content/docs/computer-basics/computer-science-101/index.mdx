<LessonIntro>

You can ship working software for years without ever knowing how a transistor flips, why big-endian matters, or what the call stack actually is. But the moment something breaks — a stack overflow, a memory leak, a slow query, a network handshake that never completes — that hidden machinery suddenly becomes the only thing standing between you and a fix. This lesson walks through every foundational concept a working developer is expected to know, in the order a computer itself encounters them: starting at the bare silicon, climbing up through operating systems, languages, data, logic, paradigms, and finally the network that connects it all.

</LessonIntro>

## What you'll learn

- How a CPU, RAM, and bits combine into a Turing machine that can compute anything
- How binary, hex, and encoding schemes represent everything you type
- How the kernel, shell, and SSH give you control over a machine
- How compilers, interpreters, variables, and memory management turn text into running programs
- How data structures (arrays, trees, graphs) and algorithms (search, recursion, dynamic programming) solve problems
- How paradigms, OOP, threads, and networking let code scale from one process to the entire internet
