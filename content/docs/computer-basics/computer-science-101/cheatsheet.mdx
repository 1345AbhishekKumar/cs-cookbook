You've travelled from a single transistor to the global network. Here is every concept from the lesson, condensed.

## Hardware & Data

| Concept | What it means |
| --- | --- |
| Turing machine | Abstract tape + read/write head; computes anything computable. |
| CPU | Silicon chip with billions of transistors; executes machine code. |
| Transistor | Microscopic on/off switch; holds one bit. |
| Bit | Single 0 or 1; smallest unit of information. |
| Byte | 8 bits; 256 possible values. |
| RAM | Memory addressed by numeric location; CPU reads/writes bytes. |
| Binary | Base-2 counting (0,1). |
| Hexadecimal | Base-16 (0–9, A–F); one digit = 4 bits. |
| Nibble | 4 bits = one hex digit. |
| ASCII / UTF-8 | Character encodings mapping bytes to text. |
| Machine code | Raw binary instructions the CPU executes. |
| Big / little endian | Byte order for multi-byte values in memory. |

## OS, Shell & Languages

| Concept | What it means |
| --- | --- |
| Kernel | OS core; sole direct hardware access. |
| Device driver | Translator between kernel and specific hardware. |
| Shell | User program wrapping the kernel; takes text commands. |
| CLI | Command Line Interface — text in, text out. |
| SSH | Encrypted remote shell protocol. |
| Abstraction | Hiding lower layers to make higher ones usable. |
| Interpreter | Runs source line-by-line (Python). |
| Compiler | Translates source to executable in advance (C++). |
| Executable | Standalone binary the OS can run. |

## Variables, Types & Memory

| Concept | What it means |
| --- | --- |
| Variable | Name bound to a memory location holding a value. |
| Dynamic typing | Types inferred at runtime (Python). |
| Static typing | Types declared at compile time (C). |
| int / float / double | Whole, decimal, and high-precision numbers. |
| char / string | Single character / sequence of characters. |
| Pointer | Variable holding another variable's address. |
| Garbage collector | Auto-frees memory no longer referenced. |

## Data Structures

| Concept | What it means |
| --- | --- |
| Array / list | Indexed, contiguous; fast lookup, slow insert. |
| Linked list | Nodes with pointers; fast insert, slow lookup. |
| Stack (LIFO) | Last in, first out; push/pop from top. |
| Queue (FIFO) | First in, first out; enqueue/dequeue. |
| Hash / map / dict | Key-value pairs; near-instant key lookup. |
| Tree | Hierarchical nodes; efficient for sorted/nested data. |
| Graph | Nodes connected by edges; arbitrary relationships. |

## Algorithms & Logic

| Concept | What it means |
| --- | --- |
| Function | Named block taking input, returning output. |
| Argument | Value passed into a function. |
| Expression | Code that produces a value. |
| Statement | Code that does something (no value). |
| Boolean | true or false. |

| Concept | What it means |

| Time / space complexity | Speed vs memory usage of an algorithm. |
| Brute force | Try every option; simple, doesn't scale. |

## Memory anchors

- **Bit → byte → nibble:** 1 → 8 → 4 bits. A nibble is half a byte (yes, really).
- **LIFO vs FIFO:** Stack = plates (last on top comes off first). Queue = line (first in is first served).
- **Big-O ladder:** O(1) &lt; O(log n) &lt; O(n) &lt; O(n log n) &lt; O(n²) &lt; O(2ⁿ). Each step roughly doubles the pain.
- **Recursion needs a base case** the way a story needs an ending — without it, infinite loop, stack overflow.
- **Concurrency ≠ parallelism:** concurrency is juggling; parallelism is having two hands.
