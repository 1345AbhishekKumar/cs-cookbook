Two tracks live here. Pick the one that matches what you need, then continue into mindset and AI workflow lessons.

- **[Computer Science 101](/docs/computer-basics/computer-science-101)** — From a single bit of silicon to the cloud that runs the internet: the science behind the code you write every day. Ten lessons, a cheat sheet, an FAQ and next steps.
- **[Intro to Programming](/docs/computer-basics/intro-to-programming)** — You tell a very literal machine exactly what to do, in a language humans can stand to read. Nine stops, with runnable code and diagrams.
- **[IT Support Fundamentals](/docs/computer-basics/it-support)** — IT roles, computing history, hardware internals, and operating systems: 18 lessons plus a single searchable glossary covering foundations, hardware, and OS terms.
- **[How the Web Works](/docs/computer-basics/how-the-web-works)** — From typing a URL to pixels on screen: Internet, DNS, TCP/IP, HTTP/HTTPS, servers, CDNs, and browser rendering, with Mermaid diagrams.
