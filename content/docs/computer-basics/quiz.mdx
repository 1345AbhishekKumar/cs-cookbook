## 3. Web Architecture & Browser Rendering

<TryIt
  question="In the browser's Critical Rendering Path, why is CSS considered 'render-blocking'?"
  options={[
    "Because CSS files are encrypted by default",
    "Because the browser must construct the complete CSSOM tree before creating the Render Tree and painting pixels to prevent a jarring Flash of Unstyled Content (FOUC)",
    "Because CSS only compiles after all JavaScript execution is finished",
    "Because modern operating systems require GPU drivers to parse CSS selectors",
  ]}
  answer="B"
  why="Later CSS rules cascade and override earlier rules. To prevent rendering content that immediately jumps and repaints when styles arrive, the browser waits until the CSSOM is constructed before its first paint."
/>

<TryIt
  question="When animating UI elements on a web page, why should developers animate CSS 'transform' rather than properties like 'left' or 'width'?"
  options={[
    "Transform runs in a separate Web Worker thread",
    "Transform executes solely in the Compositing stage on the GPU, avoiding expensive Layout (reflow) and Paint cycles on the browser's main thread",

    "Transform prevents memory leaks in React and Vue",
  ]}
  answer="B"
  why="Changes to geometric dimensions like width or margin force the browser to recalculate layout positions for the entire document tree. CSS transform operates on GPU layers without triggering layout or paint."

## 4. Multimedia, Audio & Video Compression

<TryIt
  question="Why does digital audio sampling require a sample rate of at least 44.1 kHz to capture audio up to 20 kHz?"
  options={[
    "Audio files must be aligned to 44.1 kB memory blocks",
    "According to the Nyquist-Shannon Sampling Theorem, the sampling rate must be at least twice the highest audible frequency to faithfully reconstruct the sound wave without aliasing distortion (2 × 20 kHz = 40 kHz)",
    "Human vocal cords vibrate at 44.1 kHz",
    "DAC chips cannot read audio below 44.1 kHz",
  ]}
  answer="B"
  why="The Nyquist theorem dictates that sampling at less than twice the maximum frequency introduces aliasing (phantom frequencies). Since humans hear up to ~20 kHz, 44.1 kHz cleanly captures the entire human hearing spectrum."
/>

<TryIt
  question="In digital video compression (such as H.264 or AV1), what is an I-Frame (Intra-coded frame)?"
  options={[
    "A frame that only stores audio wave data",
    "A complete, standalone compressed image (keyframe) that does not rely on any preceding or following frames to render",
    "A frame that stores only the difference between two moving objects",
    "An uncompressed 24-bit raw bitmap stored directly on disk",
  ]}
  answer="B"
  why="I-frames are full keyframes. P-frames and B-frames only store differences and vectors relative to surrounding frames, allowing video streams to reduce raw file sizes by over 99%."
/>
