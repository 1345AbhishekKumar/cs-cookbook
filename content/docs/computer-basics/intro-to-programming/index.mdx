Nine lessons covering the core mental models and mechanics of programming — from binary machine code and variables to algorithms and language selection. Each lesson features interactive mental models, runnable code examples, and diagrams.

- **[What is Programming?](/docs/computer-basics/intro-to-programming/01-what-is-programming)** — Why machines need exact instructions, binary machine code, and how programming languages bridge human logic to hardware.
- **[Writing & Running Code](/docs/computer-basics/intro-to-programming/02-writing-and-running-code)** — IDE workbench, the edit-run-console loop, print statements, and arithmetic operators.
- **[Variables & Data Types](/docs/computer-basics/intro-to-programming/03-variables-and-data-types)** — Named memory boxes: integers, floats, strings, booleans, reassignments, and handling empty values.
- **[Conditionals & Arrays](/docs/computer-basics/intro-to-programming/04-conditionals-and-arrays)** — Decision branching with `if`/`else` railway switches, ordered collections, and zero-based indexing.
- **[Loops & Error Types](/docs/computer-basics/intro-to-programming/05-loops-and-errors)** — Repetition with `for` and `while`, avoiding infinite loops, and distinguishing Syntax, Runtime, and Logic errors.

## Abstraction, Scaling & Algorithms

- **[Debugging & Functions](/docs/computer-basics/intro-to-programming/06-debugging-and-functions)** — Print-based debugging protocol and packaging reusable logic with parameters and return values.
- **[Libraries & Containers](/docs/computer-basics/intro-to-programming/07-libraries-and-containers)** — Targeted imports, dynamic ArrayLists, and key-value dictionaries (hash maps).
- **[Search & Recursion](/docs/computer-basics/intro-to-programming/08-search-and-recursion)** — Linear vs binary search, Big O efficiency, call stacks, and recursive base cases.
- **[Pseudocode & Choosing a Language](/docs/computer-basics/intro-to-programming/09-pseudocode-and-language)** — Planning algorithms with pseudocode and flowcharts, navigating language ecosystems, and shipping small projects.
