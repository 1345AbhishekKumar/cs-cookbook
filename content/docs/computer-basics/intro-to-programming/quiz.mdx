## 2. Variables, Types & Memory

<TryIt
  question="In most languages, what is the value of '3' + 4 (adding string '3' and number 4)?"

    "Both B and C describe common behaviors in dynamically typed vs strictly typed languages",
  ]}

<TryIt

  answer="C"

## 3. Control Flow & Loops

<TryIt
  question="Consider the loop: 'while (count < 5) { console.log(count); }'. If 'count' begins at 0 and is never incremented inside the block, what occurs?"
  options={[
    "The loop executes 5 times and terminates normally",
    "An infinite loop occurs, consuming 100% of the CPU thread until halted or killed",
    "The compiler automatically adds 'count++' at the end of the loop",
    "The operating system pauses the process after 1 second",
  ]}
  answer="B"
  why="A while loop repeats as long as its condition evaluates to true. If the loop body never updates the condition variable toward termination, the condition never becomes false."
/>

<TryIt
  question="What is the result of the boolean expression: (true && false) || (!false)?"
  options={["false", "true", "undefined", "null"]}
  answer="B"
  why="(true && false) evaluates to false. (!false) evaluates to true. Then false || true evaluates to true."
/>

## 5. Recursion & Problem Decomposition

<TryIt
  question="What happens if a recursive function is missing a Base Case?"
  options={[
    "The CPU runs the calculation in reverse",
    "The function calls itself indefinitely until the call stack exceeds its allocated memory, triggering a Stack Overflow error",
    "The operating system allocates heap memory to complete the recursion",
    "The function returns undefined immediately",
  ]}
  answer="B"
  why="Every recursive call pushes a new execution stack frame onto the call stack. Without a base case stopping condition, the call stack exhausts available memory and crashes the process."
