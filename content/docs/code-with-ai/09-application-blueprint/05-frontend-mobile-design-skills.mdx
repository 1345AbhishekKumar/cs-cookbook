## 1. Shadcn UI & Improve

Shadcn UI revolutionized frontend architecture by replacing black-box component libraries with copy-pasteable, accessible Radix UI primitives styled with Tailwind CSS.

### Installation

```bash
# Core Shadcn UI skill
bunx --bun skills add shadcn/ui
# or
npx skills add shadcn/ui

# Autonomous UI review agent
npx skills add https://github.com/shadcn/improve --skill improve
```

### Sub-Skills Catalog

```
shadcn/ui & improve
├── shadcn (Component discovery, registry CLI, and Radix composition)
├── migrate-radix-to-base (Updating legacy Radix imports to Base UI)
└── improve (Independent visual hierarchy and design auditor)
```

### What They Teach the Agent:
* **`shadcn`**: Guides the agent to use `npx shadcn@latest add <component>`, configure `components.json` path aliases (`@/components/ui`), adapt CSS variables for dark mode, and compose complex dialogs, sheets, tables, and form controls.
* **`improve`**: Acts as an automated design critic. You can ask `/improve` to audit an existing page; it systematically checks typography scale, color contrast, whitespace rhythm, and button hover states, proposing direct code refinements.

## 2. Emil Kowalski Design Skills (`emilkowalski/skills`)

Created by acclaimed design engineer **Emil Kowalski**, this collection codifies the invisible details that make modern web and native software feel delightful, responsive, and tactile.

### Installation

```bash
npx skills add emilkowalski/skills
```

To install globally for Google Antigravity:
```bash
npx skills add emilkowalski/skills -g -a antigravity -y
```

### Sub-Skills Catalog

The `emilkowalski/skills` package bundles **12 specialized craft skills**:

```
emilkowalski/skills
├── animate (Motion curves, Framer Motion, spring physics)
├── animate-expo (Hardware-accelerated mobile animations via Reanimated)
├── animation-vocabulary (Design terminology & physical easing metrics)
├── apple-design (High-end Apple HIG aesthetics & blurred glassmorphism)
├── ask-sonner (Toast notifications, queue stacking & dismiss kinetics)
├── break-ui (Stress-testing responsive layouts with overflow data)
└── and accompanying micro-interaction & layout transition guidelines
```

### Deep Dive into Emil's Rules
* **No Linear Easing**: Physics in the real world have mass, inertia, and friction. Linear transitions look robotic. Emil's skills teach the agent to use spring physics (`stiffness: 400`, `damping: 30`) or cubic-bezier curves (`cubic-bezier(0.16, 1, 0.3, 1)`).
* **GPU Hardware Acceleration**: Restricts animations strictly to `transform` (scale, translate) and `opacity`. Never animate `width`, `height`, `top`, or `padding`, which trigger continuous CPU layout reflows.
* **Tactile Press States**: Buttons and interactive surfaces must have active press scales (e.g. `active:scale-[0.98]`) and subtle transition timings (< 150ms).

## 3. Paul Bakaus: Impeccable (`pbakaus/impeccable`)

Created by **Paul Bakaus**, `impeccable` enforces pixel-level design craft and frontend standards.

### Installation

```bash
npx skills add pbakaus/impeccable
```

### Sub-Skill: `impeccable`
* **Fluid Typography**: Uses CSS `clamp()` and container query units to ensure headlines scale smoothly across mobile, tablet, and widescreen monitors without hard breakpoint jumps.
* **Touch Targets**: Guarantees all interactive touch elements are at least `44x44px` with sufficient padding for human thumbs.
* **Rhythm & Spacing**: Enforces standard 4px/8px design token intervals for margins, padding, and gap spacing.

## 5. Visual Asset & Branding Skills

Building an application also requires high-converting store presentations and cohesive brand marks.

### 1. App Store Screenshots (`ParthJadhav/app-store-screenshots`)
```bash
npx skills add ParthJadhav/app-store-screenshot
```
* **Sub-Skill**: `app-store-screenshots`
* **What It Does**: Scaffolds a local Next.js screenshot studio inside your project. Automatically renders your mobile UI inside realistic 3D and 2D device frames (iPhone 16 Pro, iPad Pro, Pixel 9), applies localized marketing titles, and exports one-click packages sized to exact Apple App Store and Google Play specifications.

### 2. IP as Logo (`s1dashu/ip-as-logo-skill`)
```bash
npx skills add s1dashu/ip-as-logo-skill
```
* **Sub-Skill**: `ip-as-logo`
* **What It Does**: Provides geometric design heuristics and vector SVG generation rules. Teaches your agent how to turn abstract application concepts, mascots, or brand intellectual property into minimalist, clean SVG brandmarks with scalable viewboxes.
