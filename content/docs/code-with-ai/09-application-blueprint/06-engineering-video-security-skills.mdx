## 1. Addy Osmani Senior Engineering Skills (`addyosmani/agent-skills`)

Authored by **Addy Osmani** (Google Chrome engineering leadership), this collection brings 25+ battle-tested workflows used at Google and open-source ecosystems to your AI agent.

### Installation

```bash
npx skills add addyosmani/agent-skills
```

To install globally for Google Antigravity:
```bash
npx skills add addyosmani/agent-skills -g -a antigravity -y
```

### Key Workflow Highlights
* **`/code-simplify`**: Agents love generating complex abstraction layers and nested helper functions. Running `/code-simplify` directs the agent to rewrite the recent change into the most readable, maintainable, repository-native syntax.
* **`/webperf`**: Audits your application for Core Web Vitals:
  - Eliminates render-blocking stylesheets and third-party scripts.
  - Generates responsive `<picture>` / `next/image` attributes.
  - Detects Largest Contentful Paint (LCP) bottlenecks and Interaction to Next Paint (INP) delays.

## 4. Cloudflare Security Audit (`cloudflare/security-audit-skill`)

Maintained by Cloudflare's security team, this skill turns your AI agent into an automated penetration tester and defensive auditor.

### Installation

```bash
npx skills add https://github.com/cloudflare/security-audit-skill
```

To install globally for Google Antigravity:
```bash
npx skills add https://github.com/cloudflare/security-audit-skill -g -a antigravity -y
```

### Sub-Skill: `security-audit`
* **Multi-Phase Auditing**: Spawns parallel reconnaissance and vulnerability-hunting passes across your codebase.
* **Edge Security Headers**: Validates Content Security Policy (`CSP`), `Strict-Transport-Security` (`HSTS`), `X-Content-Type-Options`, and `Referrer-Policy`.
* **OWASP Top 10 Checks**: Inspects SQL injections, unvalidated redirects, SSRF (Server-Side Request Forgery), and insecure direct object references (IDOR).
* **Machine-Readable Findings**: Outputs structured remediation tickets into `findings.json` that feed directly into the Blueprint workflow.

## 5. Complementary Ecosystem Extensions

To complete your agentic workstation, install these high-utility skills:

### 1. Vercel Next.js (`vercel/next.js`)
```bash
npx skills add vercel/next.js
```
* **Capabilities**: Direct access to Next.js 15/16 App Router conventions: Partial Prerendering (`PPR`), the `use cache` directive, `cacheLife`, `cacheTag`, and Server Actions.

### 2. Humanizer (`blader/humanizer`)
```bash
npx skills add https://github.com/blader/humanizer --skill humanizer
```
* **Capabilities**: Removes 20+ telltale signs of AI writing (words like *"delve"*, *"testament"*, *"crucial"*, *"beacon"* and formulaic conclusion paragraphs) to produce natural, engaging developer documentation and copy.

### 3. Archify (`tt-a1i/archify`)
```bash
npx skills add https://github.com/tt-a1i/archify --skill archify
```
* **Capabilities**: Analyzes your repository and compiles an interactive, animated architecture diagram into a self-contained HTML file with component dependency maps and data flows.

### 4. Agent Reach (`panniantong/agent-reach`)
```bash
npx skills add https://github.com/panniantong/agent-reach --skill agent-reach
```
* **Capabilities**: Gives your AI agent autonomous internet research access across Twitter, Reddit, YouTube, GitHub, Bilibili, and arXiv without requiring individual API subscription keys.

### 5. Agent Browser (`vercel-labs/agent-browser`)
```bash
npx skills add https://github.com/vercel-labs/agent-browser --skill agent-browser
```
* **Capabilities**: Playwright browser automation for headless DOM inspection, visual screenshot testing, and end-to-end user verification.
