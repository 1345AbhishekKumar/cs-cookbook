The **Application Blueprint** (codified in `E:\intercom` and maintained at [ai-blueprint.dev](https://ai-blueprint.dev/)) is a battle-tested, tool-agnostic workflow overlay layer designed to scaffold, develop, verify, and ship production applications with AI coding agents.

<Callout type="info" title="Official Blueprint Source">
The framework is published and maintained at **[https://ai-blueprint.dev/](https://ai-blueprint.dev/)**. You can install or overlay it on any project via the official CLI:
```bash
npx create-ai-blueprint@latest
```
</Callout>

Rather than being a static starter template or an empty app skeleton, the Blueprint is an **AI workflow operating system**. You scaffold your application using standard toolchains (`create-next-app`, Vite, Expo, FastAPI), and overlay the Blueprint architecture on top. The Blueprint then governs every interaction between you and your AI agents (Google Antigravity, Claude Code, OpenAI Codex, GitHub Copilot, and OpenCode).

## Core Feature Lifecycle

The Blueprint enforces a disciplined, repeatable feature development loop that replaces blind code generation with verified engineering:

```
  /brief (preview)
     │
     ▼
  /feature ──► Writes blueprint/context/current-feature.md & creates branch
     │
     ▼
  /implement ──► Builds in small reviewed steps; runs project verify/tests
     │
     ▼
  /check ──────► Proves runtime behavior (or /check guide for manual QA)
     │
     ▼
  /audit ──────► Independent code review & security pass; logs findings
     │
     ▼
  /complete ───► Archives history & executes approved local squash merge or PR
```
