Modern applications rely on serverless databases, low-latency key-value stores, distributed message queues, and global payment rails. Without domain-specific skills, AI agents frequently produce unindexed queries, run into connection pool exhaustion, write vulnerable Row-Level Security (RLS) policies, or mishandle asynchronous webhook events.

Here is the complete catalog of database, caching, and cloud infrastructure skills installed in the `E:\intercom` ecosystem.

---

## 1. Supabase (`supabase/agent-skills`)

**Supabase** provides an open-source Firebase alternative powered by PostgreSQL, Row-Level Security, Edge Functions, Auth, and Realtime channels.

### Installation

```bash
npx skills add supabase/agent-skills
```

To install globally for Google Antigravity:
```bash
npx skills add supabase/agent-skills -g -a antigravity -y
```

### Sub-Skills Catalog

```
supabase/agent-skills
├── supabase
└── supabase-postgres-best-practices
```

### Deep Dive into Supabase Skills
* **`supabase`**:
  - Directs SDK setup using `@supabase/supabase-js` and `@supabase/ssr` across Next.js Server Components, Server Actions, and Route Handlers.
  - Guides cookie-based session management (`createBrowserClient`, `createServerClient`).
  - Sets up Realtime database listeners and broadcast channels with cleanup hooks.
* **`supabase-postgres-best-practices`**:
  - Safe migration patterns: enforces non-blocking schema migrations without table-lock downtime.
  - Row Level Security (RLS) enforcement: generates explicit `SELECT`, `INSERT`, `UPDATE`, and `DELETE` policies tied to `auth.uid()`.
  - Schema constraints: automatically incorporates reference rules from `schema-constraints.md` to prevent cascading delete anomalies.
  - B-tree and GIN indexing for high-frequency foreign keys and JSONB fields.

## 2. Neon Database (`neondatabase/agent-skills`)

**Neon** is a serverless, multi-cloud Postgres database built with separation of storage and compute. It enables instant autoscaling to zero and zero-copy database branching.

### Installation

```bash
npx skills add neondatabase/agent-skills
```

To install globally for Google Antigravity:
```bash
npx skills add neondatabase/agent-skills -g -a antigravity -y
```

### Sub-Skills Catalog

The `neondatabase/agent-skills` package bundles **8 specialized sub-skills**:

```
neondatabase/agent-skills
├── neon (General router & CLI helpers)
├── neon-postgres (Database connection & drivers)
├── neon-postgres-branches (Ephemeral branch environments)
├── neon-postgres-egress-optimizer (Data transfer reduction)
├── neon-auth (Integrated serverless auth)
├── neon-functions (Edge serverless functions)
├── neon-object-storage (Cloud asset bindings)
└── neon-ai-gateway (LLM routing & semantic caching)
```

### Deep Dive into Neon Skills
* **`neon-postgres`**: Configures the serverless `@neondatabase/serverless` driver with WebSocket connection pooling, preventing connection spikes during high traffic.
* **`neon-postgres-branches`**: Guides CI/CD and agent workflows to create ephemeral database branches for every Pull Request or feature branch (`feature/oauth-login` gets its own isolated Postgres clone in < 1 second).
* **`neon-postgres-egress-optimizer`**: Analyzes generated queries to prevent heavy cross-region egress costs by trimming `SELECT *` statements, using pagination cursors, and compressing payloads.
* **`neon-ai-gateway`**: Implements AI caching and semantic deduplication layers over vector embeddings directly inside the database infrastructure.

## 3. Upstash (`upstash/skills`)

**Upstash** delivers serverless, REST-based Redis, message queues (QStash), vector search, and durable workflows designed specifically for edge runtimes (Cloudflare Workers, Vercel Edge, Next.js).

### Installation

```bash
npx skills add upstash/skills
```

To install globally for Google Antigravity:
```bash
npx skills add upstash/skills -g -a antigravity -y
```

### Sub-Skills Catalog

The `upstash/skills` package provides **14 specialized sub-skills**:

```
upstash/skills
├── Caching & Rate Limiting
│   ├── upstash (Meta router)
│   ├── upstash-redis-js (Edge Redis SDK)
│   ├── upstash-redis-start (Quickstart configuration)
│   └── upstash-ratelimit-js (Sliding-window rate limiters)
├── Messaging & Workflows
│   ├── upstash-qstash-js (Serverless queue & cron scheduler)
│   ├── upstash-workflow-js (Durable multi-step workflows)
│   ├── upstash-vector-js (Vector search & embeddings)
│   ├── upstash-search-js (Full-text indexer)
│   └── upstash-blob-js (Binary object storage)
└── Tooling & Sandboxes
    ├── upstash-cli (Terminal provisioning)
    └── upstash-box-* (upstash-box-cli, js, py, remote-work)
```

### Deep Dive into Upstash Skills
* **`upstash-ratelimit-js`**: Enforces edge API protection using token bucket or sliding-window algorithms:
  ```typescript
  import { Ratelimit } from "@upstash/ratelimit";
  import { Redis } from "@upstash/redis";

  const ratelimit = new Ratelimit({
    redis: Redis.fromEnv(),
    limiter: Ratelimit.slidingWindow(10, "10 s"),
  });
  ```
* **`upstash-qstash-js`**: Dispatches asynchronous background jobs and schedule cron jobs without maintaining persistent workers or Redis daemons.
* **`upstash-workflow-js`**: Builds durable multi-step agent pipelines where executions can pause for hours or days, auto-retry on network errors, and resume without losing state.
* **`upstash-vector-js`**: Fast, lightweight semantic search and vector retrieval for RAG (Retrieval-Augmented Generation) systems.


### Sub-Skills Catalog

```
docs.stripe.com
├── stripe-pay (Core Checkout, Payment Intents & customer billing)
├── stripe-docs (Reference API & SDK lookup)
├── stripe-best-practices (Zero-loss webhook idempotency & PCI compliance)
├── stripe-apps (Embedded Stripe dashboard extensions)
├── stripe-projects (Fullstack payment application scaffolding)
├── stripe-directory (Marketplace & seller directory models)
├── connect-recommend (Stripe Connect platform architecture)
├── connect-required-verification-information (KYC onboarding rules)
├── metronome (Usage-based meter billing pipelines)
└── upgrade-stripe (Migrating Stripe API version pins safely)
```

### Deep Dive into Stripe Skills
* **`stripe-pay`**: Implements prebuilt hosted Stripe Checkout Sessions or custom embedded Payment Elements, handling currency conversions and tax calculation.
* **`stripe-best-practices`**:
  - Enforces cryptographic webhook validation (`stripe.webhooks.constructEvent` with `STRIPE_WEBHOOK_SECRET`).
  - Implements **idempotency keys** on all mutation calls to prevent duplicate customer charges during network retries.
  - Automatically handles asynchronous events (`checkout.session.completed`, `invoice.payment_failed`, `customer.subscription.deleted`).
* **`connect-recommend`**: Guides the design of multi-sided marketplaces (split payments, application fees, connected custom/express accounts, and payouts).
