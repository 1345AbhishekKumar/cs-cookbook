## Engineering Discipline & Workflows

- **[Decision Ownership](/docs/code-with-ai/01-environment-setup/01-mindset)** — 'Build me X' is a wish, not a plan. You make engineering decisions; the agent executes syntax.
- **[The Agentic Cockpit](/docs/code-with-ai/01-environment-setup/02-environment)** — Agentic IDE with browser tools, skill caps under 100, and voice dictation for maximum throughput.
- **[The Standing Brief](/docs/code-with-ai/03-agent-setup/01-context-files)** — PRD, glossary, tech-stack declaration, concise AGENTS.md, and DESIGN.md.
- **[The Two-Session Workflow](/docs/code-with-ai/04-llm-strategy/05-two-session-workflow)** — Session 1 is architectural discussion producing a game plan. Session 2 executes via an orchestrator with specialized sub-agents.
- **[The Two-Stage Verification Loop](/docs/code-with-ai/06-testing/01-verification)** — The agent tests in headless browser; you test manually before reading a single line of code diff.
