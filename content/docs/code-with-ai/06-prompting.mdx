<LessonIntro>
The difference between an engineer who struggles with AI and one who ships entire production systems is not prompt length — it is information density and conversational posture. Poor prompting treats the model like an unreliable vending machine, issuing reactive commands ("fix this error", "make it look nice"). Masterful prompting treats the model like an expert colleague: it attaches real visual references, asks "what do you think?" before initiating edits, and anchors the agent directly to upstream documentation URLs.
</LessonIntro>

## The 4 Golden Rules of High-Bandwidth Prompting

### 1. Ask "What Do You Think?" Before "Fix This"
When encountering a tricky bug or designing a feature, avoid demanding an immediate code rewrite. Force the model into analytical mode first:

```text
❌ Reactive Prompt: "Fix this error: TypeError: cannot read property of undefined."
✅ Analytical Prompt: "Here is the stack trace and the calling function. Before touching any code, what are the top three potential root causes of this failure, and how can we verify which one is active?"
```

### 2. Attach Reference Visual Assets
LLMs with multimodal vision capabilities (Claude 3.7 Sonnet, GPT-4o) understand layout, typography, and visual balance infinitely better when you attach a screenshot.
- Screenshot a landing page section from Mobbin or Godly and paste it into the prompt.
- Prompt: *"Recreate this layout rhythm using our Tailwind design tokens from `DESIGN.md`. Notice the generous padding, the pill badges, and the subtle 1px border."*

### 3. Anchor Agents to Authoritative Documentation URLs
Models have fixed training cutoffs and will hallucinate deprecated syntax for fast-moving frameworks (Next.js 15, Drizzle, React 19). Always paste the official documentation URL or markdown content directly into the conversation:
```text
"We are implementing Next.js 15 async cookies. Refer to the official migration guide at https://nextjs.org/docs/app/building-your-application/upgrading/version-15#async-request-apis. Do not use deprecated synchronous cookies()."
```

## Reusable Artifact: The Prompt Patterns Library

<Tabs items={['Feature Implementation', 'Bug Diagnosis', 'Architecture Review', 'Refactoring']}>
  <Tab value="Feature Implementation">
```text
Task: Implement [Feature Name].
Context: We have [Table Name] in the database and user session available in middleware.
Acceptance Criteria:
1. User can execute [Action] from [Page / URL].
2. Payload is validated with Zod schema [Schema Name].
3. Optimistic UI updates while mutation completes.
4. Error banner renders if server returns 4xx/5xx.
Constraints: Do not touch [Protected File]. Adhere strictly to DESIGN.md.
```
  </Tab>

  <Tab value="Bug Diagnosis">
```text
Bug Report:
- Expected: [What should happen]
- Actual: [What actually happened]
- Stack Trace: [Paste exact error]
- Scope: File [File Path]
Do NOT write code yet. Outline the execution flow, identify where state diverges from expectations, and propose the minimal surgical fix.
```
  </Tab>

  <Tab value="Architecture Review">
```text
You are an adversarial Staff Security Engineer. 
Review the following proposed database schema and API route for:
1. Insecure Direct Object References (IDOR)
2. Missing foreign key constraints or cascade rules
3. Potential N+1 query traps
Propose changes with justifications.
```
  </Tab>

  <Tab value="Refactoring">
```text
Refactor [File Path] for maintainability:
1. Extract inline business logic into pure helper functions with strict types.
2. Ensure no functions exceed 40 lines of code.
3. Keep all existing Vitest test suites green.
Show the git diff and explanation.
```
  </Tab>
</Tabs>

High-bandwidth prompting replaces reactive demands with collaborative inquiry, visual anchors, and documented constraints.
