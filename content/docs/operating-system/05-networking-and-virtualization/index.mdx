Welcome to **Stage 5: Networking & Virtualization**. Cloud computing and microservices architecture depend entirely on operating system isolation mechanisms.

This stage demystifies what actually happens when you run a virtual machine or container, how the Linux network stack routes packets, and how kernels sandbox untrusted user code.

---

## What You Will Master

- **The Linux Network Stack**: Socket buffers (`sk_buff`), netfilter 5-hook packet traversal, connection tracking (`conntrack`), and kernel-bypass acceleration via XDP (eXpress Data Path) and DPDK.
- **Hardware Virtualization**: Type 1 (bare-metal) vs Type 2 (hosted) hypervisors, Intel VT-x root/non-root execution, KVM hypervisor internals, and Extended Page Tables (EPT).
- **The Container Reality**: Proving why "containers" do not exist in the Linux kernel — how the 7 namespaces isolate vision while cgroups v2 enforces CPU quotas, memory limits, and Pressure Stall Information (PSI).
- **Container Sandboxing & Security**: Linux Capabilities, rootless user namespaces, `seccomp-bpf` syscall filters, and microVM hardware isolation (AWS Firecracker, Google gVisor).
