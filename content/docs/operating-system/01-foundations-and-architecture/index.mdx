Welcome to **Stage 1: Foundations & Architecture**. This stage lays down the bedrock for everything that follows in systems engineering.

Before an operating system can schedule a thread or map a virtual page, physical hardware must initialize, firmware must hand off execution to a bootloader, and the kernel must configure CPU privilege rings.

---

## What You Will Master

- **The Boot Sequence**: The exact chain of custody from electrical power to UEFI firmware, GRUB bootloader, kernel decompression, initramfs, and systemd PID 1.
- **Architectural Paradigms**: The deep tradeoffs between Monolithic kernels (Linux), Microkernels (QNX, seL4), Hybrid designs (Windows NT, macOS XNU), Exokernels, and Unikernels.
- **The Core Abstractions**: How the operating system creates the illusion that each program owns all CPU cores, all physical memory, and dedicated persistence devices.
- **Process Anatomy**: Inside user address space (code, data, heap, stack) and kernel context (PCB, kernel stack, file descriptor tables).
- **The Privilege Ring Boundary**: How CPU hardware enforces Ring 3 (User) vs Ring 0 (Kernel), the exact instruction mechanics of `syscall`, and why crossings cost microseconds.
