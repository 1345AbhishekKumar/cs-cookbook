Welcome to **Stage 3: Memory Systems & Translation**. Virtual memory is among the greatest abstractions in computer engineering. It allows every process to pretend it has a contiguous, private 128TB address space, isolated from every other process on the machine.

This stage takes you from the physical silicon of DRAM through the hardware Memory Management Unit (MMU), multi-level page tables, modern user-space allocators, and multi-socket NUMA bus topologies.

---

## What You Will Master

- **Segmentation & Fragmentation**: The historical architecture before paging: segment tables, base-limit registers, internal vs external memory fragmentation, and memory compaction.
- **Hardware Page Translation**: x86-64 4-level page tables (PML4), Page Table Entry (PTE) hardware flags, and hardware page table walks.
- **The TLB Cache & Shootdowns**: Sub-nanosecond TLB translation, multi-core Inter-Processor Interrupt (IPI) invalidation shootdowns, and cache thrashing.
- **Paging Dynamics**: Minor (soft) vs Major (hard disk) page faults, demand paging Effective Access Time (EAT), FIFO vs Optimal vs LRU page replacement, Belady's anomaly, and thrashing.
- **User-Space Allocators**: Why `malloc()` uses `brk()` and `mmap()`, how `jemalloc`/`tcmalloc` eliminate lock contention using thread-local caches (`tcache`), and Transparent Huge Pages (THP).
- **NUMA Architectures**: Non-Uniform Memory Access on multi-socket servers, local vs remote DRAM latency, and memory-mapped files (`mmap`).
