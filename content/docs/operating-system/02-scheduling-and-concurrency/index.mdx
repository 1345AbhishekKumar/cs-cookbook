Welcome to **Stage 2: Scheduling & Concurrency**. On modern multi-core machines, hundreds of processes and thousands of threads fight for a limited number of execution cores.

This stage explores the twin pillars of concurrency: **resource arbitration** (how the kernel chooses who runs on the CPU) and **resource coordination** (how threads safely share mutable state without data races or deadlocks).

---

## What You Will Master

- **The Scheduling Trilemma**: Balancing throughput, interactive latency, and fairness across classical MLFQ, Linux CFS virtual runtime, and modern 6.6+ EEVDF.
- **Hardware Atomicity**: Compare-And-Swap (CAS), MESI cache coherence, memory barriers, and why software locks require CPU silicon support.
- **The Linux Futex**: How fast user-space mutexes achieve ~10ns uncontended lock acquisitions with zero system calls.
- **Classic Concurrency Problems**: Production-grade solutions to Producer-Consumer (bounded buffer), Readers-Writers variants, and Dining Philosophers.
- **Deadlock Engineering**: The four Coffman conditions, Resource Allocation Graphs (RAG), and Banker's Algorithm safe-state verification.
- **Inter-Process Communication**: The performance spectrum from UNIX pipes to domain sockets with `SCM_RIGHTS` fd passing and zero-copy shared memory.
