Welcome to **Stage 4: Storage, Persistence & I/O**. Non-volatile storage devices (HDDs, NVMe SSDs) operate at latencies thousands to millions of times slower than DDR5 RAM.

To prevent storage from grinding computing to a halt, the operating system kernel deploys intricate caching, journaling, multiplexing, and completion ring architectures.

---

## What You Will Master

- **The Virtual File System (VFS)**: The "everything is a file" interface: superblocks, inodes, dentries, file objects, and the Page Cache dirty writeback mechanism.
- **Crash Consistency & Journaling**: How Ext4 avoids hours-long `fsck` scans with Write-Ahead Logging (WAL), and how Copy-on-Write (ZFS/Btrfs) enables instant snapshots and bit-rot self-healing.
- **Physical Silicon Reality**: Flash Translation Layers (FTL), write amplification, TRIM commands, and NVMe multi-queue hardware eliminating lock serialization.
- **Disk Scheduling & RAID**: Classical seek-time algorithms (FCFS, SSTF, SCAN, LOOK) and RAID architectures (RAID 0, 1, 5, 6, 10).
- **The Event Multiplexing Revolution**: Hardware interrupts, SoftIRQs, DMA, solving the C10K problem, and $O(1)$ event dispatch with Linux `epoll`.
- **The io_uring Revolution**: Asynchronous completion rings, SQPOLL zero-syscall mode, `sendfile`, and true zero-copy networking.
