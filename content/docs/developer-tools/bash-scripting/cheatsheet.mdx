## 1. Script Anatomy & Execution

```bash
# Shebang (Line 1, character 1)
#!/bin/bash

# Portability Shebang
#!/usr/bin/env bash

# Enterprise Defensive Header
set -euo pipefail
```

### Execution Commands

```bash
chmod +x script.sh       # Grant execute permission
./script.sh arg1 arg2    # Run executable directly (child subshell)
bash script.sh           # Run with bash interpreter (no +x required)
source script.sh         # Run inside CURRENT shell (exports & cwd persist)
. script.sh              # Shorthand for source
bash -x script.sh        # Debug trace mode (xtrace)
```

## 2. Special Parameters

| Parameter | Description |
| :--- | :--- |
| **`$0`** | Name of the script currently executing |
| **`$1` ... `$9`** | Positional arguments 1 through 9 |
| **`${10}` ...** | Positional arguments 10 and higher (**braces mandatory**) |
| **`$#`** | Number of positional arguments passed |
| **`$@`** | All arguments as separate quoted strings: `"$1" "$2" "$3"` |
| **`$*`** | All arguments joined as a single string: `"$1 $2 $3"` |
| **`$?`** | Exit status code of the last executed command (`0` = success) |
| **`$$`** | Process ID (PID) of the running script |
| **`$!`** | Process ID (PID) of the most recently executed background job |

## 4. Conditional Tests

Use double brackets `[[ ... ]]` for modern Bash scripts:

### Integer Comparisons
```bash
[[ $a -eq $b ]]   # Equal to
[[ $a -ne $b ]]   # Not equal to
[[ $a -lt $b ]]   # Less than
[[ $a -le $b ]]   # Less than or equal to
[[ $a -gt $b ]]   # Greater than
[[ $a -ge $b ]]   # Greater than or equal to
```

### String Comparisons
```bash
[[ "$s1" == "$s2" ]]  # Strings are identical
[[ "$s1" != "$s2" ]]  # Strings are not identical
[[ -z "$s1" ]]        # String is EMPTY (Zero length)
[[ -n "$s1" ]]        # String is NOT empty (Non-zero length)
[[ "$s1" =~ ^[0-9]+$ ]] # Matches Regular Expression (digits)
```

### File & Directory Tests
```bash
[[ -e "$path" ]]  # Exists (file or folder)
[[ -f "$path" ]]  # Exists and is a regular file
[[ -d "$path" ]]  # Exists and is a directory
[[ -s "$path" ]]  # Exists and file size > 0 bytes
[[ -r "$path" ]]  # Readable
[[ -w "$path" ]]  # Writable
[[ -x "$path" ]]  # Executable
```

### Compound Boolean Logic
```bash
[[ cond1 && cond2 ]]  # Logical AND
[[ cond1 || cond2 ]]  # Logical OR
[[ ! cond1 ]]         # Logical NOT
```

## 5. Control Flow Structures

### If-Elif-Else Statement
```bash
if [[ "$env" == "prod" ]]; then
  echo "Deploying to production"
elif [[ "$env" == "staging" ]]; then
  echo "Deploying to staging"
else
  echo "Unknown environment: $env"
  exit 1
fi
```

### Case Statement
```bash
case "$action" in
  start|run)
    systemctl start myapp
    ;;
  stop)
    systemctl stop myapp
    ;;
  restart)
    systemctl restart myapp
    ;;
  *)
    echo "Usage: $0 {start|stop|restart}"
    exit 1
    ;;
esac
```

## 6. Loops & Iteration

### For Loop Over Range
```bash
# Range 1 to 10
for i in {1..10}; do
  echo "Index: $i"
done

# Step range: 0, 10, 20, 30... 100
for n in {0..100..10}; do
  echo "Step: $n"
done
```

### C-Style For Loop
```bash
for (( i = 0; i < 5; i++ )); do
  echo "Iteration $i"
done
```

### While Loop
```bash
count=1
while [[ $count -le 5 ]]; do
  echo "Count: $count"
  (( count++ ))
done
```

### Reading Files Line-by-Line (The Safe Idiom)
```bash
while IFS= read -r line || [[ -n "$line" ]]; do
  echo "Line: $line"
done < input.txt
```

## 7. Arithmetic Expansion `$(( ))`

```bash
sum=$(( a + b ))               # Addition
diff=$(( a - b ))              # Subtraction
product=$(( a * b ))           # Multiplication
quotient=$(( a / b ))          # Integer division
remainder=$(( a % b ))         # Modulo
power=$(( 2 ** 8 ))            # Exponent (256)

(( count++ ))                  # Increment in-place
(( total += 10 ))              # Compound addition

# Random range (1 to 100):
rand_num=$(( (RANDOM % 100) + 1 ))
```

## 8. Parameter Expansion Magic

| Syntax | Description | Example (`name=""`, `path="/var/log/app.log"`) |
| :--- | :--- | :--- |
| **`${var:-default}`** | Use default if `var` is unset or empty | `${PORT:-8080}` -> `8080` |
| **`${var:=default}`** | Assign default to `var` if unset/empty | `${PORT:=8080}` sets `PORT` |
| **`${var:?error}`** | Abort script with error message if unset | `${DB_USER:?Must set DB_USER}` |
| **`${#var}`** | Length of string in characters | `${#password}` |
| **`${var:offset:length}`** | Substring extraction | `${path:5:3}` -> `"log"` |
| **`${var#pattern}`** | Remove shortest matching prefix | `${path#*/}` -> `"var/log/app.log"` |
| **`${var##pattern}`** | Remove longest matching prefix | `${path##*/}` -> `"app.log"` (basename!) |
| **`${var%pattern}`** | Remove shortest matching suffix | `${path%.*}` -> `"/var/log/app"` |
| **`${var%%pattern}`** | Remove longest matching suffix | `${path%%/*}` |
| **`${var/find/replace}`** | Replace first occurrence | `${path/log/data}` |
| **`${var//find/replace}`** | Replace ALL occurrences | `${path//\//_}` |
| **`${var^^}`** | Convert string to UPPERCASE | `${name^^}` |
| **`${var,,}`** | Convert string to lowercase | `${name,,}` |

## 9. Streams, Redirection & Pipes

| Syntax | Meaning |
| :--- | :--- |
| **`cmd > file`** | Overwrite stdout to file |
| **`cmd >> file`** | Append stdout to file |
| **`cmd < file`** | Read file into stdin |
| **`cmd 2> file`** | Redirect stderr to file |
| **`cmd 2>> file`** | Append stderr to file |
| **`cmd > file 2>&1`** | Merge stderr into stdout and save to file |
| **`cmd &> file`** | Modern Bash shorthand to redirect both stdout & stderr |
| **`cmd &> /dev/null`** | Discard all output and errors silently |
| **`cmd \| tee file`** | Display output on terminal AND save to file |
| **`cmd <<< "$var"`** | Here String: feeds variable into stdin |
| **`diff <(cmd1) <(cmd2)`**| Process substitution (treats outputs as files) |

## 10. Defensive Scripting Template

Copy this production template for any new script:

```bash title="template.sh"
#!/bin/bash
# ==============================================================================
# Script: template.sh
# Author: DevOps Team
# Description: Production hardened automation template
# ==============================================================================
set -euo pipefail

# Script directory resolution
SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"

# Temporary directory with automatic cleanup
TMP_DIR=$(mktemp -d -t script_XXXXXX)
cleanup() {
  local exit_code=$?
  rm -rf "$TMP_DIR"
  if [[ $exit_code -ne 0 ]]; then
    echo "❌ Script exited with error status $exit_code" >&2
  fi
}
trap cleanup EXIT SIGINT SIGTERM

main() {
  echo "Running production automation from $SCRIPT_DIR..."
  # Core logic goes here
}

main "$@"
```
