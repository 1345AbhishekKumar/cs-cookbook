## Lessons & Reference Manuals

Interactive guides and full-length reference manuals covering daily command-line tooling, package management, scripting, and version control.

### JavaScript Package Managers & Runtimes

- [**Node.js Runtime Basics**](/docs/developer-tools/nodejs-runtime-basics) — How Node.js actually works: V8 + libuv, event loop phases, thread pool, CommonJS vs ESM, EventEmitter, streams, and when to use it.
- [**npm for Beginners**](/docs/developer-tools/npm) — Foundational JavaScript package management, semantic versioning (`^`, `~`), local vs. global installs, scripts, and lockfiles.
- [**pnpm for Beginners**](/docs/developer-tools/pnpm) — Fast, disk-efficient, and strict alternative using content-addressable storage, hard links, and non-flat `node_modules`.
- [**Bun for Beginners**](/docs/developer-tools/bun) — All-in-one JavaScript toolkit written in Zig and powered by JavaScriptCore. Runtime, bundler, package manager, and test runner.
- [**Deno for Beginners**](/docs/developer-tools/deno) — Modern, secure JavaScript & TypeScript runtime built on V8 and Rust. Sandboxed permissions, web standards, JSR, and built-in developer tooling.
- [**npm vs Yarn vs pnpm vs Bun**](/docs/developer-tools/bun-vs-npm) — Complete comparative analysis: dependency resolution, hoisting algorithms, benchmarks, disk usage, and selection criteria.

### Python Toolchain

- [**pip for Beginners**](/docs/developer-tools/pip) — The universal Python package installer: PyPI, venv isolation, `requirements.txt`, version specifiers, wheels vs sdists, and pip vs uv.
- [**uv: The Python Toolchain in One Command**](/docs/developer-tools/uv) — Astral's ultra-fast Rust-based Python package and project manager with interactive benchmark calculator and command builder.
- [**Python Code Quality & Automation**](/docs/developer-tools/python-code-quality) — Complete modern toolchain: Ruff linter & formatter, static type checking with mypy, pre-commit git hooks, and Just/Make task runners.

### Linux & Shell Scripting

- [**Linux Fundamentals**](/docs/developer-tools/linux/basics) — Shells vs. terminals, Unix filesystem hierarchy (`/etc`, `/var`, `/proc`), users, permissions (`chmod`, `chown`), and environment variables.
- [**50 Most Popular Linux Commands**](/docs/developer-tools/linux/commands-50) — Complete reference manual with interactive command search, category filtering, syntax, options, and gotchas.
- [**Bash Scripting Masterclass**](/docs/developer-tools/bash-scripting) — Complete hands-on curriculum from first script to production automation: Shebang, variables, arithmetic, conditions, loops, functions, streams, defensive scripting, interactive terminal simulator, and real-world projects (Elden Ring RPG, Push-up counter, network sweeper).
- [**Shell Scripting & CLI**](/docs/developer-tools/shell-cli) — From beginner terminal usage to automation wizard: standard streams (`stdin`, `stdout`, `stderr`), piping, redirection, loops, and interactive simulations.
- [**PowerShell: Objects, Not Text**](/docs/developer-tools/powershell) — Understanding PowerShell's object-oriented pipeline architecture with interactive cmdlet and object projection demos.
- [**WSL: Linux on Windows**](/docs/developer-tools/wsl) — Windows Subsystem for Linux (WSL 2): architecture, filesystem performance (/mnt/c vs ext4), path translation, VS Code integration, and Windows-Linux interop.

### Environment & Configuration

- [**Environment Configuration (.env, direnv & Secrets Hygiene)**](/docs/developer-tools/env) — Complete guide to local environment variables: `.env` hierarchies, `.env.example` contracts, ambient shell switching with `direnv`, runtime secret injection, and git leak prevention.

### Version Control

- [**Learning Git**](/docs/developer-tools/git) — From first commit to team workflows: the three trees (Working Tree, Index, HEAD), DAG commit history, branching, merge vs. rebase, and interactive graph simulator.
- [**GitHub for Beginners**](/docs/developer-tools/github) — From local git to collaborative GitHub: repos, HTTPS vs SSH auth, remotes, push/pull, branches, pull requests, forks, Issues, and gh CLI.
- [**Team Workflow & Release Practices**](/docs/developer-tools/release-workflow) — The three practices that keep releases predictable: code review gates, semantic versioning (SemVer), and changelogs.
