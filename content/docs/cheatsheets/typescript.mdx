TypeScript is typed JavaScript: annotations + static checks, erased at compile time. Stable syntax across 5.x → 7.x (7.0, July 2026, is a Go rewrite — faster, `strict` on by default — same annotations).

Use this page as a quick reference: tables plus minimal copy-paste snippets.

## Setup & First type

```bash
npm i -D typescript tsx @types/node
npx tsc --init   # creates tsconfig.json
npx tsc --noEmit # typecheck only
```

```ts
let name: string = "geeks";
let n: number = 42;
let ok: boolean = true;

// Inference — annotation optional when obvious
let lang = "TS"; // inferred: string
// lang = 5;     // Error
```

## Primitives & Top/Bottom types

| Type | Meaning | Example |
| --- | --- | --- |
| `string` | Text. | `let s: string = "hi";` |
| `number` | All numbers (int + float). | `let n: number = 3.14;` |
| `boolean` | True / false. | `let b: boolean = true;` |
| `bigint` | Arbitrary-precision ints. | `let b: bigint = 10n;` |
| `symbol` | Unique identifiers. | `let s: symbol = Symbol("id");` |
| `null` | Intentional nothing. | `let x: null = null;` |
| `undefined` | Unassigned. | `let y: undefined = undefined;` |
| `any` | Opt out of checking. Avoid. | `let a: any = 1;` |
| `unknown` | Safe top type. Narrow before use. | `let u: unknown = x;` |
| `never` | Bottom type. Unreachable / empty union. | `function fail(m: string): never` |
| `void` | Returns nothing meaningful. | `function log(m: string): void` |
| `object` | Any non-primitive. | `let o: object = {};` |

Hierarchy: `unknown` (top, safe) → everything → `never` (bottom). `any` escapes the checker — prefer `unknown` + narrowing.

```ts
function fail(msg: string): never { throw new Error(msg); }
function log(msg: string): void { console.log(msg); }

let u: unknown = JSON.parse("{}");
// u.foo; // Error — must narrow first
if (typeof u === "object" && u !== null) { /* ok */ }
```

## Literals, Unions, Intersections

| Construct | Meaning | Example |
| --- | --- | --- |
| `Literal` | Exact value as type. | `type Dir = "up";` |
| `Union` | Either member (`\|`). | `type S = "ok" \| "err";` |
| `Intersection` | Both at once (`&`). | `type T = A & B;` |
| `Literal widening lock` | Keep literal, don't widen. | `const x = "a" as const;` |

```ts
type Status = "ok" | "error" | "loading";
type Id = string | number;

type A = { a: string };
type B = { b: number };
type Both = A & B; // { a: string; b: number }

const COLORS = ["r", "g", "b"] as const;
type Color = (typeof COLORS)[number]; // "r" \| "g" \| "b"
```

Prefer literal unions over `enum` for new code — lighter, tree-shakeable.

## Arrays & Tuples

| Form | Meaning | Example |
| --- | --- | --- |
| `Array` | List of one type. | `let a: number[] = [1, 2];` |
| `Generic array` | Same, generic spelling. | `let b: Array<string> = [];` |
| `Readonly array` | Immutable view. | `let r: readonly number[] = [1];` |
| `Tuple` | Fixed length + positions. | `let t: [string, number];` |
| `Named tuple` | Labels for readability. | `let t: [name: string, age: number];` |
| `Variadic tuple` | Mixed fixed + rest. | `type T = [string, ...number[]];` |
| `Optional tuple element` | May be absent. | `type T = [string, number?];` |

```ts
let t: [string, number] = ["age", 42];
// t = [42, "age"]; // Error — order matters

function rest(...args: string[]): void {}
const pair = ["a", 1] as const; // readonly ["a", 1]
```

With `noUncheckedIndexedAccess`, `arr[i]` is `T \| undefined` — handle it.

## Objects — type vs interface

| Form | Use when | Example |
| --- | --- | --- |
| `type` | Unions, intersections, mapped, conditional, most flexible. Default choice. | `type T = { a: string };` |
| `interface` | Public object contracts, `extends` / `implements`, declaration merging. | `interface I { a: string }` |
| `extends` | Single-parent inheritance (interface). | `interface A extends B { … }` |
| `Intersection` | Multi-parent composition. | `type T = A & B;` |
| `Optional` | May be absent. | `{ b?: string }` |
| `Readonly` | Cannot reassign. | `{ readonly a: number }` |
| `Index signature` | Dynamic keys. | `{ [k: string]: number }` |

```ts
type User = { id: string; name: string; age?: number; readonly created: Date };

interface Base { id: string }
interface Admin extends Base { role: "admin" }
type Power = Admin & { super: boolean };

// Declaration merging — only interfaces
interface Window { __myFlag?: boolean }

// Augment third-party types the same way
declare module "express-serve-static-core" {
  interface Request { userId?: string }
}
```

Default to `type`. Reach for `interface` when you want merging (e.g. extending `Express.Request`, `Window`).

## Functions

```ts
// Params + return
function add(a: number, b: number): number { return a + b; }

// Optional / default / rest
function greet(name: string, title?: string): string { return `hi ${name}`; }
function pow(base: number, exp = 2): number { return base ** exp; }
function sum(...nums: number[]): number { return nums.reduce((t, n) => t + n, 0); }

// Arrow
const mul = (a: number, b: number): number => a * b;

// Function type + void callback
type Fn = (a: string) => number;
function run(cb: () => void): void { cb(); }

// Overloads — signature list + one implementation
function fmt(x: number): string;
function fmt(x: string): string;
function fmt(x: unknown): string { return String(x); }

// async always returns Promise
async function get(id: string): Promise<User> { /* … */ return user; }
```

`void` = ignore return; `never` = never returns (throws / infinite loop).

## Classes

```ts
class Animal {
  constructor(public name: string, private age: number) {}
  describe(): string { return this.name; }
}

class Dog extends Animal {
  readonly legs = 4;
  protected barkVolume = 3;
  #secret = "bone"; // JS-private, harder than TS private

  override describe(): string { return `dog ${this.name}`; }
  static species = "Canis familiaris";
}

abstract class Shape {
  abstract area(): number; // must implement
}

class Circle extends Shape {
  constructor(public r: number) { super(); }
  area(): number { return Math.PI * this.r ** 2; }
}

interface HasId { id: string }
class Entity implements HasId { constructor(public id: string) {} }
```

| Modifier | Meaning |
| --- | --- |
| `public` | Anywhere (default). |
| `private` | Inside class only (compile-time). |
| `protected` | Class + subclasses. |
| `#field` | True JS-private at runtime. |
| `readonly` | Assign once (constructor). |
| `static` | On class, not instance. |
| `abstract` | Must be extended, cannot `new`. |
| `override` | Explicitly replacing parent. |

Generic classes: `class Box<T> { constructor(public value: T) {} }`.

## Enums vs Literal unions

```ts
// Numeric enum (legacy) — avoid in new code
enum Color { R, G, B }

// String enum — clearer
enum Role { Admin = "ADMIN", User = "USER" }

// Preferred: literal union + const object
const ROLES = ["admin", "user"] as const;
type Role2 = (typeof ROLES)[number]; // "admin" \| "user"
```

Rule: literal unions for data shapes; `enum` only when you need the runtime object + reverse mapping.

## Generics

Type parameters preserving input↔output relationships. Inferred at call site, constrained with `extends`, defaulted with `=`.

```ts
function id<T>(x: T): T { return x; }
id("a"); // T inferred as string

// Constraint — body can rely on shape
function len<T extends { length: number }>(x: T): number { return x.length; }

// Key constrained to object keys — type-safe access
function get<T, K extends keyof T>(obj: T, key: K): T[K] { return obj[key]; }

// Default — used when inference fails
interface ApiResponse<T = unknown> { data: T; ok: boolean }

// const type param — preserves literal narrowness (TS 5.0+)
function asTuple<const T extends string[]>(...args: T): T { return args; }
```

| Pattern | Syntax |
| --- | --- |
| `Generic function` | `function f<T>(x: T): T` |
| `Generic interface` | `interface Box<T> { value: T }` |
| `Generic class` | `class Stack<T> { items: T[] }` |
| `Constraint` | `<T extends { length: number }>` |
| `Key constraint` | `<T, K extends keyof T>` |
| `Default` | `<T = unknown>` |
| `Const modifier` | `<const T extends …>` |
| `Multiple params` | `<T, U>(a: T, b: U)` |

## Narrowing & Type Guards

Collapse a wide type to one member per branch. TS tracks this through control flow.

| Guard | Narrows | Example |
| --- | --- | --- |
| `typeof` | Primitives. | `typeof x === "string"` |
| `instanceof` | Class instances. | `x instanceof Error` |
| `in` | Property existence. | `"kind" in x` |
| `Discriminated union` | `switch` on literal tag. Canonical pattern. | `switch (x.kind)` |
| `Predicate` | Custom guard. | `(v): v is Dog => …` |
| `Asserts` | Throw-on-failure guard. | `(v): asserts v is string` |
| `Non-null` | Strip `null`/`undefined`. Sparingly. | `x!` |
| `as` | Cast. You own the lie. | `x as string` |
| `satisfies` | Check shape, keep literals. Preferred over annotation. | `x satisfies T` |
| `as const` | Lock to literal. | `[1, "a"] as const` |

```ts
type Shape2 = { kind: "circle"; r: number } | { kind: "square"; size: number };

function area(s: Shape2): number {
  switch (s.kind) { // discriminated narrowing
    case "circle": return Math.PI * s.r ** 2;
    case "square": return s.size ** 2;
  }
}

// Custom predicate
function isDog(v: unknown): v is { bark(): void } {
  return typeof v === "object" && v !== null && "bark" in v;
}

// satisfies keeps literals; annotation widens them
const cfg = { mode: "dark", retries: 3 } satisfies { mode: string; retries: number };
// cfg.mode is "dark", not string
```

Exhaustive check for future safety:

```ts
function assertNever(x: never): never { throw new Error("unhandled: " + x); }
function handle(s: Shape2): number {
  switch (s.kind) {
    case "circle": return 1;
    case "square": return 2;
    default: return assertNever(s); // errors when a new kind is added
  }
}
```

## keyof, typeof, Indexed access

```ts
interface User { id: string; name: string; age: number }

type Keys = keyof User;            // "id" \| "name" \| "age"
type NameType = User["name"];      // string
type Pick2 = User["id" | "name"];  // string (union of both)

const config = { retries: 3, verbose: true } as const;
type Config = typeof config;       // { readonly retries: 3; readonly verbose: true }
```

Pattern: define runtime value once with `as const`, derive all types via `typeof` + `keyof` + indexed access. One source of truth.

## Utility Types — the standard library

Built from mapped + conditional types. Four jobs: change modifiers, select keys, filter unions, read functions/promises.

| Utility | Job | Example |
| --- | --- | --- |
| `Partial<T>` | All props optional. PATCH payloads. | `Partial<User>` |
| `Required<T>` | All props required. | `Required<User>` |
| `Readonly<T>` | All props readonly (shallow). | `Readonly<User>` |
| `Pick<T, K>` | Keep keys K. Response shaping. | `Pick<User, "id" \| "name">` |
| `Omit<T, K>` | Drop keys K. Inverse of Pick. | `Omit<User, "password">` |
| `Record<K, V>` | Object from keys K to values V. Lookup tables. | `Record<string, User>` |
| `Exclude<U, M>` | Remove members M from union. | `Exclude<Status, "error">` |
| `Extract<U, M>` | Keep members matching M. | `Extract<Id, string>` |
| `NonNullable<T>` | Strip `null`/`undefined`. = `Exclude<T, null \| undefined>`. | `NonNullable<string \| null>` |
| `ReturnType<F>` | Return type of function. Pair with `typeof`. | `ReturnType<typeof fn>` |
| `Parameters<F>` | Param tuple. Index `[0]`, `[1]`. | `Parameters<typeof fn>` |
| `ConstructorParameters<C>` | Params of a `new`. | `ConstructorParameters<typeof Date>` |
| `InstanceType<C>` | Instance of a class. | `InstanceType<typeof Date>` |
| `Awaited<T>` | Recursively unwrap `Promise`. | `Awaited<Promise<Promise<number>>>` |
| `Uppercase<S>` | Uppercase string literal. | `Uppercase<"ab">` |
| `Lowercase<S>` | Lowercase string literal. | `Lowercase<"AB">` |
| `Capitalize<S>` | First letter up. | `Capitalize<"ab">` |
| `Uncapitalize<S>` | First letter down. | `Uncapitalize<"Ab">` |
| `NoInfer<T>` | Block inference at a spot (TS 5.4+). | `NoInfer<T>` |

```ts
type UpdatePayload = Partial<User>;                 // PATCH body
type Preview = Pick<User, "id" | "name">;           // list view
type Safe = Omit<User, "passwordHash">;             // public API
type ById = Record<string, User>;                   // lookup
type OnlyStrings = Extract<Id, string>;             // string
type Ret = ReturnType<typeof getUser>;              // no manual sync
type FirstArg = Parameters<typeof getUser>[0];      // string
```

## Conditional Types + infer

`T extends U ? X : Y` — "if T assignable to U, then X, else Y". Distributes over unions unless wrapped in a tuple.

```ts
type IsString<T> = T extends string ? true : false;
type A = IsString<"a">; // true
type B = IsString<1>;   // false

// Distributive: applies per member
type ToArray<T> = T extends unknown ? T[] : never;
type C = ToArray<string | number>; // string[] \| number[]

// Block distribution with tuple wrap
type NoDist<T> = [T] extends [string] ? true : false;
type D = NoDist<string | number>; // false (whole union tested)
```

`infer` captures part of the matched type — the engine behind `ReturnType`:

```ts
type Unwrap<T> = T extends Promise<infer R> ? R : T;
type E = Unwrap<Promise<number>>; // number

type First<T> = T extends [infer H, ...unknown[]] ? H : never;
type F = First<["a", 1, 2]>; // "a"

// How ReturnType is actually defined:
type MyReturn<T> = T extends (...args: never[]) => infer R ? R : never;
```

## Mapped Types

Type-level loop over keys: `{ [K in keyof T]: … }`. Add/remove `?` / `readonly` with `+`/`-`; rename/filter with `as`.

```ts
type Opt<T> = { [K in keyof T]?: T[K] };            // like Partial
type Froze<T> = { +readonly [K in keyof T]: T[K] }; // like Readonly
type Mutable<T> = { -readonly [K in keyof T]: T[K] };

// Remap keys + filter (falsy `as` keys are dropped)
type Getters<T> = {
  [K in keyof T as `get${Capitalize<string & K>}`]: () => T[K];
};

// Filter out function props
type DataOnly<T> = {
  [K in keyof T as T[K] extends Function ? never : K]: T[K];
};
```

## Template Literal Types

Compose string literal types; pair with `infer` and intrinsic transforms.

```ts
type Event = `on${Capitalize<"click" | "hover">}`; // "onClick" \| "onHover"
type Route = `/users/${string}` | `/posts/${number}`;

type GetterName<T extends string> = `get${Capitalize<T>}`;
type G = GetterName<"name">; // "getName"

// Parse with infer
type ParseId<S> = S extends `user-${infer N}` ? N : never;
type P = ParseId<"user-42">; // "42"
```

## Modules — import / export

```ts
// named.ts
export const a = 1;
export type T = { x: number };
export default function main(): void {}

// consumer.ts
import main, { a, type T } from "./named"; // `type` import — erased
import type { T as T2 } from "./named";    // type-only import
export * from "./named";                   // re-export all
export { a as b } from "./named";

// Dynamic (lazy / conditional)
const mod = await import("./heavy");

// Ambient declaration (no runtime file)
declare module "*.css" { const c: Record<string, string>; export default c; }
```

Use `import type` for pure types — tree-shaking + avoids runtime cycles. Enable `isolatedModules` for esbuild/swc compatibility.

## Decorators (standard, TS 5+)

```ts
function logged<T extends new (...a: never[]) => object>(Ctor: T, _ctx: ClassDecoratorContext): T {
  return class extends Ctor {
    constructor(...args: never[]) { super(...args); console.log("created"); }
  };
}

@logged
class Service {}
```

Enable with `experimentalDecorators: false` (standard) — legacy flag only for old libraries.

## Error handling — narrow unknown

`catch` variables are `unknown` under `strict` / `useUnknownInCatchVariables`. Never trust them.

```ts
try {
  JSON.parse("bad");
} catch (e) {
  if (e instanceof Error) console.error(e.message);
  else console.error(String(e));
}
```

## Typed fetch boundary (Zod + TS)

TS checks shapes you declare, not what arrives at runtime. Parse at the boundary, trust inside.

```ts
import { z } from "zod";

const UserSchema = z.object({ id: z.string(), name: z.string() });
type User2 = z.infer<typeof UserSchema>; // inferred, single source

async function getJSON<T>(url: string, schema: z.ZodType<T>): Promise<T> {
  const res = await fetch(url);
  if (!res.ok) throw new Error(`HTTP ${res.status}`);
  return schema.parse(await res.json()); // runtime-checked
}

const user = await getJSON("/api/user", UserSchema); // User2
```

## tsconfig essentials

```jsonc
{
  "compilerOptions": {
    "strict": true,                 // master flag: null checks, noImplicitAny, …
    "target": "ES2022",             // output JS level — match runtime
    "module": "NodeNext",           // Node ESM/CJS resolution
    "moduleResolution": "Bundler",  // use with Vite / esbuild / webpack
    "lib": ["ES2022", "DOM"],
    "noUncheckedIndexedAccess": true, // arr[i] → T \| undefined (recommended)
    "exactOptionalPropertyTypes": true, // {a?: string} ≠ {a: string \| undefined}
    "skipLibCheck": true,           // skip .d.ts checking — always on for apps
    "isolatedModules": true,        // esbuild / swc compatibility
    "declaration": true,            // emit .d.ts (libraries)
    "sourceMap": true,
    "paths": { "@/*": ["src/*"] },  // alias (mirror in bundler)
    "types": ["node"]
  },
  "include": ["src"]
}
```

| Flag | Why |
| --- | --- |
| `strict` | The safety net: `strictNullChecks`, `noImplicitAny`, etc. in one line. |
| `noUncheckedIndexedAccess` | Catches undefined-index bugs. Highest value-per-letter flag. |
| `target` | Don't downlevel modern syntax you can already run. |
| `module` / `moduleResolution` | Must match runtime: `NodeNext` for Node, `Bundler` for Vite. |
| `skipLibCheck` | Faster builds, fewer third-party type fights. |
| `exactOptionalPropertyTypes` | Distinguishes missing key from explicit `undefined`. |

## Common patterns

```ts
// API response wrapper
type ApiResult<T> = { ok: true; data: T } | { ok: false; error: string };

// Update payload from entity
type Update<T> = Partial<Omit<T, "id" | "createdAt">>;

// Exhaustive state machine
type State = { s: "idle" } | { s: "loading" } | { s: "done"; data: string };

// Typed event emitter — event name determines payload
type Events = { login: { id: string }; logout: undefined };
declare function emit<K extends keyof Events>(e: K, p: Events[K]): void;
emit("login", { id: "1" }); // payload checked per event

// Config with enforced literal + shape check
const db = { host: "x", port: 5432 } as const satisfies Record<string, string | number>;
```

## Memory anchors

- **Top vs bottom:** `unknown` is the safe top (narrow me), `never` is the empty bottom, `any` is the escape hatch you pay for later.
- **Either vs both:** union (`\|`) = either, intersection (`&`) = both. Narrow unions with `typeof / instanceof / in / switch(kind)`.
- **type vs interface:** `type` composes (unions, mapped, conditional), `interface` merges (extend third-party). Default `type`.
- **satisfies beats annotation:** `x satisfies T` checks shape but keeps literals; `x: T` widens them away.
- **Utilities do 4 jobs:** modifiers (`Partial/Required/Readonly`), keys (`Pick/Omit/Record`), unions (`Exclude/Extract/NonNullable`), functions (`ReturnType/Parameters/Awaited`).
- **infer lives in extends:** `T extends (…infer R) ? R : …` — how `ReturnType`, `Awaited`, unwraps are built.
- **Mapped = loop over keys:** `[K in keyof T]` + optional `as` rename/filter + `±readonly/?` modifiers.
- **Literals compose:** template types (`` `on${…}` ``) + `as const` + `typeof` = types derived from one runtime truth.
- **Boundary rule:** validate untrusted input (Zod/Valibot) once, then trust types inside. `catch` is `unknown` — narrow it.
- **tsconfig two-liner:** `strict: true` + `noUncheckedIndexedAccess: true` catches most real-world bugs.
