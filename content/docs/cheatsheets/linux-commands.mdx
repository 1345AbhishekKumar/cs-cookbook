## Filesystem Hierarchy Standard (FHS)

Everything in Linux is represented as a file under the root directory `/`.

| Directory           | Purpose                                                          | Typical Contents                                 |
| ------------------- | ---------------------------------------------------------------- | ------------------------------------------------ |
| `/bin` & `/usr/bin` | Essential executable binary programs.                            | `bash`, `ls`, `grep`, `python3`                  |
| `/etc`              | System-wide host-specific configuration files.                   | `/etc/passwd`, `/etc/nginx/`, `/etc/hosts`       |
| `/var`              | Variable data that changes during system operation.              | `/var/log/`, `/var/www/`, `/var/cache/`          |
| `/home`             | Non-root users' personal files and user configs.                 | `/home/alice/.bashrc`, `/home/alice/.ssh/`       |
| `/root`             | Home directory of the root superuser.                            | `/root/.ssh/`                                    |
| `/tmp`              | Temporary scratch files wiped upon reboot.                       | Socket handles, ephemeral caches                 |
| `/proc`             | Virtual pseudo-filesystem exposing live kernel & process states. | `/proc/cpuinfo`, `/proc/meminfo`, `/proc/<PID>/` |
| `/sys`              | Virtual pseudo-filesystem exposing hardware device parameters.   | Power states, network interfaces, PCI buses      |
| `/dev`              | Device nodes representing physical or virtual hardware.          | `/dev/sda` (disk), `/dev/null`, `/dev/urandom`   |

## File Navigation & Directory Operations

| Command     | Action                                                                | Example                                     |
| ----------- | --------------------------------------------------------------------- | ------------------------------------------- |
| `ls -lah`   | List files with permissions, human-readable sizes, and hidden files.  | `ls -lah /var/log`                          |
| `pwd`       | Print absolute path of current working directory.                     | `pwd`                                       |
| `cd -`      | Switch back to previously visited directory.                          | `cd -`                                      |
| `mkdir -p`  | Create directory tree, creating missing parent folders automatically. | `mkdir -p src/components/ui`                |
| `cp -r`     | Recursively copy directories and files.                               | `cp -r config/ config.backup/`              |
| `mv`        | Move or rename files and directories.                                 | `mv app.js server.js`                       |
| `rm -rf`    | Forcefully and recursively remove files and directories.              | `rm -rf dist/ node_modules/`                |
| `ln -s`     | Create a symbolic link (symlink).                                     | `ln -s /opt/node-20/bin/node /usr/bin/node` |
| `tree -L 2` | Display graphical directory tree up to 2 levels deep.                 | `tree -L 2 -I 'node_modules'`               |

## File Inspection & Text Paging

```bash
# 1. Page through large files without loading entire file into RAM
less -N /var/log/syslog    # -N displays line numbers (Press 'q' to quit, '/' to search)

# 2. View head or tail of files
head -n 25 app.log         # First 25 lines
tail -n 50 app.log         # Last 50 lines

# 3. Live log streaming (follow mode)
tail -f -n 100 /var/log/nginx/access.log

# 4. View file with non-printable characters / line endings
cat -A script.sh           # Shows $ at line ends and ^M for Windows CRLF endings
```

## The Text Processing Power Trio: Grep, Sed, Awk

Combine these stream processors via pipes (`|`) to slice, search, and transform any text.

### 1. `grep` — Regular Expression Pattern Search

```bash
# Basic case-insensitive recursive search
grep -rin "DATABASE_URL" /etc/

# Search and invert match (show lines NOT containing pattern)
grep -v "^#" /etc/ssh/sshd_config   # Show config ignoring comment lines

# Count matching lines
grep -c "ERROR" app.log

# Show match with surrounding context lines (-B before, -A after, -C both)
grep -C 3 "NullPointerException" server.log

# Extended regex search (ERE)
grep -E "(404|500|502)" /var/log/nginx/access.log
```

### 2. `sed` — Stream Editor (Transformations & In-Place Edits)

```bash
# Replace first occurrence of 'http://' with 'https://' per line
sed 's/http:\/\//https:\/\//' urls.txt

# Global replacement across entire file
sed 's/old_api/new_api/g' config.js

# In-place file modification (saves directly to file!)
sed -i 's/DEBUG = True/DEBUG = False/g' settings.py

# Delete lines 1 to 5 from output
sed '1,5d' file.txt

# Print only lines 40 through 60
sed -n '40,60p' app.log
```

### 3. `awk` — Structured Field Scanning & Data Processing

`awk` splits each line into fields (`$1`, `$2`, `$3`...) based on whitespace or custom delimiters.

```bash
# Print specific columns (e.g. usernames and home shells from /etc/passwd)
awk -F: '{print $1, $7}' /etc/passwd

# Filter based on numeric conditions (find processes using > 50% CPU)
ps aux | awk '$3 > 50.0 {print $2, $3, $11}'

# Calculate sum and average of column 1
awk '{sum += $1} END {print "Total:", sum, "Average:", sum/NR}' numbers.txt

# Format output into clean columns
awk 'NR > 1 {printf "%-15s %-10s\n", $1, $4}' input.txt
```

### 4. Pipeline Helpers: Cut, Sort, Uniq, Tr

```bash
# Extract top 10 most frequent client IP addresses from Nginx log:
awk '{print $1}' /var/log/nginx/access.log | sort | uniq -c | sort -nr | head -n 10

# Count total lines of code across project
find src/ -name "*.ts" | xargs wc -l
```

## File & Directory Search (`find` & `fd`)

```bash
# 1. Find by name (case-insensitive)
find /var/www -iname "*.html"

# 2. Find by type (f = file, d = directory, l = symlink)
find . -type f -name "*.env"

# 3. Find files modified in the last 24 hours (-mtime -1) or older than 30 days (+30)
find /backups -type f -mtime +30

# 4. Find large files (> 100 Megabytes)
find / -xdev -type f -size +100M -exec ls -lh {} +

# 5. Execute command on all matching files safely (using + batches arguments)
find . -type f -name "*.tmp" -exec rm -f {} +
```

## Command Multiplier: `xargs`

Constructs and executes commands from `stdin`, bypassing command-line argument limits.

```bash
# 1. Null-delimiter safety (handles filenames with spaces, newlines, and quotes)
find . -type f -name "*.bak" -print0 | xargs -0 rm -v

# 2. Parallel processing (-P specifies CPU thread concurrency)
cat urls.txt | xargs -P 8 -n 1 curl -O -s

# 3. Custom argument placeholder (-I {})
cat hosts.txt | xargs -I {} scp deploy.tar.gz {}:/opt/app/
```

## Permissions, Ownership & Sticky Bits

### Permission Bits Matrix

| Bit Value | Binary | Meaning       | Directory Meaning                                      |
| --------- | ------ | ------------- | ------------------------------------------------------ |
| `4`       | `100`  | `r` (Read)    | Can view files inside directory (`ls`).                |
| `2`       | `010`  | `w` (Write)   | Can create, rename, and delete files inside directory. |
| `1`       | `001`  | `x` (Execute) | Can enter directory (`cd`) and access child files.     |
| `0`       | `000`  | `-` (None)    | No access.                                             |

```text
  -rwxr-xr--   1   alice   developers   4096   Oct 17 12:00   script.sh
  ┬───┬───┬───
  │ │   │   └── Others (Read: 4)
  │ │   └────── Group (Read + Execute: 4 + 1 = 5)
  │ └────────── Owner (Read + Write + Execute: 4 + 2 + 1 = 7)
  └──────────── File Type (- = file, d = directory, l = symlink)
```

```bash
# Octal permission setting
chmod 755 script.sh     # rwxr-xr-x (standard for executables/scripts)
chmod 644 config.json   # rw-r--r-- (standard for readable data files)
chmod 600 id_rsa        # rw------- (strictly private SSH keys)

# Symbolic permission setting
chmod +x build.sh       # Add execute permission for everyone
chmod u=rwx,go=rx app   # Owner gets rwx; group and others get rx

# Change owner and group
chown -R www-data:www-data /var/www/html

# Sticky bit (1777 on /tmp: users can only delete files they themselves own)
chmod 1777 /tmp
```

## Process Management & Systemd Services

### 1. Process Inspection

```bash
ps aux                    # Full snapshot of all running processes
pgrep -l node             # Find PIDs of running Node.js instances
top                       # Classic live process viewer
htop                      # Enhanced interactive process viewer (colors, tree mode)
```

### 2. Signals & Terminating Processes

| Signal | Name      | Behavior                                                                    |
| ------ | --------- | --------------------------------------------------------------------------- |
| `1`    | `SIGHUP`  | Reload configuration without dropping connections.                          |
| `2`    | `SIGINT`  | Interrupt from keyboard (`Ctrl+C`).                                         |
| `15`   | `SIGTERM` | Polite request to cleanly shut down and save state (default for `kill`).    |
| `9`    | `SIGKILL` | Immediate kernel kill. Cannot be caught or ignored. May corrupt open files! |

```bash
kill 14205                # Send graceful SIGTERM (15) to PID
kill -9 14205             # Forceful immediate SIGKILL
pkill -f "python app.py"  # Kill by command pattern
killall nginx             # Kill all processes named nginx
```

### 3. Systemd Service Control

```bash
sudo systemctl status nginx       # Check running state, PID, memory, recent logs
sudo systemctl start nginx        # Start service
sudo systemctl stop nginx         # Stop service
sudo systemctl restart nginx      # Restart service
sudo systemctl reload nginx       # Reload config without terminating worker connections
sudo systemctl enable nginx       # Start automatically on system boot
sudo systemctl daemon-reload      # Reload systemd manager after modifying .service unit files

# Query logs using journalctl
journalctl -u nginx -f            # Follow live nginx logs
journalctl -u nginx --since "1 hour ago"
journalctl -p err -b              # View all system errors since last boot
```

## Networking & Socket Diagnostics

```bash
# 1. Modern socket inspection (replaces deprecated netstat)
ss -tulnp
# -t (TCP), -u (UDP), -l (Listening only), -n (Numeric IPs/ports), -p (Show PID & process name)

# 2. Check which process is occupying a specific port
sudo lsof -i :8080
sudo ss -lptn 'sport = :8080'

# 3. IP address and routing configuration
ip -br addr               # Brief summary of all network interfaces and IPs
ip route show             # Display default gateway and routing table

# 4. HTTP client & API inspection
curl -Iv https://example.com                 # Inspect response headers and SSL handshake
curl -s -X POST https://api.com/v1/auth \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","token":"xyz"}'

# 5. DNS and connection testing
dig +short google.com     # Fast DNS lookup
ping -c 4 1.1.1.1         # Send 4 ICMP echo packets
traceroute 8.8.8.8        # Trace network hops to destination
```

## Storage, Disk Usage & Hardware Health

```bash
# 1. Filesystem disk capacity
df -h                     # Human-readable free space per mounted partition
df -hT /                  # Show filesystem type (ext4, xfs, btrfs)

# 2. Directory size calculation
du -sh /var/log           # Total size of directory
du -sh * | sort -h        # List size of all items in current folder sorted by size

# 3. Memory & CPU utilization
free -h                   # View total, used, free, and cached RAM
uptime                    # System running duration and 1, 5, 15 minute load averages
lscpu                     # Detailed CPU architecture, cores, sockets, caches
lsblk                     # Block devices and disk partition tree
```

## Archives, Compression & Remote Sync

```bash
# 1. Create compressed tar archive (.tar.gz)
tar -czvf backup.tar.gz /var/www/app

# 2. Extract tar archive
tar -xzvf backup.tar.gz -C /target/destination/

# 3. View contents of tar archive without extracting
tar -tzvf backup.tar.gz

# 4. Rsync: High-speed incremental remote synchronization
# -a (archive: preserves permissions/timestamps), -v (verbose), -z (compress), -P (progress)
rsync -avzP /local/dir/ user@remote.server.com:/remote/dir/

# Mirror source to dest, deleting remote files removed locally
rsync -avzP --delete /source/ user@remote.server.com:/destination/
```

## Anti-patterns vs Best practices

| Anti-pattern                                      | Why it harms                                                                       | Best practice                                                               |
| ------------------------------------------------- | ---------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| `chmod 777`                                       | Gives any local process write and execution access; severe security vulnerability. | Use minimal permissions (`755` for scripts, `644` for files).               |
| Using `kill -9` as first resort                   | Process cannot clean up sockets, flush buffers, or close files; risks corruption.  | Always send graceful `kill -15` (SIGTERM) first; wait 5s before `kill -9`.  |
| Piping `cat` into `grep` (`cat file \| grep`)     | Useless use of cat; creates unnecessary process and pipe.                          | Run directly: `grep "pattern" file.txt`.                                    |
| Running destructive commands without dry-run      | Accidental data loss from wrong directory references.                              | Test destructive commands first with `rsync -n` or `find -print`.           |
| Ignoring `systemctl status` logs on failed starts | Guessing errors wastes hours.                                                      | Run `journalctl -u <service> -n 50 --no-pager` to read the exact traceback. |

## Memory anchors

- **Everything is a file:** Regular files, directories, sockets, devices (`/dev`), and kernel metrics (`/proc`).
- **Grep for search, Sed for edits, Awk for columns:** The ultimate trio of command-line data processing.
- **`find -print0 | xargs -0`:** Handles spaces, quotes, and newlines in file paths safely without crashes.
- **Permission values:** `4 = read`, `2 = write`, `1 = execute`. Sum them up: `755` = owner all, group & others read+execute.
- **Port conflicts:** `sudo ss -tulnp` or `sudo lsof -i :PORT` reveals the exact offending PID.
- **`rsync -avzP`:** The gold standard for remote file transfers with automatic resume and progress reporting.
- **Graceful shutdown first:** Signal `15` (SIGTERM) allows process cleanup; signal `9` (SIGKILL) is the emergency hammer.
