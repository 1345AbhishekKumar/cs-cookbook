Python is an interpreted, dynamically-typed language with indentation blocks. Targets: **Python 3.12** (PEP 695 generics, PEP 701 f-strings) and **3.13** (new REPL, free-threaded build, JIT experiment).

Use this page as a quick reference: syntax, tables, and minimal runnable snippets.

## Setup, Run & venv

```bash
python -V                    # check version (want 3.12+)
python script.py             # run a file
python -m venv .venv         # create env (stdlib since 3.3)
source .venv/bin/activate    # Unix / macOS
.venv\Scripts\activate       # Windows CMD
.venv\Scripts\Activate.ps1   # Windows PowerShell
deactivate

python -m pip install --upgrade pip
python -m pip install requests
python -m pip install -r requirements.txt
python -m pip freeze > requirements.txt
```

| Practice | Rule |
| --- | --- |
| `python -m pip` | Always via `python -m`, never bare `pip` — guarantees the right interpreter. |
| `.venv/` | One per project, in root, gitignored. Never install globally. |
| Repro | Commit `requirements.txt` / `pyproject.toml`, not `.venv/`. |
| REPL (3.13+) | Multiline edit, history, color; `help` / `exit` work without `()`. |

## Syntax, Comments & Variables

Indentation (4 spaces) + `:` defines blocks. No braces, no semicolons needed.

```python
# Single-line comment
"""Docstring / multiline string."""
'''Also multiline.'''

x = 5  # dynamic, no declare keyword
name, age = "Ada", 36   # unpack
PI = 3.14159            # CONST by convention
_count = 1              # "private" by convention

if x > 0:
    print("pos")  # indented block
```

## Match statement (3.10+)

```python
match status:
    case 400: return "Bad request"
    case 404: return "Not found"
    case _: return "Other"  # wildcard, must be last

match cmd:
    case "q" | "quit": running = False  # or-pattern
    case [t, *rest]: print(t, rest)     # sequence + starred

match user:
    case {"role": "admin", "name": name}: print(f"Admin {name}")

match point:
    case (0, 0): print("origin")
    case (x, y): print(f"at {x},{y}")
```

Pitfall: bare `case x:` matches **anything** and binds — put captures last, use `_` to discard.

## Tuples

Immutable, ordered, `()`. Hashable if elements are → usable as dict keys.

```python
t = (1, 2, 3)
t = 1, 2          # packing, parens optional
one = (42,)       # trailing comma required
empty = ()
a, b, *rest = (1, 2, 3, 4)  # a=1, rest=[3, 4]
```

Only two methods: `count(x)`, `index(x)`. Use for fixed records, keys, `namedtuple`.

## Dicts

Mutable, insertion-ordered, `{k: v}`.

| Method / Op | Description |
| --- | --- |
| `d[k]` / `d[k] = v` | Get / set (`KeyError` if missing). |
| `get(k, default)` | Safe get. |
| `setdefault(k, default)` | Get or insert. |
| `update(other)` / `d1 \| d2` | Merge (3.9+ union). |
| `pop(k, default)` | Remove + return. |
| `popitem()` | Remove last inserted. |
| `keys() / values() / items()` | Live views. |
| `k in d` / `len(d)` | Membership / size. |
| `dict.fromkeys(keys, val)` | Build with default. |

```python
d = {"a": 1}
d.get("x", 0)            # 0, no error
d.setdefault("x", 0)     # inserts
merged = {"a": 1} | {"b": 2}
for k, v in d.items():
    print(k, v)
```

## Sets

Mutable, unordered, unique. `{}` is an empty **dict** — use `set()`.

| Method / Op | Description |
| --- | --- |
| `add(x)` / `update(iter)` | Add one / many. |
| `remove(x)` / `discard(x)` | Remove (`KeyError` vs silent). |
| `pop()` / `clear()` | Remove arbitrary / empty. |
| `\| / & / - / ^` | Union / intersect / diff / symmetric diff. |
| `<= / >= / isdisjoint()` | Subset / superset / disjoint. |

```python
s = {1, 2, 2, 3}  # {1, 2, 3}
empty = set()
{1, 2} | {2, 3}   # {1, 2, 3}
{1, 2} & {2, 3}   # {2}
```

## Slicing — `seq[start:stop:step]`

Works on `str`, `list`, `tuple`, `range`. `start` inclusive, `stop` exclusive.

```python
a = ["zero", "one", "two", "three", "four"]
a[1:3]  # ['one', 'two']
a[1:]   # to end
a[:3]   # from start
a[:]    # full copy
a[::2]  # every 2nd
a[::-1] # reversed
a[-3:]  # last 3
"Hello"[1:4]  # 'ell'
```

| Pattern | Meaning |
| --- | --- |
| `s[i]` / `s[-1]` | Item / last item. |
| `s[a:b]` / `s[a:]` / `s[:b]` | Range / to end / from start. |
| `s[::k]` / `s[::-1]` | Every k-th / reverse. |
| `del l[2:]` | Delete slice (lists only). |
| `l[1:2] = [x, y]` | Slice assignment. |

```python
def add(a, b=0):

def func(pos, default="d", *args, kwonly, **kwargs):
```

## Scope — LEGB

Lookup: **L**ocal → **E**nclosing → **G**lobal → **B**uiltin. Else `NameError`.

```python
count = 0
def inc():
    global count
    count += 1  # write global, else creates local

def outer():
    n = 0
    def inner():
        nonlocal n
        n += 1  # write enclosing
    inner()
```

Class blocks do **not** count as enclosing scope. Comprehensions have their own scope in Py3.

## Type hints

Runtime does **not** enforce — check with `mypy` / `pyright`.

```python
def greeting(name: str) -> str:
    return "Hello " + name

names: list[int] = [1, 2, 3]  # 3.9+ builtin generics
mapping: dict[str, int] = {"a": 1}
maybe: int | None = None      # 3.10+ X|Y (old: Optional[int])
either: int | str = 1         # (old: Union[int, str])

# 3.12+ type-param syntax (PEP 695)
def first[T](xs: list[T]) -> T | None:
    return xs[0] if xs else None

type Point = tuple[float, float]  # 3.12+ alias
```

| Old | Modern |
| --- | --- |
| `Union[int, str]` | `int \| str` |
| `Optional[int]` | `int \| None` |
| `List[int]`, `Dict[k, v]` | `list[int]`, `dict[k, v]` |

## Classes & OOP

```python
class Animal:
    def speak(self): return "..."

class Dog(Animal):
    def __init__(self, name):
        super().__init__()  # first line in child
        self.name = name
    def speak(self): return "Woof!"  # override
```

| Item | Rule |
| --- | --- |
| `self` | Explicit instance ref, first param. |
| `_x` | Protected by convention. |
| `__x` | Private — mangled to `_Cls__x`. |
| `__slots__` | No `__dict__`, less memory, no new attrs. |
| `isinstance(o, C)` | Prefer over `type() ==`. |
| `MRO` | `C.__mro__` — C3, left-to-right. |
| `ABC` | `class S(Shape, ABC)` + `@abstractmethod`. |

## Dataclasses

```python
from dataclasses import dataclass, field

@dataclass(slots=True)
class Point:
    x: int
    y: int = 0
    tags: list[str] = field(default_factory=list)
    def __post_init__(self):
        self.norm = (self.x ** 2 + self.y ** 2) ** 0.5
```

| Param | Effect |
| --- | --- |
| `frozen=True` | Read-only, raises on set. |
| `kw_only=True` | `__init__` args keyword-only (3.10+). |
| `slots=True` | Auto `__slots__` (3.10+). |
| `eq / order` | Auto `__eq__` / ordering. |

Never use mutable defaults (`=[]`) — use `field(default_factory=list)`.

## Decorators, classmethod & property

```python
from functools import wraps

def timer(f):
    @wraps(f)
    def w(*a, **k): return f(*a, **k)
    return w

@timer
def run(): ...
# run = timer(run); stacked: @a @b == a(b(f))
```

| Decorator | First arg | Use for |
| --- | --- | --- |
| instance method | `self` | Normal behavior. |
| `@classmethod` | `cls` | Alternative constructors, shared state. |
| `@staticmethod` | none | Namespaced utility. |
| `@property` + `@x.setter` | `self` | Computed attr, validation. |

```python
class Employee:
    @classmethod
    def from_str(cls, s): return cls(*s.split())

    @staticmethod
    def is_valid(s): return len(s) > 0

    @property
    def salary(self): return self._s

    @salary.setter
    def salary(self, v):
        if v < 0: raise ValueError("neg")
        self._s = v
```

## Errors — try / except / raise

```python
try:
    int("x")
except ValueError as e:
    raise RuntimeError("bad") from e  # chain; `from None` to suppress
except (OSError, FileNotFoundError):
    pass
else:
    print("no error")  # runs if no except
finally:
    print("always")
```

| Item | Note |
| --- | --- |
| `Hierarchy` | `BaseException > Exception` — never catch bare `except` (catches `KeyboardInterrupt`). |
| `raise` | `raise ValueError("msg")`; bare `raise` re-raises. |
| `Custom` | `class AppError(Exception): pass` |
| `except*` | For `ExceptionGroup` (3.11+). |
| `Common` | `ValueError  TypeError  KeyError  IndexError  FileNotFoundError  ImportError  StopIteration` |

## Context managers — `with`

```python
with open("f.txt", encoding="utf-8") as f:
    data = f.read()  # auto-close

from contextlib import suppress, contextmanager
with suppress(FileNotFoundError):
    Path("tmp").unlink()

@contextmanager
def ctx():
    print("enter"); yield "val"; print("exit")
```

Class protocol: `__enter__` → value; `__exit__(exc_type, exc, tb)` → `True` suppresses. Exits run LIFO.

## Generators & Iterators

```python
def countdown(n):
    while n > 0:
        yield n; n -= 1  # lazy, stateful, one-shot

it = countdown(3); next(it)  # 3
gen_exp = (x * x for x in range(n))  # lazy
delegated = yield from it
```

| Concept | API |
| --- | --- |
| `Iterable vs Iterator` | `iter(obj)`, `next(it)` |
| `Generator func` | `def g(): yield x` |
| `Generator exp` | `(x for x in it)` |
| `Delegate` | `yield from it` |
| `Async gen` | `async def g(): yield x` + `async for` |

## Regex — `re`

Use raw strings `r"..."`.

| Task | Pattern |
| --- | --- |
| `Compile` | `p = re.compile(r"\d+", re.I)` |
| `Search / match / full` | `p.search(s)`, `p.match(s)`, `p.fullmatch(s)` |
| `Find all` | `re.findall(r"\w+@\w+\.\w+", s)` |
| `Subst / split` | `re.sub(r"\s+", " ", s)`, `re.split(r",\s*", s)` |
| `Groups` | `m.group(1)`, `m.groups()`, `m.groupdict()` |
| `Named` | `(?P<year>\d{4})-(?P<mo>\d{2})` |

```python
import re
m = re.search(r"(?P<user>\w+)@(?P<host>\w+)", "hi bob@x")
m.groupdict()  # {'user': 'bob', 'host': 'x'}
re.sub(r"\d+", "#", "a1b22")  # 'a#b#'
```

Flags: `re.I | re.M | re.S | re.X`.

## Datetime

Always aware — never naive. `zoneinfo` replaces `pytz`.

```python
from datetime import datetime, timedelta, timezone
from zoneinfo import ZoneInfo  # 3.9+

now = datetime.now(timezone.utc)  # aware, preferred
local = now.astimezone(ZoneInfo("America/New_York"))
print(now.isoformat(), local.strftime("%Y-%m-%d %H:%M %Z"))
dt = datetime(2026, 1, 1, 12, tzinfo=ZoneInfo("Asia/Kolkata"))
dt + timedelta(days=1, hours=2)
datetime.fromisoformat("2026-03-16T12:30:00+00:00")
```

| Pitfall | Fix |
| --- | --- |
| `Naive vs aware` | Always `tzinfo=timezone.utc` / `ZoneInfo`. |
| `utcnow()` | Deprecated — use `now(timezone.utc)`. |
| `Parse` | `fromisoformat()` / `strptime(s, "%Y-%m-%d")`. |

| `count / cycle / repeat` | Infinite iterators. |

`functools`: `lru_cache`, `cached_property`, `partial`, `reduce`.

## async / await

```python
import asyncio

async def fetch(url: str) -> str:
    await asyncio.sleep(0.1)
    return url

async def main():
    print(await asyncio.gather(*(fetch(f"u{i}") for i in range(3))))
    async with asyncio.TaskGroup() as tg:  # 3.11+, preferred
        tasks = [tg.create_task(fetch(f"u{i}")) for i in range(3)]
    print([t.result() for t in tasks])
    async with asyncio.timeout(2):  # 3.11+
        await fetch("x")

asyncio.run(main())  # entry point
```

| API | Purpose |
| --- | --- |
| `async def` | Coroutine. |
| `await` | Suspend until done. |
| `asyncio.run(main())` | Entry, creates loop. |
| `create_task(coro)` | Schedule concurrently. |
| `gather(*coros)` | Run concurrently, ordered results. |
| `TaskGroup` | Structured concurrency. |
| `to_thread()` | Run blocking code off loop. |

## Memory anchors

- **Indent is syntax:** `:` + 4 spaces = block. No braces.
- **Mutability split:** immutable `str, tuple, frozenset` vs mutable `list, dict, set`. `dict` keeps insertion order, `set` is unique + unordered.
- **`{}` is a dict:** empty set is `set()`, not `{}`.
- **Ends vs anywhere:** `append/pop` work the end, `insert/remove` work anywhere, `slice` copies, `splice` doesn't exist — slice-assign does.
- **Safe dict reads:** `get(k, default)` reads, `setdefault` inserts, `\|` merges, `in` checks keys.
- **Copy ladder:** comprehension > `map/filter` for readability; generator `(x for …)` for lazy million-item loops.
- **Args order:** `pos, default, *args, kwonly, **kwargs`. Never `def f(x=[])` — use `None`.
- **LEGB:** Local → Enclosing → Global → Builtin. `global` writes module, `nonlocal` writes enclosing.
- **Hints don't run:** `int \| None` is docs + checkers (`mypy`), not enforcement. Modern: `list[int]`, `X \| Y`, `def f[T]()`.
- **Errors:** `try` risky, `except` handle, `else` no-error, `finally` always. Never bare `except`.
- **Files:** `with open(…, encoding="utf-8")` auto-closes; `pathlib` for paths, `json`/`csv` for formats.
- **EAFP idiom:** `try: v = d["k"] except KeyError: v = default` beats `if k in d`.
- **Async trio:** `asyncio.run` enters, `await` waits, `TaskGroup` runs together.
