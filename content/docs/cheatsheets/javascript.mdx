JavaScript is a lightweight, cross-platform language for dynamic, interactive web content. Alongside HTML and CSS, it is a core technology of the World Wide Web.

Use this page as a quick reference: syntax, tables, and minimal runnable snippets.

## Variables

Containers for storing data. Three declaration keywords:

| Keyword | Description | Example |
| --- | --- | --- |
| `var` | Function-scoped, re-declarable, re-assignable. | `var x = value;` |
| `let` | Block-scoped, re-assignable. | `let y = value;` |
| `const` | Block-scoped, fixed binding (cannot reassign). | `const z = value;` |

```js
console.log("Using var");
var x = 1;
if (x === 1) { var x = 2; console.log(x); } // 2
console.log(x); // 2 — leaked out of block

console.log("Using let");
let x1 = 1;
if (x1 === 1) { let x1 = 2; console.log(x1); } // 2
console.log(x1); // 1 — block-scoped

const number = 48;
// number = 42; // TypeError: reassignment
console.log(number); // 48
```

## Data types

Primitive and non-primitive values JS variables can hold.

| Type | Description | Example |
| --- | --- | --- |
| `Number` | Integer or real number. | `let x = 42;` |
| `String` | Characters in quotes. | `let x = "chars";` |
| `Boolean` | `true` or `false`. | `let x = true;` |
| `Null` | Intentionally empty. | `let x = null;` |
| `Undefined` | Declared, not assigned. | `let x;` |
| `Symbol` | Immutable unique identifier. | `Symbol("hello")` |
| `Object` | Collection of key-value pairs. | `let x = { key: "value" };` |
| `Array` | Ordered list in one variable. | `let x = ["y1", "y2"];` |
| `Function` | Callable object (block of code). | `function x(a) { /* … */ }` |

```js
let str = "hello geeks"; console.log(str);
const num = 10;          console.log(num);
const flag = true;       console.log(flag);
let name;                console.log(name); // undefined
const empty = null;      console.log(empty);

const v1 = Symbol("hello"), v2 = Symbol("hello");
console.log(v1 === v2); // false — each Symbol is unique

const user = { firstName: "geek", lastName: null, batch: 2 };
console.log(user);
```

## Operators

Symbols performing operations on operands (variables).

| Group | Description | Symbols |
| --- | --- | --- |
| `Arithmetic` | Basic math. | `+  -  *  /  %  ++  --  **` |
| `Comparison` | Compare two operands. | `==  ===  !=  !==  >  <  >=  <=` |
| `Bitwise` | Bit-level operations. | `&  \|  ^  ~  <<  >>  >>>` |
| `Logical` | AND (all true), OR (any true), NOT (flip). | `exp1 && exp2`, `exp1 \|\| exp2`, `!exp` |
| `Assignment` | Assign values. | `=  +=  -=  *=  /=  %=` |

```js
let x = 5, y = 3;
console.log(x + y);  // 8
console.log(x - y);  // 2
console.log(x * y);  // 15
console.log(x / y);  // 1.666…
console.log(x % y);  // 2
console.log(++x);    // 6
console.log(x ** y); // 216

console.log(x > y);     // true
console.log(2 == 2);    // true (loose)
console.log(2 === 2);   // true (strict)
console.log(2 !== 2);   // false
console.log(x < 6 && y < 5); // true
console.log(x < 6 || y > 6); // true
console.log(!(x < 6));       // false
```

## Scope & Scope chain

- **Scope** — where a variable is visible / accessible.
- **Scope chain** — JS resolves a name in the current scope, then outer scopes up to global. If never found: implicit global (sloppy mode) or error.

| Scope | Description |
| --- | --- |
| `function` | `var` inside a function — visible throughout that function (local scope). |
| `block` | `let` / `const` inside `{}` — visible only inside that block. |
| `global` | Declared outside everything — visible anywhere. |

```js
let z = 3; // global

function foo() {
  if (true) {
    var x = "1";   // function scope
    const y = "2"; // block scope
  }
  console.log(x); // "1"
  // console.log(y); // ReferenceError — block-scoped
  console.log(z); // 3 — global
}
foo();
```

## Functions (utilities)

Reusable blocks executed when called. Common built-ins:

| Function | Description |
| --- | --- |
| `parseInt()` | Parse to integer. |
| `parseFloat()` | Parse to floating-point number. |
| `isNaN()` | Is the value Not-a-Number? |
| `Number()` | Convert argument to number. |
| `eval()` | Evaluate a string as JS (avoid in prod). |
| `prompt()` | Dialogue box for user input. |
| `encodeURI()` | Encode a URI to UTF-8. |
| `match()` | Match a string against a regex. |

```js
console.log(parseInt("3.14"));                 // 3
console.log(parseFloat("2018.12@site"));       // 2018.12
console.log(isNaN(12));                        // false
console.log(Number(true));                     // 1
console.log(encodeURI("https://x.com/?q=a b")); // …?q=a%20b
```

## Arrays

One variable holding an ordered list, indexed by number.

```js
let House = [];            // Method 1
let House2 = new Array();  // Method 2
```

| Method | Description |
| --- | --- |
| `push()` | Add element at end. |
| `pop()` | Remove last element. |
| `unshift()` | Add elements at start. |
| `shift()` | Remove first element. |
| `concat()` | Join arrays into one. |
| `reverse()` | Reverse element order. |
| `slice()` | Copy part into a new array. |
| `splice()` | Add / remove at a position. |
| `indexOf()` | First index of element. |
| `lastIndexOf()` | Last index of element. |
| `join()` | Combine into a single string. |
| `sort()` | Sort by condition. |
| `toString()` | Elements as string. |
| `valueOf()` | Primitive value of object. |

```js
let arr = [10, 20, 30, 40, 50];
arr.push(60);      // […, 60]
arr.unshift(0);    // [0, …]
arr.pop();         // remove end
arr.shift();       // remove start
arr.splice(2, 1);  // remove 1 at index 2
arr.reverse();
console.log(arr.concat([110, 120])); // merged
```

## Loops

Repeat a block until a condition is met.

| Loop | Description | Syntax |
| --- | --- | --- |
| `for` | Condition checked up front. | `for (init; test; step) { … }` |
| `while` | Entry-controlled: checks, then runs. | `while (cond) { … }` |
| `do-while` | Exit-controlled: runs once, then checks. | `do { … } while (cond);` |
| `for-in` | Iterate enumerable keys. | `for (k in obj) { … }` |

```js
for (let i = 2; i <= 4; i++) console.log("x:" + i);

const langs = { first: "C", second: "Java", fifth: "JavaScript" };
for (let k in langs) console.log(langs[k]);

let y = 1;
while (y <= 4) { console.log("y:" + y); y++; }

let z = 21;
do { console.log("z:" + z); z++; } while (z < 20); // runs once
```

## If-else

Run a block conditionally; nestable.

```js
if (condition) {
  // runs when true

  // runs when false

const i = 10;
if (i < 15) console.log("less than 15");
else console.log("15 or more");
```

## Strings

Primitive, immutable text. Zero or more chars.

| Method | Description |
| --- | --- |
| `concat()` | Join strings. |
| `match()` | Match against pattern. |
| `replace()` | Find and replace text. |
| `slice()` | Extract a section. |
| `substr()` | Extract N chars. |
| `split()` | Split into array. |
| `charAt()` | Char at index. |
| `indexOf()` / `lastIndexOf()` | First / last position. |
| `toUpperCase()` / `toLowerCase()` | Change case. |
| `valueOf()` | Primitive value. |

```js
let gfg = "GFG ";
```

## Regular Expressions

A search pattern for text search / replace. Single char or complex pattern.

```js
const regex1 = /^ab/;           // literal
const regex2 = new RegExp("^ab"); // constructor
// Syntax: /pattern/modifiers;
```

| Modifier class | Example | Description |
| --- | --- | --- |
| `Character class` | `[abc]` | Any char inside brackets. |
| `Range` | `[0-9]` | Any digit 0–9. |
| `Alternation` | `(x\|y)` | x or y. |

| Metachar | Description |
| --- | --- |
| `.` | Any single char except newline. |
| `\d` | A digit. |
| `\s` | Whitespace. |
| `\uxxxx` | Unicode char by hex. |

| Quantifier | Description |
| --- | --- |
| `n+` | One or more n. |
| `n*` | Zero or more n. |
| `n?` | Zero or one n. |
| `n{X}` | Exactly X n's. |
| `^n` | n at start. |

```js
function validateEmail(email) {
  const re = /\S+@\S+\.\S+/g;
  console.log(re.test(email) ? "valid" : "not valid");
}
validateEmail("abc@gmail.com"); // valid
validateEmail("abc#$#@45com");  // not valid
```

## Data Transformation

Higher-order functions take functions as input and return results. The big three take a callback:

| Method | Description | Syntax |
| --- | --- | --- |
| `map()` | Call fn on every element, collect results. | `arr.map(fn(cur, i, arr), thisArg)` |
| `filter()` | Keep elements passing a test. | `arr.filter(fn(el, i, arr), thisArg)` |
| `reduce()` | Reduce array to a single value. | `arr.reduce(fn(total, cur, i, arr), init)` |

```js
console.log([16, 25].map(Math.sqrt)); // [4, 5]

const ages = [19, 37, 16, 42];
console.log(ages.filter((a) => a >= 18)); // [19, 37, 42]

console.log([165, 84, 35].reduce((t, n) => t - n)); // 46
```

## Date objects

Built-in type for dates/times. Created with `new Date()`.

```js
new Date();
new Date(milliseconds);
new Date(dateString);
new Date(year, month, date, hour, minute, second, ms);
```

| Method | Description |
| --- | --- |
| `getDate()` | Day of month (1–31). |
| `getDay()` | Weekday (0–6). |
| `getFullYear()` | Four-digit year. |
| `getMinutes()` | Minutes (0–59). |
| `getTime()` | Ms since Jan 1, 1970. |
| `parse()` | Ms since epoch for a string. |
| `setDate()` | Set day of month. |
| `setTime()` | Set time (ms since epoch). |

```js
let d = new Date("October 13, 1996 05:35:32");
console.log(d.getDate());      // 13
console.log(d.getTime());      // ms since epoch
console.log(d.getMinutes());   // 35
console.log(d.getFullYear());  // 1996
console.log(d.getDay());       // weekday number
d.setDate(15);
console.log(Date.parse("February 48, 2018 12:30 PM")); // NaN — invalid
```

## DOM

The Document Object Model — the logical structure JS can manipulate (JS sees objects, not tags).

| Method | Description |
| --- | --- |
| `appendChild()` | Add child as last child. |
| `cloneNode()` | Duplicate an element. |
| `hasAttributes()` | True if element has attributes. |
| `removeChild()` | Remove a child node. |
| `getAttribute()` | Value of an attribute. |
| `getElementsByTagName()` | List of child elements by tag. |
| `isEqualNode()` | Are two elements equal? |

```js
// append
const node = document.createElement("p");
node.appendChild(document.createTextNode("GeeksforGeeks"));
document.getElementById("sudo").appendChild(node);

// clone
const clone = document.getElementsByTagName("div")[0].cloneNode(true);
document.body.appendChild(clone);

// query / compare / remove
console.log(document.body.hasAttributes());
document.getElementById("listitem").removeChild(
  document.getElementById("listitem").childNodes[0]
);
const divs = document.getElementsByTagName("div");
console.log(divs[0].isEqualNode(divs[2]));
```

## Errors — try / catch / throw / finally

JS throws on invalid syntax, bad input, or logic faults. Handle with:

| Statement | Description |
| --- | --- |
| `try` | Test a block for errors. |
| `catch` | Handle the error. |
| `throw` | Create / raise an error. |
| `finally` | Always run after try / catch. |

```js
function check(input) {
  try {
    if (input == "") throw "is empty";
    if (isNaN(input)) throw "is not a number";
    input = Number(input);
    if (input > 20) throw "is too high";
    if (input <= 20) throw "is too low";
  } catch (err) {
    console.log("Input " + err);
  } finally {
    console.log("done");
  }
}
```

## Memory anchors

- **Attach + comment:** `<script src>` for files, `//` for one line, `/* … */` for blocks.
- **var vs let vs const:** `var` leaks (function scope), `let` stays in `{}` and reassigns, `const` stays and never reassigns.
- **Falsy shortlist:** `false, 0, "", null, undefined, NaN` — everything else is truthy.
- **Loose vs strict:** `==` converts, `===` does not. Default to `===` / `!==`.
- **Scope ladder:** block (`let/const`) → function (`var`) → global. Lookup climbs outward.
- **Array ends:** `push/pop` work the end, `unshift/shift` work the start, `splice` works anywhere, `slice` copies.
- **Transform trio:** `map` reshapes, `filter` keeps, `reduce` collapses to one value.
- **String surgery:** `slice/split/replace/match` cut and find, `charAt/indexOf` locate, case via `toUpperCase/toLowerCase`.
- **Regex shape:** `/pattern/flags` — `.` any char, `\d` digit, `\s` space, `+/*/?` how many, `^` start.
- **Dates count ms:** `getTime()` is ms since epoch; construct with `new Date(...)`, read with `get*`, write with `set*`.
- **DOM verbs:** `create/append/clone/remove` nodes, `get*` finds them, `isEqualNode` compares them.
- **Errors:** `try` the risky code, `catch` the fall, `throw` your own, `finally` always cleans up.
- **Window timers:** `setTimeout` once, `setInterval` forever, `clearTimeout` cancels.
