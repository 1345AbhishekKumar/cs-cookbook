GSAP (GreenSock Animation Platform) by Webflow is the high-performance standard for scripted web animations. It delivers frame-accurate 60fps-120fps animations across SVG, Canvas, Three.js, WebGL, and standard DOM elements without layout thrashing.

- **Official Website:** [https://gsap.com](https://gsap.com)
- **Documentation:** [https://gsap.com/docs/v3](https://gsap.com/docs/v3)
- **GitHub Repository:** [https://github.com/greensock/GSAP](https://github.com/greensock/GSAP)

Use this page as an exhaustive reference: tween methods, timeline position syntax, ScrollTrigger configurations, React integration (`useGSAP`), and copy-paste recipes.

## Setup & Plugin Registration

```bash
npm install gsap @gsap/react
```

```ts
import gsap from "gsap";
import { ScrollTrigger } from "gsap/ScrollTrigger";
import { Flip } from "gsap/Flip";
import { Observer } from "gsap/Observer";
import { TextPlugin } from "gsap/TextPlugin";

// Always register plugins before creating tweens
gsap.registerPlugin(ScrollTrigger, Flip, Observer, TextPlugin);
```

## Core Tweens

| Method | Description | Signature |
| --- | --- | --- |
| `gsap.to(targets, vars)` | Animates from current state to specified destination. | `gsap.to(".card", { x: 100, duration: 1 })` |
| `gsap.from(targets, vars)` | Animates from specified values to current state. | `gsap.from(".card", { autoAlpha: 0, y: 50 })` |
| `gsap.fromTo(targets, from, to)` | Explicitly declares both starting and ending values. | `gsap.fromTo(".card", { x: 0 }, { x: 200 })` |
| `gsap.set(targets, vars)` | Zero-duration immediate property assignment (no animation). | `gsap.set(".card", { autoAlpha: 0, y: 100 })` |

### Key Tween Properties

```ts
gsap.to(".card", {
  // Compositor GPU transforms
  x: 100,               // translateX(100px)
  y: "20%",             // translateY(20%)
  xPercent: -50,        // -50% of element's own width (ideal for centering)
  scale: 1.2,
  scaleX: 1.5,
  rotation: 45,         // rotate(45deg)
  rotationX: 30,        // 3D rotation
  skewX: 10,
  transformOrigin: "center center",
  force3D: true,        // Force hardware layer promotion

  // Opacity & Visibility
  autoAlpha: 1,         // Animates opacity; sets visibility: hidden at 0

  // Timing & Loops
  duration: 0.8,        // in seconds (default: 0.5)
  delay: 0.2,           // seconds before starting
  repeat: -1,           // -1 for infinite loop, 1 for run twice
  yoyo: true,           // alternates backwards on repeat
  repeatDelay: 0.5,

  // Easing
  ease: "power2.out",

  // Callbacks
  onStart: () => console.log("Tween started"),
  onUpdate: () => console.log("Progress:", this.progress()),
  onComplete: () => console.log("Tween finished"),
});
```

> **Why `autoAlpha` beats `opacity`:** An element animated to `opacity: 0` remains interactive in the DOM, intercepting clicks meant for elements beneath it. `autoAlpha: 0` automatically applies `visibility: hidden` once opacity hits 0, freeing CPU rendering and eliminating ghost clicks.

## Timelines & Position Parameter Masterclass

Timelines sequence animations together without brittle `delay` calculations.

```ts
const tl = gsap.timeline({
  defaults: { duration: 0.5, ease: "power2.out" },
  repeat: 0,
  paused: false,
  onComplete: () => console.log("Timeline complete"),
});

// Chained tweens play in sequence
tl.to(".title", { y: 0, autoAlpha: 1 })
  .to(".subtitle", { y: 0, autoAlpha: 1 }, "-=0.2") // Overlaps by 0.2s
  .to(".badge", { scale: 1 }, "<")                  // Starts at same time as subtitle
  .addLabel("step2")
  .to(".cta-button", { scale: 1.1 }, "step2+=0.3"); // 0.3s after label
```

### The Position Parameter Syntax Table

| Syntax | Description | Example |
| --- | --- | --- |
| *(omitted)* | Directly after the previous animation finishes. | `tl.to(...)` |
| `1.5` | Exactly at the 1.5-second timestamp of the timeline (absolute). | `tl.to(..., 1.5)` |
| `"+=1"` | 1 second after the previous animation finishes (gap). | `tl.to(..., "+=1")` |
| `"-=0.5"` | 0.5 seconds before previous animation finishes (overlap). | `tl.to(..., "-=0.5")` |
| `"<"` | Exactly when the previous animation **starts** (concurrent). | `tl.to(..., "<")` |
| `">"` | Exactly when the previous animation **ends** (explicit sequence).| `tl.to(..., ">")` |
| `"<0.2"` | 0.2 seconds after the previous animation **started**. | `tl.to(..., "<0.2")` |
| `"<-0.2"` | 0.2 seconds before the previous animation **started**. | `tl.to(..., "<-0.2")` |
| `"label"` | At the timestamp marked by `tl.addLabel("label")`. | `tl.to(..., "label")` |
| `"label+=0.5"`| 0.5 seconds after a named label. | `tl.to(..., "label+=0.5")` |

### Timeline Playback Control

```ts
tl.play();             // Play forwards
tl.pause();            // Freeze playback
tl.resume();           // Continue from current playhead
tl.reverse();          // Play backwards
tl.restart();          // Restart from beginning
tl.seek(2.5);          // Jump playhead to 2.5s
tl.progress(0.5);      // Jump to 50% mark
tl.timeScale(2.0);     // 2x double speed (0.5 for half speed)
tl.kill();             // Completely destroy timeline and remove listeners
```

## Staggers & 2D Grid Ripples

```ts
// 1. Simple interval stagger
gsap.from(".item", {
  autoAlpha: 0,
  y: 40,
  stagger: 0.1, // 0.1s offset between consecutive items
});

// 2. Advanced 2D Grid Stagger Object
gsap.from(".grid-box", {
  scale: 0,
  duration: 0.6,
  ease: "back.out(1.7)",
  stagger: {
    amount: 1.2,         // Total duration distributed across all elements
    from: "center",      // "start" | "center" | "end" | "edges" | "random" | index
    grid: [5, 5],        // [rows, columns] for 2D spatial ripple
    axis: "y",           // Wave direction bias: "x" | "y" | null
    ease: "power2.inOut",
  },
});
```

## Eases & Curves Reference

```ts
// Standard Power Eases (1: gentle, 4: dramatic)
ease: "power1.out"   // or power2.out, power3.out, power4.out
ease: "power2.in"    // accelerates
ease: "power2.inOut" // accelerates and decelerates

// Organic Eases
ease: "back.out(1.7)"       // Overshoots boundary and snaps back
ease: "elastic.out(1, 0.3)" // True spring elasticity (amplitude, frequency)
ease: "bounce.out"          // Ball bouncing against a surface
ease: "steps(6)"            // Stepped tick animation (sprite sheets / clock ticks)
ease: "none"                // Linear (constant speed for spinners/marquee)
```

## React Integration (`useGSAP`)

In React 18 and 19, `useEffect` triggers double-invocations in Strict Mode, leaving behind duplicate rogue tweens. Always use the official `@gsap/react` hook.

```tsx
import { useRef } from "react";
import gsap from "gsap";
import { useGSAP } from "@gsap/react";

export function HeroBanner() {
  const containerRef = useRef<HTMLDivElement>(null);

  useGSAP(
    () => {
      // Scoped: querySelector(".box") ONLY finds boxes inside containerRef!
      gsap.from(".box", {
        scale: 0.8,
        opacity: 0,
        duration: 0.8,
        stagger: 0.15,
      });

      gsap.to(".spin-icon", {
        rotation: 360,
        repeat: -1,
        ease: "none",
        duration: 10,
      });
    },
    {
      scope: containerRef, // Scopes all string selectors
      dependencies: [],    // Re-runs whenever dependencies change (like useEffect)
      revertOnUpdate: true,// Reverts previous tweens before re-running on dep changes
    }
  );

  return (
    <div ref={containerRef} className="hero-container">
      <div className="box">Feature 1</div>
      <div className="box">Feature 2</div>
      <div className="spin-icon" />
    </div>
  );
}
```

## ScrollTrigger Masterclass

Binds animations directly to viewport scroll positions.

```ts
import gsap from "gsap";
import { ScrollTrigger } from "gsap/ScrollTrigger";

gsap.registerPlugin(ScrollTrigger);

// 1. Entry trigger
gsap.from(".card", {
  scrollTrigger: {
    trigger: ".section",
    start: "top 80%",    // [trigger edge, viewport edge]
    end: "bottom 20%",
    toggleActions: "play none none reverse",
    // 4 Keywords: "onEnter onLeave onEnterBack onLeaveBack"
    // Available: "play", "pause", "resume", "reverse", "restart", "reset", "complete", "none"
    markers: false,      // Set to true to view start/end guide lines in dev
  },
  y: 60,
  autoAlpha: 0,
  stagger: 0.2,
});

// 2. Scrubbed Animation (Scrollbar drives playhead)
gsap.to(".progress-line", {
  scrollTrigger: {
    trigger: ".article",
    start: "top top",
    end: "bottom bottom",
    scrub: 1, // 1-second lag smoothing out jumpy wheel ticks
  },
  scaleX: 1,
  transformOrigin: "left center",
  ease: "none",
});

// 3. Section Pinning (Horizontal Gallery)
const sections = gsap.utils.toArray<HTMLElement>(".gallery-panel");

gsap.to(sections, {
  xPercent: -100 * (sections.length - 1),
  ease: "none",
  scrollTrigger: {
    trigger: ".gallery-wrapper",
    pin: true,
    scrub: 1,
    snap: 1 / (sections.length - 1),
    end: () => "+=" + document.querySelector(".gallery-wrapper")!.clientWidth,
  },
});
```

### Standalone `ScrollTrigger.create()`

Run callbacks without tying to a tween:

```ts
ScrollTrigger.create({
  trigger: ".nav-sentinel",
  start: "top top",
  onEnter: () => nav.classList.add("nav-scrolled"),
  onLeaveBack: () => nav.classList.remove("nav-scrolled"),
});
```

### Batching Scroll Triggers (`ScrollTrigger.batch`)

Stagger elements as they enter the screen without creating individual ScrollTriggers for each one:

```ts
ScrollTrigger.batch(".card", {
  onEnter: (batch) => gsap.to(batch, { autoAlpha: 1, y: 0, stagger: 0.15, overwrite: true }),
  onLeave: (batch) => gsap.set(batch, { autoAlpha: 0, y: -40, overwrite: true }),
  onEnterBack: (batch) => gsap.to(batch, { autoAlpha: 1, y: 0, stagger: 0.15, overwrite: true }),
  onLeaveBack: (batch) => gsap.set(batch, { autoAlpha: 0, y: 40, overwrite: true }),
});
```

## High-Frequency Updates (`gsap.quickTo`)

For 60fps cursor followers and magnetic buttons, `quickTo` updates a single running tween rather than spawning new tweens on every frame:

```ts
const follower = document.querySelector(".custom-cursor");

// Pre-allocate quickTo functions
const xTo = gsap.quickTo(follower, "x", { duration: 0.4, ease: "power3" });
const yTo = gsap.quickTo(follower, "y", { duration: 0.4, ease: "power3" });

window.addEventListener("mousemove", (e) => {
  xTo(e.clientX);
  yTo(e.clientY);
});
```

## Responsive Animations (`gsap.matchMedia`)

Manages responsive breakpoints and tears down animations when viewports change:

```ts
const mm = gsap.matchMedia();

mm.add("(min-width: 800px)", () => {
  // Desktop timeline
  gsap.to(".sidebar", { x: 0 });
  gsap.to(".content", { marginLeft: 260 });

  return () => {
    // Optional breakpoint cleanup
  };
});

mm.add("(max-width: 799px)", () => {
  // Mobile timeline
  gsap.set(".sidebar", { x: -300 });
});
```

Observer.create({
  target: window,
  type: "wheel,touch,pointer",

  onDown: () => goToNextSlide(),

  tolerance: 10,
  preventDefault: true,

## Useful Utilities (`gsap.utils`)

Built-in math and array manipulation helpers:

```ts
// Clamp number between limits
gsap.utils.clamp(0, 100, 150); // 100

// Map values between ranges
gsap.utils.mapRange(0, 1000, 0, 360, 500); // 180

// Normalize to 0 -> 1 range
gsap.utils.normalize(0, 500, 250); // 0.5

// Linear interpolation (lerp)
gsap.utils.interpolate(0, 100, 0.5); // 50

// Random values with optional snap increment
gsap.utils.random(-50, 50, 5); // Random multiple of 5 between -50 and 50

// Snap value to grid increment
gsap.utils.snap(20, 48); // 40

// Wrap number circularly in range
gsap.utils.wrap(0, 5, 6); // 1

// Convert NodeList / selector to array
const elements = gsap.utils.toArray<HTMLElement>(".box");
```

## FLIP Layout Morphing (`Flip` Plugin)

Animate layout transitions using the FLIP (First, Last, Invert, Play) technique:

```ts
import { Flip } from "gsap/Flip";

function toggleCardExpanded(card: HTMLElement, fullContainer: HTMLElement) {
  // 1. Snapshot First state
  const state = Flip.getState(card);

  // 2. Perform DOM reparenting or class toggle
  fullContainer.appendChild(card);

  // 3. Invert & Play
  Flip.from(state, {
    duration: 0.7,
    ease: "power3.inOut",
    absolute: true,
  });
}
```

## Anti-patterns vs Best practices

| Anti-pattern | Why it harms | Best practice |
| --- | --- | --- |
| Animating `top`, `left`, `margin`, `padding` | Forces layout recalculation and CPU thrashing. | Animate `x`, `y`, `xPercent`, `yPercent`, and `scale`. |
| Spawning `gsap.to` inside React `useEffect` | Strict Mode remount causes duplicate animations and memory leaks. | Use `useGSAP()` with `{ scope: containerRef }`. |
| Calling `gsap.to()` on every `mousemove` | Creates hundreds of competing tweens per second. | Use `gsap.quickTo()`. |
| Hardcoding cumulative manual delays | Editing one delay breaks the whole animation sequence. | Use `gsap.timeline()` with relative position offsets (`"<"`, `"-=0.2"`). |
| Forgetting `gsap.registerPlugin()` | Plugins fail silently or break in tree-shaken production bundles. | Call `gsap.registerPlugin(ScrollTrigger)` at module level. |
| Neglecting `ScrollTrigger.refresh()` after async loads | ScrollTrigger triggers at incorrect offsets because DOM layout expanded. | Call `ScrollTrigger.refresh()` after content or images finish loading. |

## Memory anchors

- **Official URLs:** [gsap.com](https://gsap.com) and [gsap.com/docs/v3](https://gsap.com/docs/v3).
- **AutoAlpha over Opacity:** `autoAlpha: 0` sets `visibility: hidden` when opacity hits 0, preventing phantom clicks.
- **Position syntax:** `"<"` starts with previous tween; `"-=0.3"` overlaps previous tween; `"+=0.5"` inserts a delay.
- **`useGSAP` in React:** Scopes selectors to your container ref and auto-reverts on component unmount.
- **`toggleActions` 4 Keywords:** `onEnter onLeave onEnterBack onLeaveBack` (e.g. `"play none none reverse"`).
- **Smooth scrolling with `scrub: 1`:** Damps mouse wheel jumps with a 1-second catchup curve.
- **60fps mouse tracking:** Use `gsap.quickTo(target, property, vars)`.
- **Responsive design:** Wrap breakpoint animations in `gsap.matchMedia()`.
