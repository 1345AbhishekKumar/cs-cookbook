**Hardware** is every physical part of your computer you can touch — CPU, RAM, SSD, GPU, motherboard, PSU. **Software** is the instructions that tell hardware what to do — Windows, Chrome, games, Python code.

**Beginner mental model: think of a kitchen:**

- **Hardware = kitchen itself** — oven, knives, countertop, pantry. Without it you can't cook.
- **Software = recipe** — step-by-step instructions. Without it the kitchen just sits there.
- **CPU = chef** — does all the chopping, mixing, cooking (math + decisions).
- **RAM = countertop** — workspace for ingredients you're using *right now*. Bigger counter = more dishes at once. Cleared when you finish (power off).
- **Storage (SSD/HDD) = pantry + fridge** — where ingredients are kept long-term, even with power off.
- **Motherboard = kitchen floor + wiring** — connects everything so chef can reach counter, pantry, oven.
- **PSU = power supply from wall** — electricity for all appliances.
- **GPU = specialist tandoor / pizza oven** — amazing at one parallel job (graphics, AI) that the normal chef is slow at.

Use this page as a quick reference: plain-English meaning first, exact terms and 2026 buying advice second. If you're new, read the intro line of each section; if revising, just scan the tables.

## Hardware vs Software vs Firmware vs Peripheral vs SoC

Don't mix these five in interviews — one line each is enough.

| Term | What it is | Example |
| --- | --- | --- |
| `Hardware` | Physical parts you can touch. | CPU, RAM, SSD |
| `Software` | Programs + data stored on hardware. Gone if deleted, survives reboot. | Windows 11, Chrome, VS Code |
| `Firmware` | Software permanently baked onto a chip to control that hardware. | UEFI/BIOS on motherboard, mouse firmware |
| `Peripheral` | External device connected to the core computer. | Monitor, keyboard, webcam, external SSD |
| `SoC` | System-on-Chip. CPU + GPU + RAM + NPU fused on one chip. | Apple M5, phone Snapdragon, laptop Ryzen AI |

SoC = whole kitchen shrunk into one magic box. That's why a MacBook Air M5 is thin, cool, and fast with no separate RAM sticks — RAM is inside the M5 package (153GB/s), but you can't upgrade it later.

## How a program runs — Fetch-Decode-Execute

Every program, from Notepad to Cyberpunk, runs as a tiny loop inside the CPU, billions of times per second.

1. **Fetch:** CPU grabs the next instruction from RAM (via cache).
2. **Decode:** Control Unit figures out what it means ("add these two numbers").
3. **Execute:** ALU does it, result stored in a register.

**Clock speed = how many cycles per second.** 5GHz = 5 billion cycles/sec. **IPC = work done per cycle.** Modern CPUs do more per cycle, so a 2026 5.5GHz chip beats a 2016 5.5GHz chip easily. That's why GHz alone doesn't decide speed.

Analogy: clock = how fast the chef chops (strokes/min), IPC = how much is chopped per stroke. A sharper knife (new architecture) cuts more per stroke.

## Inside the CPU

CPU = one chip with billions of transistors doing three jobs together.

| Part | Beginner meaning | One-liner |
| --- | --- | --- |
| `ALU` | Calculator. Does `+ - * /` and comparisons. | Every `a + b` in Python ends here. |
| `CU` | Boss. Fetches, decodes, tells ALU/RAM what to do. | No math itself, just control signals. |
| `Registers` | Chef's hands. Tiniest, fastest storage (&lt;1ns), holds current numbers. | ~32-64 tiny slots, bytes in size. |
| `FPU / SIMD` | Decimal + bulk calculator. Does many numbers in one instruction. | Video, games, AI need this; AVX, NEON, SSE are SIMD flavors. |
| `NPU` | AI assistant. Runs neural nets efficiently (TOPS). | Intel AI Boost, AMD XDNA, Apple Neural Engine for Copilot+, blur, denoise. |
| `iGPU` | Tiny graphics oven on the same chip. | Enough for Office, 4K video, light games; not for AAA ultra. |

## Cores, Threads, Clock, Cache, TDP

Five numbers decide if a CPU is fast for *your* work.

| Term | Beginner meaning | 2026 rule |
| --- | --- | --- |
| `Cores` | How many chefs. 6-24 in 2026 desktops. | Games want 6-8 fast cores; video/AI wants 12-24. |
| `Threads` | Hands per chef. 2 threads = chef juggles 2 dishes. | AMD Hyper-Threading: 2T/core. Intel Arrow Lake: 1T/core (no HT, uses P+E instead). |
| `P-core / E-core` | Fast chefs (P) + efficient helpers (E). | Ultra 9 285K = 8P + 16E = 24 cores. OS sends games to P, background to E. |
| `Clock` | Speed per chef. Base 3-4GHz, boost 5.2-5.7GHz. | Boost only on few cores + good cooling; laptop sustains less than desktop. |
| `Cache L1/L2/L3` | Chef's pocket / apron / side-table. Superfast memory on CPU. | L1 = KB, L2 = MB, L3 = 24-36MB. X3D stacks +96MB L3 — huge for gaming. |
| `TDP` | Heat to cool, ~ power hunger. | 35W thin laptop, 65W desktop, 125-250W flagship. Bigger TDP = bigger cooler + PSU. |

> More cores ≠ always faster. A 6-core 5.7GHz chip beats a 16-core 3GHz chip in most games. Check single-core + cache for gaming, core count for rendering.

## 32-bit vs 64-bit

| Type | Max RAM | Meaning in 2026 |
| --- | --- | --- |
| `32-bit` | 4GB max. Old. | Only for retro PCs, cheap microcontrollers. Can't run modern Windows/games. |
| `64-bit` | Effectively unlimited (TBs). | Everything now — Windows 11, macOS, phones, PS5. If buying, always 64-bit. |

If an app says `x86_64 / ARM64`, that's just 64-bit for Intel/AMD vs Apple/Qualcomm.

## Motherboard — the floor + wiring

Motherboard doesn't make you faster, but a wrong one blocks upgrades. Match **socket + size + chipset**.

| Term | Beginner meaning | 2026 pick |
| --- | --- | --- |
| `Socket` | CPU-shaped hole. Must match CPU. | AM5 for Ryzen 7000/8000/9000; LGA1851 for Intel Ultra 200. No cross-fit. |
| `Size ATX / Micro-ATX / Mini-ITX` | Board size. | ATX = full slots; Micro-ATX = value sweet spot; Mini-ITX = tiny SFF, 1 GPU + 2 RAM slots. |
| `Chipset B850 vs X870E / B860 vs Z890` | Feature + OC permission. | B850/B860 = value, no CPU OC. X870E/Z890 = overclock + more USB/PCIe. Gamers: B850 is enough. |
| `VRM` | Power delivery to CPU. | Cheap board + 16-core = throttling. Creator/OC needs beefy VRM + heatsinks. |
| `UEFI/BIOS` | Setup screen (Del/F2). Enable XMP/EXPO here. | New RAM runs at 4800 until you enable XMP/EXPO — #1 beginner fix. |
| `CR2032` | Coin battery keeping clock + settings. | PC forgets time/settings every boot? Replace $3 battery. |

## RAM — countertop

RAM holds what you're *using now* — open tabs, game level, timeline. Power off = wiped. More + faster RAM = more multitasking, less stutter.

SRAM (cache, ~1ns) is superfast but tiny and costly; DRAM (main RAM, ~50ns) is slower but GBs and cheap. That's why both exist.

| Term | DDR4 (old) | DDR5 (buy now) |
| --- | --- | --- |
| `Speed` | 2133-3200MT/s | 5600 base; sweet spot 6000 CL30 (AMD) / 6400 (Intel); 7200+ OC kits |
| `Voltage` | 1.2V | 1.1V (cooler) |
| `Stick` | DIMM desktop / SO-DIMM laptop | DIMM + CUDIMM (clocked, for 8000MT/s+ stability) |
| `Channels` | 2x sticks = dual-channel (~2x bandwidth) | Same — always buy `2x16GB`, never `1x32GB` |
| `Board support` | DDR4 board ≠ DDR5 slot | Not interchangeable. Check board spec first. |

| Capacity | Enough for | Example |
| --- | --- | --- |
| `16GB` | Office, web, students | 2x8GB DDR5 5600 laptop/office |
| `32GB` | Gaming + coding sweet spot 2026 | 2x16GB DDR5 6000 CL30 — do this |
| `64GB+` | 4K editing, VMs, AI models | 2x32GB DDR5 6400 creator / M5 Pro 48-64GB unified |

> Laptop with soldered RAM? Get 32GB upfront — you can't add later, same as Mac.

## Storage — pantry

| Type | Speed | Beginner meaning |
| --- | --- | --- |
| `HDD` | 80-160MB/s, spinning disk | Huge + cheap (4TB). Good for backups. Dies if dropped, slow for OS/games. Listen for RPM 5400/7200. |
| `SATA SSD 2.5"` | ~550MB/s | 10x snappier than HDD for boot. Fine for old PC upgrade. Same speed limit for all SATA. |
| `NVMe Gen4 SSD` | ~7000MB/s | 2026 default. Boots in 10s, games load 3x faster. Needs M.2 slot. |
| `NVMe Gen5 SSD` | ~14000MB/s | Flagship + DirectStorage games. Hot — needs heatsink, barely matters for Office. |

| Buying term | What to check |
| --- | --- |
| `TLC vs QLC` | TLC = faster + longer life (buy this for OS). QLC = cheaper per TB, fine for game library. |
| `TBW` | Lifespan (terabytes you can write). 600TBW 1TB = years for normal use. Bigger = longer. |
| `DRAM cache` | Map of SSD. DRAM-less = cheaper, slower sustained writes. OS drive: get DRAM. |
| `M.2 2280 M-key` | 22mm x 80mm stick, notch on one side. Most common. Fits 99% desktops/laptops/PS5. |
| `PCIe 4.0x4 = 8GB/s, 5.0x4 = 16GB/s` | Slot ceiling. Gen5 SSD in Gen4 slot still works, just capped at ~7000MB/s. |
| `PS5 rule` | Must be Gen4 5500MB/s+ *with heatsink*. Add $10 heatsink or buy heatsink version. |
| `DirectStorage` | GPU loads from SSD directly, skips CPU. Needs NVMe + RTX 3000+/RX 6000+ + Win11. Cuts game load stutter. |

2026 picks: 1TB Gen4 TLC with DRAM (~$70) for OS + 2TB QLC Gen4 (~$110) for games is the value combo.

## GPU — graphics oven

CPU draws 1 picture slowly; GPU draws 10,000 tiny triangles at once. Needed for games, 4K video, 3D, AI.

| Type | Meaning | Buy |
| --- | --- | --- |
| `iGPU` | Free graphics inside CPU/SoC | Office, YouTube 4K, Valorant low. Zero extra cost/power. M5 iGPU is unusually strong. |
| `dGPU` | Separate card with own VRAM + fans | AAA games, Blender, local LLM. RTX 5060 (1080p), 5070 (1440p), 5090 (4K/AI), RX 9070 (value 1440p/4K). |

| Term | Beginner meaning | 2026 rule |
| --- | --- | --- |
| `VRAM` | GPU's own countertop for textures/models | 8GB = 1080p only; 12GB = 1440p sweet; 16-24GB = 4K + AI. Running out = stutter even if chip is fast. |
| `CUDA vs ROCm` | AI/video software language | NVIDIA CUDA works everywhere (Blender, Adobe, AI). AMD ROCm catching up but check your app first. |
| `DLSS / FSR` | AI upscaling: render low, display sharp | Free +30-80% FPS. DLSS (NVIDIA) slightly better; FSR works on all. Always turn on in 2026. |
| `Bottleneck rule` | Which part limits FPS? | 1080p = CPU matters (chef speed). 4K = GPU matters (oven power). Pair 9800X3D + 5070 for 1440p balance. |

## PSU — power box

Wrong PSU = random crashes or dead PC. Never cheap out here.

Formula: `(CPU watts + GPU watts + 150) x 1.3 = PSU watts`. Example: 170W CPU + 250W GPU + 150 = 570 x 1.3 ≈ 740W → buy 750W.

| Need | Watts | Notes |
| --- | --- | --- |
| `Office / iGPU` | 450-550W | Any Bronze is fine. |
| `Mid gaming (4060/5060/9070)` | 650-750W | 2026 sweet spot. Get ATX 3.0 + native 12VHPWR cable for RTX cards. |
| `Flagship (5090 + 9950X/285K)` | 1000W+ | Needs 1000-1200W Gold/Platinum, big case airflow. |

`80+ Bronze < Gold < Platinum` = less wasted heat + lower bill. **Gold is the sweet spot** — Platinum only for 24/7 rigs. Always check wattage first, rating second.

## Cooling — don't let the chef faint

Chips slow themselves (throttle) when hot to avoid damage. Good cooling = sustained speed.

| Option | Meaning | When |
| --- | --- | --- |
| `Stock cooler` | Free small fan in box | Only for 65W office CPUs. Loud under load. |
| `Tower air` | Big metal + fan(s), $30-50 | Best value for 90% builds. AK400 / Peerless Assassin cools 9800X3D fine. |
| `AIO liquid 240/360mm` | Radiator + pump | 16-24 core flagships, overclocking, quiet glass builds. |
| `Thermal paste` | Grey goo between CPU and cooler | Pea-sized dot. Replace every 4-5 years or if temps spike. |
| `Airflow` | Front in, back/top out | 2x front intake + 1x rear exhaust minimum. Cables tucked, dust filter cleaned. |

Throttle temps (slowdown starts): CPU ~95°C, GPU ~83°C, NVMe SSD ~75°C. Gaming at 70-85°C CPU / 65-75°C GPU is normal. 100°C + crash = remount cooler.

## USB ports — the naming trap

USB names were renamed — trap! Ignore the marketing name, look at **Gbps**.

| Label to look for | Speed | Connector | Use |
| --- | --- | --- | --- |
| `USB 2.0` | 480Mbps | A | Mouse, keyboard, printer only |
| `USB 5Gbps (aka 3.0/3.1 Gen1/3.2 Gen1)` | 5Gbps | A/C | All the same thing! HDDs, webcams |
| `USB 10Gbps (aka 3.1 Gen2/3.2 Gen2)` | 10Gbps | A/C | SATA SSD enclosures, fast sticks |
| `USB 20Gbps (aka 3.2 Gen2x2)` | 20Gbps | C only | NVMe enclosures |
| `USB4 40Gbps / Thunderbolt 4 40Gbps` | 40Gbps | C only | Docks, eGPU, 4K monitors |
| `USB4 v2 80G / Thunderbolt 5 80G (120 Boost)` | 80-120Gbps | C only | 8K / multi-4K, AI docks. TB5 also gives 240W charging (PD). |

> If a cable/port just says "USB 3.0", assume 5Gbps. For NVMe enclosures and docks, you must use a real C-to-C 10G/40G cable — phone charging cables throttle to 480Mbps.

## Video ports — HDMI vs DisplayPort

| Port | Bandwidth | Best for |
| --- | --- | --- |
| `HDMI 2.1` | 48Gbps (42.6 effective) | TVs, PS5, 4K120 living room. ARC/eARC for soundbars. |
| `DisplayPort 2.1` | 80Gbps (77.4 effective) | PC monitors. Only one that does 4K240 natively without compression. Buy DP for 1440p165+ / 4K144+ gaming. |

Dev rule: office 4K60 = either is fine. Competitive 1440p240 / 4K240 = DisplayPort. Always use the cable in the monitor box for high refresh.

## Ethernet + Wi-Fi — Mbps vs MBps

`Mbps/8 = MBps`. Network speeds are in **bits (b)**, file/storage speeds in **bytes (B)**. 8 bits = 1 byte.

| Port | Speed | Meaning |
| --- | --- | --- |
| `1GbE` | 1000Mbps = 125MBps | Old default, fine for 4K streaming + office |
| `2.5GbE` | 2500Mbps = 312MBps | 2026 standard on B850/Z890 boards. Get this + cheap 2.5G switch for NAS. |
| `10GbE` | 10Gbps | Video studios, NAS editors only. Needs Cat6a + pricey switch. |

Quick math: 7000MB/s SSD = 56000Mbps — 50x faster than 1GbE internet. That's why copying from NAS is slower than local SSD. Downloading a 50GB game on 500Mbps takes `50,000MB / 62.5MBps ≈ 13 min`.

## PCIe slots — highways on the board

PCIe = slots/lanes connecting GPU and SSDs to CPU. Bigger `x number` = wider road. Newer `gen` = faster cars — each gen doubles speed.

| Slot | Lanes + speed | Holds |
| --- | --- | --- |
| `PCIe x16 (GPU slot)` | Gen4 32GB/s, Gen5 64GB/s | GPU. Top slot is always fastest (wired to CPU). Use that one. |
| `M.2 CPU slot` | Usually Gen5 in 2026 | Fastest SSD (OS drive here). |
| `M.2 chipset slot(s)` | Usually Gen4 | Second SSD for games — fine, no real game difference. |
| `PCIe x1 / x4` | Short slots | Wi-Fi card, capture card, extra USB. |

Gens: 3.0 → 4.0 → 5.0 → 6.0 each ~2x. GPU on Gen4 x16 loses &lt;3% vs Gen5 in 2026 — don't panic if your board is Gen4. SSD Gen5 only matters for huge file moves + DirectStorage.

## Memory hierarchy — fast-small vs slow-big

CPU checks storage from fastest-smallest to slowest-biggest. Hit = fast, miss = wait for next level.

`Registers (under 1ns) → L1 (1ns, KB) → L2 (~3ns, MB) → L3 (~12ns, 24-96MB) → RAM (~80ns, GB) → NVMe (~50us) → HDD (ms)`

Numbers to feel: RAM is ~80x slower than registers, NVMe ~600x slower than RAM, HDD ~20x slower than NVMe. That's why cache + RAM size matter more than you think.

Apple unified memory = CPU + GPU share one pool — no copying between RAM and VRAM, so 32GB M5 feels like 32GB that *both* use. On PC, 16GB RAM + 12GB VRAM are separate — copying wastes time/power.

## Units — KB vs KiB, MB vs Mb

| Trap | Truth |
| --- | --- |
| `KB (1000) vs KiB (1024)` | Makers use 1000, Windows uses 1024. So 1TB drive = 931GiB in Windows — not missing, just math. `1TB = 10^12B / 2^30 ≈ 931GiB`. |
| `MB/s (bytes) vs Mbps (bits)` | Internet in Mbps, SSD in MB/s. `7000MB/s SSD = 56000Mbps`. Divide bits by 8 to get bytes. |
| `MT/s vs MHz (RAM)` | DDR transfers 2x per clock, so DDR5-6000 = 3000MHz clock, 6000MT/s. Box shows MT/s. |
| `GHz vs cores` | GHz = speed per core, cores = count. Need both. |

## Bottlenecks — what's slowing you?

| Symptom | Likely bottleneck | Fix |
| --- | --- | --- |
| `Game stutters, GPU at 60%, CPU at 100%` | CPU bottleneck (common at 1080p) | Lower crowd/AI settings, upgrade CPU, enable XMP, close Chrome/Discord. |
| `Low FPS, GPU at 99-100%` | GPU bottleneck (normal at 4K) | Intended! Lower resolution, turn on DLSS/FSR, upgrade GPU. |
| `Chrome reloads tabs, disk 100% on HDD` | RAM too small / HDD | Add RAM to 32GB, move OS to NVMe SSD. Biggest old-PC upgrade. |
| `4K timeline lags, RAM 95%+` | RAM + VRAM | 64GB RAM, GPU with 16GB+ VRAM, proxy media, NVMe scratch disk. |
| `Wi-Fi fast, download slow` | ISP / server, not PC | Test wired, check Mbps vs MBps math, reboot router. |

Golden rule: upgrade the part at 95-100% while others idle. Upgrading a 60% part gives zero gain.

## Upgrading tips — biggest wins first

1. **Enable XMP/EXPO first.** New DDR5 runs at 4800 until you enable it in UEFI → free +15% FPS. Takes 30 seconds.
2. **Use 2 sticks (dual-channel).** 1x32GB is ~15% slower than 2x16GB. Always fill A2+B2 slots per manual.
3. **HDD → NVMe SSD.** Single biggest old-PC upgrade. Clone OS to Gen4 NVMe, boot 60s → 10s.
4. **GPU before CPU for 1440p/4K.** If GPU is 100% and CPU 60%, new CPU won't help.
5. **Check PSU + case before GPU.** 12GB+ VRAM cards need 650W+ ATX 3.0 + 300mm clearance + airflow.
6. **Repaste + dust = free speed.** 5-year-old PC throttling at 95°C? Clean fans, new paste, -$0 vs new CPU.
7. **Laptop/Mac SoC? Upgrade at buy.** RAM/SSD soldered — 16GB → 32GB now is cheaper than a new laptop later.

## How to read a spec sheet

Pattern: `CPU / RAM / Storage / GPU / Screen / Power`. Decode each chunk, then ask "what's missing for my use?"

**Example 1 — $1299 gaming tower:** `9800X3D / 32GB DDR5-6000 CL30 / 1TB Gen4 NVMe / RTX 5070 12GB / 750W Gold`

Read: 8 fast X3D cores = top 1440p gaming; 32GB dual-channel at AMD sweet spot (check XMP on); 1TB TLC is enough for OS + 5-6 games (add 2TB later in chipset slot); 12GB VRAM = ultra 1440p, ok 4K with DLSS; 750W Gold + ATX 3.0 = correct headroom. Verdict: balanced, no bottleneck at 1440p165. Missing: no HDD needed, add second SSD when full.

**Example 2 — $2499 creator laptop:** `M5 Pro 12c/16c / 48GB unified 273GB/s / 1TB / 14" Liquid Retina`

Read: SoC CPU+GPU share 48GB — great for 4K Premiere + local 13B AI (no VRAM copy); bandwidth 273GB/s ≈ 2x base M5 = faster timeline scrub; 1TB soldered — add TB4 external NVMe for footage; no PSU/GPU watts to worry, 22hr battery + silent. Verdict: buy RAM/storage now, you can't upgrade. If you do 8K/3D daily, step to M5 Max 64GB+.

Checklist before paying: socket matches CPU? RAM 2 sticks + XMP? SSD Gen4 5000+ with DRAM for OS? PSU `(CPU+GPU+150)*1.3` Gold? Case fits GPU length + cooler height? Monitor cable DP for 144Hz+?

## FAQs

**Do I need 32GB RAM in 2026?**
For gaming + coding + 30 Chrome tabs, yes. 16GB works for pure Office/study, but 32GB (2x16GB DDR5 6000) is only ~$30 more and stops stutter. Creators/VMs get 64GB.

**Is iGPU enough or do I need a graphics card?**
Office, web, movies, Valorant/Fortnite-low: iGPU/M5 is fine. AAA ultra, Blender, DaVinci 4K, local AI: get a dGPU with 12GB+ VRAM. No middle ground — a $150 dGPU barely beats modern iGPUs.

**DDR4 vs DDR5 — can I reuse old RAM?**
No, slots differ physically. New 2026 boards are DDR5-only. DDR5 6000 CL30 beats DDR4 3200 by ~15-20% in games + uses less power. Don't build new on DDR4.

**How much SSD do I need?**
512GB minimum (Windows + apps = 150GB). 1TB sweet spot for most. 2TB+ if you play 5+ AAA games (100GB each) or edit video. Always NVMe Gen4+ for OS — SATA only to revive old laptops.

**What watt PSU for RTX 5070 + 9800X3D?**
(120W + 250W + 150) x 1.3 ≈ 676W → 750W Gold ATX 3.0. Same math for any combo. Never use the free PSU that came with a $40 case for a gaming GPU.

**Why is my new PC slow?**
90% of the time: XMP off (RAM at 4800), single RAM stick, OS on HDD, or monitor plugged into motherboard instead of GPU. Fix those before buying anything.

**Does Gen5 SSD make games faster?**
Load screens 5-10% faster than Gen4, in-game FPS identical. Buy Gen5 only for heavy 4K editing/file moves or if price gap is under $20. Put money into GPU/VRAM first.

**Apple unified memory vs PC RAM+VRAM?**
Apple: one pool both use, no copy, great efficiency — but soldered, pay Apple prices. PC: separate pools, upgradeable and cheaper per GB, but copies waste time. 32GB M5 ≈ 16GB RAM + 12GB VRAM workflow-wise.
