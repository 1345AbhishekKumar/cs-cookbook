C is a compiled, procedural language. `main()` is the entry point; headers like `<stdio.h>` provide library functions.

Use this page as a quick reference: syntax, tables, and minimal snippets.

## Basic Syntax — Hello World

```c
// C Hello World program
#include <stdio.h>

int main()
{
  printf("Hello World!");
  return 0;
}
```

Output: `Hello World!`

| Part | Meaning |
| --- | --- |
| `#include <stdio.h>` | Header inclusion — enables `printf()`. |
| `int main()` | Entry point of every C program. |
| `printf("Hello World!")` | Prints to standard output. |
| `return 0;` | Exit status from `main()`. |

## Variables

A variable names a memory location storing data.

```c
data_type variable_name;
data_type variable_name = initial_value;
```

| Kind | Meaning |
| --- | --- |
| `Local` | Declared inside a function / block. |
| `Global` | Declared outside all functions. |
| `Static` | Retains value across calls. |
| `Extern` | Declared elsewhere (another file). |
| `Auto` | Default storage class for locals. |
| `Register` | Hint to store in CPU register. |

Naming rules: letters, digits, underscore only — start with letter or `_`, no whitespace, never a keyword.

## Data Types

Three families: basic, derived, user-defined.

| Basic type | Holds |
| --- | --- |
| `char` | Characters. |
| `int` | Integral numbers. |
| `float` | Decimals, ~6–7 digits precision. |
| `double` | Decimals, ~15 digits precision. |
| `void` | Valueless entity. |

```c
char c = 'a';
int integer = 24;
float f = 24.32;
double d = 24.3435;
```

Type modifiers change size / range: `short`, `long`, `signed`, `unsigned`.

```c
unsigned int var1;
long double var2;
long int var3;
```

| Family | Members |
| --- | --- |
| `Derived` | Arrays, Pointers. |
| `User-defined` | `struct`, `union`, `enum`. |

## Identifiers & Keywords

Identifiers name variables, functions, structs. Rules: alphanumerics + `_`, start with letter/`_`, no spaces, not a keyword.

```c
var, any_other_name, __this_var, var22; // valid
```

Keywords are reserved — cannot be identifiers. Examples: `auto`, `float`, `int`, `return`, `switch`.

## Basic Input & Output

`<stdio.h>` provides `printf()` (output) and `scanf()` (input).

```c
printf("formatted-string", arguments_list);
scanf("formatted-string", address_list);
```

- `formatted-string` — text + format specifiers / escape sequences.
- `printf` takes values; `scanf` takes addresses (`&var`), except strings (array name).

```c
#include <stdio.h>

int main()
{
  int roll_num;
  char name[50];

  printf("Enter Roll No: ");
  scanf("%d", &roll_num);
  printf("Enter Name: ");
  scanf("%s", name);

  printf("Name is %s and Roll Number is %d", name, roll_num);
  return 0;
}
```

## Conditional Statements

```c
if (condition) { /* runs if true */ }

if (expr) { /* if block */ }
else { /* else block */ }

if (expr) { /* block 1 */ }
else if (expr) { /* block 2 */ }
else { /* else block */ }

switch (expr) {
  case value1: /* … */ break;
  case value2: /* … */ break;
  default: /* … */ break;
}

(cond) ? (if-true) : (if-false);
```

```c
#include <stdio.h>
int main()
{
  int i = 5 < 25 ? 10 : 20; // 10

  if (i == 10) printf("i is 10");
  else if (i == 15) printf("i is 15");
  else if (i == 20) printf("i is 20");
  else printf("i is not present");
}
```

Output: `i is 10`

## Loops

Repeat a block until a condition is false.

```c
for (init; condition; update) { /* … */ }  // entry-controlled
while (condition) { /* … */ }              // entry-controlled
do { /* … */ } while (condition);          // exit-controlled: runs at least once
```

## Jump Statements

Override normal control flow.

| Statement | Effect | Syntax |
| --- | --- | --- |
| `break` | Exit loop / `switch`. | `break;` |
| `continue` | Skip to next iteration. | `continue;` |
| `goto` | Jump to a label. | `goto label; … label:` |

```c
#include <stdio.h>
int main()
{
  int i = 0;

  for (i = 1; i <= 10; i++) {       // continue
    if (i == 5 || i == 7) continue;
    printf("%d ", i);
  }
  printf("\n");

  i = 1;                            // break
  while (i <= 10) {
    if (i == 7) break;
    printf("%d ", i++);
  }
  printf("\n");

  i = 1;                            // do-while
  do { printf("%d ", i++); } while (i <= 10);
  printf("\n");

  i = 1;                            // goto
any_label:
  printf("%d ", i++);
  if (i <= 10) goto any_label;

  return 0;
}
```

## Arrays

Fixed-size, homogeneous, contiguous — with random access by index. Size cannot change; can be multi-dimensional.

```c
data_type arr[size];              // 1D
data_type arr[size1][size2];      // 2D
data_type arr[s1][s2][s3];        // 3D
```

```c
#include <stdio.h>
int main()
{
  int arr[5] = { 10, 20, 30, 40, 50 };
  arr[2] = 100; // modify index 2

  printf("Elements in Array: ");
  for (int i = 0; i < 5; i++) printf("%d ", arr[i]);
  return 0;
}
```

Output: `Elements in Array: 10 20 100 40 50`

## Strings

Sequence of chars terminated by `'\0'`, stored as a char array.

```c
char string_name[] = "any_text";
```

```c
#include <stdio.h>
#include <string.h>
int main()
{
  char str[] = "Geeks";
  printf("%s\n", str);
  printf("Length of string str is %d", (int)strlen(str));
  return 0;
}
```

| Function | Purpose |
| --- | --- |

| `strcmp()` | Compare two strings. |
| `strcpy()` | Copy one string to another. |
| `strcat()` | Concatenate strings. |
| `strchr()` | Find a character. |
| `strstr()` | Find a substring. |

## Pointers

Variables holding addresses. `&` takes an address; `*` declares a pointer and dereferences it.

```c
data_type *ptr_name;
ptr = &var;   // address of var
*ptr;         // value at ptr
```

```c
#include <stdio.h>
int main()
{
  int var = 10;
  int *ptr;
  ptr = &var; // same type required

  printf("Value at ptr = %p \n", (void *)ptr);
  printf("Value at var = %d \n", var);
  printf("Value at *ptr = %d \n", *ptr);
  return 0;
}
```

Pointer flavors: double, function, structure, `NULL`, dangling, wild.

## Functions

Blocks in `{ }` doing one task — reusable and modular. Three parts:

```c
return_type function_name(param_types...); // 1. prototype: declares existence

return_type function_name(params...) {     // 2. definition: actual body
  /* statements */
}

function_name(args...);                    // 3. call: after prototype/definition
```

- Return type: single optional value returned.
- Parameters: data passed in by the caller.

```c
#include <stdio.h>
int sum(int a, int b) { return a + b; }

int main()
{
  int add = sum(10, 30);
  printf("Sum is: %d", add); // Sum is: 40
  return 0;
}
```

Four combos of return/params: no-return + no-params, no-return + params, return + no-params, return + params. Two origins: library vs user-defined.

## Dynamic Memory (`<stdlib.h>`)

Allocate at runtime. Four functions:

| Function | Purpose | Syntax |
| --- | --- | --- |
| `malloc()` | Block of `size` bytes; `NULL` on failure. | `malloc(size)` |
| `calloc()` | `num` blocks of `size` bytes, zeroed. | `calloc(num, size)` |
| `realloc()` | Resize existing allocation. | `realloc(ptr, new_size)` |
| `free()` | Release allocation. | `free(ptr)` |

```c
#include <stdio.h>
#include <stdlib.h>
int main()
{
  int *ptr = (int *)malloc(sizeof(int) * 10);
  int *ptr2 = (int *)calloc(10, sizeof(int));

  printf("malloc Array Size: %d\n", 10);
  printf("calloc Array Size: %d\n", 10);

  ptr = realloc(ptr, sizeof(int) * 5);
  printf("malloc Array Size after using realloc: %d", 5);

  free(ptr);
  free(ptr2);
  return 0;
}
```

## Structures

User-defined type bundling different-typed members. Declared with `struct`, accessed via `.`.

```c
struct struct_name {
  member_type1 name1;
  member_type2 name2;
};

struct struct_name var1, var2; // variables
```

```c
#include <stdio.h>
struct str1 { int i; char c; float f; char s[30]; };
struct str2 { int ii; char cc; float ff; } var;

int main()
{
  struct str1 var1 = { 1, 'A', 1.00, "GeeksforGeeks" }, var2;
  struct str2 var3 = { .ff = 5.00, .ii = 5, .cc = 'a' };

  var2 = var1; // struct copy via assignment

  printf("Struct 1:\n\ti = %d, c = %c, f = %f, s = %s\n",
    var1.i, var1.c, var1.f, var1.s);
  return 0;
}
```

## Union

Like `struct`, but members share memory — only one holds data at a time. Access with `.`.

```c
union union_name {
  // members
};

union un var1;
var1.member1 = 15;
```

```c
#include <stdio.h>
union un { int member1; char member2; float member3; };
int main()
{
  union un var1;
  var1.member1 = 15;
  printf("The value stored in member1 = %d", var1.member1);
  return 0;
}
```

## Enumeration (enum)

Named integral constants. Members default from `0`, overridable manually.

```c
enum { name1, name2, name3 = value };
```

```c
#include <stdio.h>
enum week { Mon, Tue, Wed, Thur, Fri, Sat, Sun };
int main()
{
  enum week day;
  day = Wed;
  printf("%d", day); // 2
  return 0;
}
```

## Memory anchors

- **Program skeleton:** `#include` → `int main()` → `printf` → `return 0`. Headers grant functions.
- **Declaration shape:** `type name;` or `type name = value;`. Name = letters/digits/`_`, never a keyword.
- **Type ladder:** `char → int → float → double → void`, tuned by `short/long/signed/unsigned`. Beyond that: arrays/pointers (`derived`), `struct/union/enum` (`user-defined`).
- **I/O pair:** `printf(values)` prints, `scanf(&vars)` reads. Format string leads: `%d int`, `%f float`, `%lf double`, `%c char`, `%s string`, `%p pointer`, `%% percent`.
- **Strings end with `\0`:** char arrays + `<string.h>` verbs — `len/cmp/cpy/cat/chr/str`: `strlen, strcmp, strcpy, strcat, strchr, strstr`.
- **Pointer duality:** `&` takes address, `*` holds/dereferences it. Types must match.
- **Branch vs jump:** `if/else-if/switch/ternary` choose paths; `break/continue/goto` force movement.
- **Loop choice:** `for` when counted, `while` when conditional, `do-while` when at-least-once.
- **Function trio:** prototype declares, definition implements, call executes. One return value max.
- **Heap quartet:** `malloc` raw block, `calloc` zeroed blocks, `realloc` resize, `free` release — always `free` what you allocate.
- **struct vs union vs enum:** `struct` bundles side-by-side, `union` overlays shared memory, `enum` names integers from `0`.
- **Files:** `fopen → fscanf/fgets or fprintf/fputs → fseek/rewind → fclose`.
