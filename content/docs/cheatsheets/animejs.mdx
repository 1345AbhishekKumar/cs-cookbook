Anime.js is a lightweight, flexible JavaScript animation engine. It animates CSS properties, 2D/3D transforms, SVG attributes, DOM attributes, and raw JavaScript objects with a clean API, advanced staggering, and timeline synchronization.

- **Official Website:** [https://animejs.com](https://animejs.com)
- **Documentation:** [https://animejs.com/documentation](https://animejs.com/documentation)
- **GitHub Repository:** [https://github.com/juliangarnier/anime](https://github.com/juliangarnier/anime)

Use this page as an exhaustive reference: targets, easing tables, timeline offsets, SVG morphing, and copy-paste recipes for both modern Anime.js v4 and classic v3.

---

## Setup & Version Syntax

```bash
npm install animejs
```

### Modern v4 (Modular) vs Classic v3 (Namespace)

```javascript
// Modern Anime.js v4 (ESM tree-shakeable)
import { animate, createTimeline, stagger, svg, onScroll } from "animejs";

// Classic Anime.js v3
import anime from "animejs";
```

| Feature | Anime.js v4 (Modern) | Anime.js v3 (Classic) |
| --- | --- | --- |
| Single Tween | `animate(targets, params)` | `anime({ targets, ...params })` |
| Timelines | `const tl = createTimeline(params)` | `const tl = anime.timeline(params)` |
| Staggers | `delay: stagger(100)` | `delay: anime.stagger(100)` |
| SVG Motion Path | `svg.motionPath('#path')` | `anime.path('#path')` |
| Scroll Control | Built-in `onScroll(...)` | Requires custom scroll event listener |

## Target Selectors

Anime.js accepts CSS selectors, DOM elements, NodeLists, or arbitrary JavaScript objects:

```javascript
// 1. CSS Selector strings
animate(".card", { opacity: 1 });

// 2. DOM Elements & NodeLists
const el = document.getElementById("hero");
animate(el, { translateX: 100 });

const buttons = document.querySelectorAll("button");
animate(buttons, { scale: 1.1 });

// 3. Mixed Array of different targets
animate([".box", el, buttons], { translateY: 50 });

// 4. Plain JavaScript Object (Number tweening)
const counter = { score: 0 };
animate(counter, {
  score: 1000,
  round: 1, // Rounds to whole integers
  onUpdate: () => console.log(counter.score),
});
```

## Animatable Properties

### 1. CSS Transforms & Styles

Always prefer transform properties (`x`, `y`, `scale`, `rotate`) over `top`/`left` to maintain GPU compositor acceleration:

```javascript
animate(".box", {
  // 2D & 3D Transforms
  translateX: 250,        // or x: 250 in v4
  translateY: "5rem",     // units supported (px, rem, %, em, vh, vw, deg, rad, turn)
  scale: 1.5,
  scaleX: [0.5, 1],       // [from, to] specific starting values
  rotate: "1turn",        // "360deg", "1turn", "6.28rad"
  rotateZ: 45,
  skewX: "15deg",

  // CSS Styles
  opacity: [0, 1],
  backgroundColor: "#6366f1",
  borderRadius: ["0%", "50%"],
});
```

### 2. DOM Attributes & Input Values

```javascript
// Animate progress bar or input values
animate("input[type=range]", {
  value: 80,
  duration: 1200,
  easing: "easeInOutQuad",
});
```

## Property Parameters & Timing

| Property | Default | Description | Example |
| --- | --- | --- | --- |
| `duration` | `1000` | Duration in milliseconds. | `duration: 600` |
| `delay` | `0` | Delay in milliseconds before animation starts. | `delay: 200` |
| `endDelay` | `0` | Delay in milliseconds after animation ends before complete/loop. | `endDelay: 100` |
| `easing` | `'easeOutQuad'` | Timing curve / physics equation. | `easing: 'spring(1, 80, 10, 0)'` |
| `round` | `0` | Rounds decimal steps (e.g. `1` for integers, `10` for tenths). | `round: 1` |
| `loop` | `1` | Number of iterations or `true` / `Infinity` for continuous looping. | `loop: true` |
| `direction` | `'normal'` | Playback direction: `'normal'`, `'reverse'`, or `'alternate'`. | `direction: 'alternate'` |
| `autoplay` | `true` | When `false`, animation pauses until `play()` is called. | `autoplay: false` |

### Specific Property Overrides

Define parameters per individual animated property:

```javascript
animate(".element", {
  translateX: {
    value: 250,
    duration: 800,
    easing: "easeInOutSine",
  },
  opacity: {
    value: 1,
    duration: 400,
    easing: "linear",
  },
  delay: 200, // Shared fallback delay
});
```

## Staggers Masterclass

The stagger function applies values or delays incrementally across target collections.

```javascript
import { animate, stagger } from "animejs";

// 1. Basic stagger delay
animate(".list-item", {
  translateY: [40, 0],
  opacity: [0, 1],
  delay: stagger(100), // 0ms, 100ms, 200ms, 300ms...
});

// 2. Stagger starting offset and direction
animate(".list-item", {
  translateX: 100,
  delay: stagger(100, {
    start: 500,        // Initial pause before first element begins
    from: "last",      // "first" | "last" | "center" | index (e.g. 2)
    direction: "reverse",
  }),
});

// 3. Staggering animated values (e.g. rotation spread)
animate(".card", {
  rotate: stagger([-30, 30]), // Distributes rotation from -30deg to +30deg
  delay: stagger(80),
});
```

### 2D Grid Staggering

Calculates delays from spatial positions in a two-dimensional grid:

```javascript
animate(".grid-cell", {
  scale: [0, 1],
  opacity: [0, 1],
  delay: stagger(60, {
    grid: [6, 6],      // [columns, rows]
    from: "center",    // Center outward ripple: "center" | "first" | "last" | index
    axis: "x",         // Bias wave along "x" or "y"
  }),
});
```

## Easing & Physics Reference

Anime.js includes pre-built bezier curves, elastic formulas, step curves, and spring physics.

```javascript
// 1. Standard Power & Curve Easings
// Curves: Quad, Cubic, Quart, Quint, Sine, Expo, Circ, Back, Bounce
easing: "easeInQuad"
easing: "easeOutExpo"
easing: "easeInOutCirc"
easing: "easeInOutBack"   // Pulls back before jumping forward

// 2. Spring Physics (mass, stiffness, damping, initialVelocity)
easing: "spring(1, 80, 10, 0)"

// 3. Elastic Curves (amplitude, period)
easing: "easeOutElastic(1, .6)"

// 4. Custom Cubic Bézier (x1, y1, x2, y2)
easing: "cubicBezier(.42, 0, .58, 1)"

// 5. Stepped Easing (Sprites / Frame ticks)
easing: "steps(8)"

// 6. Linear
easing: "linear"
```

## Timelines & Multi-Stage Choreography

Timelines chain animations synchronously without computing cumulative delays.

### Modern v4 Timelines

```javascript
import { createTimeline } from "animejs";

const tl = createTimeline({
  defaults: {
    duration: 600,
    easing: "easeOutQuad",
  },
  loop: false,
});

// Chained stages with relative offsets
tl.add(".hero-title", { y: [40, 0], opacity: [0, 1] })
  .add(".hero-subtitle", { y: [30, 0], opacity: [0, 1] }, "-=400") // Starts 400ms before previous finishes
  .add(".hero-cta", { scale: [0.8, 1], opacity: [0, 1] }, "-=200")
  .add(".hero-image", { x: [100, 0], opacity: [0, 1] }, 200);     // Absolute timestamp at 200ms
```

### Classic v3 Timelines

```javascript
const tl = anime.timeline({
  easing: "easeOutExpo",
  duration: 750,
});

tl.add({ targets: ".title", translateY: [50, 0], opacity: [0, 1] })
  .add({ targets: ".badge", scale: [0, 1] }, "-=300")
  .add({ targets: ".card", translateY: [30, 0], opacity: 1, delay: anime.stagger(100) });
```

## SVG Animations & Morphing

### 1. SVG Line Drawing (`strokeDashoffset`)

```javascript
// Animates drawing stroke along any SVG line, path, or polygon
animate(".svg-line", {
  strokeDashoffset: [anime.setDashoffset, 0],
  easing: "easeInOutSine",
  duration: 1500,
  delay: (el, i) => i * 250,
});
```

### 2. SVG Path Morphing

Animate the `d` attribute of a `<path>` or `points` of a `<polygon>`. (Note: Paths should share equal anchor point counts for optimal morphing).

```javascript
animate("#morph-blob", {
  d: [
    { value: "M10 80 Q 95 10 180 80 T 350 80" },
    { value: "M10 80 Q 95 180 180 80 T 350 80" },
  ],
  duration: 2000,
  easing: "easeInOutQuad",
  direction: "alternate",
  loop: true,
});
```

### 3. Motion Path Following (`anime.path`)

Make any DOM element or SVG icon travel along an arbitrary SVG curve:

```javascript
// Classic v3
const path = anime.path("#motion-track");

anime({
  targets: ".rocket-icon",
  translateX: path("x"),
  translateY: path("y"),
  rotate: path("angle"), // Automatically turns element to match path slope
  easing: "linear",
  duration: 4000,
  loop: true,
});
```

## Playback Controls & Callbacks

```javascript
const animation = animate(".box", {
  translateX: 300,
  autoplay: false, // Wait for user trigger
});

// Control API
animation.play();      // Play forward
animation.pause();     // Freeze playback
animation.restart();   // Rewind and play from start
animation.reverse();   // Reverse direction
animation.seek(500);   // Jump playhead to 500ms

// Lifecycle Callbacks
animate(".box", {
  translateX: 250,
  begin: (anim) => console.log("Animation started, targets:", anim.animatables.length),
  update: (anim) => console.log("Progress:", anim.progress, "%"),
  complete: (anim) => console.log("Animation finished"),
  loopBegin: (anim) => console.log("Loop iteration started"),
  loopComplete: (anim) => console.log("Loop iteration finished"),
});
```

## Common Creative Recipes

### 1. Kinetic Staggered Text Reveal

```javascript
// HTML: <span class="letter">H</span><span class="letter">e</span>...
animate(".letter", {
  translateY: ["110%", "0%"],
  opacity: [0, 1],
  rotateZ: [-20, 0],
  duration: 800,
  easing: "spring(1, 90, 12, 0)",
  delay: stagger(40),
});
```

### 2. Animated Number Counter

```javascript
const obj = { value: 0 };

animate(obj, {
  value: 48950,
  round: 1, // Whole integers
  duration: 2000,
  easing: "easeOutExpo",
  onUpdate: () => {
    document.getElementById("counter").textContent = obj.value.toLocaleString();
  },
});
```

### 3. Circular Ripple Burst

```javascript
animate(".particle", {
  translateX: () => (Math.random() - 0.5) * 300,
  translateY: () => (Math.random() - 0.5) * 300,
  scale: [1, 0],
  opacity: [1, 0],
  duration: 1000,
  easing: "easeOutExpo",
});
```

## Anti-patterns vs Best practices

| Anti-pattern | Why it harms | Best practice |
| --- | --- | --- |
| Animating `top`, `left`, `margin` | Causes continuous CPU paint and layout reflows. | Animate `translateX`, `translateY`, `scale`, `rotate`. |
| Hardcoding cumulative manual delays | Editing one stage breaks all following stages. | Use `createTimeline()` / `anime.timeline()` with relative offsets (`"-=300"`). |
| Looping endless animations on offscreen tabs | Wastes device battery and CPU cycles. | Pause offscreen animations with `animation.pause()` or IntersectionObserver. |
| Morphing SVG paths with unequal point counts | Visual glitches and path collapsing. | Normalize SVG paths in vector tools (e.g., Figma) to share identical vertex counts. |
| In modern v4: calling default `anime({})` | Causes `TypeError` because v4 uses named function exports. | Use `import { animate } from 'animejs'` in v4. |

## Memory anchors

- **Official URLs:** [animejs.com](https://animejs.com) and [animejs.com/documentation](https://animejs.com/documentation).
- **v4 vs v3:** Modern v4 uses named modular exports `animate()` and `createTimeline()`; v3 uses the global `anime({})` function.
- **`stagger(delay, { from: 'center' })`:** Generates organic wave ripples across lists and 2D grids effortlessly.
- **Springs in easing:** Specify `'spring(mass, stiffness, damping, velocity)'` for tactile, physical responses.
- **SVG Stroke Drawing:** Animate `strokeDashoffset: [anime.setDashoffset, 0]`.
- **Motion Paths:** Animate along curves with `path('x')`, `path('y')`, and auto-angle rotation with `path('angle')`.
- **Number tweening:** Animate arbitrary JavaScript objects `{ score: 0 }` with `round: 1`.
