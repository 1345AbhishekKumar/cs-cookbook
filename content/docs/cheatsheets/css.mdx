CSS (Cascading Style Sheets) describes the presentation of a document written in HTML or XML — how elements render on screen or in other media.

Use this page as a quick reference: common selectors, properties, and minimal snippets.

## CSS Basics — 3 ways to add CSS

| Method | How | Syntax |
| --- | --- | --- |
| `External` | Separate `.css` file, linked from HTML. | `<link rel="stylesheet" href="/style.css" />` |
| `Internal / Embedded` | Inside a `<style>` tag in the HTML file. | `<style>div { color: #444; }</style>` |
| `Inline` | `style` attribute directly on a tag. | `<tag style="property: value">` |

```css
/* external / internal rule shape */
selector {
  property1: value1;
  property2: value2;
}
```

```html
<link rel="stylesheet" type="text/css" href="/style.css" />

<style type="text/css">
  div { color: #444; }
</style>

<tag style="property: value"></tag>
```

Clearfix — clears floats to control margins and padding:

```css
.clearfix::after {
  content: "";
  clear: both;
  display: block;
}
```

## Selectors

Used to find / select the HTML elements you want to style.

| Selector | Description | Syntax |
| --- | --- | --- |
| `Universal` | Selects all elements. | `* { property: value; }` |
| `Type` | All elements of a given tag. | `p { property: value; }` |
| `Id` | Element with a unique id. | `#id { property: value; }` |
| `Class` | All elements with a given class. | `.class { property: value; }` |
| `Attribute` | Elements with a specified attribute. | `a[attr=value] { property: value; }` |
| `Combinators` | Two+ selectors with a relationship. | `sel1 sel2`, `sel1+sel2`, `sel1 > sel2` |
| `Pseudo` | Special state of an element. | `selector:pseudo-class { property: value; }` |

```css
* { background-color: hsl(325, 63%, 82%); text-align: center; } /* universal */
span { background-color: skyblue; }                              /* type */
#div1 { color: green; font-size: 20px; font-weight: bold; }       /* id */
.div2 { color: orange; font-size: 10px; }                         /* class */
div[style] { color: purple; font-size: 20px; }                    /* attribute */
div > p { color: #009900; font-size: 32px; }                      /* combinator */
.box:hover { background-color: orange; }                          /* pseudo */
```

## Font properties

Set the font of an element's text content.

| Property | Description | Syntax |
| --- | --- | --- |
| `font-family` | Font family for text. | `font-family: family-name, generic-family` |
| `font-style` | Normal, italic, or oblique face. | `font-style: normal / italic / oblique` |
| `font-variant` | Lowercase to uppercase rendering. | `font-variant: normal / small-caps` |
| `font-weight` | Thickness / weight. | `font-weight: normal / bold / number` |
| `font-size` | Size of text. | `font-size: small / medium / large / length` |

```css
.style1 {
  font-family: "Times New Roman", sans-serif;
  font-weight: bold; font-size: 30px;
  font-style: normal; font-variant: normal;
}
.style2 {
  font-family: sans-serif; font-size: 15px;
  font-style: italic;
}
.style3 {
  font-family: arial; font-size: 20px;
  font-style: oblique; font-variant: small-caps;
}
```

## Text properties

Format and style text — color, alignment, spacing.

| Property | Description | Syntax |
| --- | --- | --- |
| `color` | Text color. | `color: value;` |
| `text-align` | Horizontal alignment. | `text-align: left / right / center / justify` |
| `text-decoration` | Add / remove decoration. | `text-decoration: decoration-type;` |
| `text-transform` | Change case. | `text-transform: none / capitalize / uppercase / lowercase` |
| `text-indent` | Indent first line. | `text-indent: length;` |
| `letter-spacing` | Space between characters. | `letter-spacing: normal / length;` |
| `line-height` | Space between lines. | `line-height: normal / number / length / %;` |
| `text-shadow` | Shadow on text. | `text-shadow: h-shadow v-shadow blur color;` |
| `word-spacing` | Space between words. | `word-spacing: normal / length;` |

```css
.color      { color: red; }
.align      { text-align: center; }
.decor      { text-decoration: underline; }
.transform  { text-transform: lowercase; }
.indent     { text-indent: 80px; }
.letter     { letter-spacing: 4px; }
.line       { line-height: 40px; }
.shadow     { text-shadow: 3px 1px blue; }
.word       { word-spacing: 15px; }
```

## Background properties

Design backgrounds and background effects.

| Property | Description | Syntax |
| --- | --- | --- |
| `background-color` | Background color. | `background-color: color-name;` |
| `background-image` | One or more background images. | `background-image: url('url');` |
| `background-repeat` | Repeat horizontally / vertically. | `background-repeat: repeat / repeat-x / repeat-y / no-repeat` |
| `background-position` | Position of the image. | `background-position: value;` |
| `background-origin` | Origin box of the image. | `background-origin: padding-box / border-box / content-box` |
| `background-attachment` | Scroll vs fixed attachment. | `background-attachment: scroll / fixed / local` |
| `background-clip` | How far background extends. | `background-clip: border-box / padding-box / content-box` |

```css
.a { background-image: url("250.png"); }
.b { background-image: url("250.png"); background-repeat: no-repeat; }
.c { background-image: url("250.png"); background-repeat: no-repeat; background-position: center; }
.d { background-image: url("gfg_200X200.png"); background-repeat: no-repeat; background-origin: initial; }
.e {
  background-image: url("geeks-25.png");
  background-position: center; background-repeat: no-repeat;
  background-attachment: fixed;
}
```

## Box properties

Every element is a box: content + padding + border + margin (inside out).

| Property | Description | Syntax |
| --- | --- | --- |
| `margin` | Outer space around the box. | `margin: value;` |
| `padding` | Space between border and content. | `padding: value;` |
| `border` | Border width, style, color. | `border: width style color;` |
| `width` | Element width. | `width: value;` |
| `height` | Element height. | `height: value;` |

```css
.gfg {
  margin-left: 60px;
  border: 50px solid #009900;
  width: 300px; height: 200px;
  text-align: center; padding: 50px;
}
```

## Shadow properties

Add shadow to text, boxes, or frames.

| Property | Description | Syntax |
| --- | --- | --- |
| `text-shadow` | Shadow on text. | `text-shadow: h-shadow v-shadow blur color` |
| `box-shadow` | Shadow on box / frame. | `box-shadow: h-offset v-offset blur spread color` |

```css
.gfg1 { border: 1px solid; padding: 10px; box-shadow: 5px 10px 10px; }
h2    { text-shadow: 5px 5px 8px #00FF00; }
```

## Gradient

Smooth transition between two or more colors.

| Type | Description | Syntax |
| --- | --- | --- |
| `Linear` | Straight-line color transition. | `background-image: linear-gradient(direction, c1, c2);` |
| `Radial` | Elliptical / circular transition. | `background-image: radial-gradient(shape size at pos, c1, c2);` |

```css
#main1 {
  height: 200px;
  background-image: linear-gradient(white, green);
}
#main2 {
  height: 350px; width: 700px;
  background-image: radial-gradient(#090, #fff, #2a4f32);
}
```

## Border properties

Control how the border of an element's box looks.

| Property | Description | Syntax |
| --- | --- | --- |
| `border-color` | Color of the border (needs `border-style`). | `border-color: color-value;` |
| `border-style` | Style: solid, dotted, dashed, etc. | `border-style: value;` |
| `border-width` | Width of the border. | `border-width: length / thin / medium / thick` |

```css
#gfg1 { border: 2px solid blue; width: 60%; }
#gfg2 { border: thick dashed green; width: 60%; }
```

## Classification properties

Specify how and where an element is displayed.

| Property | Description | Syntax |
| --- | --- | --- |
| `display` | How the element is displayed. | `display: inline / block / flex / grid / none` |
| `float` | Flow of content. | `float: none / left / right` |
| `position` | Positioning method. | `position: static / relative / absolute / fixed / sticky` |
| `clear` | Sides where no floats allowed. | `clear: left / right / both / none` |
| `visibility` | Visible or not (keeps space). | `visibility: visible / hidden / collapse` |
| `cursor` | Cursor shape over element. | `cursor: auto / default / pointer / wait` |

```css
#geeks1 { height: 50px; width: 100px; background: teal; display: block; }
.pos    { position: relative; left: 30px; border: 3px solid #73AD21; }
.clr    { width: 100px; height: 100px; background: green; float: left; }
p.GFG   { clear: left; }
.wait   { cursor: wait; }
```

## CSS Functions

Built-in functions usable as property values — colors, math, shapes, transforms, gradients, animations. Some nest.

| Function | Description | Syntax |
| --- | --- | --- |
| `attr()` | Value of an attribute of selected element. | `attr(attr-name)` |
| `calc()` | Evaluates a math expression. | `calc(expression)` |
| `max()` | Largest of comma-separated numbers. | `max(v1, v2, v3)` |
| `url()` | Loads images, fonts, content. | `url(string)` |
| `var()` | Value of a custom property (`--*`). | `var(--name, fallback)` |

```css
a::before { content: attr(href) " =>"; }
.geeks { width: calc(100% - 20%); height: calc(100px - 20px); }
.url   { background-image: url("download3.png"); }
:root  { --main-bg-color: green; }
.gfg1  { background-color: var(--main-bg-color); padding: 10px; }
```

## Media Queries

Apply a block of CSS only when an expression is true — the basis of responsive design.

```css
@media not / only mediatype and (expression) {
  /* CSS rules here */
}
```

| Media type | Used for |
| --- | --- |
| `all` | All media devices. |
| `print` | Printers. |
| `screen` | Computer screens, smartphones, etc. |
| `speech` | Screen readers reading aloud. |

```css
/* example: two-column on wide screens only */
@media only screen and (min-width: 768px) {
  .container { display: grid; grid-template-columns: 1fr 1fr; }
}
```

## Memory anchors

- **3 insertions:** external file (`<link>`), internal (`<style>`), inline (`style=`). Specificity rises in that order.
- **Selector power:** `*` hits all, `p` hits a type, `.class` hits many, `#id` hits one, `[attr]` hits by attribute, `:` hits a state.
- **Font vs text:** `font-*` picks the typeface, `text-*` lays it out (align, transform, spacing, shadow).
- **Background stack:** `color + image + repeat + position + origin + clip + attachment` — image needs `url()`.
- **Box inside-out:** content → `padding` → `border` → `margin`. `box-shadow` paints outside, `text-shadow` paints letters.
- **Gradient axis:** `linear-gradient(direction, …)` runs straight, `radial-gradient(…)` radiates from a point.
- **Layout trio:** `display` decides the mode, `position + float + clear` places it, `visibility` hides it but keeps its space (unlike `display: none`).
- **Functions:** `calc()` does math, `var(--x)` reads a variable, `url()` loads a file, `attr()` reads HTML, `max()` picks the winner.
- **Responsive gate:** `@media <type> and (<feature>)` — `screen` for phones/desktops, `print` for printers, `speech` for readers.
