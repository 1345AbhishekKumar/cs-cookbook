HTML (HyperText Markup Language) is the basic building block of all web pages. It provides structure — images, text, video — by creating a skeleton. Whatever framework you use, the output is rendered as HTML.

Use this page as a quick reference: ready-to-use tags, attributes, and minimal snippets.

## Main root & Boilerplate

| Tag | Description | Syntax |
| --- | --- | --- |
| `<html>` | Root (top-level / document element). All other elements are descendants. | `<html>…</html>` |

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <title>Geeks For Geeks</title>
  </head>
  <body>
    <!-- your content goes here -->
    Welcome to Geeks for Geeks
  </body>
</html>
```

## Sectioning root — Headings

The `<body>` element holds the document content. There can be only one per document.

| Tag | Description | Syntax |
| --- | --- | --- |
| `<h1>` | Page title, generally once per page. ~2em. | `<h1>…</h1>` |
| `<h2>` | Medium title. ~1.5em. | `<h2>…</h2>` |
| `<h3>` | Subsection. ~1.17em. | `<h3>…</h3>` |
| `<h4>` | Highlight. ~1em. | `<h4>…</h4>` |
| `<h5>` | Fifth-level heading. ~0.83em. | `<h5>…</h5>` |
| `<h6>` | Least significant detail. ~0.67em. | `<h6>…</h6>` |

```html
<h1>GeeksforGeeks</h1>
<h2>GeeksforGeeks</h2>
<h3>GeeksforGeeks</h3>
<h4>GeeksforGeeks</h4>
<h5>GeeksforGeeks</h5>
<h6>GeeksforGeeks</h6>
```

## Container tags

Container tags wrap content (text, images) between opening and closing tags.

| Tag | Description | Syntax |
| --- | --- | --- |
| `<div>` | Block element, defines a division. | `<div>…</div>` |
| `<span>` | Inline element for part of a text / document. | `<span>…</span>` |
| `<p>` | Paragraph. | `<p>…</p>` |
| `<pre>` | Pre-formatted text, rendered exactly as written. | `<pre>…</pre>` |
| `<code>` | Source code snippet. | `<code>…</code>` |

```html
<p>
  GeeksforGeeks is a
  <span style="color:red;font-weight:bolder">computer science</span>
  portal for <span style="background-color: lightgreen;">geeks</span>
</p>

<pre>
This
is a pre tag.
</pre>

<code>
  #include&lt;stdio.h&gt;
  int main() { printf("Hello Geeks"); }
</code>

<p>Click <a href="https://www.geeksforgeeks.org">GeeksforGeeks</a></p>
```

## Document information

Tags that describe the document (metadata overview).

| Tag | Description | Syntax |
| --- | --- | --- |
| `<head>` | Container for metadata (data about data). | `<head>…</head>` |
| `<link>` | Links external stylesheets / documents. | `<link />` |
| `<meta>` | Metadata about the document. | `<meta />` |
| `<title>` | Document title (browser tab). | `<title>…</title>` |
| `<style>` | Embedded CSS for the document. | `<style>…</style>` |

```html
<head>
  <title>Title goes here</title>
  <link rel="stylesheet" type="text/css" href="style.css" />
  <meta name="keywords" content="Meta Tags, Metadata" />
  <style>
    #first { font-family: Castellar; background-color: green; color: white; }
    .second { text-align: center; font-size: 30px; color: red; }
  </style>
</head>
<body>
  <p id="first">Hello GeeksforGeeks.</p>
  <p class="second">Welcome Geeks</p>
</body>
```

## Sectioning content

Sectioning elements define ARIA landmarks by default. Mostly descendants of `<body>`.

| Tag | Description | Syntax |
| --- | --- | --- |
| `<header>` | Introductory content. | `<header>…</header>` |
| `<main>` | Dominant content of the document. | `<main>…</main>` |
| `<section>` | Groups related elements. | `<section>…</section>` |
| `<nav>` | Navigation links section. | `<nav>…</nav>` |
| `<article>` | Self-contained, independently distributable composition. | `<article>…</article>` |
| `<aside>` | Content aside from surrounding content. | `<aside>…</aside>` |
| `<footer>` | Footer for its sectioning root. | `<footer>…</footer>` |
| `<address>` | Contact information for person / org. | `<address>…</address>` |

```html
<article>
  <header>
    <h3>GeeksforGeeks Learning</h3>
    <nav>
      <a href="#">Home</a> |
      <a href="#">Interview</a> |
      <a href="#">Languages</a> |
      <a href="#">Data Structure</a> |
      <a href="#">Algorithm</a>
    </nav>
  </header>
</article>

<main>
  <section>
    <h1>Geeksforgeek: Section 1</h1>
    <p>Content of section</p>
  </section>
  <aside>
    <h1>Heading in aside Tag</h1>
    <p>Paragraph in aside Tag</p>
  </aside>
</main>

<footer>
  <address>
    Organization Name: GeeksforGeeks<br />
    Web Site: <a href="https://www.geeksforgeeks.org/about/contact-us/">GeeksforGeeks</a><br />
    A-118, Sector 136, Noida, Uttar Pradesh (201305)
  </address>
  <p>@geeksforgeeks, Some rights reserved</p>
</footer>
```

## Text formatting & Inline semantics

Makes the document more expressive. Inline semantics define meaning / style of a word or line.

| Tag | Description | Syntax |
| --- | --- | --- |
| `<em>` | Stress / emphasis. | `<em>…</em>` |
| `<strong>` | Strong importance. | `<strong>…</strong>` |
| `<sub>` | Subscript. | `<sub>…</sub>` |
| `<sup>` | Superscript. | `<sup>…</sup>` |
| `<abbr>` | Abbreviation / acronym. | `<abbr>…</abbr>` |
| `<mark>` | Highlighted reference text. | `<mark>…</mark>` |
| `<cite>` | Title of a creative work. | `<cite>…</cite>` |
| `<time>` | Specific period of time. | `<time>…</time>` |

```html
<div><em>Emphasized text</em></div>
<div><strong>Important text!</strong></div>
<div>GFG<sub>subscript text</sub></div>
<div>GFG<sup>Superscript text</sup></div>
<div><abbr>Abbreviation</abbr></div>
<div><mark>Highlighted text</mark></div>
<div><cite>Title of creative work</cite></div>
<div>Time <time>9:00 am</time> to <time>7:00 pm</time></div>
```

## Lists

- **Unordered list** — related items in no particular order.
- **Ordered list** — related items in a specific order.
- **Description list** — name / value pairs (terms + definitions).

| Tag | Description | Syntax |
| --- | --- | --- |
| `<ul>` | Unordered list. | `<ul>…</ul>` |
| `<ol>` | Ordered list. | `<ol>…</ol>` |
| `<li>` | Item in a list. | `<li>…</li>` |
| `<dl>` | Description list. | `<dl>…</dl>` |
| `<dt>` | Term in a description list. | `<dt>…</dt>` |
| `<dd>` | Description of the term. | `<dd>…</dd>` |

```html
<h5>Unordered List</h5>
<ul>
  <li>Data Structures &amp; Algorithm</li>
  <li>Web Technology</li>
  <li>Aptitude &amp; Logical Reasoning</li>
</ul>

<h5>Ordered List</h5>
<ol>
  <li>Array</li>
  <li>Linked List</li>
  <li>Stacks</li>
</ol>

<h5>Description List</h5>
<dl>
  <dt>Courses:</dt><dd>100</dd>
  <dt>Quizes:</dt><dd>500</dd>
  <dt>Interview Experiences:</dt><dd>1000</dd>
</dl>
```

## Forms

A form is a container for input controls — text fields, passwords, menus, checkboxes, radios, submit buttons.

| Tag | Description | Syntax |
| --- | --- | --- |
| `<form>` | Section with controls for submitting info. | `<form>…</form>` |
| `<input>` | Interactive control accepting data. | `<input />` |
| `<textarea>` | Multi-line plain-text editing control. | `<textarea>…</textarea>` |
| `<select>` | Drop-down menu of options. | `<select>…</select>` |
| `<option>` | Option in a select list. | `<option>…</option>` |
| `<optgroup>` | Groups options inside `<select>`. | `<optgroup>…</optgroup>` |
| `<datalist>` | Predefined options + autocomplete for `<input>`. | `<datalist>…</datalist>` |
| `<button>` | Clickable button. | `<button>…</button>` |
| `<label>` | Label for an `<input>`. | `<label>…</label>` |
| `<progress>` | Completion indicator for a task. | `<progress>…</progress>` |

```html
<form>
  <fieldset>
    <legend>Personal Details</legend>
    <label>Salutation<br />
      <select name="salutation">
        <option>--None--</option>
        <option>Mr.</option>
        <option>Ms.</option>
        <option>Mrs.</option>
      </select>
    </label>
    <p><label>First name: <input name="firstName" /></label></p>
    <p><label>Last name: <input name="lastName" /></label></p>
    <p>
      Gender:
      <label><input type="radio" name="gender" value="male" /> Male</label>
      <label><input type="radio" name="gender" value="female" /> Female</label>
    </p>
    <p>
      <label>Email: <input type="email" name="email" /></label>
    </p>
    <p>
      <label>Date of Birth: <input type="date" name="birthDate" /></label>
    </p>
    <p>
      <label>Address:<br />
        <textarea name="address"></textarea>
      </label>
    </p>
    <input list="lang" placeholder="Choose language" />
    <datalist id="lang">
      <option value="java"></option>
      <option value="reactjs"></option>
      <option value="php"></option>
      <option value="python"></option>
    </datalist>
    <p><button type="submit">Submit</button></p>
    <p>Downloading progress: <progress value="57" max="100"></progress></p>
  </fieldset>
</form>
```

## Multimedia

Multimedia is anything you hear or see — images, video, sound in various formats.

| Tag | Description | Syntax |
| --- | --- | --- |
| `<img>` | Links images to the page. | `<img />` |
| `<audio>` | Sound content. | `<audio>…</audio>` |
| `<video>` | Media player for video files. | `<video>…</video>` |
| `<figure>` | Groups diagrams / images / illustrations / code. | `<figure>…</figure>` |
| `<figcaption>` | Caption for figure content. | `<figcaption>…</figcaption>` |
| `<embed>` | Embeds multimedia. | `<embed />` |
| `<object>` | Embeds objects — images, audio, video, PDF. | `<object>…</object>` |

```html
<img
  src="https://media.geeksforgeeks.org/wp-content/uploads/geeksforgeeks-13.png"
  width="420" height="100" alt="Geeksforgeeks.org" />

<audio controls>
  <source src="test.mp3" type="audio/mp3" />
  <source src="test.ogg" type="audio/ogg" />
</audio>

<video width="400" height="350" controls>
  <source src="myvid.mp4" type="video/mp4" />
  <source src="myvid.ogg" type="video/ogg" />
</video>

  <img
    src="https://media.geeksforgeeks.org/wp-content/uploads/geeks-25.png"
```

## Memory anchors

- **Skeleton → head → body:** `html` wraps everything, `head` is metadata, `body` is visible content. One `head`, one `body`.
- **Block vs inline:** `div` stacks (block), `span` flows (inline). `p` = paragraph, `pre` = preserve whitespace, `code` = code.
- **Landmarks:** `header / nav / main / section / article / aside / footer` — outline the page before styling it.
- **Emphasis ladder:** `em` = stress, `strong` = importance, `mark` = highlight, `abbr / cite / time` = meaning.
- **Lists:** `ul` = bullets, `ol` = numbers, `dl + dt + dd` = term + definition.
- **Tables:** `table > caption + thead + tbody + tfoot > tr > th / td`.
- **Forms:** `form > label + input / select + option / textarea / datalist + button`. `progress` is display-only.
- **Media:** `img` is void (`<img />`), `audio / video` need `<source>`, `figure + figcaption` pairs image with caption.
- **Escape hatch:** `<` = `&lt;`, `>` = `&gt;`, `&` = `&amp;`, space that must not break = `&nbsp;`.
- **`id` vs `class` vs `style`:** `id` is unique, `class` is reusable, `style` is inline and wins.
