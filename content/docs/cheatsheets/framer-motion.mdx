Framer Motion (now officially maintained and distributed as **Motion**) is a production-grade animation and gesture library for React. It powers natural spring physics, FLIP-based layout morphing, exit transitions, and hardware-accelerated scroll animations.

- **Official Website:** [https://motion.dev](https://motion.dev)
- **Documentation:** [https://motion.dev/docs](https://motion.dev/docs)
- **GitHub Repository:** [https://github.com/motiondivision/motion](https://github.com/motiondivision/motion)

Use this page as an exhaustive reference: prop tables, transition physics, motion value hooks, SVG animations, and copy-paste recipes.

## Core Component Props

Any HTML or SVG tag can be transformed into an animated component by prefixing it with `motion.` (e.g. `motion.div`, `motion.button`, `motion.path`, `motion.circle`).

| Prop | Type | Description |
| --- | --- | --- |
| `initial` | `Target \| Variant \| false` | Visual properties when the element first mounts. Pass `false` to disable entrance animation. |
| `animate` | `Target \| Variant` | Destination values to animate towards whenever props change. |
| `exit` | `Target \| Variant` | Target state to execute before unmounting (requires direct parent `<AnimatePresence>`). |
| `transition` | `Transition` | Governs physics, durations, delays, stagger, and easing curves. |
| `whileHover` | `Target \| Variant` | Animation applied while mouse pointer rests over the element. |
| `whileTap` | `Target \| Variant` | Animation applied while the mouse button is held down or mobile touch is active. |
| `whileFocus` | `Target \| Variant` | Animation applied while element has keyboard focus (`:focus-visible`). |
| `whileDrag` | `Target \| Variant` | Animation applied while element is being dragged. |
| `whileInView` | `Target \| Variant` | Triggers when the element intersects the viewport. |
| `viewport` | `ViewportOptions` | Options for viewport detection (`{ once: true, margin: "-100px", amount: 0.5 }`). |
| `layout` | `boolean \| "position" \| "size"` | Automatically animates bounding box changes caused by flex, grid, or CSS width/height. |
| `layoutId` | `string` | Seamless shared-element transition between two distinct elements in the DOM. |
| `style` | `MotionStyle` | Style object accepting MotionValues (`x`, `opacity`, `scale`) for zero-render mutations. |

## Transitions: Springs vs Tweens vs Inertia

Motion defaults to **spring physics** for 2D transforms and **tweens** for opacity and colors.

```tsx
// 1. Physics-based Spring (recommended for tactile UI)
<motion.div
  animate={{ scale: 1 }}
  transition={{
    type: "spring",
    stiffness: 300,  // Higher = faster snap (default: 100)
    damping: 20,     // Higher = less bounce/oscillation (default: 10)
    mass: 1,         // Higher = heavier inertia / sluggish start (default: 1)
    velocity: 2,     // Initial velocity impulse
    restSpeed: 0.01, // Speed below which animation is marked complete
    restDelta: 0.01, // Distance threshold below which animation finishes
  }}
/>

// Simplified Spring (Bounce + Duration)
<motion.div
  animate={{ scale: 1 }}
  transition={{
    type: "spring",
    duration: 0.6,   // Total intended duration
    bounce: 0.25,    // 0 = no bounce (critically damped), 1 = extreme bounce
  }}
/>

// 2. Tween (Traditional time-based easing)
<motion.div
  animate={{ opacity: 1, backgroundColor: "#3b82f6" }}
  transition={{
    type: "tween",
    duration: 0.4,
    ease: "easeInOut", // "linear" | "easeIn" | "easeOut" | "easeInOut" | [0.16, 1, 0.3, 1]
    delay: 0.1,
  }}
/>

// 3. Inertia (Fling physics, used for momentum scrolling & sliders)
<motion.div
  animate={{ x: 500 }}
  transition={{
    type: "inertia",
    velocity: 200,
    power: 0.8,
    timeConstant: 350,
  }}
/>

// 4. Per-property transitions
<motion.div
  animate={{ x: 100, opacity: 1 }}
  transition={{
    x: { type: "spring", stiffness: 400, damping: 25 },
    opacity: { type: "tween", duration: 0.2, ease: "linear" },
  }}
/>
```

## Variants & Orchestration

Variants decouple animation definitions from JSX markup and orchestrate multi-tier child stagger trees automatically.

```tsx
import { motion, Variants } from "motion/react";

const containerVariants: Variants = {
  hidden: { opacity: 0 },
  visible: {
    opacity: 1,
    transition: {
      when: "beforeChildren",       // Finish container before animating children
      staggerChildren: 0.08,        // 80ms delay between consecutive children
      delayChildren: 0.15,          // Initial pause before first child runs
      staggerDirection: 1,          // 1 for forwards, -1 for reverse
    },
  },
  exit: {
    opacity: 0,
    transition: {
      when: "afterChildren",
      staggerChildren: 0.05,
      staggerDirection: -1,
    },
  },
};

const childVariants: Variants = {
  hidden: { opacity: 0, y: 30, scale: 0.95 },
  visible: {
    opacity: 1,
    y: 0,
    scale: 1,
    transition: { type: "spring", stiffness: 350, damping: 24 },
  },
  exit: { opacity: 0, y: -20, transition: { duration: 0.2 } },
};

export function CardGrid({ items }: { items: string[] }) {
  return (
    // Descendants automatically inherit "hidden", "visible", and "exit" state keys!
    <motion.ul
      variants={containerVariants}
      initial="hidden"
      animate="visible"
      exit="exit"
      className="grid grid-cols-3 gap-4"
    >
      {items.map((item, idx) => (
        <motion.li key={idx} variants={childVariants} className="p-4 bg-white shadow rounded-lg">
          {item}
        </motion.li>
      ))}
    </motion.ul>
  );
}
```

### Dynamic Variants with `custom` Prop

Pass dynamic runtime parameters (such as indexes or direction flags) into variants:

```tsx
const slideVariants: Variants = {
  enter: (direction: number) => ({
    x: direction > 0 ? 500 : -500,
    opacity: 0,
  }),
  center: {
    x: 0,
    opacity: 1,
    transition: { type: "spring", stiffness: 300, damping: 30 },
  },
  exit: (direction: number) => ({
    x: direction < 0 ? 500 : -500,
    opacity: 0,
  }),
};

// Usage:
<motion.div custom={direction} variants={slideVariants} initial="enter" animate="center" exit="exit" />
```

## Exit Animations with `<AnimatePresence>`

React removes unmounted components instantly from the DOM. `<AnimatePresence>` suspends DOM unmounting until child `exit` animations finish.

```tsx
import { motion, AnimatePresence } from "motion/react";

export function NotificationToast({ message, onDismiss }: { message: string | null; onDismiss: () => void }) {
  return (
    <AnimatePresence mode="wait">
      {message && (
        <motion.div
          key="toast"
          initial={{ opacity: 0, y: 50, scale: 0.9 }}
          animate={{ opacity: 1, y: 0, scale: 1 }}
          exit={{ opacity: 0, y: 20, scale: 0.95 }}
          transition={{ type: "spring", stiffness: 400, damping: 28 }}
          className="fixed bottom-6 right-6 p-4 bg-slate-900 text-white rounded-xl shadow-2xl"
        >
          <span>{message}</span>
          <button onClick={onDismiss} className="ml-4 font-bold">✕</button>
        </motion.div>
      )}
    </AnimatePresence>
  );
}
```

### Modes Matrix

| Mode | Behavior | Ideal Use Case |
| --- | --- | --- |
| `mode="sync"` *(default)* | Entering and exiting items animate simultaneously. | Overlapping cross-fades, tags. |
| `mode="wait"` | Waits for the exiting component to completely exit before mounting the new one. | Page routes, tab switches, wizards. |
| `mode="popLayout"` | Removes exiting item from CSS layout flow immediately, so surviving items rearrange smoothly without an empty gap. | Dismissable notification lists, reordered cards. |

## Layout Animations & Shared Elements (`layoutId`)

Motion uses GPU-accelerated inverted transforms (`translate` and `scale`) under the hood to simulate layout geometry changes without forcing browser layout recalculations.

### 1. Auto-Smooth Resizing with `layout`

```tsx
// Animates smoothly when content expands or flex container resizes
<motion.div layout transition={{ type: "spring", damping: 25, stiffness: 300 }}>
  <h3>{title}</h3>
  {isOpen && <p>{description}</p>}
</motion.div>
```

### 2. Shared Element Transitions (`layoutId`)

Animates a continuous visual bridge between distinct DOM components (e.g. active tab indicators, expanding cards to full modals):

```tsx
import { motion } from "motion/react";
import { useState } from "react";

const NAV_ITEMS = ["Home", "Docs", "Showcase", "Pricing"];

export function SlidingNavbar() {
  const [active, setActive] = useState("Home");

  return (
    <nav className="flex space-x-2 bg-slate-100 p-1 rounded-full">
      {NAV_ITEMS.map((item) => (
        <button
          key={item}
          onClick={() => setActive(item)}
          className={`relative px-4 py-1.5 text-sm font-medium rounded-full transition-colors ${
            active === item ? "text-white" : "text-slate-600"
          }`}
        >
          {active === item && (
            <motion.div
              layoutId="nav-bubble"
              className="absolute inset-0 bg-indigo-600 rounded-full -z-10"
              transition={{ type: "spring", bounce: 0.2, duration: 0.6 }}
            />
          )}
          {item}
        </button>
      ))}
    </nav>
  );
}
```

## Gestures & Drag Controls

```tsx
<motion.div
  // 1. Hover & Tap
  whileHover={{ scale: 1.04, y: -2 }}
  whileTap={{ scale: 0.96 }}

  // 2. Dragging
  drag                     // true | "x" | "y"
  dragConstraints={{ left: -150, right: 150, top: -50, bottom: 50 }}
  dragElastic={0.2}        // Elastic resistance past boundary (0 = rigid, 1 = effortless)
  dragSnapToOrigin={true}  // Returns to initial spot on pointer release
  dragMomentum={true}      // Carries momentum after release

  // 3. Callbacks
  onDragStart={() => console.log("Drag started")}
  onDragEnd={(event, info) => {
    console.log("End position:", info.point);
    console.log("Offset:", info.offset);
    console.log("Velocity:", info.velocity);
  }}
/>
```

### Manual Drag Control (`useDragControls`)

Initiate dragging from a dedicated drag handle:

```tsx

export function DraggableCard() {
```

## Scroll-Driven Motion (`useScroll`)

The `useScroll` hook delivers reactive MotionValues for both page and element-level scrolling.

```tsx
import { motion, useScroll, useTransform, useSpring } from "motion/react";
import { useRef } from "react";

export function ScrollExperience() {
  const containerRef = useRef<HTMLDivElement>(null);

  // Element-based scroll progress
  const { scrollYProgress } = useScroll({
    target: containerRef,
    // [targetEdge, containerEdge]
    // "start end" = top of target meets bottom of viewport (just entered)
    // "end start" = bottom of target leaves top of viewport (fully exited)
    offset: ["start end", "end start"],
  });

  // Smooth out jagged mouse-wheel steps with a spring
  const smoothProgress = useSpring(scrollYProgress, { stiffness: 120, damping: 25 });

  // Map 0 -> 1 progress to styling transformations
  const y = useTransform(smoothProgress, [0, 1], [-120, 120]);
  const opacity = useTransform(smoothProgress, [0, 0.25, 0.75, 1], [0, 1, 1, 0]);
  const rotate = useTransform(smoothProgress, [0, 1], [0, 45]);

  return (
    <section ref={containerRef} className="h-[150vh] relative flex items-center justify-center">
      <motion.div style={{ y, opacity, rotate }} className="w-64 h-64 bg-gradient-to-tr from-pink-500 to-purple-500 rounded-3xl" />
    </section>
  );
}
```

## Motion Values & Reactive Templates

MotionValues track state outside React's render loop, achieving 60fps-120fps updates without triggering component re-renders.

```tsx
import { useMotionValue, useVelocity, useTransform, useMotionTemplate, motion } from "motion/react";

export function MouseSpotlight() {
  const mouseX = useMotionValue(0);
  const mouseY = useMotionValue(0);

  // Velocity tracker
  const mouseXVelocity = useVelocity(mouseX);

  // Reactive CSS Template String (No re-renders!)
  const background = useMotionTemplate`radial-gradient(400px circle at ${mouseX}px ${mouseY}px, rgba(99, 102, 241, 0.15), transparent 80%)`;

  function handleMouseMove(e: React.MouseEvent<HTMLDivElement>) {
    const rect = e.currentTarget.getBoundingClientRect();
    mouseX.set(e.clientX - rect.left);
    mouseY.set(e.clientY - rect.top);
  }

  return (
    <div onMouseMove={handleMouseMove} className="relative w-full h-96 bg-slate-900 overflow-hidden">
      <motion.div style={{ background }} className="absolute inset-0 pointer-events-none" />
    </div>
  );
}
```

## Imperative Sequences (`useAnimate`)

Trigger complex, multi-stage choreography on demand without intermediate React state:

```tsx
import { useAnimate } from "motion/react";

export function CheckoutButton() {
  const [scope, animate] = useAnimate();

  const handleOrder = async () => {
    // Stage 1: Compress button
    await animate("button", { scale: 0.95 }, { duration: 0.1 });

    // Stage 2: Reveal spinner
    await animate(".btn-text", { opacity: 0, y: -10 }, { duration: 0.2 });
    await animate(".spinner", { opacity: 1, rotate: 360 }, { duration: 0.8, repeat: 1 });

    // Stage 3: Burst success checkmark
    await animate(".spinner", { opacity: 0 }, { duration: 0.1 });
    await animate(".checkmark", { opacity: 1, scale: [0.5, 1.2, 1] }, { type: "spring", bounce: 0.4 });
    await animate("button", { backgroundColor: "#10b981", scale: 1 }, { duration: 0.3 });
  };

  return (
    <div ref={scope}>
      <button onClick={handleOrder} className="px-6 py-3 bg-indigo-600 text-white rounded-xl relative overflow-hidden">
        <span className="btn-text">Complete Purchase</span>
        <span className="spinner opacity-0 absolute inset-0 flex items-center justify-center">⟳</span>
        <span className="checkmark opacity-0 absolute inset-0 flex items-center justify-center">✓</span>
      </button>
    </div>
  );
}
```

## Global Configuration & Accessibility

### `<MotionConfig>` & `useReducedMotion`

Respect user preferences for reduced motion:

```tsx
import { MotionConfig, useReducedMotion } from "motion/react";

export function AppRoot({ children }: { children: React.ReactNode }) {
  const shouldReduceMotion = useReducedMotion();

  return (
    <MotionConfig reducedMotion="user" transition={{ duration: shouldReduceMotion ? 0 : 0.3 }}>
      {children}
    </MotionConfig>
  );
}
```

## Bundle Optimization (`LazyMotion`)

Drop Motion's initial JavaScript bundle contribution from **~34kB down to ~4.5kB** by lazily loading animation features:

```tsx
import { LazyMotion, domAnimation, m } from "motion/react";

export function LightweightApp({ children }: { children: React.ReactNode }) {
  // Use `m.div` instead of `motion.div`
  return (
    <LazyMotion features={domAnimation}>
      <m.div initial={{ opacity: 0 }} animate={{ opacity: 1 }}>
        {children}
      </m.div>
    </LazyMotion>
  );
}
```

## Anti-patterns vs Best practices

| Anti-pattern | Why it harms | Best practice |
| --- | --- | --- |
| Animating `top`, `left`, `margin`, `width` | Forces CPU layout reflows; causes frame drops on mobile. | Animate `x`, `y`, `scale`, or use `<motion.div layout>`. |
| Omitting `key` on direct children of `<AnimatePresence>` | Motion cannot track which element was unmounted; exit animations fail. | Provide a unique stable `key` on every exiting component. |
| Passing conflicting `duration` alongside `stiffness`/`damping` | Spring equation arguments conflict with time curves. | Tune springs with `stiffness` + `damping`, or `duration` + `bounce`. |
| Wrapping large un-virtualized tables in `layout` | Recalculating hundreds of bounding boxes concurrently crashes frame rates. | Limit `layout` to modal dialogues, tabs, and visible list rows. |
| Storing rapid motion values inside `useState` | Causes 60-120 full React component re-renders per second. | Use `useMotionValue` and `useTransform` directly in `style`. |

## Memory anchors

- **Official URLs:** [motion.dev](https://motion.dev) and [motion.dev/docs](https://motion.dev/docs).
- **Import convention:** `import { motion } from "motion/react"`.
- **Compositor acceleration:** Transforms (`x`, `y`, `scale`, `rotate`) and `opacity` are executed on the GPU compositor.
- **Natural springs:** Transforms default to physics springs; adjust `stiffness` (snap) and `damping` (decay).
- **Variants cascade:** Variant names (`"hidden"`, `"visible"`) cascade down to children without prop drilling.
- **`<AnimatePresence>` requirements:** Requires a unique `key` on children and an `exit` target.
- **`layoutId` connects cards to modals:** Giving two components the same `layoutId` morphs them into one another.
- **SVG path drawing:** Animate `pathLength: [0, 1]` on `<motion.path>` or `<motion.circle>`.
- **Zero-render updates:** `useMotionValue` and `useTransform` drive style changes without executing React component functions.
- **Bundle diet:** Use `<LazyMotion features={domAnimation}>` and `m.div` to save ~30kB of bundle footprint.
