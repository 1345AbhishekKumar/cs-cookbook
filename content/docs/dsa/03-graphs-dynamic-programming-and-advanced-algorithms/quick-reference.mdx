## 1. Graph Algorithm Selector Matrix

Use this decision table to select the optimal graph algorithm based on your problem constraints:

| Objective / Problem Signature              | Graph Constraints           | Optimal Algorithm                        | Time Complexity               | Auxiliary Space    |
| :----------------------------------------- | :-------------------------- | :--------------------------------------- | :---------------------------- | :----------------- | --- | -------------------- | --------------------------------------------- | ---------------- |
| **Shortest path (unweighted)**             | Undirected or Directed      | **BFS**                                  | $\mathcal{O}(V + E)$          | $\mathcal{O}(V)$   |
| **Shortest path (weights $\in \{0, 1\}$)** | Non-negative weights 0 or 1 | **0-1 BFS (Deque)**                      | $\mathcal{O}(V + E)$          | $\mathcal{O}(V)$   |
| **Shortest path (general non-negative)**   | Weights $\ge 0$             | **Dijkstra (Min-Heap)**                  | $\mathcal{O}((V + E) \log V)$ | $\mathcal{O}(V)$   |
| **Shortest path with negative edges**      | Directed / Undirected       | **Bellman-Ford**                         | $\mathcal{O}(V \cdot E)$      | $\mathcal{O}(V)$   |
| **Currency / Negative cycle arbitrage**    | Arbitrary edge weights      | **Bellman-Ford ($V$-th pass)**           | $\mathcal{O}(V \cdot E)$      | $\mathcal{O}(V)$   |
| **All-pairs shortest path ($V \le 500$)**  | Dense graph                 | **Floyd-Warshall**                       | $\mathcal{O}(V^3)$            | $\mathcal{O}(V^2)$ |
| **Minimum Spanning Tree (sparse)**         | Undirected, $               | E                                        | \ll                           | V                  | ^2$ | **Kruskal + DSU**    | $\mathcal{O}(E \log E)$                       | $\mathcal{O}(V)$ |
| **Minimum Spanning Tree (dense)**          | Undirected, $               | E                                        | \approx                       | V                  | ^2$ | **Prim's Algorithm** | $\mathcal{O}(V^2)$ or $\mathcal{O}(E \log V)$ | $\mathcal{O}(V)$ |
| **Dependency resolution / Topo Order**     | Directed Graph              | **Kahn's (In-Degree BFS)**               | $\mathcal{O}(V + E)$          | $\mathcal{O}(V)$   |
| **Circular dependency detection**          | Directed Graph              | **3-Color DFS or Kahn's**                | $\mathcal{O}(V + E)$          | $\mathcal{O}(V)$   |
| **Strongly Connected Components (SCC)**    | Directed Graph              | **Tarjan's (Single-pass)**               | $\mathcal{O}(V + E)$          | $\mathcal{O}(V)$   |
| **Network critical links (Bridges)**       | Undirected Graph            | **Tarjan's Bridge (`low > tin`)**        | $\mathcal{O}(V + E)$          | $\mathcal{O}(V)$   |
| **Single Point of Failure (Cut Vertices)** | Undirected Graph            | **Tarjan's Articulation (`low >= tin`)** | $\mathcal{O}(V + E)$          | $\mathcal{O}(V)$   |

## 2. Dynamic Programming Recurrence Catalog

| Pattern                | Canonical Problem             | State Definition                        | Transition Recurrence                                                             | Loop Direction / Optimization                          |
| :--------------------- | :---------------------------- | :-------------------------------------- | :-------------------------------------------------------------------------------- | :----------------------------------------------------- |
| **1D Rolling**         | House Robber                  | $dp[i]$: Max loot up to house $i$       | $dp[i] = \max(dp[i-1], dp[i-2] + v[i])$                                           | Compress to 2 scalar registers: $\mathcal{O}(1)$ space |
| **1D Unbounded**       | Coin Change                   | $dp[a]$: Min coins to make $a$          | $dp[a] = 1 + \min_{c} dp[a - c]$                                                  | Forward loop $a \in [1..A]$                            |
| **2D Grid**            | Min Path Sum                  | $dp[i][j]$: Min path to $(i, j)$        | $dp[i][j] = g[i][j] + \min(dp[i-1][j], dp[i][j-1])$                               | Compress to 1 row array: $\mathcal{O}(N)$ space        |
| **0/1 Knapsack**       | Subset Sum / Knapsack         | $dp[w]$: Max value at weight $w$        | $dp[w] = \max(dp[w], dp[w - wt] + val)$                                           | **REVERSE loop**: $w$ from $W$ down to $wt$            |
| **Unbounded Knapsack** | Rod Cutting                   | $dp[w]$: Max value with reuse           | $dp[w] = \max(dp[w], dp[w - wt] + val)$                                           | **FORWARD loop**: $w$ from $wt$ up to $W$              |
| **Subsequence**        | Longest Common Subseq         | $dp[i][j]$: LCS of $S_1[..i], S_2[..j]$ | Match: $1 + dp[i-1][j-1]$; Mismatch: $\max(\text{up}, \text{left})$               | Compress to 2 rows: $\mathcal{O}(\min(M, N))$ space    |
| **String Edit**        | Levenshtein Distance          | $dp[i][j]$: Min edits to align          | $\min(\text{Replace}, \text{Delete}, \text{Insert}) + 1$                          | Initialize row 0 and col 0 with $0, 1, \dots$          |
| **Patience Sort**      | LIS ($\mathcal{O}(N \log N)$) | `tails[k]`: Min tail of length $k+1$    | Overwrite with `lower_bound(x)` or append                                         | Binary search maintains sorted invariant               |
| **Interval DP**        | Burst Balloons                | $dp[i][j]$: Optimal on range $[i..j]$   | $\max_{k} (dp[i][k-1] + dp[k+1][j] + \text{gain}(k))$                             | **Length loop outermost**: $L \in [1..N]$              |
| **Tree DP**            | House Robber III              | `(rob, skip)` per tree node             | $\text{rob} = v + \text{skip}_L + \text{skip}_R$; $\text{skip} = \max_L + \max_R$ | Postorder bottom-up synthesis                          |
| **Bitmask DP**         | Traveling Salesperson         | $dp[\text{mask}][u]$: Visited subset    | $\min_{v \notin \text{mask}} (dp[\text{mask} \mid 2^v][v] + c[u][v])$             | $N \le 20$; iterates integer masks $1 .. 2^N - 1$      |

## 3. Production DSU (Disjoint Set Union) Drop-In Template

Copy-pasteable, verified implementations with **Path Compression** and **Union by Rank**:

<Tabs items={['Python', 'TypeScript', 'C++']}>
  <Tab value="Python">
```python
class DisjointSetUnion:
    """Production-grade Disjoint Set Union (DSU / Union-Find)."""
    def __init__(self, n: int):
        self.parent = list(range(n))
        self.rank = [0] * n
        self.components = n

    def find(self, i: int) -> int:
        if self.parent[i] == i:
            return i
        self.parent[i] = self.find(self.parent[i])  # Path compression
        return self.parent[i]

    def union(self, i: int, j: int) -> bool:
        root_i = self.find(i)
        root_j = self.find(j)
        if root_i == root_j:
            return False  # Already in the same component

        # Union by rank
        if self.rank[root_i] < self.rank[root_j]:
            self.parent[root_i] = root_j
        elif self.rank[root_i] > self.rank[root_j]:
            self.parent[root_j] = root_i
        else:
            self.parent[root_j] = root_i
            self.rank[root_i] += 1

        self.components -= 1
        return True

    def connected(self, i: int, j: int) -> bool:
        return self.find(i) == self.find(j)

````

```typescript
export class DisjointSetUnion {
  private parent: number[];
  private rank: number[];
  public components: number;

  constructor(n: number) {
    this.parent = Array.from({ length: n }, (_, i) => i);
    this.rank = new Array(n).fill(0);
    this.components = n;
  }

  find(i: number): number {
    if (this.parent[i] === i) return i;
    return (this.parent[i] = this.find(this.parent[i])); // Path compression
  }

  union(i: number, j: number): boolean {
    const rootI = this.find(i);
    const rootJ = this.find(j);
    if (rootI === rootJ) return false;

    if (this.rank[rootI] < this.rank[rootJ]) {
      this.parent[rootI] = rootJ;
    } else if (this.rank[rootI] > this.rank[rootJ]) {
      this.parent[rootJ] = rootI;
    } else {
      this.parent[rootJ] = rootI;
      this.rank[rootI]++;
    }

    this.components--;
    return true;
  }

  connected(i: number, j: number): boolean {
    return this.find(i) === this.find(j);
  }
}
````

#include <vector>

class DisjointSetUnion {
std::vector<int> parent;
std::vector<int> rank;
int num_components;

public:
explicit DisjointSetUnion(int n) : parent(n), rank(n, 0), num_components(n) {
std::iota(parent.begin(), parent.end(), 0);
}

    int find(int i) {
        if (parent[i] == i) return i;
        return parent[i] = find(parent[i]); // Path compression
    }

    bool unite(int i, int j) {
        int root_i = find(i);
        int root_j = find(j);
        if (root_i == root_j) return false;

        if (rank[root_i] < rank[root_j]) {
            parent[root_i] = root_j;
        } else if (rank[root_i] > rank[root_j]) {
            parent[root_j] = root_i;
        } else {
            parent[root_j] = root_i;
            rank[root_i]++;
        }

        num_components--;
        return true;
    }

    bool connected(int i, int j) {
        return find(i) == find(j);
    }

    int count() const {
        return num_components;
    }

};

## 4. Production & Interview Edge Case Checklist

<Steps>
  <Step>
    #### 1. Disconnected Graph Traversal
    Never assume the graph is fully connected starting from node `0`. Always wrap DFS, BFS, or cycle detection in an outer loop over all vertices $i \in [0..V-1]$ to ensure all disconnected components are visited.
  </Step>

  <Step>
    #### 2. Directed vs Undirected Cycle Detection
    - **Undirected**: Track `parent`. A cycle exists if you hit an already visited neighbor $v \ne \text{parent}$.
    - **Directed**: A boolean `visited` array is insufficient! You **must use 3 colors (White, Grey, Black)** or Kahn's algorithm to avoid confusing cross-edges with back-edges.
  </Step>

  <Step>
    #### 3. Dijkstra on Non-Negative Weights Only
    If an edge has a negative weight, Dijkstra will fail or loop infinitely. Use **Bellman-Ford** or SPFA instead.
  </Step>

  <Step>
    #### 4. Integer Overflow Sentinel in Minimum DP
    When calculating $\min$, avoid `INT_MAX`. Adding even $1$ to `INT_MAX` causes signed integer overflow in C++ (undefined behavior). Use `1e9` or check `dp[state] != INF` before adding.
  </Step>

  <Step>
    #### 5. Knapsack Loop Direction Invariant
    - **0/1 Knapsack (At most once)**: Iterate capacity backwards ($W \to wt$).
    - **Unbounded Knapsack (Unlimited use)**: Iterate capacity forwards ($wt \to W$).
  </Step>

  <Step>
    #### 6. Bitwise Operator Precedence in C++ & JS
    The bitwise AND `&` has lower precedence than equality `==`. Always write:
    `if ((mask & (1 << i)) != 0)`
    Never write:
    `if (mask & (1 << i) != 0)`
  </Step>
</Steps>
