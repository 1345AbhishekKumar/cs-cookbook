The **Convex Hull** of a finite set of points $S$ in the 2D plane is the smallest convex polygon that contains all points in $S$. Intuitively, it is the shape formed by stretching an elastic rubber band around all the points.

While the naive gift-wrapping algorithm takes $\mathcal{O}(N \cdot H)$ (where $H$ is the number of hull vertices), **Andrew's Monotone Chain algorithm** computes the convex hull in **optimal $\mathcal{O}(N \log N)$ time** with zero trigonometric operations.

---

## 1. Andrew's Monotone Chain Algorithm

Andrew's algorithm decomposes the hull into two halves:

1. Sort all points lexicographically (primarily by $x$, secondarily by $y$).
2. **Build Lower Hull**: Iterate through sorted points left-to-right. While the last two points in the hull and the new point make a right (clockwise) turn, pop the previous point from the hull stack.
3. **Build Upper Hull**: Iterate through sorted points right-to-left. Repeat the identical counter-clockwise turn invariant.
4. Concatenate lower and upper hulls, omitting duplicate endpoints.

```python
"""Computes convex hull in O(N log N) using Andrew's Monotone Chain."""
sorted_pts = sorted(points, key=lambda p: (p.x, p.y))
if len(sorted_pts) <= 1:
return sorted_pts

    # Build lower hull
    lower = []
    for p in sorted_pts:
        while len(lower) >= 2 and cross_product(lower[-2], lower[-1], p) <= 0:
````

```typescript
export interface Point {
  x: number;
  y: number;
}

function crossProduct(o: Point, a: Point, b: Point): number {
  return (a.x - o.x) * (b.y - o.y) - (a.y - o.y) * (b.x - o.x);
}

export function convexHullAndrew(points: Point[]): Point[] {
  const pts = [...points].sort((a, b) => (a.x !== b.x ? a.x - b.x : a.y - b.y));
  if (pts.length <= 1) return pts;

  const lower: Point[] = [];
  for (const p of pts) {
    while (lower.length >= 2 && crossProduct(lower[lower.length - 2], lower[lower.length - 1], p) <= 0) {
      lower.pop();
    }
    lower.push(p);
  }

  const upper: Point[] = [];
  for (let i = pts.length - 1; i >= 0; i--) {
    const p = pts[i];
    while (upper.length >= 2 && crossProduct(upper[upper.length - 2], upper[upper.length - 1], p) <= 0) {
      upper.pop();
    }
    upper.push(p);
  }

  lower.pop();
  upper.pop();
  return lower.concat(upper);
}
````
