While the standard Euclidean algorithm computes the Greatest Common Divisor $\gcd(a, b)$ in logarithmic time, the **Extended Euclidean Algorithm** also finds integer coefficients $x$ and $y$ that satisfy **Bézout's Identity**:

$$a \cdot x + b \cdot y = \gcd(a, b)$$

This identity is the cryptographic foundation for:

1. Finding **modular multiplicative inverses** ($a^{-1} \pmod M$) when $\gcd(a, M) = 1$.
2. Solving **Linear Diophantine Equations** ($a \cdot x + b \cdot y = c$).
3. The Chinese Remainder Theorem and RSA public key generation.

---

## 1. Inductive Derivation

From the division algorithm: $a = q \cdot b + r$, where $q = \lfloor a / b \rfloor$ and $r = a \bmod b$.

By induction, suppose we have resolved coefficients $x_1, y_1$ for subproblem $(b, a \bmod b)$:

$$b \cdot x_1 + (a \bmod b) \cdot y_1 = g$$

Substitute $a \bmod b = a - \lfloor a / b \rfloor \cdot b$:

$$b \cdot x_1 + \left( a - \left\lfloor \frac{a}{b} \right\rfloor \cdot b \right) y_1 = g$$
$$a \cdot y_1 + b \cdot \left( x_1 - \left\lfloor \frac{a}{b} \right\rfloor y_1 \right) = g$$

Matching coefficients with $a \cdot x + b \cdot y = g$:

$$x = y_1$$
$$y = x_1 - \left\lfloor \frac{a}{b} \right\rfloor y_1$$

```python
def extended_gcd(a: int, b: int) -> tuple[int, int, int]:
    """Returns (gcd, x, y) such that a*x + b*y = gcd(a, b)."""
    if b == 0:
        return a, 1, 0
    g, x1, y1 = extended_gcd(b, a % b)
    x = y1
    y = x1 - (a // b) * y1
    return g, x, y

def mod*inverse(a: int, m: int) -> int | None:
"""Computes a^(-1) mod m, or None if inverse doesn't exist."""
g, x, * = extended_gcd(a, m)
if g != 1:
return None # Coprime required
return (x % m + m) % m
````

```typescript
export function extendedGCD(a: number, b: number): [number, number, number] {
  if (b === 0) {
    return [a, 1, 0];
  }
  const [g, x1, y1] = extendedGCD(b, a % b);
  const x = y1;
  const y = x1 - Math.floor(a / b) * y1;
  return [g, x, y];
}

export function modInverse(a: number, m: number): number | null {
  const [g, x] = extendedGCD(a, m);
  if (g !== 1) return null;
  return ((x % m) + m) % m;
}
````
