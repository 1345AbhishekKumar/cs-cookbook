The **Shoelace Formula** (also known as **Gauss's Area Formula**) computes the area of any simple (non-self-intersecting) polygon whose vertices are given in sequential order $(x_0, y_0), (x_1, y_1), \dots, (x_{N-1}, y_{N-1})$ in **$\mathcal{O}(N)$ linear time**.

It calculates the signed area by summing cross products of consecutive vertices with the origin $(0, 0)$:

$$2 \cdot \text{Area} = \left| \sum_{i=0}^{N-1} (x_i y_{i+1} - x_{i+1} y_i) \right|$$

where $(x_N, y_N) = (x_0, y_0)$ (wrapping back to the start).

---

## 1. Visualizing the Shoelace Cross Sum

```
Coordinates:
  x0      y0
     \  /
  x1      y1
     \  /
  x2      y2
     \  /
  x0      y0
```

- Sum down-right products: $x_0 y_1 + x_1 y_2 + \dots + x_{N-1} y_0$.
- Subtract down-left products: $y_0 x_1 + y_1 x_2 + \dots + y_{N-1} x_0$.
- Divide absolute value by 2.

```python
def polygon_area(points: list[tuple[float, float]]) -> float:
    """Computes area of arbitrary simple polygon in O(N) time."""
    n = len(points)
    if n < 3:
        return 0.0

    area2 = 0.0
    for i in range(n):
        x1, y1 = points[i]
        x2, y2 = points[(i + 1) % n]
        area2 += (x1 * y2) - (x2 * y1)

    return abs(area2) / 2.0

````

```typescript
export function polygonArea(points: [number, number][]): number {
  const n = points.length;
  if (n < 3) return 0;

  let area2 = 0;
  for (let i = 0; i < n; i++) {
    const [x1, y1] = points[i];
    const [x2, y2] = points[(i + 1) % n];
    area2 += x1 * y2 - x2 * y1;
  }

  return Math.abs(area2) / 2.0;
}
````
