While Kruskal's algorithm is edge-centric (sorting all edges globally), **Prim's Algorithm** is vertex-centric.

Starting from an arbitrary seed vertex, it grows a single connected tree by repeatedly adding the cheapest edge crossing the **cut** between vertices already in the tree and vertices outside the tree (the fundamental Cut Property of MSTs).

---

## 1. Cut Property & Priority Queue Maintenance

At any iteration, let $S$ be the set of finalized tree vertices, and $V \setminus S$ be the remaining vertices.
By the **Cut Property**, the minimum-weight edge crossing between $S$ and $V \setminus S$ is guaranteed to belong to some Minimum Spanning Tree.

Prim's maintains this frontier using a min-heap:

- Push all edges leaving the newly finalized vertex into the priority queue.
- Extract the cheapest edge $(u, v)$ connecting to an unvisited vertex $v$.
- Add $v$ to $S$, and repeat until all $V$ vertices are spanned.

```python
import heapq

def prim_mst(num_nodes: int, adj: list[list[tuple[int, int]]], start: int = 0):
"""Computes MST in O((V + E) log V) using Prim's algorithm."""
visited = [False] \* num_nodes
pq = [(0, start, -1)] # (weight, node, parent)
mst_edges = []
total_cost = 0

    while pq and len(mst_edges) < num_nodes:
        w, u, p = heapq.heappop(pq)
        if visited[u]:
            continue

        visited[u] = True
        total_cost += w
        if p != -1:
            mst_edges.append((p, u, w))

        for v, weight in adj[u]:
            if not visited[v]:
                heapq.heappush(pq, (weight, v, u))

    return total_cost, mst_edges
````

```typescript
export function primMst(
  numNodes: number,
  adj: [number, number][][],
  start: number = 0
): { totalCost: number; mstEdges: [number, number, number][] } {
  const visited = new Uint8Array(numNodes);
  const pq: [number, number, number][] = [[0, start, -1]];
  let totalCost = 0;
  const mstEdges: [number, number, number][] = [];

  while (pq.length > 0 && mstEdges.length < numNodes - 1) {
    let minIdx = 0;
    for (let i = 1; i < pq.length; i++) {
      if (pq[i][0] < pq[minIdx][0]) minIdx = i;
    }
    const [w, u, p] = pq.splice(minIdx, 1)[0];

    if (visited[u]) continue;
    visited[u] = 1;
    totalCost += w;
    if (p !== -1) mstEdges.push([p, u, w]);

    for (const [v, weight] of adj[u]) {
      if (!visited[v]) {
        pq.push([weight, v, u]);
      }
    }
  }

  return { totalCost, mstEdges };
}
````

std::tuple<long long, int, int>,

    pq.emplace(0, start, -1);

    while (!pq.empty()) {
        auto [w, u, p] = pq.top();
