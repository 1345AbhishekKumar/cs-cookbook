## The Greedy Principle

A **Greedy Algorithm** builds a solution piece by piece, always choosing the immediate next option that offers the greatest local benefit without looking ahead or reconsidering previous choices.

Unlike dynamic programming or backtracking, a greedy algorithm makes a choice and never backtracks.

## Proving Greedy Optimality: The Exchange Argument

Why does a greedy choice lead to a globally optimal solution rather than a local trap? The standard mathematical proof technique is the **Exchange Argument**:

1. Assume an arbitrary optimal solution $S^*$ exists that differs from the greedy solution $S_{\text{greedy}}$.
2. Identify the first choice where $S^*$ diverges from $S_{\text{greedy}}$.
3. "Exchange" the choice in $S^*$ with the greedy choice.
4. Prove mathematically that this substitution **does not decrease the quality/value** of the solution (and preserves all feasibility constraints).
5. By induction across all steps, $S^*$ can be transformed into $S_{\text{greedy}}$ without loss of optimality. Thus, $S_{\text{greedy}}$ is optimal.

## Classical Archetype: Fractional Knapsack

Given $N$ items with weight $w_i$ and value $v_i$, fill a knapsack of capacity $W$ to maximize total value, where fractional amounts of items can be taken.

**Greedy Invariant**: Sort items in descending order of **value density** $\rho_i = v_i / w_i$. Greedily consume the item with highest density completely until capacity is reached, taking a fractional slice of the final item.

```python
from typing import List, Tuple

def fractional_knapsack(capacity: float, items: List[Tuple[float, float]]) -> float:
"""Calculates maximum value in Fractional Knapsack using greedy density sorting.
items: List of (value, weight) tuples.
""" # Sort descending by value / weight ratio
sorted_items = sorted(items, key=lambda x: x[0] / x[1], reverse=True)
total_val = 0.0
rem_cap = capacity

    for val, weight in sorted_items:
        if rem_cap <= 0:
            break
        if weight <= rem_cap:
            total_val += val
            rem_cap -= weight
        else:
            total_val += val * (rem_cap / weight)
            rem_cap = 0

    return total_val
````

```typescript
interface Item {
  value: number;
  weight: number;
}

export function fractionalKnapsack(capacity: number, items: Item[]): number {
  // Sort descending by density
  items.sort((a, b) => b.value / b.weight - a.value / a.weight);

  let totalValue = 0;
  let remainingCapacity = capacity;

  for (const item of items) {
    if (remainingCapacity <= 0) break;

    if (item.weight <= remainingCapacity) {
      totalValue += item.value;
      remainingCapacity -= item.weight;
    } else {
      totalValue += item.value * (remainingCapacity / item.weight);
      remainingCapacity = 0;
    }
  }

  return totalValue;
}
````
