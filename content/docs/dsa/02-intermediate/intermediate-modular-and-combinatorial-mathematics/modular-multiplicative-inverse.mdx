## The Division Dilemma in Modular Arithmetic

In real arithmetic, dividing by $b$ is equivalent to multiplying by $1/b$. In modular arithmetic, integers cannot be fractional: $(a / b) \pmod M \neq ((a \pmod M) / (b \pmod M)) \pmod M$.

Instead, we define the **Modular Multiplicative Inverse** of $b$ modulo $M$, denoted as $b^{-1}$, as the unique integer satisfying:
$$b \cdot b^{-1} \equiv 1 \pmod M$$
Division is then computed as multiplication by this inverse:
$$(a / b) \equiv a \cdot b^{-1} \pmod M$$

---

## Method 1: Fermat's Little Theorem (When $M$ is Prime)

Pierre de Fermat proved that if $M$ is a prime number and $\gcd(b, M) = 1$:
$$b^{M - 1} \equiv 1 \pmod M$$
Multiplying both sides by $b^{-1}$:
$$b^{-1} \equiv b^{M - 2} \pmod M$$

Using **Binary Exponentiation**, we compute $b^{-1} = \text{power}(b, M - 2, M)$ in just $\mathcal{O}(\log M)$ time!

```python
MOD = 1_000_000_007

def mod_inverse(b: int, m: int = MOD) -> int:
````

```typescript
const MOD = 1000000007n;

function power(base: bigint, exp: bigint, mod: bigint): bigint {
  let res = 1n;
  base %= mod;
  while (exp > 0n) {
    if ((exp & 1n) === 1n) res = (res * base) % mod;
    base = (base * base) % mod;
    exp >>= 1n;
  }
  return res;
}

export function modInverse(b: bigint, m: bigint = MOD): bigint {
  return power(b, m - 2n, m);
}

export function modDivide(a: bigint, b: bigint, m: bigint = MOD): bigint {
  return ((a % m) * modInverse(b, m)) % m;
}
````

#include <cstdint>

constexpr int64_t MOD = 1000000007LL;

int64*t power(int64_t base, int64_t exp, int64_t mod = MOD) {
int64_t res = 1;
base %= mod;
while (exp > 0) {
if (exp & 1) res = (res * base) % mod;
base = (base \_ base) % mod;
exp >>= 1;
}
return res;
}

inline int64_t modInverse(int64_t b, int64_t m = MOD) {
return power(b, m - 2, m);
}

inline int64_t modDivide(int64_t a, int64_t b, int64_t m = MOD) {
return ((a % m) \* modInverse(b, m)) % m;
}
