## Output & Input

| Syntax                  | Action / Meaning                                                                    |
| :---------------------- | :---------------------------------------------------------------------------------- |
| `print("...")`          | Write a message or expression to the terminal.                                      |
| `input("prompt ")`      | Print a prompt, pause, wait for user input, and return it — **always as a string**. |
| `print(a, b, sep=", ")` | Print multiple values joined by an explicit separator string.                       |

---

## Values, Types & Variables

| Syntax         | Action / Meaning                                                                           |
| :------------- | :----------------------------------------------------------------------------------------- |
| `name = value` | Bind a variable label to a value in memory. Use lowercase with underscores (`snake_case`). |
| `int(x)`       | Convert string or float to integer: `int("42") -> 42`.                                     |
| `float(x)`     | Convert string or int to floating-point number: `float("3.14") -> 3.14`.                   |
| `str(x)`       | Convert any object to its string representation: `str(10) -> "10"`.                        |
| `bool(x)`      | Evaluate truthiness: `bool(0) -> False`, `bool("hello") -> True`.                          |
| `type(x)`      | Report the data type / class of object `x`: `type(10) -> <class 'int'>`.                   |
| `len(x)`       | General-purpose function returning length (characters in string, items in list/dict).      |

## Strings

| Syntax                  | Action / Meaning                                                                |
| :---------------------- | :------------------------------------------------------------------------------ |
| `'…' · "…"`             | Standard string quotes. Nest double quotes inside single quotes and vice versa. |
| `'''…''' · """…"""`     | Triple quotes: span multiple lines and preserve indentation/newlines.           |
| `s[0]`                  | Index from front: first character (zero-based).                                 |
| `s[-1]`                 | Index from back: last character.                                                |
| `s[a:b]`                | Slice: substring from index `a` (inclusive) to `b` (exclusive).                 |
| `s[:]`                  | Full copy/clone of string `s`.                                                  |
| `s[::-1]`               | Reversed string `s`.                                                            |
| `f"{var}"`              | Formatted string: curly braces are evaluated and interpolated at runtime.       |
| `s.upper() · s.lower()` | Change letter case — **returns a new string** (original untouched).             |
| `s.find(sub)`           | Return index of first occurrence, or `-1` if not found (case-sensitive).        |
| `s.replace(a, b)`       | Replace all occurrences of `a` with `b` (returns a new string).                 |
| `sub in s`              | Returns boolean `True` if substring `sub` exists within string `s`.             |

## Collections

| Type      | Definition        |  Mutability   |        Lookup Speed         | Example                         |
| :-------- | :---------------- | :-----------: | :-------------------------: | :------------------------------ |
| **List**  | Ordered sequence  |  **Mutable**  | $O(N)$ search, $O(1)$ index | `names = ["Alice", "Bob"]`      |
| **Tuple** | Ordered record    | **Immutable** | $O(N)$ search, $O(1)$ index | `coords = (10, 20)`             |
| **Dict**  | Key-Value mapping |  **Mutable**  |  **$O(1)$ Instant lookup**  | `user = {"id": 1, "name": "A"}` |
| **Set**   | Unique collection |  **Mutable**  |    **$O(1)$ Membership**    | `unique_ids = {1, 2, 3}`        |

## Control Flow & Functions

| Syntax                 | Meaning                                                           |
| :--------------------- | :---------------------------------------------------------------- |
| `if / elif / else`     | Conditional branching based on indented blocks (4 spaces).        |
| `and · or · not`       | Boolean logical operators.                                        |
| `for item in seq:`     | Iterate directly through sequence elements.                       |
| `while cond:`          | Loop while condition remains truthy.                              |
| `var := expr`          | Walrus operator: assign variable value inside an expression.      |
| `match val: case ...:` | Structural pattern matching (Python 3.10+).                       |
| `def func(a, b=val):`  | Define a function. Never use mutable defaults (`[]`); use `None`! |
| `return val`           | Return value to caller. Omitting `return` returns `None`.         |

## Comments & Documentation

| Syntax            | Meaning / Usage                                                          |
| :---------------- | :----------------------------------------------------------------------- |
| `# comment`       | Single-line comment ignored by the Python interpreter.                   |
| `code  # comment` | Inline comment: separated from code by at least 2 spaces.                |
| `"""docstring"""` | Docstring attached to `obj.__doc__` for functions, classes, and modules. |

## Errors & Exception Handling

| Syntax                    | Meaning / Usage                                                    |
| :------------------------ | :----------------------------------------------------------------- |
| `try: ... except Err:`    | Intercept and handle specific runtime errors without crashing.     |
| `except (E1, E2) as err:` | Catch multiple exceptions and bind the error object.               |
| `else: ...`               | Executes only when the `try` block completes with zero exceptions. |
| `finally: ...`            | Guaranteed to execute regardless of errors or return statements.   |
| `raise ValueError(...)`   | Intentionally trigger an exception with a custom message.          |

## File I/O & Filesystem Paths

| Syntax                                      | Meaning / Usage                                                  |
| :------------------------------------------ | :--------------------------------------------------------------- |
| `Path("a") / "b"`                           | Cross-platform path joining (`pathlib.Path`).                    |
| `Path(__file__).resolve().parent`           | Directory containing the currently executing script.             |
| `with open(p, "r", encoding="utf-8") as f:` | Open file safely; automatically closes on block exit.            |
| `with open(p, "w", encoding="utf-8") as f:` | Write to file (overwrites existing contents).                    |
| `with open(p, "a", encoding="utf-8") as f:` | Append to end of file.                                           |
| `for line in f:`                            | Memory-efficient line streaming for large files ($O(1)$ memory). |
| `p.read_text(encoding="utf-8")`             | Read entire file as string.                                      |
| `p.write_text("...", encoding="utf-8")`     | Write string directly to file.                                   |
| `p.mkdir(parents=True, exist_ok=True)`      | Create directory and parents idempotently.                       |

## Modules, Packaging & Organization

| Syntax                                  | Meaning / Usage                                                            |
| :-------------------------------------- | :------------------------------------------------------------------------- |
| `if __name__ == "__main__":`            | Guard block: runs only when file is executed directly.                     |
| `import math` / `from math import sqrt` | Import standard library or installed third-party modules.                  |
| `src/` layout                           | Recommended directory structure separating package code from tests.        |
| `uv add <pkg>` / `pip install <pkg>`    | Install packages from PyPI into an isolated virtual environment (`.venv`). |

## Data Formats & HTTP APIs

| Syntax                                | Meaning / Usage                                                     |
| :------------------------------------ | :------------------------------------------------------------------ |
| `json.loads(s)` / `json.dumps(obj)`   | Parse JSON string to Python dict / serialize dict to JSON string.   |
| `json.load(f)` / `json.dump(obj, f)`  | Read/write JSON directly to open file objects.                      |
| `csv.DictReader(f)`                   | Read CSV file rows as dictionaries keyed by header names.           |
| `csv.DictWriter(f, fieldnames=[...])` | Write list of dictionaries to structured CSV file.                  |
| `httpx.get(url, params={...})`        | Send HTTP GET request with query parameters.                        |
| `httpx.post(url, json={...})`         | Send HTTP POST request with JSON request body.                      |
| `res.raise_for_status()`              | Raise `HTTPStatusError` if status code is 4xx or 5xx.               |
| `res.json()`                          | Deserialize HTTP JSON response body directly into Python dict/list. |
