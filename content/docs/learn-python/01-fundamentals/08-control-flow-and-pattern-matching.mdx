## 1. Conditional Branching: `if`, `elif`, `else`

In Python, code blocks are defined by **indentation** (typically 4 spaces), not curly braces:

```python
is_hot = False
is_cold = True

if is_hot:
    print("It's a hot day! Drink plenty of water.")
elif is_cold:
    print("It's a cold day! Wear warm clothes.")
else:
    print("It's a lovely day.")

print("Enjoy your day!")
```

Output:

```text
It's a cold day! Wear warm clothes.
Enjoy your day!
```

### Logical Operators: `and`, `or`, `not`

```python
has_high_income = True
has_good_credit = True
has_criminal_record = False

# 'and' requires BOTH conditions to be True
if has_high_income and has_good_credit:
    print("Eligible for loan")

# 'not' inverts a boolean value
if has_good_credit and not has_criminal_record:
    print("Eligible for background approval")
```

Output:

```text
Eligible for loan
Eligible for background approval
```

## 2. Looping: `while` & `for`

### The `while` Loop: Repeating Until a Condition Changes

```python
i = 1
while i <= 3:
    print("*" * i)
    i += 1  # Increment i by 1 (equivalent to i = i + 1)
print("Done")
```

Output:

```text
*
**
***
Done
```

### The `for` Loop: Iterating Over Items

A `for` loop iterates directly over sequences (strings, lists, ranges):

```python
# Iterating over a list
for item in ['Apples', 'Oranges', 'Grapes']:
    print(f"Item: {item}")

# Iterating over a number range (start, stop_exclusive, step)
for i in range(1, 4):
    print(f"Count: {i}")
```

Output:

```text
Item: Apples
Item: Oranges
Item: Grapes
Count: 1
Count: 2
Count: 3
```

## 3. The Walrus Operator (`:=`): Assignment Expressions

Introduced in PEP 572, the **walrus operator** (`:=`) allows you to assign a value to a variable *inside* an expression or conditional check:

<Tabs items={['Modern Walrus (:=)', 'Traditional Approach']}>
<Tab value="Modern Walrus (:=)">
```python
# Evaluates len(data), assigns to 'n', and checks condition simultaneously:
data = [1, 2, 3, 4, 5, 6]

if (n := len(data)) > 3:
    print(f"List is too long ({n} elements, expected <= 3)")
```
</Tab>
<Tab value="Traditional Approach">
```python
data = [1, 2, 3, 4, 5, 6]

n = len(data)
if n > 3:
    print(f"List is too long ({n} elements, expected <= 3)")
```
</Tab>
</Tabs>

The walrus operator is invaluable when reading file buffers or streams:
```python
# Keep reading chunks until reaching empty string
while (chunk := file.read(1024)) != "":
    process_chunk(chunk)
```

## 4. Modern Structural Pattern Matching (`match / case`)

Introduced in Python 3.10 (PEP 634), `match/case` provides pattern matching far more powerful than traditional C/Java `switch` statements:

```python
def handle_command(command: str):
    match command.split():
        case ["quit" | "exit"]:
            print("System shutting down...")

        case ["go", ("north" | "south" | "east" | "west") as direction]:
            print(f"Player moving toward the {direction}!")

        case ["pickup", *items] if len(items) > 0:
            print(f"Picking up inventory: {', '.join(items)}")

        case _:
            print(f"Unknown command: '{command}'")

handle_command("go north")
handle_command("pickup sword shield potion")
handle_command("dance")
```

Output:

```text
Player moving toward the north!
Picking up inventory: sword, shield, potion
Unknown command: 'dance'
```

### Pattern Matching Highlights:
- **OR Patterns (`|`)**: `"quit" | "exit"` matches either word.
- **Variable Capture (`as direction`)**: Automatically extracts matching tokens into variables.
- **Sequence Unpacking (`*items`)**: Gathers remaining tokens into a sublist.
- **Guard Clauses (`if len(items) > 0`)**: Adds conditional checks directly on the match line.
- **Wildcard (`_`)**: Catches all unmatched cases (like a fallback `default:`).

## Summary Reference

- **`if / elif / else`**: Evaluates conditions top-to-bottom based on indentation.
- **`and` / `or` / `not`**: Boolean logical combinators.
- **`for x in iterable:`**: Idiomatic sequence iteration.
- **Walrus `:=`**: Assigns variable value within an expression.
- **`match / case`**: Structural pattern matching with deconstruction and guard clauses.
