## Stage 2 Core Topics

<Steps>
<Step>
### 01. Classes & Objects Foundations: From Blueprint to Instance
Anatomy of a class, the constructor `__init__`, memory allocation, demystifying `self` under the hood, instance vs class attributes (`__dict__`), and the three method types (`instance`, `@classmethod`, `@staticmethod`).
</Step>

<Step>
  ### 02. The Four Pillars: Encapsulation & Abstraction Access control
  conventions (`public`, `_protected`, `__private`), name mangling internals,
  Pythonic `@property` getters/setters/deleters, and enforcing architectural
  contracts with Abstract Base Classes (`abc.ABC`, `@abstractmethod`).
</Step>

<Step>
  ### 03. The Four Pillars: Inheritance & Polymorphism Single, multilevel, and
  hierarchical inheritance, demystifying `super()`, method overriding, Duck
  Typing ("if it walks like a duck..."), why Python omits traditional method
  overloading, and operator overloading (`__add__`, `__eq__`, `__len__`).
</Step>

<Step>
  ### 04. Advanced OOP: Multiple Inheritance, MRO, Mixins & Composition Solving
  the Diamond Problem, step-by-step C3 Linearization (Method Resolution Order),
  cooperative multiple inheritance, reusable Mixin architectures, "Composition
  over Inheritance", and memory optimization with `__slots__`.
</Step>

<Step>
  ### 05. The Dunder Protocol Matrix The foundational philosophy of Python's
  object model: `__repr__` (unambiguous, for developers) vs `__str__` (readable,
  for users), `__eq__`, `__hash__`, and why equal objects must produce equal
  hashes.
</Step>

<Step>
  ### 06. First-Class Functions, Closures & Execution Frames Lexical scoping in
  depth, function introspection, cell objects (`__closure__`), and
  `functools.partial`.
</Step>

<Step>
  ### 07. Production Decorators Deep Dive Writing robust decorators with
  arguments, preserving function metadata using `functools.wraps`, runtime
  signature inspection (`inspect.signature`), and type-safe decorator typing
  using `typing.ParamSpec` (PEP 612).
</Step>

<Step>
  ### 08. Generators, Iterators & Stream Pipelines The iterator protocol
  (`__iter__`, `__next__`), generator functions (`yield`), bidirectional
  communication (`send()`, `throw()`), and composing lazy data pipelines with
  `itertools`.
</Step>

<Step>
  ### 09. Modern Dataclasses & Strict Type Protocols High-performance
  `@dataclass(slots=True, frozen=True, kw_only=True)`, structural subtyping with
  `typing.Protocol` (PEP 544), and native type parameter syntax (PEP 695).
</Step>

<Step>
  ### 10. The Descriptor Protocol & Properties The engine powering `@property`,
  `classmethod`, and ORM fields: understanding `__get__`, `__set__`, and
  attribute lookup precedence (Data Descriptors vs Instance `__dict__` vs
  Non-Data Descriptors).
</Step>

<Step>
  ### 11. Context Managers & Resource Management The context management protocol
  (`__enter__`, `__exit__`), creating custom context managers with
  `contextlib.contextmanager`, and transaction rollbacks.
</Step>

<Step>
  ### 12. Pattern Matching with Regular Expressions Pattern recognition and
  extraction using the `re` module: raw strings, compile, search vs fullmatch vs
  finditer, capture groups, greedy vs lazy quantifiers, character classes,
  zero-width lookarounds, and ReDoS defense.
</Step>

<Step>
  ### 13. Working with APIs: HTTP & REST Connecting Python to live internet
  services: HTTP methods (GET, POST), headers, query parameters, resilient
  network requests using modern `httpx`, and error status handling.
</Step>

<Step>
### Capstone: active-lite Mini-ORM
Build a declarative SQLite ORM from scratch using custom field descriptors, `__init_subclass__` schema reflection, and transaction context managers.
</Step>
</Steps>
