Welcome to **Stage 2: The Python Data Model & Idiomatic OOP**.

In this stage, you transition from writing imperative code to mastering Python's special object model: treating Python as a unified, protocol-driven language where syntactic constructs are powered by special double-underscore ("dunder") methods.

---

## Stage 2 Core Topics

<Steps>
<Step>
### 01. The Dunder Protocol Matrix
The foundational philosophy of Python's object model: `__repr__` (unambiguous, for developers) vs `__str__` (readable, for users), `__eq__`, `__hash__`, and why equal objects must produce equal hashes.
</Step>

<Step>
### 02. Sequence & Mapping Protocols
Implementing custom collections that support `len(obj)`, indexing `obj[key]`, slicing, and iteration by implementing `__len__`, `__getitem__`, `__setitem__`, and `__contains__`.
</Step>

<Step>
### 03. First-Class Functions, Closures & Execution Frames
Lexical scoping in depth, function introspection, cell objects (`__closure__`), and `functools.partial`.
</Step>

<Step>
### 04. Production Decorators & Signatures
Writing robust decorators with arguments, preserving function metadata using `functools.wraps`, runtime signature inspection (`inspect.signature`), and type-safe decorator typing using `typing.ParamSpec` (PEP 612).
</Step>

<Step>
### 05. Generators, Iterators & Stream Pipelines
The iterator protocol (`__iter__`, `__next__`), generator functions (`yield`), bidirectional communication (`send()`, `throw()`), and composing lazy data pipelines with `itertools`.
</Step>

<Step>
### 06. Classes, Multiple Inheritance & C3 MRO
Object-oriented architecture, the diamond problem, Method Resolution Order (C3 Linearization), and cooperative multiple inheritance with `super()`.
</Step>

<Step>
### 07. Modern Dataclasses & Strict Type Hints
`dataclasses.dataclass(frozen=True, slots=True, kw_only=True)`, static duck typing with `typing.Protocol` (PEP 544), and native type parameter syntax (PEP 695).
</Step>

<Step>
### 08. The Descriptor Protocol & Properties
The engine powering `@property`, `classmethod`, and ORM fields: understanding `__get__`, `__set__`, and attribute lookup precedence (Data Descriptors vs Instance `__dict__` vs Non-Data Descriptors).
</Step>

<Step>
### 09. Context Managers & Resource Management
The context management protocol (`__enter__`, `__exit__`), creating custom context managers with `contextlib.contextmanager`, and transaction rollbacks.
</Step>

<Step>
### Capstone: active-lite Mini-ORM
Build a declarative SQLite ORM from scratch using custom field descriptors, `__init_subclass__` schema reflection, and transaction context managers.
</Step>
</Steps>
