Before writing complex optimization logic, you must **measure**. Guessing where performance bottlenecks exist is almost always wrong.

In this lesson, we cover profiling tools and a high-impact memory optimization: **`__slots__`**.

## 1. CPU Profiling with `cProfile`

Python includes a native deterministic profiler: **`cProfile`**. It tracks the total time, number of calls, and cumulative time spent inside every single function:

```python
import cProfile
import pstats
import time

def slow_step():
    time.sleep(0.3)

def fast_step():
    total = sum(i for i in range(100_000))
    return total

def run_pipeline():
    for _ in range(3):
        slow_step()
        fast_step()

# Profile execution:
profiler = cProfile.Profile()
profiler.enable()

run_pipeline()

profiler.disable()
stats = pstats.Stats(profiler).sort_stats("cumulative")
stats.print_stats(5)
```

Output:

```text
         100021 function calls in 0.912 seconds

   Ordered by: cumulative time
   List reduced from 15 to 5 due to restriction <5>

   ncalls  tottime  percall  cumtime  percall filename:lineno(function)
        1    0.000    0.000    0.912    0.912 app.py:12(run_pipeline)
        3    0.000    0.000    0.901    0.300 app.py:5(slow_step)
        3    0.901    0.300    0.901    0.300 {built-in method time.sleep}
        3    0.008    0.003    0.011    0.004 app.py:8(fast_step)
```

The output reveals instantly that `slow_step` accounts for 98.7% of total runtime, pinpointing exactly what needs optimization.

## 2. Memory Optimization: The Power of `__slots__`

By default, Python stores all instance attributes inside a dynamic dictionary (`self.__dict__`). While flexible, a dictionary carries a significant memory footprint (~150+ bytes per instance).

If your system stores **1,000,000 objects in RAM** (such as geographic coordinates or financial quotes), standard instances will consume gigabytes of unnecessary memory!

### The Solution: `__slots__`
`__slots__` tells CPython: *"This class will only ever have these specific attributes."* CPython eliminates the instance `__dict__` and allocates a **compact, fixed-size C array**:

```python
import sys

# 1. Standard class with dynamic __dict__
class StandardPoint:
    def __init__(self, x: float, y: float):
        self.x = x
        self.y = y

# 2. Optimized class with fixed __slots__
class SlottedPoint:
    __slots__ = ("x", "y")
    def __init__(self, x: float, y: float):
        self.x = x
        self.y = y

p_standard = StandardPoint(1.0, 2.0)
p_slotted = SlottedPoint(1.0, 2.0)

print("Standard Instance Overhead:", sys.getsizeof(p_standard) + sys.getsizeof(p_standard.__dict__), "bytes")
print("Slotted Instance Overhead:", sys.getsizeof(p_slotted), "bytes")
```

Output:

```text
Standard Instance Overhead: 152 bytes
Slotted Instance Overhead: 48 bytes
```

### Scale Benchmark: 1,000,000 Objects

| Object Type | 1,000,000 Instances in RAM | Memory Saved |
| :--- | :--- | :--- |
| **Standard Class (`__dict__`)** | ~150 MB | 0% |
| **`__slots__` Class** | **~48 MB** | **68% RAM Reduction!** |

In modern Python, you can apply this automatically using:
```python
@dataclass(slots=True)
class Coordinate:
    lat: float
    lon: float
```

## Summary Reference

- **`cProfile`**: Built-in deterministic profiler tracking function call durations.
- **`py-spy`**: Zero-overhead sampling profiler that attaches to production Python processes without restarting them.
- **`__slots__`**: Replaces the per-instance dictionary with a compact C array.
- **`@dataclass(slots=True)`**: Modern idiomatic way to create slotted classes.
