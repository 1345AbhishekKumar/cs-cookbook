The reading list behind this roadmap. Each title earns its place by covering something the others assume you already know, so the shelf is deliberately short and opinionated rather than exhaustive.

<Bookshelf />

<Callout type="info" title="Adding a book">
Append one object to the `books` array in `lib/books.ts`. It appears on this shelf immediately, grouped and counted by its `category`:

```ts
{
  title: 'Book Title',
  author: 'Author Name',
  category: 'Software Craft', // one of BOOK_CATEGORIES
  year: 2024,
  note: 'One line on why it is worth reading.',
}
```
</Callout>
