## Complete IPv4 Subnetting Cheat Sheet (/8 to /32)

| CIDR | Subnet Mask | Total IPs | Usable Hosts (LAN) | Usable (AWS VPC) | Block Size | Typical Scope |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **/8** | `255.0.0.0` | 16,777,216 | 16,777,214 | N/A | 16M | Massive enterprise private block |
| **/16** | `255.255.0.0` | 65,536 | 65,534 | 65,531 | 65K | Standard Cloud VPC Supernet |
| **/20** | `255.255.240.0` | 4,096 | 4,094 | 4,091 | 16 in 3rd octet | Kubernetes Node Subnet pool |
| **/24** | `255.255.255.0` | 256 | 254 | 251 | 1 in 3rd octet | Standard office subnet / Cloud subnet |
| **/25** | `255.255.255.128` | 128 | 126 | 123 | 128 | Medium department pool |
| **/26** | `255.255.255.192` | 64 | 62 | 59 | 64 | Department subnet |
| **/27** | `255.255.255.224` | 32 | 30 | 27 | 32 | Bastion / DMZ subnet |
| **/28** | `255.255.255.240` | 16 | 14 | 11 | 16 | Small subnet (AWS minimum) |
| **/29** | `255.255.255.248` | 8 | 6 | 3 | 8 | Public ISP IP allocation pool |
| **/30** | `255.255.255.252` | 4 | 2 | Unsupported | 4 | WAN Point-to-Point link |
| **/31** | `255.255.255.254` | 2 | 2 (RFC 3021) | Unsupported | 2 | Modern router point-to-point links |
| **/32** | `255.255.255.255` | 1 | 1 (Host Route) | 1 (Host Route) | 1 | Exact host route / Security group |

## Cisco IOS CLI Command Matrix

| Task | Configuration Mode | Command Syntax |
| :--- | :--- | :--- |
| **Enter Privileged Mode** | User EXEC (`Router>`) | `enable` |
| **Enter Configuration Mode**| Privileged EXEC (`Router#`) | `configure terminal` |
| **Assign Router Hostname** | Global Config (`(config)#`) | `hostname R1-EDGE` |
| **Configure IP on Interface**| Interface Config (`(config-if)#`)| `ip address 192.168.1.1 255.255.255.0` |
| **Enable Interface** | Interface Config (`(config-if)#`)| `no shutdown` |
| **Add Static Route** | Global Config (`(config)#`) | `ip route 10.0.2.0 255.255.255.0 192.168.1.2` |
| **Add Default Gateway Route**| Global Config (`(config)#`) | `ip route 0.0.0.0 0.0.0.0 203.0.113.1` |
| **Inspect Routing Table** | Privileged EXEC (`#`) | `show ip route` |
| **Save Running Configuration**| Privileged EXEC (`#`) | `write memory` (or `copy running-config startup-config`) |
