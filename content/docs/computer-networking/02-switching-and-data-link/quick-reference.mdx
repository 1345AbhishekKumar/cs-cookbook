## Standard Ethernet II Frame Structure

Total frame size: **64 to 1518 bytes** (standard MTU 1500 payload), or up to **9000 bytes** for Jumbo Frames.

| Field | Size (Bytes) | Description |
| :--- | :--- | :--- |
| **Preamble** | 7 bytes | `10101010` alternating bit pattern for clock synchronization |
| **SFD** | 1 byte | Start Frame Delimiter (`10101011`) signaling frame boundary |
| **Destination MAC** | 6 bytes | 48-bit hardware address of receiving interface (or broadcast `FF:FF:FF:FF:FF:FF`) |
| **Source MAC** | 6 bytes | 48-bit hardware address of transmitting interface |
| **802.1Q Tag (Optional)** | 4 bytes | TPID (`0x8100`) + Priority (3 bits) + DEI (1 bit) + VLAN ID (12 bits) |
| **EtherType** | 2 bytes | Identifies encapsulated payload (`0x0800` = IPv4, `0x86DD` = IPv6, `0x0806` = ARP) |
| **Payload** | 46 – 1500 bytes | Layer 3 packet data (padded to 46 bytes minimum if necessary) |
| **FCS / CRC-32** | 4 bytes | Frame Check Sequence cyclic redundancy check for error detection |

## 802.1Q VLAN Tag Breakdown

When an Ethernet frame crosses an 802.1Q trunk link, a 4-byte tag is inserted between the Source MAC and EtherType:

$$
\text{Total Tag} = 32\text{ bits (4 bytes)}
$$

* **TPID (16 bits):** Tag Protocol Identifier, always `0x8100` for standard 802.1Q.
* **PCP (3 bits):** Priority Code Point (CoS / Quality of Service, 0–7).
* **DEI (1 bit):** Drop Eligible Indicator (may be dropped under congestion).
* **VLAN ID (12 bits):** Supports $2^{12} = 4,096$ IDs (IDs `1`–`4094` usable).

## MAC Address Anatomy (EUI-48)

A MAC address consists of 12 hexadecimal digits ($48\text{ bits}$):
```text
  00 : 1A : 2B : 3C : 4D : 5E
  └─── OUI ───┘ └── Device ID ──┘
```
* **OUI (Organizationally Unique Identifier):** First 24 bits assigned by IEEE to hardware manufacturer (e.g. Cisco, Apple, Intel).
* **NIC Specific / Device ID:** Last 24 bits uniquely assigned by manufacturer.
* **Individual/Group Bit (bit 0 of octet 1):** `0` = Unicast, `1` = Multicast.
* **Universal/Local Bit (bit 1 of octet 1):** `0` = Globally unique, `1` = Locally administered.

## Layer 2 Diagnostic Commands

| Operating System | Command | Purpose |
| :--- | :--- | :--- |
| **Linux** | `ip link show` | List network interfaces, MAC addresses, and link states |
| **Linux** | `ip neigh show` | Display kernel ARP neighbor cache table |
| **Linux** | `bridge fdb show` | Display software bridge MAC forwarding database |
| **Windows** | `getmac /v` | List all network adapters with associated MAC addresses |
| **Windows** | `arp -a` | Print current ARP resolution table |
| **Cisco IOS** | `show mac address-table` | Display dynamic switch CAM table mappings (MAC to Port/VLAN) |
| **Cisco IOS** | `show interfaces trunk` | Display active 802.1Q trunk links and allowed VLANs |
