| :--- | :--- | :--- | :--- |

| **67 / 68** | UDP | DHCP | Dynamic Host Configuration (67 Server, 68 Client) |

| **587** | TCP | SMTP Submission | Authenticated mail submission |

| **5432** | TCP | PostgreSQL | PostgreSQL database client connection |

| **10250**| TCP | Kubelet API | Kubernetes node agent management |

## TCP Control Flags Reference

A TCP header includes 6 primary 1-bit control flags:

| Flag | Name | Meaning & Protocol Behavior |
| :--- | :--- | :--- |
| **SYN** | Synchronize | Initiates a connection; synchronizes Initial Sequence Numbers (ISN). |
| **ACK** | Acknowledgment | Acknowledges receipt of data or control segments (`Acknowledgment Number` valid). |
| **FIN** | Finish | Gracefully terminates sending direction of connection (half-close). |
| **RST** | Reset | Abruptly aborts connection (e.g., port closed, state mismatch). |
| **PSH** | Push | Informs receiver OS to push buffered data immediately to user-space application. |
| **URG** | Urgent | Points to urgent data requiring immediate priority processing. |

## Dynamic Routing Comparison: OSPF vs. BGP

| Feature | OSPF (Open Shortest Path First) | BGP (Border Gateway Protocol) |
| :--- | :--- | :--- |
| **Type** | Interior Gateway Protocol (IGP) | Exterior Gateway Protocol (EGP) |
| **Algorithm** | Link-State (Dijkstra SPF) | Path-Vector (AS-Path, Local Pref, MED) |
| **Convergence** | Extremely Fast (seconds) | Controlled / Deliberate (tens of seconds) |
| **Scale** | Single Enterprise / Autonomous System | The entire planetary global Internet |
| **Transport** | Raw IP protocol 89 | TCP port 179 |

## Cloud & Kubernetes Networking Primitives

| Component | Layer / Scope | Function |
| :--- | :--- | :--- |
| **VPC** | Cloud Region | Isolated software-defined private cloud network |
| **IGW** | VPC Edge | Internet Gateway performing 1:1 public-to-private NAT |
| **Security Group** | Virtual NIC | Stateful firewall attached directly to cloud instances |
| **NACL** | Subnet Boundary | Stateless subnet-level packet filtering rules |
| **Linux `netns`** | OS Kernel | Isolated network stack (own routing table, interfaces, iptables) |
| **veth pair** | Virtual Cable | Connects container network namespace to host bridge |
| **ClusterIP** | Kubernetes | Virtual stable IP load-balanced across matching Pods via iptables/IPVS |
| **Ingress Controller**| Kubernetes L7 | Reverse proxy (Envoy, Nginx) routing HTTP traffic to Services |
