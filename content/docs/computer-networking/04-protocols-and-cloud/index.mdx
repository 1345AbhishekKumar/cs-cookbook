Welcome to **Stage 4: Protocols & Cloud Networking**. 

With physical media, local switching, and IP routing in place, we arrive at the heart of modern software engineering: how reliable byte streams, secure encryption, web protocols, and cloud-native container overlays operate.

---

## Pedagogical Philosophy

<Callout type="info" title="The Reliability & Scale Paradox">
The underlying Internet is fundamentally unreliable — optical cables can be severed, routers can drop packets under buffer bloat, and wireless signals fluctuate. Yet modern applications expect 99.999% reliability. Stage 4 reveals how TCP reconstructs reliable ordering, how TLS encrypts traffic over hostile public transit, and how Kubernetes orchestrates tens of thousands of container IP addresses seamlessly.
</Callout>

In this advanced stage, you will master:
* **Transport Reliability & Multiplexing:** TCP 3-way handshakes, sequence/acknowledgment numbers, sliding windows, congestion control algorithms (BBR/CUBIC), and low-latency UDP datagrams.
* **The Modern Web Stack:** Recursive DNS resolution, HTTP/1.1 vs HTTP/2 multiplexing vs HTTP/3 QUIC over UDP, SSH key exchange, and SMTP.
* **Planetary Routing & Crypto:** OSPF within enterprise autonomous systems, planetary BGP border peering, TLS 1.3 1-RTT cryptographic handshakes, and Anycast CDN distribution.
* **Cloud & Cloud-Native Infrastructure:** AWS/GCP Virtual Private Clouds (VPCs), subnets, Internet Gateways, stateful Security Groups, Linux network namespaces (`netns`), veth pairs, and Kubernetes CNI overlays.
